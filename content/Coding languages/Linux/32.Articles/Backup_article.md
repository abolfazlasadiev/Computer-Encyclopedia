# بکاپ و آرشیو

بکاپ یعنی از اطلاعاتت نسخهٔ پشتیبان داشته باشی تا اگر فایل‌ها حذف شدن، هارد خراب شد یا سیستم از دسترس خارج شد، بتونی اطلاعاتت رو برگردونی.

لینوکس ابزارهای قدرتمندی برای این کار داره و یکی از مهم‌ترین‌هاش **`rsync`** هست.

## قانون 3-2-1

یک روش استاندارد برای مدیریت بکاپ:

- **۳ نسخه** از داده‌ها داشته باش.
    
- روی **۲ نوع حافظهٔ متفاوت** ذخیره‌شون کن.
    
- **۱ نسخه** رو خارج از سیستم یا محل اصلی نگه دار.
    

## بکاپ با `rsync`

برای کپی کردن یک پوشه روی هارد یا USB:

```bash
rsync -avh --progress /home/user_name /media/usb-drive/Backup/
```

گزینه‌های مهم:

- `-a` → حالت Archive؛ حفظ ساختار، مجوزها و ویژگی‌های فایل‌ها
    
- `-v` → نمایش جزئیات عملیات
    
- `-h` → نمایش خواناتر اندازه‌ها
    
- `--progress` → نمایش روند انتقال
    

### انتقال از طریق SSH

برای گرفتن بکاپ از یک سیستم دیگر:

```bash
rsync -avz --progress root@192.168.1.1:/home/document/myImportantData ./target_location
```

در این حالت `rsync` اطلاعات را از طریق **SSH** منتقل می‌کند و در مسیر مقصد ذخیره می‌کند.

> **نکته:** بکاپ زمانی مفید است که واقعاً بتوانی آن را Restore کنی؛ بنابراین هر چند وقت یک‌بار صحت بکاپ‌ها را بررسی و بازیابی آزمایشی انجام بده.
