# بکاپ و ارشیو

تهیهٔ پشتیبان از داده‌ها مثل بیمه کردن اطلاعات است . از خدا میخوای هیچ وقت نیاز بهش نداشته باشی و وقتی دیسکت سوخت یا فایلات پرید اونوقت حالت جا میاد

- لینوکس قدرت فوق‌العاده‌ای برای بک‌گیری در اختیارتان می‌گذارد، اما در کنار این قدرت، تنوع ابزار هم زیاد است.
- یه قانون هست که میگه ۳ تا نسخه از اطلاعاتت داشته باش ؛‌ رو ۲ تا هارد مختلف ؛ و ۱ جا غیر از محل خودت
  با **rsync** شروع میکنیم :

```bash
  rsync -avh --progress /home/user_name /media/usb-drive/Backup/

```

- یا اگه ssh کردی :

```bash
rsync -avz --progress root@192.168.1.1:/home/document/myImportantData ./target_location
```
