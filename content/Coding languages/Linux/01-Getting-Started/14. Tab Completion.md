#  (تکمیل خودکار با Tab در لینوکس) - Tab Completion

---

## معرفی و مرور کلی

**تکمیل خودکار با Tab** (Tab Completion) یکی از قدرتمندترین، پرکاربردترین و زمان‌صرفه‌جویی‌ترین ویژگی‌های خط فرمان در لینوکس است. این قابلیت به شما اجازه می‌دهد با فشردن کلید **Tab** (برگه)، نام فایل‌ها، دایرکتوری‌ها، دستورات، گزینه‌ها و حتی متغیرهای محیطی را به صورت خودکار کامل کنید. این ویژگی نه تنها سرعت تایپ شما را به طور قابل توجهی افزایش می‌دهد، بلکه از اشتباهات تایپی و خطاهای ناشی از نام‌های طولانی و پیچیده جلوگیری می‌کند.

تکمیل خودکار با Tab، یکی از آن ویژگی‌هایی است که پس از مدتی استفاده، به یک عادت ضروری تبدیل می‌شود و کار با خط فرمان را بسیار لذت‌بخش‌تر و کارآمدتر می‌کند. در این مقاله جامع، به طور کامل تمام جنبه‌های این ویژگی حیاتی را بررسی می‌کنیم.

---

## ۱. تکمیل خودکار با Tab چیست و چرا اهمیت دارد؟

### ۱.۱. تعریف دقیق

**تکمیل خودکار با Tab** (Tab Completion) یا **اتوماتیک کامپلیشن** (Automatic Completion) یک ویژگی در شل‌های خط فرمان (مانند Bash، Zsh و Fish) است که با فشردن کلید Tab، به صورت هوشمندانه نام دستورات، فایل‌ها، دایرکتوری‌ها، گزینه‌ها و متغیرهای محیطی را بر اساس آنچه تا آن لحظه تایپ کرده‌اید، کامل می‌کند.

### ۱.۲. اهمیت و مزایا

**صرفه‌جویی در زمان**: با تایپ چند کاراکتر اول و فشردن Tab، می‌توانید نام‌های طولانی را در کسری از ثانیه کامل کنید.

**کاهش اشتباهات تایپی**: خطر تایپ اشتباه نام فایل‌ها، دستورات یا مسیرها را به شدت کاهش می‌دهد.

**کمک به یادگیری**: با مشاهده گزینه‌های پیشنهادی، با نام فایل‌ها و دستورات جدید آشنا می‌شوید.

**بازدهی بالاتر**: به ویژه هنگام کار با فایل‌ها و دایرکتوری‌هایی که نام‌های طولانی یا پیچیده دارند، بسیار مفید است.

**کشف قابلیت‌ها**: با دوبار فشردن Tab، می‌توانید لیست تمام گزینه‌های ممکن را مشاهده کنید.

## ۲. انواع تکمیل خودکار

### ۲.۱. تکمیل دستورات (Command Completion)

با تایپ چند حرف اول یک دستور و فشردن Tab، شل دستور را کامل می‌کند.

```bash
# مثال: تکمیل دستور
# تایپ کنید:
sys[Tab]

# نتیجه (در صورت وجود یک دستور با این پیشوند):
systemctl

# یا اگر چندین گزینه وجود داشته باشد:
systemd-analyze  systemd-cat  systemd-cgls  systemctl  ...
```

**مثال‌های بیشتر**:

```bash
# تایپ 'gre' و Tab
gre[Tab]   # کامل می‌شود به: grep

# تایپ 'pyt' و Tab
pyt[Tab]   # کامل می‌شود به: python3 (اگر نصب باشد)

# تایپ 'net' و Tab دو بار برای دیدن گزینه‌ها
net[Tab][Tab]  # نمایش: netcat  netplan  netstat  ...
```

### ۲.۲. تکمیل فایل‌ها و دایرکتوری‌ها (File/Directory Completion)

با تایپ بخشی از نام یک فایل یا دایرکتوری و فشردن Tab، شل نام آن را کامل می‌کند.

```bash
# مثال: تکمیل دایرکتوری
# تایپ کنید:
cd /ho[Tab]

# کامل می‌شود به:
cd /home/

# مثال: تکمیل فایل
# تایپ کنید:
cat /etc/hos[Tab]

# کامل می‌شود به:
cat /etc/hosts
```

**مثال‌های بیشتر**:

```bash
# تکمیل مسیرهای طولانی
cd /usr/local/[Tab][Tab]   # نمایش همه دایرکتوری‌های موجود در /usr/local/
cat /var/log/sys[Tab]      # کامل می‌شود به: /var/log/syslog
ls Do[Tab]                 # اگر دایرکتوری Documents وجود داشته باشد
```

### ۲.۳. تکمیل گزینه‌های دستورات (Option Completion)

در برخی شل‌های پیشرفته (مانند Zsh و Bash با پیکربندی مناسب)، با تایپ `-` یا `--` و فشردن Tab، گزینه‌های موجود برای آن دستور نمایش داده می‌شوند.

```bash
# تکمیل گزینه‌ها در Bash (با پیکربندی)
ls --[Tab][Tab]   # نمایش گزینه‌های موجود: --all --almost-all --help ...
grep -[Tab]       # نمایش گزینه‌های grep: -A -B -C -c ...
```

**نکته**: این قابلیت در Bash به صورت پیش‌فرض فعال نیست و نیاز به نصب بسته `bash-completion` دارد.

### ۲.۴. تکمیل متغیرهای محیطی (Variable Completion)

با تایپ `$` و بخشی از نام یک متغیر محیطی و فشردن Tab، نام متغیر کامل می‌شود.

```bash
# مثال:
echo $HO[Tab]   # کامل می‌شود به: echo $HOME
echo $P[Tab]    # کامل می‌شود به: echo $PATH (اگر تنها گزینه باشد)
```

### ۲.۵. تکمیل نام‌های کاربری (Username Completion)

با تایپ `~` و بخشی از نام یک کاربر و فشردن Tab، نام کاربر کامل می‌شود.

```bash
# مثال:
cd ~ro[Tab]   # کامل می‌شود به: cd ~root (اگر کاربر root وجود داشته باشد)
cd ~am[Tab]   # کامل می‌شود به: cd ~amir (اگر کاربر amir وجود داشته باشد)
```

### ۲.۶. تکمیل نام‌های هاست (Hostname Completion)

در برخی شل‌ها، با تایپ `@` و بخشی از نام یک هاست (از فایل `~/.ssh/known_hosts` یا `/etc/hosts`)، نام کامل می‌شود.

```bash
# مثال (در Zsh با پیکربندی):
ssh user@my[Tab]   # کامل می‌شود به: ssh user@myserver
```

## ۳. نحوه استفاده از Tab Completion

### ۳.۱. تکمیل کامل

اگر فقط یک گزینه ممکن وجود داشته باشد، با یک بار فشردن Tab، نام کامل می‌شود.

```bash
# مثال: فقط یک فایل با پسوند .txt در دایرکتوری فعلی وجود دارد
cat re[Tab]   # کامل می‌شود به: cat report.txt
```

### ۳.۲. نمایش گزینه‌ها (دو بار Tab)

اگر بیش از یک گزینه ممکن وجود داشته باشد، با **دوبار** فشردن Tab، لیست تمام گزینه‌های ممکن نمایش داده می‌شود.

```bash
# مثال: چندین فایل با پسوند .txt
ls re[Tab][Tab]
# نمایش:
# readme.txt  report.txt  resume.txt
```

### ۳.۳. تکمیل با پیشوند مشترک

اگر چندین گزینه وجود داشته باشند اما همه آنها یک پیشوند مشترک داشته باشند، با یک بار فشردن Tab، تا جایی که ممکن است کامل می‌شود و سپس می‌توانید دوباره Tab بزنید تا گزینه‌ها را ببینید.

```bash
# مثال: فایل‌های project_1.txt، project_2.txt، project_3.txt
ls proj[Tab]   # کامل می‌شود به: ls project_
# سپس با تایپ 1 و Tab: project_1.txt
```

### ۳.۴. تکمیل در مسیرهای طولانی

می‌توانید از Tab Completion در هر بخش از یک مسیر استفاده کنید.

```bash
# مثال:
cd /usr/local/[Tab]share[Tab]doc[Tab]
# گام‌ها:
# 1. cd /usr/local/[Tab] → /usr/local/share/
# 2. /usr/local/share/do[Tab] → /usr/local/share/doc/
# 3. /usr/local/share/doc/[Tab] → نمایش محتویات doc
```

## ۴. سفارشی‌سازی و بهینه‌سازی Tab Completion

### ۴.۱. فعال‌سازی bash-completion

در بسیاری از توزیع‌ها، `bash-completion` به صورت پیش‌فرض نصب نیست. برای نصب و فعال‌سازی آن:

```bash
# در توزیع‌های مبتنی بر دبیان/اوبونتو
sudo apt install bash-completion

# در توزیع‌های مبتنی بر رد هت/فدورا
sudo dnf install bash-completion

# در توزیع‌های مبتنی بر آرچ
sudo pacman -S bash-completion
```

پس از نصب، خطوط زیر را به `~/.bashrc` اضافه کنید:

```bash
# فعال‌سازی bash-completion
if [ -f /usr/share/bash-completion/bash_completion ]; then
    . /usr/share/bash-completion/bash_completion
fi
```

### ۴.۲. تنظیم رفتار Tab Completion

می‌توانید رفتار Tab Completion را با متغیرهای محیطی تنظیم کنید:

```bash
# نمایش گزینه‌ها با یک بار Tab (در Bash)
set show-all-if-ambiguous on

# حساسیت به بزرگ/کوچکی در تکمیل
set completion-ignore-case on

# تعداد گزینه‌های نمایش داده شده
set completion-query-items 100
```

این تنظیمات را می‌توانید به `~/.inputrc` اضافه کنید.

### ۴.۳. ایجاد تکمیل اختصاصی برای دستورات خاص

می‌توانید برای دستورات سفارشی خود، تکمیل خودکار تعریف کنید:

```bash
# مثال: تکمیل برای یک دستور سفارشی به نام mycmd
_mycmd_completion() {
    local cur prev opts
    COMPREPLY=()
    cur="${COMP_WORDS[COMP_CWORD]}"
    prev="${COMP_WORDS[COMP_CWORD-1]}"
    opts="start stop restart status help"

    COMPREPLY=( $(compgen -W "${opts}" -- ${cur}) )
    return 0
}
complete -F _mycmd_completion mycmd
```

### ۴.۴. تکمیل در Zsh

Zsh به صورت پیش‌فرض قابلیت تکمیل پیشرفته‌تری دارد:

```bash
# فعال‌سازی تکمیل پیشرفته در Zsh
autoload -Uz compinit
compinit

# فعال‌سازی تکمیل گزینه‌ها
setopt complete_aliases
```

## ۵. خطاهای رایج و راه‌حل‌ها

### ۵.۱. تکمیل کار نمی‌کند

```bash
# مشکل: Tab Completion کار نمی‌کند

# راه‌حل 1: بررسی نصب bash-completion
dpkg -l | grep bash-completion   # دبیان/اوبونتو
rpm -qa | grep bash-completion   # فدورا/رد هت

# راه‌حل 2: بارگذاری مجدد پیکربندی
source ~/.bashrc

# راه‌حل 3: بررسی مجوزهای فایل‌ها
ls -la /usr/share/bash-completion/
```

### ۵.۲. تکمیل گزینه‌ها کار نمی‌کند

```bash
# مشکل: با تایپ - و Tab، گزینه‌ها نمایش داده نمی‌شوند

# راه‌حل: نصب و فعال‌سازی bash-completion
sudo apt install bash-completion   # یا دستور مناسب توزیع
source ~/.bashrc
```

### ۵.۳. تکمیل بسیار کند است

```bash
# مشکل: Tab Completion کند کار می‌کند

# راه‌حل 1: افزایش محدودیت تعداد گزینه‌ها
set completion-query-items 100  # در ~/.inputrc

# راه‌حل 2: غیرفعال‌سازی تکمیل برای برخی دایرکتوری‌ها
# می‌توانید از متغیر FIGNORE استفاده کنید
export FIGNORE=".o:.pyc:.swp"
```

### ۵.۴. تکمیل نام فایل‌ها با فاصله

```bash
# مشکل: فایل‌هایی با فاصله در نام به درستی تکمیل نمی‌شوند

# راه‌حل: استفاده از کاراکتر فرار
# اگر فایلی به نام "My Documents" دارید
ls My\ Doc[Tab]   # کامل می‌شود به: ls My\ Documents/
# یا با نقل‌قول:
ls "My Doc"[Tab]  # کامل می‌شود به: ls "My Documents"/
```

## ۶. تمرین‌های عملی

### ۶.۱. تمرین پایه

```bash
# 1. تکمیل دستورات
# تایپ کنید و Tab بزنید:
sys[Tab]
gre[Tab]
pyt[Tab]
hist[Tab]

# 2. تکمیل فایل‌ها و دایرکتوری‌ها
# ابتدا چند فایل و دایرکتوری ایجاد کنید
mkdir -p practice/{docs,src,backup}
touch practice/docs/report.txt
touch practice/src/main.py
touch practice/README.md

# 3. تکمیل مسیرها
cd prac[Tab]
cd docs/[Tab]
cat READ[Tab]
ls bac[Tab]

# 4. تکمیل با چندین گزینه
cd /usr/[Tab][Tab]   # نمایش همه دایرکتوری‌های /usr
ls /etc/[Tab][Tab]   # نمایش همه فایل‌های /etc
```

### ۶.۲. تمرین پیشرفته

```bash
# 1. ایجاد یک ساختار پیچیده
mkdir -p project/{src/{main,test},docs,bin}
touch project/src/main/app.py
touch project/src/test/test_app.py
touch project/README.md
touch project/docs/guide.txt

# 2. تکمیل مسیرهای طولانی
cat pro[Tab]src[Tab]main[Tab]app[Tab]   # تکمیل کامل
cat pro[Tab]/src[Tab]/test[Tab]/test_[Tab]   # تکمیل در مسیر

# 3. تکمیل با فایل‌های مشابه
touch project/data_{1,2,3,4,5}.csv
ls project/data_[Tab][Tab]   # نمایش data_1.csv data_2.csv ...

# 4. تکمیل دستورات با گزینه‌ها (در صورت پشتیبانی)
ls --[Tab][Tab]   # نمایش گزینه‌ها
grep -[Tab]       # نمایش گزینه‌ها
```

### ۶.۳. تمرین با متغیرها

```bash
# 1. تکمیل متغیرهای محیطی
echo $HO[Tab]     # کامل می‌شود به: echo $HOME
echo $PA[Tab]     # کامل می‌شود به: echo $PATH
echo $SE[Tab]     # کامل می‌شود به: echo $SHELL

# 2. تکمیل نام‌های کاربری
cd ~ro[Tab]       # کامل می‌شود به: cd ~root (اگر دسترسی داشته باشید)
```

## ۸. خلاصه و نتیجه‌گیری

### ۸.۱. نکات کلیدی

- **Tab Completion** یکی از مهم‌ترین ویژگی‌های خط فرمان لینوکس است.
- با **یک بار** Tab، اگر تنها یک گزینه وجود داشته باشد، کامل می‌شود.
- با **دو بار** Tab، لیست تمام گزینه‌های ممکن نمایش داده می‌شود.
- Tab Completion در **انواع مختلف** شامل دستورات، فایل‌ها، گزینه‌ها، متغیرها و نام‌های کاربری کار می‌کند.
- برای تکمیل گزینه‌ها، باید `bash-completion` نصب و فعال باشد.

### ۸.۲. عادات مفید

```bash
# 1. همیشه از Tab برای تکمیل مسیرها استفاده کنید
cd /usr/local/[Tab]   # به جای تایپ کامل

# 2. برای دیدن گزینه‌ها، دو بار Tab بزنید
ls [Tab][Tab]         # نمایش همه فایل‌ها و دایرکتوری‌ها

# 3. در مسیرهای طولانی، بخش‌بخش از Tab استفاده کنید
cd /ho[Tab]/am[Tab]/Do[Tab]

# 4. برای تکمیل دستورات، چند حرف اول را تایپ کنید
sys[Tab]   # به جای systemctl
```

## سؤالات متداول

**سؤال: چرا Tab Completion من کار نمی‌کند؟**  
ممکن است `bash-completion` نصب نباشد. با دستور مناسب توزیع خود، آن را نصب کنید.

**سؤال: چگونه گزینه‌های یک دستور را با Tab ببینم؟**  
با تایپ `-` یا `--` و فشردن دو بار Tab (در صورت فعال بودن bash-completion).

**سؤال: آیا Tab Completion در همه شل‌ها یکسان است؟**  
خیر، Zsh و Fish قابلیت‌های پیشرفته‌تری نسبت به Bash دارند.

**سؤال: چگونه تکمیل گزینه‌ها را در Bash فعال کنم؟**  
با نصب `bash-completion` و افزودن خطوط مربوطه به `~/.bashrc`.

**سؤال: آیا می‌توانم تکمیل خودکار برای دستورات خودم تعریف کنم؟**  
بله، با استفاده از دستور `complete` و تعریف یک تابع تکمیل.

**سؤال: چگونه تکمیل فایل‌ها را با فاصله در نام انجام دهم؟**  
با استفاده از کاراکتر فرار (`\`) یا نقل‌قول (`" "`).

## مفاهیم مرتبط

- **شل (Shell)**: محیط اجرای دستورات (Bash، Zsh، Fish)
- **بش (Bash)**: محبوب‌ترین شل در لینوکس
- **تکمیل خودکار (Auto-completion)**: تکمیل خودکار متن
- **تاریخچه دستورات (Command History)**: ذخیره و بازیابی دستورات قبلی
- **کلید Tab**: کلید برگه روی صفحه‌کلید
