# (ترمینال در لینوکس) - Terminal

---

## معرفی و مرور کلی

**ترمینال** (Terminal) یا **Command-Line Interface (CLI)**، یک رابط متنی برای ارتباط با سیستم‌عامل لینوکس است که به کاربران اجازه می‌دهد تا با تایپ دستورات، وظایف مختلفی را انجام دهند. این محیط که اغلب با نام‌های **کنسول** (Console) یا **شل** (Shell) نیز شناخته می‌شود، برخلاف رابط‌های گرافیکی (GUI)، نیازی به موس ندارد و تمام تعاملات از طریق صفحه‌کلید انجام می‌شود.

در حالی که محیط‌های دسکتاپ مدرن مانند GNOME یا KDE تجربه‌ای بصری و گرافیکی ارائه می‌دهند، ترمینال همچنان یکی از قدرتمندترین و ضروری‌ترین ابزارها در لینوکس محسوب می‌شود. بسیاری از کاربران حرفه‌ای، مدیران سیستم و توسعه‌دهندگان، ترمینال را به دلیل **سرعت بالا، قابلیت اسکریپت‌نویسی، دسترسی کامل به سیستم و امکان خودکارسازی وظایف** ترجیح می‌دهند.

---

## ۱. ترمینال چیست و چه تفاوتی با شل دارد؟

برای درک صحیح، باید تفاوت بین **ترمینال** و **شل** را بدانیم:

| مفهوم | توضیحات |
|-------|----------|
| **ترمینال (Terminal)** | یک **برنامه گرافیکی** (یا سخت‌افزاری در گذشته) است که یک پنجره برای ورود و خروجی متن فراهم می‌کند. ترمینال خودش دستورات را اجرا نمی‌کند؛ بلکه آنها را به شل ارسال می‌کند و خروجی را نمایش می‌دهد. |
| **شل (Shell)** | یک **مفسر خط فرمان** است که دستورات را دریافت، تفسیر و اجرا می‌کند. شل در واقع مغز اصلی ترمینال است. محبوب‌ترین شل در لینوکس، **Bash** (Bourne Again SHell) است. |

به عبارت ساده‌تر، ترمینال **پنجره** است و شل **موتور** اجرای دستورات درون آن.

---

## ۲. چرا از ترمینال استفاده کنیم؟

دلایل متعددی برای یادگیری و استفاده از ترمینال وجود دارد:

- **سرعت بیشتر**: بسیاری از کارها با چند دستور ساده در کسری از ثانیه انجام می‌شوند در حالی که در محیط گرافیکی可能需要 چندین کلیک و جستجو.
- **دسترسی کامل به سیستم**: ترمینال دسترسی به تمام بخش‌های سیستم را فراهم می‌کند، حتی بخش‌هایی که در رابط‌های گرافیکی قابل مشاهده نیستند.
- **خودکارسازی (Automation)**: با نوشتن اسکریپت‌های ساده (Bash Scripts)، می‌توانید وظایف تکراری را به طور کامل خودکار کنید.
- **مدیریت از راه دور**: برای مدیریت سرورها از طریق SSH، تنها راه ممکن استفاده از ترمینال است، زیرا سرورها معمولاً فاقد محیط گرافیکی هستند.
- **عیب‌یابی پیشرفته**: بسیاری از مشکلات سیستم (مانند خطاهای بوت، مشکلات شبکه یا خرابی سرویس‌ها) فقط از طریق ترمینال قابل تشخیص و رفع هستند.
- **حرفه‌ای‌گری**: تسلط بر ترمینال یک مهارت ضروری برای هر متخصص فناوری اطلاعات، توسعه‌دهنده و مدیر سیستم محسوب می‌شود.

## ۳. ساختار ترمینال و پرامپت (Prompt)

هنگامی که ترمینال را باز می‌کنید، با یک **پرامپت** (Prompt) مواجه می‌شوید که آمادگی سیستم برای دریافت دستور را نشان می‌دهد.

ساختار استاندارد پرامپت به این شکل است:

```text
[USERNAME]@[HOSTNAME]:[CURRENT_PATH][SYMBOL]
```

| بخش | توضیحات |
|-----|----------|
| **USERNAME** | نام کاربری فعلی (مثلاً `amir`) |
| **HOSTNAME** | نام کامپیوتر (مثلاً `my-laptop`) |
| **CURRENT_PATH** | مسیر دایرکتوری فعلی (برای خانه، علامت `~` نشان داده می‌شود) |
| **SYMBOL** | `$` برای کاربر عادی و `#` برای کاربر ریشه (root) |

**مثال**:

```text
amir@my-laptop:~$ cd /etc
amir@my-laptop:/etc$
```

در این مثال، کاربر `amir` روی کامپیوتر `my-laptop` است و در دایرکتوری خانه (`~`) قرار دارد (`$` نشان‌دهنده کاربر عادی است). پس از اجرای دستور `cd /etc`، مسیر به `/etc` تغییر کرده است.

## ۴. نحوه باز کردن ترمینال

بسته به توزیع و محیط دسکتاپ، روش‌های مختلفی برای باز کردن ترمینال وجود دارد:

- **میانبر صفحه‌کلید (رایج‌ترین)**: **`Ctrl + Alt + T`** در اکثر توزیع‌ها.
- **از منوی برنامه‌ها**: معمولاً در بخش **System Tools**، **Utilities** یا **Accessories** با نام **Terminal**، **Konsole**، **GNOME Terminal** یا **XTerm**.
- **کلیک راست روی دسکتاپ**: در برخی محیط‌ها (مانند GNOME)، گزینه **Open in Terminal** وجود دارد.
- **از طریق منوی زمینه فایل‌منیجر**: در بسیاری از مدیران فایل، با کلیک راست و انتخاب **Open in Terminal**، ترمینال در همان دایرکتوری باز می‌شود.

## ۵. میانبرهای کلیدی ضروری ترمینال

برای کار سریع‌تر با ترمینال، آشنایی با میانبرهای کلیدی ضروری است:

| میانبر | عملکرد |
|--------|---------|
| **Ctrl + A** | حرکت به ابتدای خط |
| **Ctrl + E** | حرکت به انتهای خط |
| **Ctrl + U** | حذف از موقعیت مکان‌نما تا ابتدای خط |
| **Ctrl + K** | حذف از موقعیت مکان‌نما تا انتهای خط |
| **Ctrl + W** | حذف یک کلمه قبل از مکان‌نما |
| **Ctrl + L** | پاک کردن صفحه ترمینال (معادل دستور `clear`) |
| **Ctrl + R** | جستجوی معکوس در تاریخچه دستورات (Reverse Search) |
| **Ctrl + C** | متوقف کردن دستور در حال اجرا (Kill) |
| **Ctrl + Z** | متوقف کردن دستور در حال اجرا (Suspend) و قرار دادن آن در پس‌زمینه |
| **Ctrl + D** | بستن ترمینال (در صورت خالی بودن خط) |
| **Ctrl + Shift + C** | کپی متن از ترمینال |
| **Ctrl + Shift + V** | چسباندن متن در ترمینال |
| **Tab** | تکمیل خودکار نام فایل‌ها، دایرکتوری‌ها و دستورات |
| **فلش بالا/پایین** | مرور تاریخچه دستورات |

## ۶. دستورات پایه و ضروری ترمینال

### ۶.۱. دستورات اطلاعاتی

```bash
whoami          # نمایش نام کاربر فعلی
hostname        # نمایش نام کامپیوتر
pwd             # نمایش مسیر دایرکتوری فعلی (Print Working Directory)
date            # نمایش تاریخ و زمان فعلی
uname -a        # نمایش اطلاعات کامل سیستم (هسته، معماری و ...)
```

### ۶.۲. دستورات مدیریت فایل و دایرکتوری

```bash
ls              # لیست محتویات دایرکتوری فعلی
ls -la          # لیست کامل با جزئیات و فایل‌های مخفی
ls -lh          # لیست با اندازه‌های قابل خواندن (Human-readable)

cd /path        # تغییر دایرکتوری به مسیر مشخص
cd ~            # رفتن به دایرکتوری خانه (Home)
cd ..           # رفتن به دایرکتوری والد (یک سطح بالاتر)
cd /            # رفتن به ریشه سیستم (Root)
cd -            # بازگشت به دایرکتوری قبلی

mkdir dirname   # ایجاد دایرکتوری جدید
mkdir -p a/b/c  # ایجاد دایرکتوری‌های تو در تو (در صورت عدم وجود، ساخته می‌شوند)

touch file.txt  # ایجاد فایل خالی یا به‌روزرسانی زمان آخرین تغییر

cp file1 file2  # کپی فایل
cp -r dir1 dir2 # کپی دایرکتوری به صورت بازگشتی (Recursive)

mv old.txt new.txt  # تغییر نام فایل
mv file.txt /path/  # انتقال فایل به مسیر دیگر

rm file.txt     # حذف فایل
rm -r dir/      # حذف دایرکتوری به صورت بازگشتی
rm -rf dir/     # حذف اجباری دایرکتوری (با احتیاط کامل!)

rmdir dir/      # حذف دایرکتوری خالی
```

### ۶.۳. دستورات مشاهده محتوای فایل

```bash
cat file.txt    # نمایش کامل محتوای فایل در ترمینال (مناسب برای فایل‌های کوچک)
less file.txt   # نمایش محتوای فایل صفحه به صفحه (با قابلیت جستجو)
head file.txt   # نمایش ۱۰ خط اول فایل (با `-n` می‌توان تعداد را تغییر داد)
tail file.txt   # نمایش ۱۰ خط آخر فایل (با `-f` می‌توان تغییرات لحظه‌ای را دنبال کرد)
wc file.txt     # شمارش خطوط، کلمات و کاراکترهای فایل
```

### ۶.۴. دستورات جستجو

```bash
grep "word" file.txt     # جستجوی کلمه در فایل
grep -r "word" /path/    # جستجوی بازگشتی در تمام فایل‌های یک دایرکتوری
grep -i "word" file.txt  # جستجوی بدون حساسیت به بزرگ/کوچکی حروف
grep -n "word" file.txt  # نمایش شماره خطوطی که شامل کلمه هستند

find . -name "*.txt"     # پیدا کردن فایل‌های با پسوند txt در دایرکتوری فعلی
find /etc -type f -size +10M  # پیدا کردن فایل‌های بزرگتر از ۱۰ مگابایت در /etc

which command   # نمایش مسیر کامل یک دستور (مثلاً which ls)
```

### ۶.۵. دستورات مدیریت فرآیندها و سیستم

```bash
ps aux          # نمایش تمام فرآیندهای در حال اجرا
top             # نمایش لحظه‌ای فرآیندها و مصرف منابع (واقع‌زمان)
htop            # نسخه بهبودیافته و تعاملی top (نیاز به نصب دارد)

kill PID        # خاتمه یک فرآیند با شناسه PID
kill -9 PID     # خاتمه اجباری فرآیند (SIGKILL)

df -h           # نمایش فضای دیسک به صورت قابل خواندن
du -sh /path/   # نمایش حجم اشغال شده توسط یک دایرکتوری

free -h         # نمایش مصرف حافظه (RAM و Swap) به صورت قابل خواندن
```

### ۶.۶. دستورات مدیریت بسته

```bash
# در توزیع‌های مبتنی بر دبیان/اوبونتو (APT)
sudo apt update         # به‌روزرسانی لیست بسته‌ها
sudo apt upgrade        # ارتقاء بسته‌های نصب شده
sudo apt install vim    # نصب بسته vim
sudo apt remove vim     # حذف بسته vim

# در توزیع‌های مبتنی بر رد هت/فدورا (DNF)
sudo dnf update         # به‌روزرسانی بسته‌ها
sudo dnf install vim    # نصب بسته vim

# در توزیع‌های مبتنی بر آرچ (Pacman)
sudo pacman -Syu        # به‌روزرسانی کامل سیستم
sudo pacman -S vim      # نصب بسته vim
```

### ۶.۷. دستورات تغییر مجوزها و مالکیت

```bash
chmod 755 script.sh     # تنظیم مجوزها به صورت اکتال (مالک: خواندن/نوشتن/اجرا، گروه و دیگران: خواندن/اجرا)
chmod u+x script.sh     # افزودن مجوز اجرا به مالک
chown user:group file   # تغییر مالک و گروه فایل
```

### ۶.۸. دستورات شبکه

```bash
ping google.com         # تست اتصال به سرور
curl ifconfig.me        # نمایش IP عمومی
ip a                    # نمایش اطلاعات شبکه (جایگزین ifconfig)
ss -tuln                # نمایش پورت‌های باز و سرویس‌های در حال گوش دادن (جایگزین netstat)
```

## ۷. مفاهیم پیشرفته‌تر

### ۷.۱. لوله‌ها (Pipes) و جهت‌دهی (Redirection)

**لوله** (`|`) خروجی یک دستور را به عنوان ورودی دستور دیگر ارسال می‌کند:

```bash
# پیدا کردن فرآیندهای مربوط به firefox
ps aux | grep firefox

# نمایش ۵ فایل آخرین تغییر یافته در دایرکتوری فعلی
ls -t | head -n 5
```

**جهت‌دهی خروجی** (`>`, `>>`):

```bash
echo "Hello" > file.txt    # ایجاد فایل و نوشتن (در صورت وجود، بازنویسی می‌کند)
echo "World" >> file.txt   # اضافه کردن به انتهای فایل
```

### ۷.۲. تاریخچه دستورات

```bash
history          # نمایش تمام دستورات قبلی
!!               # اجرای آخرین دستور
!100             # اجرای دستور شماره ۱۰۰ از تاریخچه
Ctrl + R         # جستجوی تعاملی در تاریخچه (محبوب‌ترین روش)
```

### ۷.۳. سیستم راهنما (Help System)

```bash
man command      # نمایش صفحه راهنمای کامل یک دستور (Manual Pages)
command --help   # نمایش خلاصه راهنما (در اکثر دستورات)
whatis command   # نمایش توضیح یک خطی از دستور
```

**نکته**: دستور `man` یکی از مهم‌ترین ابزارها برای یادگیری است. برای مثال، `man ls` تمام گزینه‌های دستور `ls` را به طور کامل توضیح می‌دهد. در داخل `man` می‌توانید با `/` جستجو کنید و با `q` خارج شوید.

### ۷.۴. متغیرهای محیطی (Environment Variables)

```bash
echo $PATH       # نمایش مسیرهای جستجوی دستورات
echo $HOME       # نمایش مسیر دایرکتوری خانه
export MYVAR="Hello"  # تعریف یک متغیر محیطی جدید
```

## ۸. جمع‌بندی و نتیجه‌گیری

ترمینال در لینوکس یک ابزار قدرتمند، ضروری و اجتناب‌ناپذیر است که به شما امکان می‌دهد:

- سیستم را با سرعت و کارایی بالا مدیریت کنید
- وظایف تکراری را خودکار کنید
- مشکلات را به صورت پیشرفته عیب‌یابی کنید
- سرورها را از راه دور مدیریت کنید
- کنترل کامل بر سیستم داشته باشید

یادگیری ترمینال ممکن است در ابتدا دشوار به نظر برسد، اما با تمرین روزانه و استفاده از دستورات پایه، به سرعت به آن مسلط خواهید شد. شروع کار با دستورات ساده مانند `ls`، `cd`، `pwd` و `mkdir` می‌تواند نقطه شروعی عالی برای ورود به دنیای قدرتمند خط فرمان لینوکس باشد.

## سؤالات متداول

**سؤال: تفاوت ترمینال و کنسول چیست؟**  
در گذشته، **کنسول** به سخت‌افزار فیزیکی (صفحه‌نمایش و صفحه‌کلید متصل به کامپیوتر) گفته می‌شد، در حالی که **ترمینال** به دستگاه‌های از راه دور اشاره داشت. امروزه این دو اصطلاح تقریباً به جای یکدیگر استفاده می‌شوند.

**سؤال: آیا می‌توانم بدون ترمینال از لینوکس استفاده کنم؟**  
بله، کاربران عادی می‌توانند تمام کارهای روزمره خود را از طریق محیط گرافیکی انجام دهند. اما در بسیاری از موارد (مانند عیب‌یابی پیشرفته یا مدیریت سرور)، ترمینال ضروری است.

**سؤال: چگونه ظاهر ترمینال را تغییر دهم؟**  
اکثر ترمینال‌ها امکان تغییر فونت، رنگ پس‌زمینه، شفافیت (Transparency) و تم را از طریق تنظیمات (Preferences) فراهم می‌کنند.

## مفاهیم مرتبط

- **شل (Shell)**: مفسر دستورات ترمینال (مانند Bash، Zsh، Fish).
- **Bash Scripting**: نوشتن اسکریپت‌های خودکار با استفاده از دستورات ترمینال.
- **SSH**: اتصال امن به ترمینال سرورها از راه دور.
- **Manager**: اجرای دستورات با سطح دسترسی مدیر (سوپرکاربر).
- **Terminal Emulator**: برنامه‌های مختلفی که ترمینال را شبیه‌سازی می‌کنند (GNOME Terminal، Konsole، Tilix).
