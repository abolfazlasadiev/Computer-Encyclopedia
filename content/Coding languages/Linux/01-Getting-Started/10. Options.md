#  (گزینه‌ها در لینوکس) - Options

---

## معرفی و مرور کلی

**گزینه‌ها** (Options) یا **پرچم‌ها** (Flags) یا **سوئیچ‌ها** (Switches) در خط فرمان لینوکس، پارامترهایی هستند که به یک دستور داده می‌شوند تا **رفتار پیش‌فرض** آن را تغییر دهند. اگر دستورات را به عنوان **افعال** و آرگومان‌ها را به عنوان **مفعول‌ها** در نظر بگیریم، گزینه‌ها **قیدهای** آن فعل هستند که نحوه و چگونگی انجام عمل را مشخص می‌کنند.

گزینه‌ها یکی از قدرتمندترین ابزارهای لینوکس هستند و به شما امکان می‌دهند تا دستورات را دقیقاً مطابق با نیاز خود سفارشی‌سازی کنید. بدون گزینه‌ها، بسیاری از دستورات فقط رفتار پایه‌ای خود را انجام می‌دهند و شما از بسیاری از قابلیت‌های پیشرفته آنها بی‌بهره خواهید ماند.

---

## ۱. گزینه چیست و چه تفاوتی با آرگومان دارد؟

### ۱.۱. تعریف دقیق

**گزینه** (Option) یک پارامتر اختیاری است که به یک دستور داده می‌شود تا نحوه عملکرد آن را تغییر دهد. گزینه‌ها معمولاً با یک یا دو خط تیره (`-` یا `--`) شروع می‌شوند.

### ۱.۲. تفاوت گزینه و آرگومان

| ویژگی | گزینه (Option) | آرگومان (Argument) |
|-------|----------------|-------------------|
| **نقش** | تغییر رفتار دستور | مشخص کردن هدف یا داده دستور |
| **نشانه** | معمولاً با `-` یا `--` شروع می‌شود | بدون خط تیره نوشته می‌شود |
| **اختیاری/اجباری** | معمولاً اختیاری | گاهی اجباری |
| **تأثیر** | بر **چگونگی** اجرا تأثیر می‌گذارد | بر **چه چیزی** اجرا می‌شود تأثیر می‌گذارد |
| **ترتیب** | معمولاً قبل از آرگومان‌ها | معمولاً بعد از گزینه‌ها |

### ۱.۳. مثال ساده

```bash
ls -l /home
# command: ls
# گزینه: -l (نمایش جزئیات)
# آرگومان: /home (مسیر هدف)
```

```bash
grep -i "error" log.txt
# command: grep
# گزینه: -i (جستجوی بدون حساسیت به بزرگ/کوچکی)
# آرگومان‌ها: "error" (الگو) و log.txt (فایل هدف)
```

## ۲. انواع گزینه‌ها در لینوکس

### ۲.۱. گزینه‌های کوتاه (Short Options)

**ویژگی‌ها**:
- با یک خط تیره (`-`) شروع می‌شوند
- معمولاً یک حرف هستند
- می‌توانند به هم متصل شوند (مثلاً `-la` معادل `-l -a` است)
- سریع‌ترین نوع برای تایپ

**مثال‌ها**:

```bash
ls -l          # نمایش جزئیات
ls -a          # نمایش فایل‌های مخفی
ls -la         # ترکیبی از -l و -a
ls -lh         # ترکیبی از -l و -h (اندازه‌های قابل خواندن)

grep -i        # جستجوی بدون حساسیت به بزرگ/کوچکی
grep -r        # جستجوی بازگشتی
grep -ri       # ترکیبی از -r و -i

rm -r          # حذف بازگشتی
rm -f          # حذف اجباری
rm -rf         # ترکیبی از -r و -f
```

### ۲.۲. گزینه‌های بلند (Long Options)

**ویژگی‌ها**:
- با دو خط تیره (`--`) شروع می‌شوند
- معمولاً یک کلمه کامل هستند
- خوانایی بیشتری دارند
- معمولاً در اسکریپت‌ها استفاده می‌شوند

**مثال‌ها**:

```bash
ls --all          # معادل ls -a
ls --help         # نمایش راهنما
ls --recursive    # نمایش بازگشتی

grep --recursive     # معادل grep -r
grep --ignore-case   # معادل grep -i

rm --recursive    # معادل rm -r
rm --force        # معادل rm -f
```

### ۲.۳. گزینه‌های با مقدار (Options with Arguments)

برخی گزینه‌ها نیاز به دریافت یک مقدار اضافی دارند.

**مثال‌ها**:

```bash
# گزینه -c نیاز به تعداد پینگ دارد
ping -c 4 google.com

# گزینه -n نیاز به تعداد خطوط دارد
head -n 20 file.txt

# گزینه --output نیاز به نام فایل خروجی دارد
grep --output=result.txt "error" log.txt

# گزینه -p نیاز به یک پورت دارد
ssh -p 2222 user@server.com

# گزینه -f نیاز به نام فایل دارد
tar -f archive.tar
```

**نکته**: در گزینه‌های با مقدار، می‌توانید از فاصله یا علامت مساوی (`=`) استفاده کنید:

```bash
# هر دو شکل زیر معادل هستند
head -n 20 file.txt
head -n20 file.txt
grep --output=result.txt log.txt
grep --output result.txt log.txt  # در برخی دستورات کار می‌کند
```

### ۲.۴. گزینه‌های ترکیبی (Combined Options)

گزینه‌های کوتاه را می‌توانید به هم متصل کنید:

```bash
# این سه دستور معادل هستند
ls -l -a
ls -la
ls -al

# این دو دستور معادل هستند
grep -r -i -n
grep -rin
```

**نکته**: گزینه‌های با مقدار را نمی‌توانید با گزینه‌های دیگر ترکیب کنید:

```bash
# اشتباه ❌
head -n20 -v file.txt  # درست است
head -n20v file.txt    # اشتباه است (v به عنوان مقدار -n در نظر گرفته می‌شود)
```

### ۲.۵. گزینه‌های پایان‌دهنده (End of Options - `--`)

علامت `--` به معنای "پایان گزینه‌ها" است. هر چیزی بعد از آن، به عنوان آرگومان در نظر گرفته می‌شود، حتی اگر با `-` شروع شود.

**کاربردها**:
- زمانی که نام فایلی با `-` شروع می‌شود
- زمانی که می‌خواهید یک آرگومان منفی را به دستور بدهید

**مثال**:

```bash
# ایجاد فایل با نام -file.txt
touch -- -file.txt

# حذف فایل با نام -file.txt
rm -- -file.txt

# جستجوی کلمه "-v" در یک فایل
grep -- -v file.txt
```

## ۴. گزینه‌ها در اسکریپت‌نویسی

### ۴.۱. پردازش گزینه‌ها با `getopts`

`getopts` یک ابزار داخلی در Bash برای پردازش گزینه‌های خط فرمان در اسکریپت‌ها است.

**ساختار اولیه**:

```bash
while getopts ":abc:d:" opt; do
    case $opt in
        a) echo "Option -a was triggered" ;;
        b) echo "Option -b was triggered" ;;
        c) echo "Option -c was triggered with value: $OPTARG" ;;
        d) echo "Option -d was triggered with value: $OPTARG" ;;
        \?) echo "Invalid option: -$OPTARG" ;;
        :) echo "Option -$OPTARG requires an argument" ;;
    esac
done
```

**توضیحات**:

- `a` و `b` گزینه‌های بدون مقدار هستند
- `c:` و `d:` گزینه‌های با مقدار هستند (علامت `:` نشان‌دهنده نیاز به مقدار است)
- `OPTARG` متغیری است که مقدار گزینه را نگه می‌دارد
- `\?` برای گزینه‌های نامعتبر
- `:` برای گزینه‌هایی که مقدار آنها وارد نشده است

### ۴.۲. مثال اسکریپت کامل

**فایل `script.sh`**:

```bash
#!/bin/bash

# تنظیم متغیرهای پیش‌فرض
verbose=0
output_file="output.txt"
input_file=""

# پردازش گزینه‌ها
while getopts ":vo:i:h" opt; do
    case $opt in
        v)
            verbose=1
            echo "Verbose mode enabled"
            ;;
        o)
            output_file="$OPTARG"
            echo "Output file: $output_file"
            ;;
        i)
            input_file="$OPTARG"
            echo "Input file: $input_file"
            ;;
        h)
            echo "Usage: $0 [-v] [-o output_file] [-i input_file]"
            exit 0
            ;;
        \?)
            echo "Invalid option: -$OPTARG"
            echo "Use -h for help"
            exit 1
            ;;
        :)
            echo "Option -$OPTARG requires an argument"
            exit 1
            ;;
    esac
done

# حذف گزینه‌ها از لیست آرگومان‌ها
shift $((OPTIND-1))

# اگر فایل ورودی مشخص نشده، از آرگومان‌های باقی‌مانده استفاده کن
if [ -z "$input_file" ]; then
    input_file="$1"
fi

# اجرای عملیات اصلی
if [ -n "$input_file" ]; then
    if [ $verbose -eq 1 ]; then
        echo "Processing file: $input_file"
    fi
    cat "$input_file" > "$output_file"
    if [ $verbose -eq 1 ]; then
        echo "File copied to: $output_file"
    fi
else
    echo "No input file specified. Use -h for help."
    exit 1
fi
```

**اجرا**:

```bash
# نمایش راهنما
./script.sh -h

# اجرا با گزینه‌ها
./script.sh -v -o result.txt -i data.txt

# اجرا با آرگومان معمولی
./script.sh -v data.txt
```

### ۴.۳. گزینه‌های بلند با `getopt`

`getopt` نسخه پیشرفته‌تری است که از گزینه‌های بلند پشتیبانی می‌کند.

```bash
#!/bin/bash

# تنظیم گزینه‌های بلند
args=$(getopt -o "vho:i:" -l "verbose,help,output:,input:" -n "script.sh" -- "$@")

# ارزیابی خروجی
eval set -- "$args"

while true; do
    case "$1" in
        -v|--verbose)
            verbose=1
            shift
            ;;
        -h|--help)
            echo "Usage: $0 [-v|--verbose] [-o|--output file] [-i|--input file]"
            exit 0
            ;;
        -o|--output)
            output_file="$2"
            shift 2
            ;;
        -i|--input)
            input_file="$2"
            shift 2
            ;;
        --)
            shift
            break
            ;;
        *)
            echo "Internal error!"
            exit 1
            ;;
    esac
done
```

## ۵. خطاهای رایج در گزینه‌ها

### ۵.۱. گزینه نامعتبر

```bash
# اشتباه ❌
ls -z

# خروجی: ls: invalid option -- 'z'

# درست ✅
ls -la
```

### ۵.۲. فراموش کردن مقدار گزینه

```bash
# اشتباه ❌
ping -c

# خروجی: ping: option requires an argument -- 'c'

# درست ✅
ping -c 4 google.com
```

### ۵.۳. اشتباه در حروف بزرگ و کوچک

```bash
# اشتباه ❌ (بسیاری از دستورات به حروف بزرگ/کوچک حساس هستند)
ls -L

# درست ✅
ls -l
```

### ۵.۴. استفاده از گزینه با مقدار و ترکیب آن با گزینه‌های دیگر

```bash
# اشتباه ❌
head -n20v file.txt   # v به عنوان مقدار -n در نظر گرفته می‌شود

# درست ✅
head -n 20 -v file.txt
head -n20 -v file.txt
```

### ۵.۵. استفاده نادرست از گزینه‌های بلند

```bash
# اشتباه ❌
ls -all

# درست ✅
ls --all
```

## ۶. جمع‌بندی و نتیجه‌گیری

گزینه‌ها در خط فرمان لینوکس، ابزاری قدرتمند برای سفارشی‌سازی و کنترل دقیق رفتار دستورات هستند. با استفاده صحیح از گزینه‌ها، می‌توانید:

- **خروجی دستورات را بهینه کنید** (با گزینه‌های `-q`، `-v` و ...)
- **رفتار پیش‌فرض دستورات را تغییر دهید** (با گزینه‌های `-r`، `-f`، `-i` و ...)
- **اطلاعات دقیق‌تری دریافت کنید** (با گزینه‌های `-l`، `-v`، `--verbose` و ...)
- **کار با دستورات را سریع‌تر کنید** (با ترکیب گزینه‌ها)

### خلاصه سریع

| نوع گزینه | توضیحات | مثال |
|----------|----------|-------|
| **گزینه کوتاه** | با `-` و یک حرف | `ls -l` |
| **گزینه بلند** | با `--` و یک کلمه | `ls --all` |
| **گزینه با مقدار** | نیاز به یک مقدار اضافی | `ping -c 4` |
| **گزینه ترکیبی** | چند گزینه کوتاه به هم متصل | `ls -la` |
| **پایان گزینه‌ها** | با `--` | `rm -- -file.txt` |

## سؤالات متداول

**سؤال: تفاوت گزینه با آرگومان چیست؟**  
گزینه‌ها با `-` یا `--` شروع می‌شوند و رفتار دستور را تغییر می‌دهند، در حالی که آرگومان‌ها هدف یا داده دستور را مشخص می‌کنند و بدون خط تیره نوشته می‌شوند.

**سؤال: کدام بهتر است: گزینه‌های کوتاه یا بلند؟**  
گزینه‌های کوتاه سریع‌تر تایپ می‌شوند، در حالی که گزینه‌های بلند خوانایی بیشتری دارند. در اسکریپت‌ها معمولاً از گزینه‌های بلند استفاده می‌شود.

**سؤال: چگونه گزینه‌های یک دستور را ببینیم؟**  
با دستور `command --help` یا `man command` می‌توانید همه گزینه‌های یک دستور را مشاهده کنید.

**سؤال: آیا همه دستورات از هر دو نوع گزینه پشتیبانی می‌کنند؟**  
خیر، برخی دستورات فقط از گزینه‌های کوتاه یا فقط از گزینه‌های بلند پشتیبانی می‌کنند.

**سؤال: `--` چه کاری انجام می‌دهد؟**  
`--` به معنای "پایان گزینه‌ها" است و به شما اجازه می‌دهد آرگومان‌هایی را که با `-` شروع می‌شوند به دستور بدهید.

## مفاهیم مرتبط

- **آرگومان‌ها (Arguments)**: داده‌های ورودی دستورات
- **سینتکس دستورات (Command Syntax)**: ساختار کلی دستورات
- **دستورات داخلی و خارجی (Built-in/External Commands)**: انواع دستورات در لینوکس
- **گزینه‌های با مقدار (Options with Arguments)**: گزینه‌هایی که نیاز به داده اضافی دارند
