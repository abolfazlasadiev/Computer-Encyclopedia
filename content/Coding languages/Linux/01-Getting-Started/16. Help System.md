# (سیستم راهنما در لینوکس) - Help System 

---

## معرفی و مرور کلی

**سیستم راهنما** (Help System) در لینوکس، مجموعه‌ای از ابزارها و منابع است که به شما کمک می‌کند تا نحوه استفاده از دستورات، برنامه‌ها و مفاهیم مختلف را یاد بگیرید. این سیستم یکی از قدرتمندترین و کامل‌ترین سیستم‌های راهنمایی در بین سیستم‌عامل‌ها محسوب می‌شود و به کاربران در تمام سطوح (از مبتدی تا حرفه‌ای) امکان می‌دهد تا اطلاعات دقیق و کاملی درباره هر جنبه از سیستم به دست آورند.

درک و تسلط بر سیستم راهنما، یکی از مهم‌ترین مهارت‌هایی است که یک کاربر لینوکس می‌تواند کسب کند. با استفاده از این ابزارها، شما می‌توانید بدون نیاز به اینترنت یا منابع خارجی، پاسخ سوالات خود را پیدا کنید و دانش خود را به طور مستمر افزایش دهید.

---

## ۱. انواع سیستم‌های راهنما در لینوکس

لینوکس چندین ابزار و روش مختلف برای ارائه راهنما دارد که هر کدام برای شرایط خاصی طراحی شده‌اند:

| ابزار | توضیحات | بهترین کاربرد |
|-------|----------|---------------|
| **`man`** | صفحات راهنمای کامل و دقیق | یادگیری عمیق و جزئیات کامل |
| **`--help`** | راهنمای سریع و مختصر | مشاهده سریع گزینه‌ها |
| **`info`** | مستندات ساختاریافته و تعاملی | مطالعه مفاهیم و موضوعات پیچیده |
| **`whatis`** | توضیح یک خطی | یادآوری سریع عملکرد |
| **`apropos`** | جستجوی در صفحات راهنما | پیدا کردن دستور مرتبط |
| **`help`** | راهنمای دستورات داخلی شل | دستورات داخلی Bash |
| **`tldr`** | راهنمای ساده و کاربردی | مشاهده مثال‌های سریع |
| **مستندات آنلاین** | وب‌سایت‌ها و ویکی‌ها | مطالعه جامع و عمیق |

## ۲. دستور `man` (Manual Pages)

### ۲.۱. معرفی

**`man`** مخفف **Manual** (راهنما) است و یکی از قدیمی‌ترین و کامل‌ترین سیستم‌های راهنما در دنیای یونیکس و لینوکس محسوب می‌شود. این دستور، صفحات راهنمای دقیق و جامعی را برای تقریباً تمام دستورات، توابع سیستمی، فایل‌های پیکربندی و مفاهیم سیستم ارائه می‌دهد.

### ۲.۲. نحوه استفاده

```bash
# نمایش صفحه راهنمای یک دستور
man ls

# نمایش صفحه راهنمای یک دستور خاص
man 5 passwd   # نمایش صفحه ۵ (فایل‌های پیکربندی)

# جستجوی در صفحات راهنما
man -k keyword

# نمایش مسیر صفحات راهنما
man -w ls
```

### ۲.۳. ساختار صفحات `man`

صفحات راهنما در لینوکس به **بخش‌های** (Sections) مختلفی تقسیم می‌شوند. شماره بخش، نوع موضوع را مشخص می‌کند.

| بخش | توضیحات | مثال |
|------|----------|-------|
| **۱** | دستورات عمومی کاربران | `man 1 ls` |
| **۲** | سیستم‌کال‌ها (System Calls) | `man 2 open` |
| **۳** | توابع کتابخانه‌ای (Library Functions) | `man 3 printf` |
| **۴** | فایل‌های دستگاه (Device Files) | `man 4 tty` |
| **۵** | فرمت فایل‌ها و پیکربندی‌ها | `man 5 passwd` |
| **۶** | بازی‌ها و نمایش‌ها | `man 6 fortune` |
| **۷** | متفرقه (مفاهیم و استانداردها) | `man 7 signal` |
| **۸** | دستورات مدیریتی سیستم | `man 8 fdisk` |
| **۹** | توابع هسته (Kernel Routines) | `man 9 vmalloc` |

### ۲.۴. ساختار یک صفحه `man`

هر صفحه راهنما از بخش‌های استاندارد زیر تشکیل شده است:

```text
NAME           ← نام دستور و توضیح مختصر
SYNOPSIS       ← نحوه استفاده و سینتکس
DESCRIPTION    ← توضیح کامل دستور
OPTIONS        ← توضیح گزینه‌ها
EXAMPLES       ← مثال‌های عملی
FILES          ← فایل‌های مرتبط
SEE ALSO       ← موضوعات مرتبط
BUGS           ← مشکلات شناخته شده
AUTHOR         ← نویسنده
```

### ۲.۵. میانبرهای کلیدی در `man`

| کلید | عملکرد |
|------|--------|
| **Space** یا **Page Down** | صفحه بعدی |
| **b** یا **Page Up** | صفحه قبلی |
| **g** | رفتن به ابتدا |
| **G** | رفتن به انتها |
| **/pattern** | جستجوی الگو |
| **n** | جستجوی بعدی |
| **N** | جستجوی قبلی |
| **q** | خروج |
| **h** | نمایش راهنمای میانبرها |

### ۲.۶. مثال‌های عملی

```bash
# نمایش راهنمای کامل ls
man ls

# جستجوی گزینه -l در صفحه ls
man ls
/l   # جستجوی l

# نمایش صفحه راهنمای grep
man grep

# نمایش راهنمای فایل passwd
man 5 passwd

# نمایش راهنمای دستورات مدیریتی
man 8 fdisk
```

## ۳. گزینه `--help`

### ۳.۱. معرفی

گزینه `--help` (و گاهی `-h`) یک راهنمای سریع و مختصر است که اکثر دستورات لینوکس از آن پشتیبانی می‌کنند. این گزینه معمولاً خلاصه‌ای از نحوه استفاده، گزینه‌های اصلی و مثال‌های ساده را نمایش می‌دهد.

### ۳.۲. نحوه استفاده

```bash
# نمایش راهنمای سریع
ls --help

# یا با -h (در برخی دستورات)
grep -h

# نمایش راهنمای دستورات پیچیده
tar --help | less
```

### ۳.۳. مقایسه `--help` و `man`

| ویژگی | `--help` | `man` |
|--------|----------|-------|
| **طول** | کوتاه و مختصر | بلند و مفصل |
| **ساختار** | ساده | ساختاریافته |
| **مثال‌ها** | محدود | کامل |
| **توضیحات** | خلاصه | دقیق |
| **سرعت** | سریع | کندتر |
| **کاربرد** | یادآوری سریع | مطالعه عمیق |

### ۳.۴. مثال‌های عملی

```bash
# نمایش راهنمای سریع curl
curl --help

# نمایش راهنمای سریع wget
wget --help

# نمایش راهنمای سریع ping
ping --help | head -20

# ذخیره راهنما در فایل
ls --help > ls_help.txt
```

## ۴. دستور `info`

### ۴.۱. معرفی

**`info`** یک سیستم راهنمای تعاملی و ساختاریافته است که توسط پروژه GNU توسعه داده شده است. برخلاف `man` که صفحات متنی ساده هستند، `info` از یک ساختار درختی و لینک‌های داخلی استفاده می‌کند که مطالعه موضوعات پیچیده را آسان‌تر می‌کند.

### ۴.۲. نحوه استفاده

```bash
# نمایش صفحه info یک دستور
info ls

# نمایش صفحه info اصلی
info

# نمایش یک موضوع خاص
info coreutils

# نمایش بخش خاصی از info
info -f /usr/share/info/bash.info.gz
```

### ۴.۳. میانبرهای کلیدی در `info`

| کلید | عملکرد |
|------|--------|
| **Space** | صفحه بعدی |
| **Backspace** | صفحه قبلی |
| **n** | گره بعدی (Next) |
| **p** | گره قبلی (Previous) |
| **u** | بالا رفتن (Up) |
| **l** | بازگشت (Last) |
| **Tab** | رفتن به لینک بعدی |
| **Enter** | دنبال کردن لینک |
| **q** | خروج |
| **h** | نمایش راهنمای میانبرها |

### ۴.۴. مثال‌های عملی

```bash
# نمایش راهنمای کامل Bash
info bash

# نمایش راهنمای GNU Coreutils
info coreutils

# جستجو در info
info --apropos "grep"

# نمایش info با رنگ‌بندی
info --vi-keys bash   # استفاده از کلیدهای vi
```

## ۵. دستور `whatis`

### ۵.۱. معرفی

**`whatis`** یک توضیح یک خطی (خلاصه) از یک دستور یا مفهوم را نمایش می‌دهد. این دستور از دیتابیس `mandb` برای نمایش سریع اطلاعات استفاده می‌کند.

### ۵.۲. نحوه استفاده

```bash
# نمایش توضیح یک خطی
whatis ls
# خروجی: ls (1) - list directory contents

whatis grep
# خروجی: grep (1) - print lines matching a pattern

whatis passwd
# خروجی: 
# passwd (1) - change user password
# passwd (5) - password file
```

### ۵.۳. مثال‌های عملی

```bash
# نمایش توضیحات چند دستور
whatis ls cp mv rm

# نمایش توضیحات دقیق‌تر
whatis -w "sys*"

# به‌روزرسانی دیتابیس whatis
sudo mandb
```

## ۶. دستور `apropos`

### ۶.۱. معرفی

**`apropos`** یک ابزار جستجو در صفحات راهنما است که به شما کمک می‌کند دستورات مرتبط با یک کلمه کلیدی را پیدا کنید. این دستور در دیتابیس `mandb` جستجو می‌کند و تمام دستوراتی را که در توضیحات آنها کلمه مورد نظر وجود دارد، نمایش می‌دهد.

### ۶.۲. نحوه استفاده

```bash
# جستجوی دستورات مرتبط با "copy"
apropos copy

# جستجوی دستورات مرتبط با "network"
apropos network

# جستجوی دقیق‌تر
apropos -a "network" "connection"
```

### ۶.۳. مثال‌های عملی

```bash
# پیدا کردن دستورات ویرایش فایل
apropos edit

# پیدا کردن دستورات شبکه
apropos "network" | head -20

# پیدا کردن دستورات فشرده‌سازی
apropos "compress"

# جستجوی با کلمات کلیدی
apropos -a "file" "permission"
```

## ۷. دستور `help` (برای دستورات داخلی)

### ۷.۱. معرفی

**`help`** یک دستور داخلی Bash است که راهنمای دستورات داخلی (Built-in) شل را نمایش می‌دهد. این دستور برای دستورات داخلی مانند `cd`، `echo`، `history` و ... کاربرد دارد.

### ۷.۲. نحوه استفاده

```bash
# نمایش راهنمای دستورات داخلی
help

# نمایش راهنمای یک دستور خاص
help cd

# نمایش راهنمای echo
help echo

# نمایش راهنمای history
help history
```

### ۷.۳. مثال‌های عملی

```bash
# نمایش لیست کامل دستورات داخلی
help | less

# نمایش راهنمای دستور cd
help cd

# نمایش راهنمای دستور exit
help exit

# نمایش راهنمای دستور source
help source
```

## ۸. ابزار `tldr` (Too Long; Didn't Read)

### ۸.۱. معرفی

**`tldr`** یک ابزار مدرن است که صفحات راهنمای ساده و کاربردی را با مثال‌های عملی ارائه می‌دهد. هدف این ابزار، ارائه سریع‌ترین و ساده‌ترین راه برای یادگیری یک دستور است.

### ۸.۲. نصب

```bash
# نصب در اوبونتو/دبیان
sudo apt install tldr

# نصب با npm
npm install -g tldr

# نصب در فدورا
sudo dnf install tldr

# نصب در آرچ
sudo pacman -S tldr
```

### ۸.۳. نحوه استفاده

```bash
# نمایش راهنمای ساده
tldr ls

# به‌روزرسانی دیتابیس
tldr --update

# نمایش راهنمای یک دستور خاص
tldr tar
tldr grep
tldr ssh
```

### ۸.۴. مثال

```bash
# خروجی tldr ls:
# ls
# List directory contents.

# - List files one per line:
# ls -1

# - List all files, including hidden files:
# ls -a

# - List all files, with trailing / added to directory names:
# ls -F

# - Long format list (permissions, ownership, size, and modification date):
# ls -la
```

## ۱۱. نکات پیشرفته

### ۱۱.۱. جستجوی پیشرفته در `man`

```bash
# جستجوی در تمام صفحات man
man -k "password"

# جستجوی با عبارت دقیق
man -K "password"   # جستجوی کامل در متن

# جستجوی در بخش خاص
man -s 5 -k "password"
```

### ۱۱.۲. تنظیمات `man`

```bash
# تنظیم نمایشگر پیش‌فرض
export PAGER=less

# تنظیم رنگ‌بندی
export LESS_TERMCAP_mb=$'\E[01;31m'
export LESS_TERMCAP_md=$'\E[01;38;5;74m'
export LESS_TERMCAP_me=$'\E[0m'
export LESS_TERMCAP_us=$'\E[04;38;5;146m'
export LESS_TERMCAP_ue=$'\E[0m'
```

### ۱۱.۳. ایجاد صفحات راهنما

```bash
# استفاده از pandoc برای ایجاد man
pandoc -s manual.md -t man -o manual.1

# نصب صفحه راهنما
cp manual.1 /usr/local/share/man/man1/
```

## ۱۳. خلاصه و نتیجه‌گیری

### ۱۳.۱. نکات کلیدی

- **`man`**: منبع اصلی و کامل راهنما
- **`--help`**: راهنمای سریع و مختصر
- **`info`**: مستندات ساختاریافته GNU
- **`whatis`**: توضیح یک خطی
- **`apropos`**: جستجوی دستورات مرتبط
- **`help`**: راهنمای دستورات داخلی
- **`tldr`**: مثال‌های ساده و کاربردی

### ۱۳.۲. دستورات مفید

| دستور | توضیحات |
|--------|----------|
| `man command` | نمایش راهنمای کامل |
| `command --help` | نمایش راهنمای سریع |
| `whatis command` | توضیح یک خطی |
| `apropos keyword` | جستجوی دستورات |
| `info command` | نمایش راهنمای GNU |
| `help command` | راهنمای دستورات داخلی |
| `tldr command` | مثال‌های سریع |

### ۱۳.۳. بهترین روش‌ها

- برای **یادآوری سریع**: از `--help` استفاده کنید.
- برای **یادگیری عمیق**: از `man` استفاده کنید.
- برای **پیدا کردن دستور**: از `apropos` استفاده کنید.
- برای **مثال‌های سریع**: از `tldr` استفاده کنید.
- برای **دستورات داخلی**: از `help` استفاده کنید.

## سؤالات متداول

**سؤال: تفاوت `man` و `--help` چیست؟**  
`man` راهنمای کامل و دقیق ارائه می‌دهد، در حالی که `--help` یک خلاصه سریع و مختصر است.

**سؤال: چگونه می‌توانم گزینه‌های یک دستور را ببینم؟**  
با `command --help` یا `man command` و جستجوی بخش OPTIONS.

**سؤال: چگونه در `man` جستجو کنم؟**  
با فشردن `/` و تایپ الگوی مورد نظر.

**سؤال: `whatis` و `apropos` چه تفاوتی دارند؟**  
`whatis` توضیح یک دستور خاص را نمایش می‌دهد، در حالی که `apropos` همه دستورات مرتبط با یک کلمه را پیدا می‌کند.

**سؤال: `info` بهتر است یا `man`؟**  
برای مستندات GNU، `info` ساختار بهتری دارد. برای سایر دستورات، `man` کامل‌تر است.

**سؤال: آیا `tldr` جایگزین `man` است؟**  
خیر، `tldr` یک مکمل است که مثال‌های سریع ارائه می‌دهد، اما جزئیات کامل در `man` موجود است.
