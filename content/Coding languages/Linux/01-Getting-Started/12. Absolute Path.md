#  (مسیر مطلق در لینوکس) - Absolute Path

---

## معرفی و مرور کلی

**مسیر مطلق** (Absolute Path) در لینوکس، یک آدرس کامل و بدون ابهام است که مکان دقیق یک فایل یا دایرکتوری را در سیستم فایل مشخص می‌کند. این مسیر همواره از **ریشه سیستم** (Root Directory) که با علامت `/` نشان داده می‌شود، شروع می‌شود و تا فایل یا دایرکتوری مورد نظر ادامه می‌یابد.

درک مسیرهای مطلق، یکی از پایه‌ای‌ترین و حیاتی‌ترین مفاهیم در کار با لینوکس است. برخلاف مسیرهای نسبی (Relative Paths) که به موقعیت فعلی شما وابسته هستند، مسیرهای مطلق مستقل از دایرکتوری فعلی بوده و همواره به یک مکان مشخص و یکتا اشاره می‌کنند. این ویژگی، مسیرهای مطلق را به ابزاری ضروری برای اسکریپت‌نویسی، پیکربندی سیستم و هر موقعیتی که نیاز به ارجاع دقیق به فایل‌ها داریم، تبدیل کرده است.

---

## ۱. مسیر مطلق چیست و چه ویژگی‌هایی دارد؟

### ۱.۱. تعریف دقیق

**مسیر مطلق** (Absolute Path) یا **مسیر کامل** (Full Path)، رشته‌ای است که از ریشه سیستم ( `/` ) شروع شده و با ذکر تمام دایرکتوری‌های میانی، به یک فایل یا دایرکتوری خاص ختم می‌شود. این مسیر، یک آدرس منحصربه‌فرد و بدون ابهام برای هر شیء در سیستم فایل است.

### ۱.۲. ویژگی‌های کلیدی

- **شروع با ریشه**: همواره با کاراکتر `/` (اسلش) آغاز می‌شود.
- **یکتایی**: هر مسیر مطلق، دقیقاً به یک مکان در سیستم فایل اشاره دارد. هیچ دو فایل یا دایرکتوری متفاوتی نمی‌توانند مسیر مطلق یکسانی داشته باشند.
- **استقلال از موقعیت**: مسیر مطلق، بدون توجه به اینکه کاربر در کدام دایرکتوری قرار دارد، همیشه به همان مقصد اشاره می‌کند. شما می‌توانید از هر جایی در سیستم، از یک مسیر مطلق برای دسترسی به یک فایل خاص استفاده کنید.
- **بدون ابهام**: برخلاف مسیرهای نسبی که ممکن است با توجه به دایرکتوری فعلی، معانی مختلفی پیدا کنند، مسیر مطلق همواره یک معنی دارد.
- **طولانی‌تر**: مسیرهای مطلق معمولاً از مسیرهای نسبی طولانی‌تر هستند، زیرا تمام دایرکتوری‌های بین ریشه و مقصد را ذکر می‌کنند.

### ۱.۳. ساختار کلی

یک مسیر مطلق از بخش‌های زیر تشکیل شده است:

```text
/[دایرکتوری سطح اول]/[دایرکتوری سطح دوم]/.../[نام فایل یا دایرکتوری هدف]
```

**مثال کامل**:

```text
/home/amir/Documents/report.pdf
│    │     │         │
│    │     │         └─── نام فایل (report.pdf)
│    │     └───────────── دایرکتوری Documents (سطح سوم)
│    └─────────────────── دایرکتوری amir (سطح دوم)
└──────────────────────── ریشه سیستم (سطح اول)
```

## ۲. مثال‌های عملی از مسیرهای مطلق

### ۲.۱. دسترسی به فایل‌های کاربری

```bash
# مسیر مطلق فایل پیکربندی Bash یک کاربر خاص
/home/amir/.bashrc

# مسیر مطلق یک فایل متنی در دایرکتوری خانه
/home/amir/notes.txt

# مسیر مطلق یک فایل در دایرکتوری Documents
/home/amir/Documents/project/proposal.docx
```

### ۲.۲. دسترسی به فایل‌های سیستم

```bash
# مسیر مطلق فایل پیکربندی GRUB
/boot/grub/grub.cfg

# مسیر مطلق فایل لاگ سیستم
/var/log/syslog

# مسیر مطلق فایل پیکربندی شبکه
/etc/network/interfaces

# مسیر مطلق فایل هاست
/etc/hosts
```

### ۲.۳. دسترسی به دستورات و برنامه‌ها

```bash
# مسیر مطلق دستور ls
/usr/bin/ls

# مسیر مطلق دستور grep
/usr/bin/grep

# مسیر مطلق دستور python
/usr/bin/python3
```

### ۲.۴. دسترسی به دایرکتوری‌ها

```bash
# مسیر مطلق دایرکتوری خانه کاربر
/home/amir

# مسیر مطلق دایرکتوری ریشه
/

# مسیر مطلق دایرکتوری etc
/etc
```

## ۳. نحوه استفاده از مسیرهای مطلق در دستورات

### ۳.۱. دستور `cat` - نمایش محتوای فایل

```bash
# نمایش محتوای فایل با مسیر مطلق
cat /home/amir/Documents/notes.txt

# نمایش محتوای فایل سیستم
cat /etc/hostname

# نمایش محتوای چند فایل
cat /home/amir/file1.txt /home/amir/file2.txt
```

### ۳.۲. دستور `cp` - کپی فایل‌ها

```bash
# کپی فایل با مسیر مطلق
cp /home/amir/file.txt /tmp/backup.txt

# کپی فایل به یک دایرکتوری با مسیر مطلق
cp /home/amir/file.txt /home/amir/Documents/

# کپی چندین فایل
cp /home/amir/*.txt /backup/
```

### ۳.۳. دستور `mv` - جابجایی و تغییر نام

```bash
# جابجایی فایل با مسیر مطلق
mv /home/amir/file.txt /tmp/file.txt

# تغییر نام با مسیر مطلق
mv /home/amir/old.txt /home/amir/new.txt

# جابجایی یک دایرکتوری
mv /home/amir/project /home/amir/archived/project
```

### ۳.۴. دستور `rm` - حذف فایل‌ها

```bash
# حذف فایل با مسیر مطلق
rm /tmp/tempfile.txt

# حذف چندین فایل
rm /home/amir/*.log

# حذف دایرکتوری با مسیر مطلق
rm -rf /tmp/old_cache/
```

### ۳.۵. دستور `cd` - تغییر دایرکتوری

```bash
# رفتن به یک دایرکتوری با مسیر مطلق
cd /etc/nginx

# رفتن به دایرکتوری خانه با مسیر مطلق
cd /home/amir

# رفتن به ریشه سیستم
cd /
```

### ۳.۶. دستور `ls` - لیست کردن محتویات

```bash
# لیست کردن یک دایرکتوری با مسیر مطلق
ls -la /var/log

# لیست کردن یک فایل خاص
ls -l /home/amir/file.txt

# لیست کردن با جزئیات کامل
ls -la /etc/apt
```

### ۳.۷. دستور `mkdir` - ایجاد دایرکتوری

```bash
# ایجاد دایرکتوری با مسیر مطلق
mkdir /home/amir/new_project

# ایجاد دایرکتوری‌های تو در تو
mkdir -p /home/amir/project/{src,bin,doc}

# ایجاد دایرکتوری با مسیر مطلق
mkdir /tmp/temp_dir
```

## ۴. مقایسه مسیر مطلق با مسیر نسبی

### ۴.۱. مثال مقایسه

فرض کنید دایرکتوری فعلی شما `/home/amir/Documents` است.

| نوع مسیر | دستور | معادل مسیر مطلق |
|----------|-------|-----------------|
| **نسبی** | `ls ../` | `ls /home/amir` |
| **نسبی** | `cd ../../` | `cd /home` |
| **نسبی** | `cat project/file.txt` | `cat /home/amir/Documents/project/file.txt` |
| **نسبی** | `./script.sh` | `/home/amir/Documents/script.sh` |
| **مطلق** | `ls /etc` | `ls /etc` (همان) |

### ۴.۲. جدول مقایسه

| ویژگی | مسیر مطلق | مسیر نسبی |
|--------|------------|------------|
| **شروع** | همیشه با `/` | بدون `/` |
| **وابستگی** | مستقل از دایرکتوری فعلی | وابسته به دایرکتوری فعلی |
| **یکتایی** | کاملاً یکتا | ممکن است مبهم باشد |
| **طول** | بلندتر | کوتاه‌تر |
| **کاربرد** | اسکریپت‌ها، پیکربندی‌ها | کار روزمره در ترمینال |
| **مقاومت** | در برابر جابجایی کاربر مقاوم است | با تغییر دایرکتوری تغییر می‌کند |
| **اشتباه** | احتمال اشتباه کمتر | احتمال اشتباه بیشتر |

### ۴.۳. مزایا و معایب

**مزایای مسیر مطلق**:
- بدون ابهام و دقیق
- مستقل از موقعیت فعلی
- قابل استفاده در اسکریپت‌ها و تنظیمات
- امکان ارجاع به فایل‌ها از هر جایی

**معایب مسیر مطلق**:
- طولانی‌تر و دیرتر تایپ می‌شود
- وابسته به ساختار ثابت سیستم (اگر ساختار تغییر کند، مسیرها خراب می‌شوند)

**مزایای مسیر نسبی**:
- کوتاه‌تر و سریع‌تر برای تایپ
- انعطاف‌پذیرتر در برابر تغییرات ساختار (اگر دایرکتوری‌ها جابجا شوند، مسیرها همچنان کار می‌کنند)

**معایب مسیر نسبی**:
- وابسته به دایرکتوری فعلی
- ممکن است مبهم باشد
- در اسکریپت‌ها و تنظیمات قابل اعتماد نیست

## ۵. مسیرهای مطلق در اسکریپت‌نویسی

### ۵.۱. اهمیت مسیرهای مطلق در اسکریپت‌ها

در اسکریپت‌نویسی، استفاده از مسیرهای مطلق یک **روش استاندارد و توصیه‌شده** است، زیرا:

- اسکریپت ممکن است از هر دایرکتوری‌ای اجرا شود
- مسیرهای نسبی ممکن است به نتایج غیرمنتظره منجر شوند
- عیب‌یابی اسکریپت با مسیرهای مطلق آسان‌تر است

### ۵.۲. مثال اسکریپت با مسیرهای مطلق

**فایل `backup.sh`**:

```bash
#!/bin/bash

# تعریف مسیرهای مطلق
SOURCE_DIR="/home/amir/Documents"
BACKUP_DIR="/backup/documents"
LOG_FILE="/var/log/backup.log"

# ایجاد دایرکتوری بکاپ با مسیر مطلق
mkdir -p "$BACKUP_DIR"

# کپی فایل‌ها با مسیرهای مطلق
cp -v "$SOURCE_DIR"/*.txt "$BACKUP_DIR/" >> "$LOG_FILE" 2>&1

# بررسی موفقیت
if [ $? -eq 0 ]; then
    echo "$(date): Backup successful" >> "$LOG_FILE"
else
    echo "$(date): Backup failed" >> "$LOG_FILE"
fi
```

### ۵.۳. دریافت مسیر مطلق در اسکریپت

```bash
#!/bin/bash

# دریافت مسیر مطلق دایرکتوری اسکریپت
SCRIPT_DIR="$(cd "$(dirname "${BASH_SOURCE[0]}")" && pwd)"
echo "Script directory: $SCRIPT_DIR"

# دریافت مسیر مطلق فایل فعلی
SCRIPT_PATH="$(readlink -f "$0")"
echo "Script path: $SCRIPT_PATH"
```

### ۵.۴. تبدیل مسیر نسبی به مطلق

```bash
#!/bin/bash

# تبدیل مسیر نسبی به مطلق با readlink
ABSOLUTE_PATH=$(readlink -f "./file.txt")
echo "Absolute path: $ABSOLUTE_PATH"

# تبدیل مسیر نسبی به مطلق با realpath
ABSOLUTE_PATH=$(realpath "./file.txt")
echo "Absolute path: $ABSOLUTE_PATH"

# تبدیل مسیر نسبی به مطلق با cd و pwd
cd "$(dirname "./file.txt")"
ABSOLUTE_PATH="$(pwd)/$(basename "./file.txt")"
echo "Absolute path: $ABSOLUTE_PATH"
```

## ۶. عیب‌یابی مسیرهای مطلق

### ۶.۱. خطای "No such file or directory"

این خطا زمانی رخ می‌دهد که مسیر مطلق شما به یک فایل یا دایرکتوری که وجود ندارد، اشاره می‌کند.

```bash
# اشتباه ❌
cat /home/amir/nonexistent.txt
# خروجی: cat: /home/amir/nonexistent.txt: No such file or directory

# راه‌حل: بررسی وجود فایل
ls -l /home/amir/nonexistent.txt
# یا
find /home/amir -name "*.txt"
```

### ۶.۲. اشتباه در املای مسیر

```bash
# اشتباه ❌ (اشتباه در املای Documents)
cat /home/amir/Documetns/file.txt

# درست ✅
cat /home/amir/Documents/file.txt
```

### ۶.۳. اشتباه در حروف بزرگ و کوچک

```bash
# اشتباه ❌
cat /Home/amir/file.txt

# درست ✅
cat /home/amir/file.txt
```

### ۶.۴. فراموش کردن `/` در ابتدای مسیر

```bash
# اشتباه ❌ (این یک مسیر نسبی است، نه مطلق)
cat home/amir/file.txt

# درست ✅
cat /home/amir/file.txt
```

### ۶.۵. بررسی مسیرهای مطلق

```bash
# بررسی اینکه آیا یک مسیر، مطلق است یا نسبی
if [[ "$path" == /* ]]; then
    echo "Absolute path"
else
    echo "Relative path"
fi
```

## ۷. تمرین‌های عملی

### ۷.۱. تمرین ساده

```bash
# 1. نمایش مسیر مطلق دایرکتوری فعلی
pwd

# 2. لیست کردن دایرکتوری /etc با مسیر مطلق
ls -la /etc

# 3. نمایش محتوای فایل /etc/hosts
cat /etc/hosts

# 4. رفتن به دایرکتوری /var/log
cd /var/log
pwd

# 5. نمایش محتوای فایل لاگ
tail -n 20 /var/log/syslog
```

### ۷.۲. تمرین پیشرفته

```bash
# 1. ایجاد یک اسکریپت با مسیرهای مطلق
nano ~/absolute_path_demo.sh

# 2. محتوای اسکریپت
#!/bin/bash
echo "Absolute path of home: $HOME"
echo "Absolute path of current directory: $PWD"
echo "Absolute path of script: $(readlink -f "$0")"
echo "Absolute path of /etc/passwd: $(realpath /etc/passwd)"

# 3. اجرای اسکریپت
bash ~/absolute_path_demo.sh

# 4. ایجاد یک ساختار دایرکتوری با مسیرهای مطلق
mkdir -p /tmp/test/{dir1,dir2,dir3}
touch /tmp/test/dir1/file1.txt
touch /tmp/test/dir2/file2.txt

# 5. کپی فایل‌ها با مسیرهای مطلق
cp /tmp/test/dir1/file1.txt /tmp/test/dir3/
cp /tmp/test/dir2/file2.txt /tmp/test/dir3/

# 6. نمایش ساختار
tree /tmp/test
```

## ۸. خلاصه و نتیجه‌گیری

### ۸.۱. نکات کلیدی

- **مسیر مطلق** از ریشه سیستم (`/`) شروع می‌شود و یک آدرس کامل و یکتا برای هر فایل یا دایرکتوری ارائه می‌دهد.
- **ویژگی اصلی** مسیر مطلق، استقلال آن از دایرکتوری فعلی است.
- مسیرهای مطلق برای **اسکریپت‌نویسی**، **پیکربندی سیستم** و هر موقعیتی که نیاز به ارجاع دقیق و بدون ابهام داریم، ضروری هستند.
- برخلاف مسیرهای نسبی، مسیرهای مطلق با جابجایی کاربر در سیستم تغییر نمی‌کنند.
- برای تایپ سریع‌تر مسیرهای مطلق، از **تکمیل خودکار با Tab** استفاده کنید.

### ۸.۲. فرمول ساده

```text
مسیر مطلق = / + [دایرکتوری سطح اول] + / + [دایرکتوری سطح دوم] + ... + / + [نام هدف]
```

**مثال**:

```text
/home/amir/Documents/project/file.txt
```

### ۸.۳. دستورات مفید

| دستور | توضیحات |
|--------|----------|
| `pwd` | نمایش مسیر مطلق دایرکتوری فعلی |
| `realpath` | تبدیل مسیر نسبی به مطلق |
| `readlink -f` | دریافت مسیر مطلق یک فایل |
| `cd /path` | تغییر دایرکتوری با مسیر مطلق |

## سؤالات متداول

**سؤال: تفاوت مسیر مطلق و نسبی چیست؟**  
مسیر مطلق از ریشه سیستم (`/`) شروع می‌شود و مستقل از دایرکتوری فعلی است، در حالی که مسیر نسبی از دایرکتوری فعلی شروع می‌شود و به آن وابسته است.

**سؤال: چه زمانی باید از مسیر مطلق استفاده کنم؟**  
در اسکریپت‌ها، فایل‌های پیکربندی، و هر موقعیتی که نیاز به ارجاع دقیق و بدون ابهام به فایل‌ها دارید، از مسیر مطلق استفاده کنید.

**سؤال: چگونه مسیر مطلق یک فایل را پیدا کنم؟**  
با استفاده از دستور `realpath filename` یا `readlink -f filename`.

**سؤال: آیا می‌توانم مسیرهای مطلق را با Tab کامل کنم؟**  
بله، در ترمینال با تایپ بخشی از مسیر و فشردن Tab، مسیر به صورت خودکار کامل می‌شود.

**سؤال: چه خطاهایی در مسیرهای مطلق رایج است؟**  
اشتباه در املای مسیر، اشتباه در حروف بزرگ و کوچک، فراموش کردن `/` در ابتدا، و اشاره به فایل یا دایرکتوری وجود ندارد.

## مفاهیم مرتبط

- **مسیر نسبی (Relative Path)**: مسیری که از دایرکتوری فعلی شروع می‌شود
- **سیستم فایل (Filesystem)**: ساختار سازماندهی فایل‌ها و دایرکتوری‌ها
- **ریشه (Root)**: بالاترین سطح سیستم فایل (`/`)
- **دایرکتوری (Directory)**: پوشه‌ای برای سازماندهی فایل‌ها
- **دستور cd**: تغییر دایرکتوری فعلی
