# 09-Arguments (آرگومان‌ها در لینوکس)

---

## معرفی و مرور کلی

**آرگومان‌ها** (Arguments) یا **پارامترها** (Parameters)، داده‌های ورودی‌ای هستند که به یک دستور در خط فرمان لینوکس داده می‌شوند تا دستور بداند دقیقاً روی چه چیزی باید عمل کند. اگر دستور را به یک **افعال** تشبیه کنیم، آرگومان‌ها **مفعول‌ها** و **قیدهای** آن هستند که مشخص می‌کنند عمل روی چه چیزی و چگونه انجام شود.

درک عمیق آرگومان‌ها، شما را از یک کاربر معمولی به یک کاربر حرفه‌ای تبدیل می‌کند که می‌تواند دستورات را به بهترین شکل ممکن ترکیب و استفاده کند. این مقاله به صورت جامع و کامل، تمام جنبه‌های آرگومان‌ها را از انواع و ساختار گرفته تا کاربردهای پیشرفته و نکات عیب‌یابی بررسی می‌کند.

---

## ۱. آرگومان چیست و چه نقشی دارد؟

### ۱.۱. تعریف دقیق

**آرگومان** (Argument) به مقدار یا داده‌ای گفته می‌شود که پس از نام دستور و گزینه‌ها (Options) در خط فرمان وارد می‌شود و هدف یا هدف‌های دستور را مشخص می‌کند.

### ۱.۲. تفاوت آرگومان و گزینه (Option)

| ویژگی | گزینه (Option) | آرگومان (Argument) |
|-------|----------------|-------------------|
| **نقش** | تغییر رفتار دستور | مشخص کردن هدف یا داده دستور |
| **نشانه** | معمولاً با `-` یا `--` شروع می‌شود | بدون خط تیره نوشته می‌شود |
| **مثال** | `-l`، `--help` | `file.txt`، `/home`، `google.com` |
| **اجباری/اختیاری** | اغلب اختیاری | گاهی اجباری (بسته به دستور) |

### ۱.۳. مثال ساده

```bash
cp file1.txt file2.txt
# command: cp
# گزینه‌ها: ندارد
# آرگومان‌ها: file1.txt (مبدأ) و file2.txt (مقصد)
```

```bash
grep -i "error" log.txt
# command: grep
# گزینه‌ها: -i (جستجوی بدون حساسیت به بزرگ/کوچکی)
# آرگومان‌ها: "error" (الگوی جستجو) و log.txt (فایل هدف)
```

## ۲. انواع آرگومان‌ها بر اساس نقش

### ۲.۱. آرگومان‌های اجباری (Required Arguments)

برخی دستورات برای اجرا شدن، نیاز به آرگومان‌های مشخصی دارند. بدون آنها، دستور با پیام خطا متوقف می‌شود.

**مثال‌ها**:

```bash
cp         # خطا: missing file operand
rm         # خطا: missing operand
cd         # بدون آرگومان، به خانه می‌رود (استثنا)
mkdir      # خطا: missing operand
```

**استفاده صحیح**:

```bash
cp file1.txt file2.txt    # دو آرگومان اجباری
rm file.txt               # یک آرگومان اجباری
mkdir new_folder          # یک آرگومان اجباری
```

### ۲.۲. آرگومان‌های اختیاری (Optional Arguments)

برخی دستورات می‌توانند بدون آرگومان نیز اجرا شوند و با آرگومان، رفتار آنها تغییر می‌کند.

**مثال**:

```bash
ls         # لیست دایرکتوری فعلی
ls /home   # لیست دایرکتوری /home
```

```bash
date       # نمایش تاریخ فعلی
date +%Y   # نمایش فقط سال
```

### ۲.۳. آرگومان‌های تکی (Single Arguments)

دستوراتی که فقط به یک آرگومان نیاز دارند:

```bash
cd /home          # یک آرگومان: مسیر مقصد
pwd               # بدون آرگومان
whoami            # بدون آرگومان
mkdir newdir      # یک آرگومان: نام دایرکتوری جدید
touch file.txt    # یک آرگومان: نام فایل جدید
```

### ۲.۴. آرگومان‌های چندگانه (Multiple Arguments)

دستوراتی که می‌توانند چندین آرگومان را بپذیرند:

```bash
# حذف چندین فایل همزمان
rm file1.txt file2.txt file3.txt

# کپی چندین فایل در یک دایرکتوری
cp file1.txt file2.txt file3.txt /backup/

# ایجاد چندین دایرکتوری همزمان
mkdir dir1 dir2 dir3

# تغییر نام چندین فایل (با استفاده از mv)
mv file1.txt file1.backup
mv file2.txt file2.backup
```

### ۲.۵. آرگومان‌های ترکیبی (Combined Arguments)

برخی آرگومان‌ها خود ترکیبی از چندین مقدار هستند:

```bash
# کپی با نام جدید
cp file1.txt file1_backup.txt

# تغییر نام فایل
mv old_name.txt new_name.txt

# جابجایی فایل به دایرکتوری دیگر
mv file.txt /home/user/Documents/
```

## ۳. انواع آرگومان‌ها بر اساس محتوا

### ۳.۱. آرگومان‌های رشته‌ای (String Arguments)

آرگومان‌هایی که از متن یا رشته تشکیل شده‌اند:

```bash
echo "Hello World"        # یک رشته
grep "error" log.txt      # رشته جستجو
useradd "John Doe"        # نام کاربری با فاصله (با نقل‌قول)
```

### ۳.۲. آرگومان‌های عددی (Numeric Arguments)

آرگومان‌هایی که عدد هستند:

```bash
head -n 20 file.txt       # ۲۰ یک آرگومان عددی است
ping -c 5 google.com      # ۵ یک آرگومان عددی است
sleep 10                  # ۱۰ ثانیه تاخیر
tail -n 50 log.txt        # ۵۰ خط آخر
```

### ۳.۳. آرگومان‌های مسیر (Path Arguments)

آرگومان‌هایی که به فایل‌ها یا دایرکتوری‌ها اشاره می‌کنند:

**مسیر مطلق (Absolute Path)**:
```bash
ls /home/amir/Documents
cd /etc/nginx
rm /var/log/syslog
```

**مسیر نسبی (Relative Path)**:
```bash
ls Documents         # دایرکتوری Documents در مسیر فعلی
cd ..               # یک سطح بالا
rm ./file.txt       # فایل در دایرکتوری فعلی
```

### ۳.۴. آرگومان‌های آدرس (Address Arguments)

آرگومان‌هایی که به آدرس‌های شبکه یا هاست‌ها اشاره می‌کنند:

```bash
ping 192.168.1.1          # آدرس IP
ping google.com           # نام دامنه
ssh user@server.com       # آدرس سرور
curl https://example.com  # آدرس URL
```

### ۳.۵. آرگومان‌های ویژه (Special Arguments)

| آرگومان | توضیحات | مثال |
|---------|----------|-------|
| `.` | دایرکتوری فعلی | `ls .` |
| `..` | دایرکتوری والد | `cd ..` |
| `~` | دایرکتوری خانه | `cd ~` |
| `/` | ریشه سیستم | `cd /` |
| `-` | دایرکتوری قبلی | `cd -` |
| `*` | همه فایل‌ها (Wildcard) | `rm *.txt` |
| `?` | یک کاراکتر (Wildcard) | `ls file?.txt` |

## ۴. آرگومان‌های با نقل‌قول (Quoted Arguments)

### ۴.۱. چرا از نقل‌قول استفاده می‌کنیم؟

نقل‌قول‌ها به شما اجازه می‌دهند:

- از فاصله در نام فایل‌ها یا رشته‌ها استفاده کنید
- کاراکترهای خاص (مانند `*`، `?`، `$` و ...) را به عنوان کاراکتر معمولی تفسیر کنید
- چندین کلمه را به عنوان یک آرگومان واحد ارسال کنید

### ۴.۲. نقل‌قول تکی (Single Quotes - `'`)

همه چیز داخل نقل‌قول تکی، به صورت **دقیق** و **بدون تغییر** تفسیر می‌شود.

```bash
echo '$HOME'        # خروجی: $HOME (متغیر تفسیر نمی‌شود)
echo 'Hello World'  # خروجی: Hello World
```

### ۴.۳. نقل‌قول دوتایی (Double Quotes - `"`)

متغیرها و کاراکترهای خاص (مانند `$` و `\`) در داخل نقل‌قول دوتایی تفسیر می‌شوند.

```bash
echo "$HOME"        # خروجی: /home/amir (متغیر تفسیر می‌شود)
echo "Hello World"  # خروجی: Hello World
```

### ۴.۴. مقایسه نقل‌قول‌ها

```bash
# با نقل‌قول تکی (تفسیر نمی‌شود)
echo 'Current user: $USER'    # خروجی: Current user: $USER

# با نقل‌قول دوتایی (تفسیر می‌شود)
echo "Current user: $USER"    # خروجی: Current user: amir
```

### ۴.۵. فرار دادن کاراکترها (Escape Characters)

با استفاده از بک‌اسلش (`\`) می‌توانید کاراکترهای خاص را فرار دهید (Escape).

```bash
echo "She said: \"Hello World\""   # خروجی: She said: "Hello World"
echo "Price is \$10"               # خروجی: Price is $10
```

## ۵. کاراکترهای جایگزین (Wildcards) به عنوان آرگومان

### ۵.۱. ستاره (`*`)

نماینده **هر تعداد کاراکتر** (صفر یا بیشتر).

```bash
# همه فایل‌های با پسوند txt
rm *.txt

# همه فایل‌هایی که با log شروع می‌شوند
ls log*

# همه فایل‌هایی که به .bak ختم می‌شوند
cp *.bak /backup/
```

### ۵.۲. علامت سوال (`?`)

نماینده **دقیقاً یک کاراکتر**.

```bash
# فایل‌هایی مثل file1.txt، fileA.txt
ls file?.txt

# فایل‌هایی مثل data1.log، data2.log
ls data?.log
```

### ۵.۳. کروشه (`[...]`)

نماینده **یکی از کاراکترهای داخل کروشه**.

```bash
# فایل‌هایی مثل file1.txt، file2.txt، file3.txt
ls file[0-9].txt

# فایل‌هایی مثل fileA.txt، fileB.txt
ls file[AB].txt
```

### ۵.۴. ترکیب Wildcardها

```bash
# فایل‌هایی که با log شروع می‌شوند و به عدد ختم می‌شوند
ls log*[0-9]

# فایل‌هایی با پسوند txt یا log
ls *.{txt,log}
```

## ۶. آرگومان‌ها و اسکریپت‌نویسی (Script Arguments)

### ۶.۱. متغیرهای ویژه آرگومان

در اسکریپت‌های Bash، آرگومان‌ها با استفاده از متغیرهای خاص قابل دسترسی هستند:

| متغیر | توضیحات | مثال |
|--------|----------|-------|
| `$0` | نام اسکریپت | `./script.sh` |
| `$1` | اولین آرگومان | `./script.sh arg1` |
| `$2` | دومین آرگومان | `./script.sh arg1 arg2` |
| `$#` | تعداد کل آرگومان‌ها | `3` |
| `$@` | تمام آرگومان‌ها به صورت جداگانه | `arg1 arg2 arg3` |
| `$*` | تمام آرگومان‌ها به صورت یک رشته | `"arg1 arg2 arg3"` |
| `$$` | PID اسکریپت | `12345` |
| `$?` | کد خروجی آخرین دستور | `0` برای موفقیت |

### ۶.۲. مثال اسکریپت با آرگومان

**فایل `greet.sh`**:

```bash
#!/bin/bash
echo "Script name: $0"
echo "First argument: $1"
echo "Second argument: $2"
echo "Number of arguments: $#"
echo "All arguments: $@"
```

**اجرا**:

```bash
./greet.sh Amir Hossein
```

**خروجی**:

```text
Script name: ./greet.sh
First argument: Amir
Second argument: Hossein
Number of arguments: 2
All arguments: Amir Hossein
```

### ۶.۳. دریافت آرگومان‌ها با حلقه

```bash
#!/bin/bash
for arg in "$@"; do
    echo "Argument: $arg"
done
```

**خروجی**:

```bash
./script.sh a b c
# Argument: a
# Argument: b
# Argument: c
```

## ۷. خطاهای رایج در آرگومان‌ها و نحوه رفع آنها

### ۷.۱. فراموش کردن آرگومان اجباری

```bash
# اشتباه ❌
cp

# خروجی: cp: missing file operand

# درست ✅
cp file1.txt file2.txt
```

### ۷.۲. استفاده نادرست از نقل‌قول

```bash
# اشتباه ❌
mkdir My Documents    # دو آرگومان: My و Documents

# درست ✅
mkdir "My Documents"  # یک آرگومان
```

### ۷.۳. استفاده از Wildcard بدون توجه

```bash
# اشتباه ❌ (اگر فایل‌ها با * مطابقت نداشته باشند)
rm *.txt

# بهتر: با تأیید
rm -i *.txt
```

### ۷.۴. استفاده از فاصله در نام فایل‌ها بدون نقل‌قول

```bash
# اشتباه ❌
touch My File.txt

# درست ✅
touch "My File.txt"
```

### ۷.۵. فراموش کردن مسیر کامل یا نسبی

```bash
# اشتباه ❌ (اگر فایل در مسیر فعلی نیست)
cp myfile.txt /backup/

# درست ✅
cp /home/amir/myfile.txt /backup/
```

### ۷.۶. ترتیب اشتباه آرگومان‌ها

```bash
# اشتباه ❌ (cp نیاز به مبدأ و سپس مقصد دارد)
cp file2.txt file1.txt   # اگر file2.txt وجود نداشته باشد، خطا می‌دهد

# درست ✅
cp file1.txt file2.txt   # کپی file1.txt به file2.txt
```

## ۸. تمرین‌های عملی

### ۸.۱. تمرین ساده

```bash
# 1. یک فایل با نام 'my file.txt' ایجاد کنید
touch "my file.txt"

# 2. محتویات دایرکتوری را مشاهده کنید
ls -la

# 3. از Wildcard برای مشاهده فایل‌های txt استفاده کنید
ls *.txt

# 4. فایل را به دایرکتوری Documents منتقل کنید
mv "my file.txt" Documents/

# 5. فایل را حذف کنید (با احتیاط)
rm Documents/"my file.txt"
```

### ۸.۲. تمرین پیشرفته

```bash
# 1. چندین فایل با پسوند مختلف ایجاد کنید
touch file1.txt file2.log file3.data

# 2. همه فایل‌های txt را کپی کنید
cp *.txt /backup/

# 3. همه فایل‌های log و data را حذف کنید
rm *.log *.data

# 4. یک اسکریپت با نام backup.sh ایجاد کنید که آرگومان می‌گیرد
nano backup.sh

# 5. در اسکریپت:
#!/bin/bash
echo "Backing up: $1"
cp "$1" /backup/

# 6. اسکریپت را اجرا کنید
./backup.sh myfile.txt
```

## ۹. خلاصه و نتیجه‌گیری

آرگومان‌ها در خط فرمان لینوکس، داده‌های ورودی دستورات هستند که مشخص می‌کنند دستور روی چه چیزی و چگونه عمل کند. انواع مختلفی از آرگومان‌ها وجود دارد:

| نوع آرگومان | توضیحات |
|-------------|----------|
| **اجباری** | دستور بدون آنها اجرا نمی‌شود |
| **اختیاری** | دستور بدون آنها نیز اجرا می‌شود |
| **رشته‌ای** | شامل متن و کاراکترها |
| **عددی** | شامل اعداد |
| **مسیر** | اشاره به فایل یا دایرکتوری |
| **آدرس** | اشاره به آدرس شبکه |

- از **نقل‌قول‌ها** برای آرگومان‌های دارای فاصله استفاده کنید
- از **Wildcardها** برای کار با چندین فایل به صورت همزمان استفاده کنید
- در اسکریپت‌نویسی، از متغیرهای `$1`، `$2` و ... برای دسترسی به آرگومان‌ها استفاده کنید

## سؤالات متداول

**سؤال: تفاوت آرگومان و گزینه چیست؟**  
گزینه‌ها (Options) برای تغییر رفتار دستور استفاده می‌شوند و با `-` یا `--` شروع می‌شوند، در حالی که آرگومان‌ها (Arguments) هدف یا داده دستور را مشخص می‌کنند و بدون خط تیره نوشته می‌شوند.

**سؤال: چگونه آرگومان‌های حاوی فاصله را به دستور بدهیم؟**  
با استفاده از نقل‌قول‌ها، مانند `"My Documents"` یا `'My Documents'`.

**سؤال: آیا می‌توان از چندین Wildcard در یک دستور استفاده کرد؟**  
بله، مانند `ls *.{txt,log}` یا `cp *.txt *.backup`.

**سؤال: چگونه آرگومان‌ها را در اسکریپت دریافت کنیم؟**  
با استفاده از متغیرهای `$1`، `$2` و `$@`.

**سؤال: اگر آرگومان‌ها زیاد باشند، چه کار کنیم؟**  
می‌توانید از حلقه‌ها مانند `for arg in "$@"; do ... done` برای پردازش تمام آرگومان‌ها استفاده کنید.

---

## مفاهیم مرتبط

- **گزینه‌ها (Options)**: تغییر رفتار دستور
- **Wildcardها**: کاراکترهای جایگزین برای مطابقت با چندین فایل
- **نقل‌قول‌ها (Quotes)**: حفظ فاصله و کاراکترهای خاص
- **اسکریپت‌نویسی (Scripting)**: استفاده از آرگومان‌ها در اسکریپت‌ها
