#  (سینتکس دستورات در لینوکس) - Command Syntax

---

## معرفی و مرور کلی

**سینتکس دستورات** (Command Syntax) در لینوکس، مجموعه قوانین و ساختارهایی است که نحوه صحیح نوشتن یک دستور در خط فرمان را مشخص می‌کند. این قوانین، مانند قواعد دستوری یک زبان، تعیین می‌کنند که چگونه باید دستورات را تایپ کنیم تا سیستم بتواند آنها را به درستی تفسیر و اجرا کند. درک دقیق سینتکس، پایه و اساس تسلط بر خط فرمان لینوکس محسوب می‌شود.

هر دستور در لینوکس از ترکیب چندین عنصر کلیدی تشکیل شده است که در ادامه به صورت جامع و کامل به بررسی تک‌تک آنها می‌پردازیم.

---

## ۱. ساختار کلی یک دستور

ساختار کلی یک دستور در لینوکس به شکل زیر است:

```text
command [options] [arguments]
```

این ساختار، قالب اصلی تمام دستورات است. درک این سه بخش، به شما امکان می‌دهد هر دستور جدیدی را که در طول یادگیری لینوکس با آن مواجه می‌شوید، به راحتی تحلیل و اجرا کنید.

| جزء | توضیحات |
|------|----------|
| **command** | نام برنامه یا دستور اصلی که می‌خواهید اجرا کنید (مثلاً `ls`، `cp`، `grep`). |
| **options** | گزینه‌هایی برای تغییر رفتار پیش‌فرض دستور (مثلاً `-l`، `-a`، `--help`). |
| **arguments** | اهداف یا داده‌هایی که دستور روی آنها عمل می‌کند (مثلاً نام فایل، مسیر دایرکتوری، متن جستجو). |

**مثال کامل:**

```bash
ls -la /home/amir
```

در این دستور:
- **command**: `ls` (لیست کردن محتویات دایرکتوری)
- **options**: `-la` (گزینه ترکیبی از `l` برای نمایش جزئیات و `a` برای نمایش فایل‌های مخفی)
- **arguments**: `/home/amir` (مسیر دایرکتوری مورد نظر)

## ۲. دستور (Command)

**دستور** (Command) قلب سینتکس است. این بخش مشخص می‌کند که شما دقیقاً چه کاری می‌خواهید انجام دهید. دستورات در لینوکس به چند دسته کلی تقسیم می‌شوند:

### ۲.۱. دستورات داخلی (Built-in Commands)

دستوراتی که مستقیماً در خود شل (Shell) پیاده‌سازی شده‌اند و برای اجرا نیازی به فراخوانی یک برنامه جداگانه ندارند. این دستورات بسیار سریع اجرا می‌شوند و بخشی از خود شل هستند.

**مثال‌ها**:
```bash
cd      # تغییر دایرکتوری
echo    # نمایش متن در خروجی
exit    # خروج از شل
pwd     # نمایش مسیر فعلی
history # نمایش تاریخچه دستورات
```

**مشاهده دستورات داخلی**:
```bash
help          # نمایش لیست دستورات داخلی Bash
type command  # مشخص می‌کند که آیا دستور داخلی است یا خارجی
```

### ۲.۲. دستورات خارجی (External Commands)

دستوراتی که به عنوان فایل‌های اجرایی جداگانه در سیستم وجود دارند و در دایرکتوری‌هایی مانند `/bin`، `/usr/bin`، `/sbin` یا `/usr/local/bin` ذخیره شده‌اند.

**مثال‌ها**:
```bash
ls        # لیست کردن فایل‌ها
cp        # کپی کردن فایل‌ها
mv        # جابجایی یا تغییر نام
rm        # حذف فایل‌ها
grep      # جستجوی الگو در فایل‌ها
```

**مشاهده مسیر یک دستور خارجی**:
```bash
which ls        # نمایش مسیر کامل دستور
whereis grep    # نمایش تمام مسیرهای مرتبط با دستور
```

### ۲.۳. دستورات از پیش تعریف شده (Alias)

Aliasها نام‌های مستعار (یا میانبر) هستند که کاربران برای دستورات طولانی یا ترکیبی ایجاد می‌کنند. این قابلیت به شما اجازه می‌دهد تا دستورات پرکاربرد را به شکل کوتاه‌تری تعریف کنید.

**ایجاد Alias**:
```bash
alias ll='ls -la'
alias gs='git status'
alias update='sudo apt update && sudo apt upgrade -y'
```

**مشاهده همه Aliasها**:
```bash
alias
```

**حذف یک Alias**:
```bash
unalias ll
```

**نکته**: Aliasها به صورت موقت در جلسه فعلی تعریف می‌شوند. برای دائمی کردن آنها، باید در فایل پیکربندی شل مانند `~/.bashrc` یا `~/.zshrc` قرار دهید.

### ۲.۴. دستورات ترکیبی (Combined Commands)

با استفاده از عملگرهای خاص، می‌توانید چندین دستور را در یک خط ترکیب کنید و یک زنجیره از عملیات ایجاد کنید. این یکی از قدرتمندترین قابلیت‌های خط فرمان است.

**عملگرهای ترکیبی**:

| عملگر | توضیحات | مثال |
|--------|----------|-------|
| `;` | اجرای دستورات به صورت پشت سر هم (صرف نظر از موفقیت یا شکست قبلی) | `cd /tmp; ls -la` |
| `&&` | اجرای دستور دوم **فقط در صورتی** که دستور اول موفق باشد | `mkdir newdir && cd newdir` |
| `\|\|` | اجرای دستور دوم **فقط در صورتی** که دستور اول ناموفق باشد | `command1 \|\| echo "Failed!"` |
| `&` | اجرای دستور در پس‌زمینه (Background) | `firefox &` |

**مثال‌های ترکیبی**:
```bash
# ایجاد دایرکتوری و ورود به آن (فقط در صورت موفقیت)
mkdir project && cd project

# آپدیت و ارتقاء سیستم
sudo apt update && sudo apt upgrade -y

# اجرای دستور در پس‌زمینه
long_running_task &

# اجرای دستور و نمایش پیام موفقیت یا شکست
./build.sh && echo "Build Successful" || echo "Build Failed"
```

## ۳. گزینه‌ها (Options / Flags)

**گزینه‌ها** (Options) یا **پرچم‌ها** (Flags) بخشی از دستور هستند که نحوه عملکرد آن را تغییر می‌دهند. بدون گزینه‌ها، دستورات با رفتار پیش‌فرض خود اجرا می‌شوند.

### ۳.۱. انواع گزینه‌ها

**گزینه‌های کوتاه (Short Options)**:
- با یک خط تیره (`-`) شروع می‌شوند
- معمولاً یک حرف هستند
- می‌توانند به هم متصل شوند (مثلاً `-la` معادل `-l -a` است)

**مثال**:
```bash
ls -l          # نمایش جزئیات
ls -a          # نمایش فایل‌های مخفی
ls -la         # ترکیب دو گزینه بالا
```

**گزینه‌های بلند (Long Options)**:
- با دو خط تیره (`--`) شروع می‌شوند
- معمولاً یک کلمه کامل هستند
- خوانایی بیشتری دارند

**مثال**:
```bash
ls --all           # معادل ls -a
ls --help          # نمایش راهنما
grep --recursive   # جستجوی بازگشتی
```

**گزینه‌های با مقدار (Options with Arguments)**:
برخی گزینه‌ها نیاز به دریافت یک مقدار اضافی دارند.

**مثال**:
```bash
# گزینه -c نیاز به تعداد پینگ دارد
ping -c 4 google.com

# گزینه --output نیاز به نام فایل خروجی دارد
grep --output=result.txt "error" log.txt

# گزینه -n در head نیاز به تعداد خطوط دارد
head -n 20 file.txt
```

### ۳.۲. جدول گزینه‌های رایج

| گزینه | توضیحات |
|-------|----------|
| `-h` یا `--help` | نمایش راهنمای سریع دستور |
| `-v` یا `--version` | نمایش نسخه دستور |
| `-f` یا `--force` | اجبار به اجرا (نادیده گرفتن هشدارها) |
| `-r` یا `--recursive` | اجرای عملیات به صورت بازگشتی (در دایرکتوری‌های تودرتو) |
| `-i` یا `--interactive` | درخواست تأیید قبل از هر عملیات |
| `-q` یا `--quiet` | اجرای بی‌صدا (بدون نمایش خروجی) |
| `-v` یا `--verbose` | نمایش اطلاعات دقیق و جزئیات بیشتر |

## ۴. آرگومان‌ها (Arguments)

**آرگومان‌ها** (Arguments) داده‌هایی هستند که دستور روی آنها عملیات خود را انجام می‌دهد. آرگومان‌ها می‌توانند انواع مختلفی داشته باشند.

### ۴.۱. انواع آرگومان‌ها

**آرگومان‌های فایل و دایرکتوری**:
```bash
cp file1.txt file2.txt   # دو آرگومان: فایل مبدأ و مقصد
rm file.txt              # یک آرگومان: فایل هدف
ls /home                 # یک آرگومان: دایرکتوری هدف
mkdir new_folder         # یک آرگومان: نام دایرکتوری جدید
```

**آرگومان‌های رشته و متن**:
```bash
echo "Hello World"       # یک آرگومان رشته‌ای
grep "error" log.txt     # دو آرگومان: رشته جستجو و فایل
```

**آرگومان‌های عددی**:
```bash
head -n 20 file.txt      # آرگومان عددی ۲۰
ping -c 5 google.com     # آرگومان عددی ۵
```

**آرگومان‌های آدرس و مسیر**:
```bash
ping 192.168.1.1         # آرگومان آدرس IP
ssh user@server.com      # آرگومان آدرس سرور
```

### ۴.۲. آرگومان‌های چندگانه

شما می‌توانید چندین آرگومان را به یک دستور بدهید:

```bash
# حذف چندین فایل به طور همزمان
rm file1.txt file2.txt file3.txt

# کپی کردن چندین فایل در یک دایرکتوری
cp file1.txt file2.txt file3.txt /backup/

# جستجوی چندین کلمه در یک فایل
grep -e "error" -e "warning" log.txt
```

### ۴.۳. آرگومان‌های اختیاری و اجباری

برخی دستورات نیاز به آرگومان‌های اجباری دارند و برخی دیگر اختیاری.

**اجباری**:
```bash
cd /home        # آرگومان مسیر اجباری است
cp file1 file2  # هر دو آرگومان اجباری هستند
```

**اختیاری**:
```bash
ls              # بدون آرگومان، دایرکتوری فعلی را لیست می‌کند
date            # بدون آرگومان، تاریخ فعلی را نمایش می‌دهد
```

## ۵. کاراکترهای خاص و استثناهای سینتکس

### ۵.۱. فاصله (Space)

فاصله در خط فرمان به عنوان **جداساز** (Separator) بین بخش‌های مختلف دستور عمل می‌کند:

```bash
# درست: سه بخش مجزا
ls -la /home

# اشتباه: همه چیز یک بخش محسوب می‌شود
ls-la/home     # این یک دستور اشتباه است
```

### ۵.۲. نقل‌قول‌ها (Quotes)

برای استفاده از فاصله یا کاراکترهای خاص در نام فایل‌ها یا رشته‌ها، باید از نقل‌قول استفاده کنید:

```bash
# بدون نقل‌قول: دو آرگومان جداگانه (اشتباه)
echo Hello World    # خروجی: Hello World (اما دو آرگومان جداگانه)

# با نقل‌قول: یک آرگومان واحد
echo "Hello World"  # خروجی: Hello World (یک آرگومان)

# کار با فایل‌هایی با نام دارای فاصله
ls "My Documents"
touch "new file.txt"
```

### ۵.۳. کاراکترهای فرار (Escape Characters)

کاراکتر بک‌اسلش (`\`) برای بی‌اثر کردن کاراکترهای خاص استفاده می‌شود:

```bash
# نمایش $ به عنوان کاراکتر معمولی
echo "Price is \$10"    # خروجی: Price is $10

# ایجاد فایل با نام دارای فاصله
touch my\ file.txt

# استفاده از کاراکتر * به عنوان کاراکتر معمولی
echo "I like \*"        # خروجی: I like *
```

### ۵.۴. موارد حساس به بزرگ‌و‌کوچکی (Case Sensitivity)

لینوکس به **بزرگ و کوچک بودن حروف** حساس است (Case-Sensitive):

```bash
ls      # درست ✅
Ls      # اشتباه ❌
LS      # اشتباه ❌

file.txt   # یک فایل
File.txt   # فایل متفاوت
FILE.TXT   # فایل متفاوت دیگر
```

### ۵.۵. کامنت‌ها (Comments)

برای نوشتن توضیحات در خط فرمان یا اسکریپت‌ها، از علامت `#` استفاده می‌شود. هر چیزی بعد از `#` نادیده گرفته می‌شود:

```bash
# این یک کامنت است و اجرا نمی‌شود
ls -la  # اینجا هم یک کامنت است
```

## ۶. استثناهای مهم در سینتکس

### ۶.۱. دستورات بدون گزینه

برخی دستورات گزینه‌ای ندارند و فقط با آرگومان کار می‌کنند:

```bash
echo "Hello"    # گزینه ندارد
pwd             # نه گزینه دارد و نه آرگومان
date            # نه گزینه دارد و نه آرگومان
```

### ۶.۲. دستورات با گزینه‌های اجباری

برخی گزینه‌ها اجباری هستند و نمی‌توانید بدون آنها از دستور استفاده کنید:

```bash
tar -cf archive.tar file1 file2  # گزینه -c و -f برای ایجاد آرشیو اجباری است
```

### ۶.۳. ترتیب گزینه‌ها و آرگومان‌ها

در اکثر دستورات، گزینه‌ها قبل از آرگومان‌ها نوشته می‌شوند:

```bash
# درست
ls -la /home

# در برخی موارد، آرگومان قبل از گزینه ممکن است کار نکند
ls /home -la    # در برخی دستورات کار می‌کند اما استاندارد نیست
```

## ۷. اشتباهات رایج در سینتکس

### ۷.۱. فراموش کردن فاصله

```bash
# اشتباه ❌
ls-la

# درست ✅
ls -la
```

### ۷.۲. استفاده نکردن از نقل‌قول برای رشته‌های دارای فاصله

```bash
# اشتباه ❌
echo Hello World   # دو آرگومان جداگانه

# درست ✅
echo "Hello World" # یک آرگومان
```

### ۷.۳. اشتباه در حروف بزرگ و کوچک

```bash
# اشتباه ❌
Ls

# درست ✅
ls
```

### ۷.۴. فراموش کردن خط تیره برای گزینه‌ها

```bash
# اشتباه ❌
ls l

# درست ✅
ls -l
```

## ۸. ابزارهای کمک‌کننده در سینتکس

### ۸.۱. تکمیل خودکار با Tab

فشردن کلید **Tab**، نام فایل‌ها، دایرکتوری‌ها و دستورات را به صورت خودکار کامل می‌کند:

```bash
# تایپ کردن
cd /hom[Tab]   # تبدیل به cd /home
```

### ۸.۲. نمایش راهنما

```bash
command --help     # نمایش راهنمای سریع
man command        # نمایش صفحه راهنمای کامل
```

### ۸.۳. اطلاعات دستور

```bash
whatis command     # توضیح یک خطی
type command       # مشخص کردن نوع دستور (داخلی، خارجی یا alias)
which command      # نمایش مسیر دستور خارجی
```

## ۹. خلاصه و نتیجه‌گیری

سینتکس دستورات در لینوکس، قوانین و ساختارهایی است که باید در تایپ و نوشتن دستورات رعایت شود. ساختار کلی دستورات لینوکس به شکل زیر است:

```text
command [options] [arguments]
```

با درک اصول سینتکس، تایپ صحیح دستورات و رعایت نکات کلیدی (فاصله، نقل‌قول، حساسیت به حروف و کاراکترهای خاص)، شما می‌توانید با اطمینان از خط فرمان استفاده کنید و از قدرت بی‌نهایت آن برای مدیریت سیستم لینوکس بهره‌مند شوید.

## مفاهیم مرتبط

- **دستورات داخلی (Built-in)**: بخشی از خود شل
- **دستورات خارجی (External)**: برنامه‌های مستقل
- **Alias**: نام‌های مستعار
- **گزینه‌ها (Options)**: تغییر رفتار دستور
- **آرگومان‌ها (Arguments)**: داده‌های ورودی دستور
- **کاراکترهای خاص**: Wildcards و Escape Characters
