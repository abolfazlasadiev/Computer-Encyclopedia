# (مسیرها در لینوکس) - Paths 

---

## معرفی و مرور کلی

**مسیرها** (Paths) در سیستم‌عامل لینوکس، آدرس‌هایی هستند که مکان دقیق یک فایل یا دایرکتوری را در ساختار درختی سیستم فایل مشخص می‌کنند. درک صحیح مسیرها، یکی از اساسی‌ترین و حیاتی‌ترین مهارت‌ها برای کار با لینوکس است، زیرا تقریباً تمام دستورات شما با فایل‌ها و دایرکتوری‌ها سروکار دارند و برای اشاره به آنها نیاز به مسیر دارید.

سیستم فایل لینوکس به شکل یک **درخت وارونه** (Inverted Tree) سازماندهی شده است که ریشه آن `/` (اسلش) نام دارد. از این ریشه، تمام دایرکتوری‌ها و فایل‌های سیستم منشعب می‌شوند. درک این ساختار و نحوه نوشتن مسیرها، شما را قادر می‌سازد تا به هر فایلی در سیستم دسترسی پیدا کنید و دستورات خود را به درستی اجرا کنید.

---

## ۱. مسیر چیست و چه نقشی دارد؟

### ۱.۱. تعریف دقیق

**مسیر** (Path) یک رشته متنی است که مکان یک فایل یا دایرکتوری را در سیستم فایل مشخص می‌کند. مسیرها با استفاده از اسلش (`/`) به عنوان جداکننده، دایرکتوری‌های مختلف را به هم متصل می‌کنند.

### ۱.۲. ساختار مسیر

یک مسیر معمولاً از ترکیب دایرکتوری‌های تو در تو تشکیل شده است:

```text
/root/home/amir/Documents/file.txt
│    │    │     │          │
│    │    │     │          └─── نام فایل
│    │    │     └─────────────── دایرکتوری Documents
│    │    └───────────────────── دایرکتوری amir
│    └────────────────────────── دایرکتوری home
└──────────────────────────────── ریشه سیستم
```

## ۲. انواع مسیرها در لینوکس

### ۲.۱. مسیر مطلق (Absolute Path)

**تعریف**: مسیری که از **ریشه سیستم** (`/`) شروع می‌شود و مسیر کامل یک فایل یا دایرکتوری را از ریشه تا هدف مشخص می‌کند.

**ویژگی‌ها**:
- همیشه با `/` شروع می‌شود
- مستقل از دایرکتوری فعلی است (همیشه کار می‌کند)
- بدون ابهام است و دقیقاً یک مکان را مشخص می‌کند

**مثال‌ها**:

```bash
/home/amir/Documents/file.txt
/etc/nginx/nginx.conf
/var/log/syslog
/usr/bin/ls
/root/
```

**کاربرد**:

```bash
# استفاده از مسیر مطلق برای دسترسی به فایل از هر جایی
cat /home/amir/Documents/file.txt

# کپی فایل از یک مسیر مطلق به مسیر مطلق دیگر
cp /home/amir/file1.txt /backup/file1.txt

# تغییر دایرکتوری با مسیر مطلق
cd /var/log
```

### ۲.۲. مسیر نسبی (Relative Path)

**تعریف**: مسیری که نسبت به **دایرکتوری فعلی** شما تعریف می‌شود و از آنجا شروع به پیدا کردن مسیر می‌کند.

**ویژگی‌ها**:
- با `/` شروع نمی‌شود (مگر اینکه دایرکتوری فعلی ریشه باشد)
- به دایرکتوری فعلی شما وابسته است
- کوتاه‌تر و سریع‌تر برای تایپ کردن است

**مثال‌ها**:

```bash
Documents/file.txt          # فایل در دایرکتوری Documents در مسیر فعلی
../file.txt                 # فایل در دایرکتوری والد
./script.sh                 # فایل در دایرکتوری فعلی
../../etc/hosts             # دو سطح بالا و سپس دایرکتوری etc
```

**کاربرد**:

```bash
# فرض کنید در /home/amir هستید
cd Documents                # رفتن به /home/amir/Documents
ls ../                      # لیست محتویات /home/amir
cat ../../etc/hosts         # نمایش فایل /etc/hosts
```

### ۲.۳. مقایسه مسیر مطلق و نسبی

| ویژگی | مسیر مطلق (Absolute) | مسیر نسبی (Relative) |
|--------|----------------------|----------------------|
| **شروع** | با `/` شروع می‌شود | با `/` شروع نمی‌شود |
| **وابستگی** | مستقل از دایرکتوری فعلی | وابسته به دایرکتوری فعلی |
| **طول** | معمولاً بلندتر | معمولاً کوتاه‌تر |
| **ابهام** | بدون ابهام | ممکن است مبهم باشد |
| **کاربرد** | در اسکریپت‌ها و تنظیمات | در ترمینال و کار روزمره |

## ۳. کاراکترهای خاص در مسیرها

### ۳.۱. `.` (دایرکتوری فعلی)

**توضیحات**: نماد نقطه (Dot) به **دایرکتوری فعلی** اشاره دارد.

**کاربردها**:

```bash
# اجرای یک برنامه در دایرکتوری فعلی
./script.sh

# کپی فایل به دایرکتوری فعلی
cp /home/file.txt .

# لیست فایل‌های دایرکتوری فعلی
ls .
```

### ۳.۲. `..` (دایرکتوری والد)

**توضیحات**: دو نقطه (Double Dot) به **دایرکتوری والد** (یک سطح بالا) اشاره دارد.

**کاربردها**:

```bash
# رفتن به یک سطح بالاتر
cd ..

# رفتن به دو سطح بالاتر
cd ../..

# کپی فایل از دایرکتوری والد
cp ../file.txt .

# نمایش فایل‌های دایرکتوری والد
ls ..
```

### ۳.۳. `~` (دایرکتوری خانه)

**توضیحات**: علامت تیلد (Tilde) به **دایرکتوری خانه کاربر فعلی** اشاره دارد.

**کاربردها**:

```bash
# رفتن به دایرکتوری خانه
cd ~

# رفتن به دایرکتوری خانه کاربر دیگر
cd ~another_user

# دسترسی به فایل در دایرکتوری خانه
cat ~/.bashrc

# کپی فایل به دایرکتوری خانه
cp file.txt ~/
```

### ۳.۴. `-` (دایرکتوری قبلی)

**توضیحات**: علامت خط تیره (Dash) به **دایرکتوری قبلی** که در آن بودید اشاره دارد.

**کاربردها**:

```bash
# رفتن به دایرکتوری قبلی
cd -

# مثال کاربردی
cd /etc      # رفتن به /etc
cd /home     # رفتن به /home
cd -         # بازگشت به /etc
cd -         # بازگشت به /home
```

### ۳.۵. `/` (ریشه سیستم)

**توضیحات**: اسلش تنها (Slash) به **ریشه سیستم فایل** اشاره دارد که بالاترین سطح دایرکتوری است.

**کاربردها**:

```bash
# رفتن به ریشه سیستم
cd /

# دسترسی به فایل در ریشه
cat /etc/hosts

# لیست محتویات ریشه
ls /
```

## ۴. قوانین نوشتن مسیرها

### ۴.۱. حساسیت به بزرگ و کوچک بودن حروف (Case Sensitivity)

لینوکس به بزرگ و کوچک بودن حروف حساس است. بنابراین `File.txt` و `file.txt` دو فایل کاملاً متفاوت هستند.

```bash
# دو فایل متفاوت
touch File.txt
touch file.txt
ls
# خروجی: File.txt  file.txt
```

### ۴.۲. فاصله در نام فایل‌ها

اگر نام فایل یا دایرکتوری دارای **فاصله** باشد، باید از نقل‌قول یا کاراکتر فرار استفاده کنید.

**روش اول: نقل‌قول**:

```bash
ls "My Documents"
cat "My Documents/file.txt"
cd "My Documents"
```

**روش دوم: کاراکتر فرار (`\`)**:

```bash
ls My\ Documents
cat My\ Documents/file.txt
cd My\ Documents
```

### ۴.۳. کاراکترهای مجاز و غیرمجاز

**کاراکترهای مجاز در نام فایل‌ها و دایرکتوری‌ها**:
- حروف انگلیسی (a-z، A-Z)
- اعداد (0-9)
- زیرخط (`_`)
- خط تیره (`-`)
- نقطه (`.`)

**کاراکترهای غیرمجاز یا نامناسب**:
- اسلش (`/`) - جداکننده دایرکتوری‌ها
- فاصله - نیاز به نقل‌قول دارد
- ستاره (`*`) - کاراکتر جایگزین
- علامت سوال (`?`) - کاراکتر جایگزین

### ۴.۴. طول مسیر

حداکثر طول مسیر در لینوکس معمولاً **۴۰۹۶ کاراکتر** است، اما بهتر است مسیرها را کوتاه و خوانا نگه دارید.

## ۵. مسیرهای مهم سیستم

### ۵.۱. مسیرهای اصلی لینوکس

| مسیر | توضیحات |
|------|----------|
| `/` | ریشه سیستم فایل |
| `/bin` | دستورات ضروری سیستم (Binary) |
| `/boot` | فایل‌های بوت (هسته، GRUB) |
| `/dev` | فایل‌های دستگاه‌ها (Devices) |
| `/etc` | فایل‌های پیکربندی سیستم |
| `/home` | دایرکتوری‌های خانه کاربران |
| `/lib` | کتابخانه‌های ضروری سیستم |
| `/media` | نقاط نصب دستگاه‌های قابل حمل |
| `/mnt` | نقاط نصب موقت |
| `/opt` | نرم‌افزارهای اختیاری (Optional) |
| `/proc` | سیستم فایل مجازی (اطلاعات فرآیندها) |
| `/root` | دایرکتوری خانه کاربر ریشه (root) |
| `/run` | فایل‌های موقت زمان اجرا |
| `/sbin` | دستورات مدیریتی سیستم |
| `/srv` | داده‌های سرویس‌ها |
| `/sys` | سیستم فایل مجازی (اطلاعات هسته) |
| `/tmp` | فایل‌های موقت (پس از ری‌استارت پاک می‌شود) |
| `/usr` | نرم‌افزارهای کاربری (User System Resources) |
| `/var` | داده‌های متغیر (لاگ‌ها، اسپول) |

### ۵.۲. مشاهده مسیر فعلی

```bash
# نمایش مسیر کامل دایرکتوری فعلی
pwd

# خروجی مثال
/home/amir/Documents
```

## ۶. مسیرها در دستورات

### ۶.۱. دستور `cd` (Change Directory)

```bash
# رفتن به دایرکتوری با مسیر مطلق
cd /etc/nginx

# رفتن به دایرکتوری با مسیر نسبی
cd Documents
cd ./Documents

# رفتن به دایرکتوری خانه
cd ~
cd

# رفتن به دایرکتوری قبلی
cd -

# رفتن به یک سطح بالاتر
cd ..

# رفتن به دو سطح بالاتر
cd ../..
```

### ۶.۲. دستور `ls` (List)

```bash
# لیست دایرکتوری فعلی
ls

# لیست دایرکتوری با مسیر مطلق
ls /etc

# لیست دایرکتوری با مسیر نسبی
ls ../Documents

# لیست با جزئیات و مسیر
ls -la /home/amir
```

### ۶.۳. دستور `cp` (Copy)

```bash
# کپی با مسیر مطلق
cp /home/amir/file.txt /backup/file.txt

# کپی با مسیر نسبی
cp file.txt ./backup/

# کپی به دایرکتوری بالاتر
cp file.txt ../

# کپی با مسیر خانه
cp ~/file.txt ~/Documents/
```

### ۶.۴. دستور `mv` (Move/Rename)

```bash
# جابجایی فایل
mv /home/amir/file.txt /tmp/file.txt

# تغییر نام
mv file.txt newname.txt

# جابجایی با مسیر نسبی
mv file.txt ../Documents/
```

### ۶.۵. دستور `rm` (Remove)

```bash
# حذف فایل با مسیر مطلق
rm /tmp/file.txt

# حذف با مسیر نسبی
rm ./file.txt

# حذف فایل در دایرکتوری والد
rm ../file.txt
```

## ۷. مسیرها و متغیرهای محیطی

### ۷.۱. متغیر `PATH`

متغیر `PATH` لیستی از دایرکتوری‌هایی است که سیستم برای پیدا کردن دستورات در آنها جستجو می‌کند.

```bash
# نمایش مسیرهای جستجو
echo $PATH
# خروجی: /usr/local/sbin:/usr/local/bin:/usr/sbin:/usr/bin:/sbin:/bin

# افزودن یک دایرکتوری به PATH
export PATH=$PATH:/my/custom/bin
```

**نکته**: اگر دستوری را اجرا می‌کنید و پیام `command not found` می‌بینید، به این معناست که آن دستور در هیچ‌کدام از دایرکتوری‌های `PATH` وجود ندارد.

### ۷.۲. متغیر `HOME`

متغیر `HOME` مسیر دایرکتوری خانه کاربر فعلی را مشخص می‌کند.

```bash
# نمایش دایرکتوری خانه
echo $HOME
# خروجی: /home/amir

# استفاده در دستورات
cp file.txt $HOME/Documents/
```

### ۷.۳. متغیر `PWD`

متغیر `PWD` مسیر دایرکتوری فعلی را نشان می‌دهد.

```bash
# نمایش دایرکتوری فعلی
echo $PWD
# خروجی: /home/amir/Documents

# استفاده در اسکریپت‌ها
echo "Current directory: $PWD"
```

### ۷.۴. متغیر `OLDPWD`

متغیر `OLDPWD` مسیر دایرکتوری قبلی را نشان می‌دهد.

```bash
# نمایش دایرکتوری قبلی
echo $OLDPWD
# خروجی: /etc
```

## ۸. مسیرها در اسکریپت‌نویسی

### ۸.۱. دریافت دایرکتوری اسکریپت

```bash
#!/bin/bash
# دریافت مسیر کامل اسکریپت
SCRIPT_PATH=$(readlink -f "$0")

# دریافت دایرکتوری اسکریپت
SCRIPT_DIR=$(dirname "$SCRIPT_PATH")

echo "Script path: $SCRIPT_PATH"
echo "Script directory: $SCRIPT_DIR"
```

### ۸.۲. کار با مسیرها در اسکریپت

```bash
#!/bin/bash
# تعیین دایرکتوری پایه
BASE_DIR="/home/amir/project"
LOG_DIR="$BASE_DIR/logs"
DATA_DIR="$BASE_DIR/data"

# ایجاد دایرکتوری‌ها
mkdir -p "$LOG_DIR"
mkdir -p "$DATA_DIR"

# استفاده از مسیرها
cp "$DATA_DIR/file.txt" "$LOG_DIR/"
```

### ۸.۳. تبدیل مسیرها

```bash
# تبدیل مسیر نسبی به مطلق
realpath ./file.txt
# خروجی: /home/amir/file.txt

# دریافت نام دایرکتوری یک مسیر
dirname /home/amir/file.txt
# خروجی: /home/amir

# دریافت نام فایل از مسیر
basename /home/amir/file.txt
# خروجی: file.txt
```

## ۹. خطاهای رایج در مسیرها

### ۹.۱. خطای "No such file or directory"

```bash
# اشتباه ❌
cat /home/amir/nonexistent.txt
# خروجی: cat: /home/amir/nonexistent.txt: No such file or directory

# درست ✅
cat /home/amir/existing.txt
```

### ۹.۲. اشتباه در علامت‌ها

```bash
# اشتباه ❌ (به جای / از \ استفاده شده)
cd C:\users

# درست ✅
cd /home/amir
```

### ۹.۳. فراموش کردن فاصله در نام فایل‌ها

```bash
# اشتباه ❌
cd My Documents
# خروجی: cd: My: No such file or directory

# درست ✅
cd "My Documents"
cd My\ Documents
```

### ۹.۴. اشتباه در حروف بزرگ/کوچک

```bash
# اشتباه ❌
cd /Home

# درست ✅
cd /home
```

### ۹.۵. استفاده از فضای اضافی

```bash
# اشتباه ❌ (فاصله بین cd و /home)
cd  /home

# درست ✅
cd /home
```

## ۱۰. تمرین‌های عملی

### ۱۰.۱. تمرین ساده

```bash
# 1. مشاهده مسیر فعلی
pwd

# 2. رفتن به ریشه سیستم
cd /
pwd

# 3. رفتن به دایرکتوری خانه
cd ~
pwd

# 4. رفتن به دایرکتوری /etc
cd /etc
pwd

# 5. بازگشت به دایرکتوری قبلی
cd -

# 6. ایجاد دایرکتوری با فاصله
mkdir "My Projects"

# 7. ورود به دایرکتوری
cd "My Projects"

# 8. بازگشت به خانه
cd ~
```

### ۱۰.۲. تمرین پیشرفته

```bash
# 1. ایجاد ساختار دایرکتوری
mkdir -p ~/project/{src,bin,doc,log}

# 2. ایجاد فایل‌ها
touch ~/project/src/main.py
touch ~/project/README.md

# 3. مشاهده ساختار
tree ~/project

# 4. کپی فایل با مسیر مطلق
cp ~/project/src/main.py ~/project/bin/

# 5. تغییر نام با مسیر نسبی
cd ~/project
mv src/main.py src/app.py

# 6. نمایش مسیر مطلق فایل‌ها
realpath src/app.py

# 7. حذف دایرکتوری
cd ~
rm -rf project
```

## ۱۱. خلاصه و نتیجه‌گیری

مسیرها در لینوکس، آدرس‌های فایل‌ها و دایرکتوری‌ها در سیستم فایل هستند. درک صحیح مسیرها برای کار با لینوکس ضروری است.

### خلاصه انواع مسیرها

| نوع مسیر | توضیحات | مثال |
|----------|----------|-------|
| **مسیر مطلق** | از ریشه (`/`) شروع می‌شود | `/home/amir/file.txt` |
| **مسیر نسبی** | از دایرکتوری فعلی شروع می‌شود | `Documents/file.txt` |
| **دایرکتوری فعلی** | با `.` نشان داده می‌شود | `./script.sh` |
| **دایرکتوری والد** | با `..` نشان داده می‌شود | `../file.txt` |
| **دایرکتوری خانه** | با `~` نشان داده می‌شود | `~/Documents` |
| **دایرکتوری قبلی** | با `-` نشان داده می‌شود | `cd -` |

## سؤالات متداول

**سؤال: تفاوت مسیر مطلق و نسبی چیست؟**  
مسیر مطلق از ریشه سیستم (`/`) شروع می‌شود و مستقل از دایرکتوری فعلی است، در حالی که مسیر نسبی از دایرکتوری فعلی شروع می‌شود و به آن وابسته است.

**سؤال: چگونه مسیر فعلی را ببینم؟**  
با دستور `pwd`.

**سؤال: چگونه به دایرکتوری خانه بروم؟**  
با دستور `cd` یا `cd ~`.

**سؤال: چگونه به دایرکتوری قبلی برگردم؟**  
با دستور `cd -`.

**سؤال: آیا مسیرها به حروف بزرگ/کوچک حساس هستند؟**  
بله، لینوکس به حروف بزرگ و کوچک حساس است.

**سؤال: چگونه با نام فایل‌های دارای فاصله کار کنم؟**

## مفاهیم مرتبط

- **دایرکتوری (Directory)**: پوشه‌ای برای سازماندهی فایل‌ها
- **سیستم فایل (Filesystem)**: روش سازماندهی و ذخیره‌سازی داده‌ها
- **ریشه (Root)**: بالاترین سطح سیستم فایل
- **دایرکتوری خانه (Home Directory)**: دایرکتوری شخصی کاربر
- **متغیرهای محیطی (Environment Variables)**: متغیرهای سراسری سیستم
