#  (تاریخچه دستورات در لینوکس) - Command History

---

## معرفی و مرور کلی

**تاریخچه دستورات** (Command History) یکی از قدرتمندترین و پرکاربردترین ویژگی‌های خط فرمان در لینوکس است که تمام دستورات تایپ شده توسط کاربر را در یک جلسه (Session) یا در طول زمان ذخیره می‌کند. این قابلیت به شما امکان می‌دهد تا دستورات قبلی خود را مرور کنید، آنها را دوباره اجرا کنید، ویرایش کنید و از آنها برای افزایش بهره‌وری و سرعت کار خود استفاده کنید.

تاریخچه دستورات نه تنها یک ابزار صرفه‌جویی در زمان است، بلکه یک منبع ارزشمند برای یادگیری، عیب‌یابی و مستندسازی فعالیت‌های شما در سیستم محسوب می‌شود. با تسلط بر این ویژگی، می‌توانید کار با خط فرمان را بسیار سریع‌تر و حرفه‌ای‌تر انجام دهید.

---

## ۱. تاریخچه دستورات چیست و چگونه کار می‌کند؟

### ۱.۱. تعریف دقیق

**تاریخچه دستورات** (Command History) یک لیست از تمام دستوراتی است که یک کاربر در شل (Shell) خود تایپ کرده است. این لیست در حافظه (برای جلسه فعلی) و در یک فایل (برای جلسات آینده) ذخیره می‌شود و به شما امکان می‌دهد تا به دستورات قبلی خود دسترسی پیدا کنید، آنها را دوباره اجرا کنید یا ویرایش کنید.

### ۱.۲. نحوه عملکرد

هنگامی که یک دستور در ترمینال تایپ و اجرا می‌شود، شل آن را به لیست تاریخچه اضافه می‌کند. این لیست در دو مکان ذخیره می‌شود:

- **حافظه (Memory)**: برای دسترسی سریع در جلسه فعلی
- **فایل تاریخچه**: برای ذخیره‌سازی دائمی بین جلسات

**فایل‌های تاریخچه در شل‌های مختلف**:

| شل | فایل تاریخچه پیش‌فرض |
|-----|----------------------|
| **Bash** | `~/.bash_history` |
| **Zsh** | `~/.zsh_history` |
| **Fish** | `~/.local/share/fish/fish_history` |

### ۱.۳. اهمیت و مزایا

- **افزایش سرعت کار**: با استفاده از دستورات قبلی، نیازی به تایپ مجدد آنها نیست.
- **کاهش اشتباهات**: با استفاده مجدد از دستورات صحیح، خطاهای تایپی کاهش می‌یابد.
- **یادگیری**: با مرور تاریخچه، می‌توانید دستورات جدید و نحوه استفاده از آنها را یاد بگیرید.
- **عیب‌یابی**: تاریخچه به شما کمک می‌کند تا ببینید چه دستوراتی اجرا شده و چه خطاهایی رخ داده است.
- **مستندسازی**: تاریخچه به عنوان یک لاگ از فعالیت‌های شما عمل می‌کند.
- **خودکارسازی**: می‌توانید از تاریخچه برای ایجاد اسکریپت‌های تکراری استفاده کنید.

## ۲. مشاهده تاریخچه دستورات

### ۲.۱. دستور `history`

ساده‌ترین راه برای مشاهده تاریخچه دستورات، استفاده از دستور `history` است.

```bash
# نمایش تمام تاریخچه
history

# نمایش آخرین N دستور
history 10

# نمایش تاریخچه با شماره خطوط
history | less
```

**خروجی مثال**:

```text
  501  ls -la
  502  cd /etc
  503  cat /etc/hosts
  504  grep "localhost" /etc/hosts
  505  sudo apt update
  506  sudo apt upgrade
  507  history
```

### ۲.۲. نمایش تاریخچه با جستجو

```bash
# جستجوی دستورات حاوی یک کلمه خاص
history | grep "apt"

# نمایش دستورات در یک بازه زمانی خاص
history 20 | tail -10
```

### ۲.۳. نمایش تاریخچه با جزئیات بیشتر

```bash
# نمایش تاریخچه با زمان اجرا (نیاز به تنظیم)
HISTTIMEFORMAT="%F %T " history

# یا
export HISTTIMEFORMAT="%Y-%m-%d %H:%M:%S "
history
```

### ۲.۴. نمایش تاریخچه سایر کاربران (با دسترسی ریشه)

```bash
# نمایش تاریخچه کاربر دیگر
cat /home/username/.bash_history

# یا
sudo cat /home/username/.bash_history
```

## ۳. اجرای مجدد دستورات از تاریخچه

### ۳.۱. کلیدهای بالا و پایین

ساده‌ترین روش برای اجرای مجدد دستورات قبلی:

- **فلش بالا (`↑`)**: رفتن به دستور قبلی
- **فلش پایین (`↓`)**: رفتن به دستور بعدی

### ۳.۲. استفاده از `!` برای اجرا

```bash
# اجرای آخرین دستور
!!

# اجرای دستور شماره N
!503

# اجرای آخرین دستور شروع شده با 'apt'
!apt

# اجرای آخرین دستور حاوی 'update'
!?update

# اجرای آخرین دستور و نمایش آن
!-1:p
```

### ۳.۳. اجرای مجدد با جایگزینی

```bash
# اجرای آخرین دستور و جایگزینی 'old' با 'new'
!!:s/old/new/

# مثال: اگر آخرین دستور 'ls -l old.txt' بود
!!:s/old/new/   # اجرا می‌شود: ls -l new.txt
```

### ۳.۴. اجرای مجدد دستورات خاص

```bash
# اجرای آخرین دستور حاوی 'grep'
!grep

# اجرای دستور شماره 500
!500

# اجرای آخرین دستور با جایگزینی
^old^new^   # مثال: ^old^new^
```

## ۴. ویرایش دستورات از تاریخچه

### ۴.۱. ویرایش با کلیدها

- **فلش بالا (`↑`)**: نمایش دستور قبلی برای ویرایش
- **Ctrl + R**: جستجوی تعاملی در تاریخچه

### ۴.۲. جستجوی تعاملی با `Ctrl + R`

این یکی از قدرتمندترین روش‌های استفاده از تاریخچه است:

```bash
# فشردن Ctrl + R
(reverse-i-search)`': 

# شروع به تایپ کنید:
(reverse-i-search)`apt': sudo apt update
```

- با فشردن **Ctrl + R** مجدد، به نتایج قبلی می‌روید.
- با فشردن **Enter**، دستور را اجرا می‌کنید.
- با فشردن **Ctrl + C**، جستجو را لغو می‌کنید.
- با فشردن **Ctrl + G**، از جستجو خارج می‌شوید.

### ۴.۳. ویرایش با `fc` (Fix Command)

```bash
# باز کردن آخرین دستور در ویرایشگر پیش‌فرض
fc

# باز کردن دستور شماره 500 در ویرایشگر
fc 500

# باز کردن دستورات 500 تا 510
fc 500 510

# باز کردن دستور با استفاده از الگو
fc -e vim 500   # ویرایش با vim
```

### ۴.۴. ویرایش با `Ctrl + X` + `Ctrl + E`

- در Bash، با فشردن **Ctrl + X** و سپس **Ctrl + E**، دستور فعلی در ویرایشگر پیش‌فرض باز می‌شود.

## ۵. مدیریت فایل تاریخچه

### ۵.۱. مشاهده فایل تاریخچه

```bash
# مشاهده فایل تاریخچه Bash
cat ~/.bash_history

# مشاهده با صفحه‌بندی
less ~/.bash_history

# مشاهده آخرین ۱۰ دستور
tail -10 ~/.bash_history
```

### ۵.۲. پاک کردن تاریخچه

```bash
# پاک کردن تاریخچه جلسه فعلی
history -c

# پاک کردن فایل تاریخچه
> ~/.bash_history

# پاک کردن کامل (جلسه و فایل)
history -c && > ~/.bash_history
```

### ۵.۳. تنظیمات فایل تاریخچه

```bash
# تنظیم تعداد دستورات ذخیره شده در حافظه
export HISTSIZE=1000

# تنظیم تعداد دستورات ذخیره شده در فایل
export HISTFILESIZE=2000

# غیرفعال‌سازی تاریخچه (برای جلسه فعلی)
export HISTSIZE=0

# فعال‌سازی مجدد
export HISTSIZE=1000
```

### ۵.۴. ادغام تاریخچه از چند ترمینال

```bash
# فعال‌سازی اشتراک تاریخچه بین جلسات
export PROMPT_COMMAND="history -a; history -c; history -r; $PROMPT_COMMAND"

# این دستور در هر پرامپت، تاریخچه را به‌روزرسانی می‌کند
```

## ۶. تنظیمات پیشرفته تاریخچه

### ۶.۱. حذف دستورات تکراری

```bash
# حذف دستورات تکراری از تاریخچه
export HISTCONTROL=ignoredups

# حذف دستورات تکراری در طول زمان
export HISTCONTROL=erasedups

# ترکیب تنظیمات
export HISTCONTROL=ignoreboth
```

### ۶.۲. حذف دستورات خاص

```bash
# حذف دستورات شروع شده با فاصله از تاریخچه
export HISTCONTROL=ignorespace

# مثال: دستور زیر در تاریخچه ذخیره نمی‌شود
 secret_command
```

### ۶.۳. فرمت زمان در تاریخچه

```bash
# افزودن زمان به تاریخچه
export HISTTIMEFORMAT="%Y-%m-%d %H:%M:%S "

# مشاهده تاریخچه با زمان
history
```

### ۶.۴. فیلتر کردن دستورات حساس

```bash
# عدم ذخیره دستورات حاوی عبارت خاص
export HISTIGNORE="ls:cd:pwd:exit:clear"

# عدم ذخیره دستورات شروع شده با فاصله
export HISTCONTROL=ignorespace
```

### ۶.۵. فایل تاریخچه سفارشی

```bash
# تعیین فایل تاریخچه سفارشی
export HISTFILE=~/.my_custom_history

# مشاهده فایل تاریخچه سفارشی
cat $HISTFILE
```

## ۷. جستجو و مدیریت پیشرفته

### ۷.۱. جستجوی پیشرفته با `grep`

```bash
# جستجوی دستورات حاوی 'ssh'
history | grep "ssh"

# جستجوی دستورات با شماره‌گذاری
history | grep -n "apt"

# نمایش دستورات در یک بازه زمانی خاص (با فرمت زمان)
history | grep "2024-01-"
```

### ۷.۲. حذف دستورات خاص از تاریخچه

```bash
# حذف یک دستور خاص از تاریخچه
history -d 500

# حذف بازه‌ای از دستورات
history -d 500-510

# حذف دستورات حاوی یک کلمه (با استفاده از ابزارهای جانبی)
# ابتدا تاریخچه را به فایل ذخیره کنید، فیلتر کنید و دوباره بارگذاری کنید
history -c
history -r
```

### ۷.۳. ذخیره و بازیابی تاریخچه

```bash
# ذخیره تاریخچه در یک فایل
history > ~/backup_history.txt

# بازیابی تاریخچه از فایل
history -r ~/backup_history.txt

# ادغام تاریخچه از فایل دیگر
history -n ~/other_history.txt
```

### ۷.۴. استفاده از تاریخچه در اسکریپت‌ها

```bash
#!/bin/bash

# دریافت آخرین دستور با استفاده از !!
last_command="$(history 1 | awk '{print $2}')"
echo "Last command was: $last_command"

# نمایش تعداد کل دستورات
total_commands=$(history 1 | head -1 | awk '{print $1}')
echo "Total commands in history: $total_commands"
```

# تنظیمات پیش‌فرض Bash

## ۹. خطاهای رایج و راه‌حل‌ها

### ۹.۱. تاریخچه در جلسات مختلف یکسان نیست

```bash
# مشکل: تاریخچه در ترمینال‌های مختلف متفاوت است
# راه‌حل: فعال‌سازی اشتراک تاریخچه
export PROMPT_COMMAND="history -a; history -c; history -r; $PROMPT_COMMAND"
```

### ۹.۲. تاریخچه خالی یا ناقص است

```bash
# مشکل: تاریخچه ذخیره نمی‌شود
# راه‌حل 1: بررسی تنظیمات
echo $HISTSIZE
echo $HISTFILESIZE

# راه‌حل 2: تنظیم مجدد
export HISTSIZE=1000
export HISTFILESIZE=2000

# راه‌حل 3: ذخیره دستی
history -a
```

### ۹.۳. دستورات تکراری در تاریخچه

```bash
# مشکل: دستورات تکراری زیاد است
# راه‌حل: حذف تکراری‌ها
export HISTCONTROL=ignoredups

# یا حذف کامل تکراری‌ها
export HISTCONTROL=erasedups
```

### ۹.۴. تاریخچه نمی‌تواند ذخیره شود

```bash
# مشکل: خطای ذخیره‌سازی تاریخچه
# راه‌حل 1: بررسی مجوزهای فایل
ls -la ~/.bash_history
chmod 600 ~/.bash_history

# راه‌حل 2: ایجاد فایل خالی
touch ~/.bash_history
```

## ۱۰. تمرین‌های عملی

### ۱۰.۱. تمرین پایه

```bash
# 1. اجرای چند دستور
ls -la
cd /etc
cat /etc/hosts
pwd
echo "Hello World"

# 2. مشاهده تاریخچه
history

# 3. نمایش آخرین ۳ دستور
history 3

# 4. اجرای آخرین دستور
!!

# 5. اجرای دستور شماره ۳ (از خروجی history)
!3
```

### ۱۰.۲. تمرین با جستجو

```bash
# 1. جستجوی دستورات حاوی 'ls'
history | grep "ls"

# 2. جستجوی دستورات با شماره‌گذاری
history | grep -n "cd"

# 3. استفاده از Ctrl + R برای جستجو
# Ctrl + R را فشار دهید و 'cat' را تایپ کنید

# 4. جستجوی معکوس
Ctrl + R + "host"
```

### ۱۰.۳. تمرین مدیریت تاریخچه

```bash
# 1. پاک کردن تاریخچه جلسه فعلی
history -c

# 2. مشاهده فایل تاریخچه
cat ~/.bash_history

# 3. ذخیره تاریخچه در یک فایل
history > ~/backup_history.txt

# 4. بازیابی تاریخچه از فایل
history -r ~/backup_history.txt
```

## ۱۱. خلاصه و نتیجه‌گیری

### ۱۱.۱. نکات کلیدی

- **تاریخچه دستورات** لیستی از تمام دستورات اجرا شده توسط کاربر است.
- با **فلش بالا/پایین** می‌توانید دستورات قبلی را مرور کنید.
- با **Ctrl + R** می‌توانید به صورت تعاملی در تاریخچه جستجو کنید.
- با **`!`** می‌توانید دستورات را به سرعت اجرا کنید.
- فایل تاریخچه در `~/.bash_history` (برای Bash) ذخیره می‌شود.
- با **`history -c`** می‌توانید تاریخچه را پاک کنید.

### ۱۱.۲. دستورات مفید

| دستور | توضیحات |
|--------|----------|
| `history` | نمایش تاریخچه |
| `history N` | نمایش آخرین N دستور |
| `!!` | اجرای آخرین دستور |
| `!N` | اجرای دستور شماره N |
| `!word` | اجرای آخرین دستور با word |
| `Ctrl + R` | جستجوی تعاملی |
| `history -c` | پاک کردن تاریخچه |
| `history -d N` | حذف دستور N |

### ۱۱.۳. نکات امنیتی

- از ذخیره دستورات حاوی رمز عبور خودداری کنید.
- برای دستورات حساس، از `HISTCONTROL=ignorespace` استفاده کنید.
- تاریخچه خود را به طور منظم بررسی و پاکسازی کنید.

## سؤالات متداول

**سؤال: چگونه دستورات تکراری را از تاریخچه حذف کنم؟**  
با تنظیم `export HISTCONTROL=ignoredups`.

**سؤال: چگونه از ذخیره یک دستور در تاریخچه جلوگیری کنم؟**  
با قرار دادن یک فاصله قبل از دستور: ` secret_command`.

**سؤال: فایل تاریخچه کجاست؟**  
در Bash: `~/.bash_history`، در Zsh: `~/.zsh_history`.

**سؤال: چگونه تاریخچه را در چند ترمینال به اشتراک بگذارم؟**  
با تنظیم `PROMPT_COMMAND="history -a; history -c; history -r"`.

**سؤال: چگونه یک دستور خاص را از تاریخچه حذف کنم؟**  
با `history -d N` که N شماره دستور است.

**سؤال: چگونه جستجوی معکوس (Ctrl+R) را متوقف کنم؟**  
با فشردن `Ctrl + C` یا `Ctrl + G`.

## مفاهیم مرتبط

- **شل (Shell)**: محیط اجرای دستورات
- **تاریخچه (History)**: ذخیره و بازیابی دستورات قبلی
- **جستجوی معکوس (Reverse Search)**: جستجوی تعاملی با `Ctrl + R`
- **متغیرهای محیطی (Environment Variables)**: تنظیمات تاریخچه
- **فایل پیکربندی (Configuration File)**: `.bashrc`، `.zshrc`
