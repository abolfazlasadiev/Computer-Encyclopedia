# حلقه while در VHDL — تحلیل جامع و عمیق

## مقدمه: تکرار شرطی در VHDL

تصور کنید در حال **دویدن** هستید. تا زمانی که **نفس دارید** می‌دوید، اما وقتی خسته شدید، می‌ایستید. این دقیقاً همان کاری است که حلقه **`while`** در VHDL انجام می‌دهد — **تکرار** تا زمانی که یک شرط برقرار است.

حلقه `while` یکی از **دستورات ترتیبی** مهم در VHDL است که برای:
- **تکرار** تا زمانی که شرط برقرار است
- **پیاده‌سازی** الگوریتم‌های با تعداد تکرار نامشخص
- **پردازش** داده‌ها تا رسیدن به شرط خاص
- **شبیه‌سازی** رفتارهای دینامیک

## ۱. ساختار حلقه `while`

### ۱.۱. ساختار کلی

```
┌─────────────────────────────────────────────────────────────────────┐
│                     WHILE LOOP STRUCTURE                          │
├─────────────────────────────────────────────────────────────────────┤
│                                                                   │
│  ┌─────────────────────────────────────────────────────────────┐  │
│  │  [label:] while condition loop                             │  │
│  │  ┌──────────────────────────────────────────────────────┐  │  │
│  │  │  -- statements                                       │  │  │
│  │  │  -- باید شرط را تغییر دهد                           │  │  │
│  │  │  -- می‌تواند شامل:                                  │  │  │
│  │  │  --   • انتساب به متغیر                            │  │  │
│  │  │  --   • if, case                                   │  │  │
│  │  │  --   • next, exit                                 │  │  │
│  │  │  --   • loop تو در تو                              │  │  │
│  │  └──────────────────────────────────────────────────────┘  │  │
│  │  end loop [label];                                      │  │
│  └─────────────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────────────┘
```

### ۱.۲. انواع حلقه `while`

```vhdl
-- ===== 1. while با شرط ساده =====
while i < 10 loop
    -- statements
    i := i + 1;  -- تغییر شرط
end loop;

-- ===== 2. while با شرط ترکیبی =====
while (i < 10) and (done = false) loop
    -- statements
    i := i + 1;
end loop;

-- ===== 3. while با label =====
SEARCH_LOOP: while not found loop
    -- statements
    if data = target then
        found := true;
    end if;
end loop SEARCH_LOOP;

-- ===== 4. while با exit =====
while true loop  -- حلقه بی‌نهایت
    -- statements
    exit when condition;  -- خروج شرطی
end loop;
```

### ۱.۳. مثال‌های ساده

```vhdl
library ieee;
use ieee.std_logic_1164.all;
use ieee.numeric_std.all;

entity while_example is
    port (
        clk     : in  std_logic;
        rst     : in  std_logic;
        start   : in  std_logic;
        
        result  : out integer;
        done    : out std_logic
    );
end entity;

architecture rtl of while_example is
begin
    process(clk, rst)
        variable i : integer := 0;
        variable sum : integer := 0;
        variable found : boolean := false;
    begin
        if rst = '1' then
            result <= 0;
            done <= '0';
            
        elsif rising_edge(clk) then
            if start = '1' then
                -- ===== while ساده =====
                i := 0;
                sum := 0;
                while i < 10 loop
                    sum := sum + i;
                    i := i + 1;
                end loop;
                -- sum = 0 + 1 + 2 + ... + 9 = 45
                
                -- ===== while با شرط ترکیبی =====
                i := 0;
                found := false;
                while (i < 100) and (not found) loop
                    if i * i = 100 then
                        found := true;
                    end if;
                    i := i + 1;
                end loop;
                
                result <= sum;
                done <= '1';
            end if;
        end if;
    end process;
end architecture;
```

## ۲. شرط در حلقه `while`

### ۲.۱. انواع شرط

```vhdl
-- ===== 1. شرط با متغیر =====
while i < 10 loop
    i := i + 1;
end loop;

-- ===== 2. شرط با boolean =====
while not done loop
    -- statements
    if condition then
        done := true;
    end if;
end loop;

-- ===== 3. شرط ترکیبی (AND) =====
while (i < 10) and (j < 20) loop
    i := i + 1;
    j := j + 2;
end loop;

-- ===== 4. شرط ترکیبی (OR) =====
while (i < 10) or (done = false) loop
    -- statements
    i := i + 1;
end loop;

-- ===== 5. شرط با توابع =====
while (i < 100) and (is_valid(data) = true) loop
    -- statements
    i := i + 1;
end loop;
```

### ۲.۲. مثال‌های کامل

```vhdl
-- ===== مثال: یافتن ریشه مربع =====
process(clk)
    variable x : integer := 16;
    variable guess : integer := 0;
    variable found : boolean := false;
begin
    if rising_edge(clk) then
        guess := 0;
        found := false;
        
        -- پیدا کردن ریشه مربع
        while (guess * guess < x) and (not found) loop
            guess := guess + 1;
            if guess * guess = x then
                found := true;
            end if;
        end loop;
        
        if found then
            sqrt_out <= guess;
        else
            sqrt_out <= -1;  -- ریشه دقیق پیدا نشد
        end if;
    end if;
end process;

-- ===== مثال: الگوریتم Euclid برای GCD =====
process(clk)
    variable a, b : integer := 48;
    variable temp : integer;
begin
    if rising_edge(clk) then
        a := 48;
        b := 18;
        
        -- الگوریتم Euclid
        while b /= 0 loop
            temp := b;
            b := a mod b;
            a := temp;
        end loop;
        -- a = GCD(48, 18) = 6
        
        gcd_out <= a;
    end if;
end process;
```

## ۳. حلقه `while` در Process

### ۳.۱. Process ترکیبی با `while`

```vhdl
-- ===== Process ترکیبی با while =====
-- • بدون Clock
-- • محاسبات فوراً انجام می‌شود
-- • ممکن است حلقه بی‌نهایت ایجاد شود

library ieee;
use ieee.std_logic_1164.all;
use ieee.numeric_std.all;

entity comb_while is
    port (
        data_in  : in  integer;
        
        factorial : out integer;
        sqrt_root : out integer
    );
end entity;

architecture rtl of comb_while is
begin
    COMB_PROC: process(data_in)
        variable n : integer;
        variable result : integer;
        variable guess : integer;
    begin
        -- ===== محاسبه فاکتوریل با while =====
        n := data_in;
        result := 1;
        while n > 1 loop
            result := result * n;
            n := n - 1;
        end loop;
        factorial <= result;
        
        -- ===== یافتن ریشه با while =====
        guess := 0;
        while guess * guess <= data_in loop
            guess := guess + 1;
        end loop;
        sqrt_root <= guess - 1;
    end process COMB_PROC;
end architecture;
```

### ۳.۲. Process سنکرون با `while`

```vhdl
-- ===== Process سنکرون با while =====
-- • با Clock
-- • محاسبات در لبه Clock انجام می‌شود

library ieee;
use ieee.std_logic_1164.all;
use ieee.numeric_std.all;

entity sync_while is
    port (
        clk     : in  std_logic;
        rst     : in  std_logic;
        en      : in  std_logic;
        data_in : in  integer;
        
        result  : out integer
    );
end entity;

architecture rtl of sync_while is
begin
    SYNC_PROC: process(clk, rst)
        variable i : integer;
        variable sum : integer;
        variable done : boolean;
    begin
        if rst = '1' then
            result <= 0;
            
        elsif rising_edge(clk) then
            if en = '1' then
                -- ===== while با شرط متغیر =====
                i := 0;
                sum := 0;
                while i < data_in loop
                    sum := sum + i;
                    i := i + 1;
                end loop;
                result <= sum;
                
                -- ===== while با شرط boolean =====
                i := 1;
                done := false;
                while not done loop
                    if i * i > data_in then
                        done := true;
                    else
                        i := i + 1;
                    end if;
                end loop;
                -- i = ریشه مربع + 1
            end if;
        end if;
    end process;
end architecture;
```

## ۴. حلقه `while` با `next` و `exit`

### ۴.۱. `next` در حلقه `while`

```vhdl
-- ===== next =====
-- رفتن به تکرار بعدی

process(clk)
    variable i : integer := 0;
    variable sum : integer := 0;
begin
    if rising_edge(clk) then
        i := 0;
        sum := 0;
        while i < 10 loop
            i := i + 1;
            if i mod 2 = 0 then
                next;  -- اعداد زوج را رد کن
            end if;
            sum := sum + i;  -- فقط اعداد فرد
        end loop;
        -- sum = 1 + 3 + 5 + 7 + 9 = 25
        result <= sum;
    end if;
end process;
```

### ۴.۲. `exit` در حلقه `while`

```vhdl
-- ===== exit =====
-- خروج از حلقه

process(clk)
    variable i : integer := 0;
    variable sum : integer := 0;
begin
    if rising_edge(clk) then
        i := 0;
        sum := 0;
        while i < 100 loop
            i := i + 1;
            sum := sum + i;
            if sum > 1000 then
                exit;  -- خروج از حلقه
            end if;
        end loop;
        result <= sum;
    end if;
end process;
```

### ۴.۳. `next` و `exit` با label

```vhdl
-- ===== next و exit با label =====
process(clk)
    variable i : integer := 0;
    variable j : integer := 0;
    variable found : boolean := false;
begin
    if rising_edge(clk) then
        i := 0;
        found := false;
        
        OUTER_LOOP: while i < 10 loop
            i := i + 1;
            j := 0;
            
            INNER_LOOP: while j < 10 loop
                j := j + 1;
                if i = j then
                    next INNER_LOOP;  -- ادامه حلقه داخلی
                end if;
                if i * j = 20 then
                    found := true;
                    exit OUTER_LOOP;  -- خروج از حلقه بیرونی
                end if;
            end loop INNER_LOOP;
        end loop OUTER_LOOP;
    end if;
end process;
```

## ۵. حلقه `while` در Function و Procedure

### ۵.۱. `while` در Function

```vhdl
-- ===== Function با while =====
package while_pkg is
    function factorial(n : integer) return integer;
    function gcd(a, b : integer) return integer;
    function find_prime(n : integer) return integer;
end package;

package body while_pkg is
    -- ===== فاکتوریل با while =====
    function factorial(n : integer) return integer is
        variable result : integer := 1;
        variable i : integer := n;
    begin
        while i > 1 loop
            result := result * i;
            i := i - 1;
        end loop;
        return result;
    end function;
    
    -- ===== GCD با while =====
    function gcd(a, b : integer) return integer is
        variable x : integer := a;
        variable y : integer := b;
        variable temp : integer;
    begin
        while y /= 0 loop
            temp := y;
            y := x mod y;
            x := temp;
        end loop;
        return x;
    end function;
    
    -- ===== پیدا کردن عدد اول بعدی =====
    function find_prime(n : integer) return integer is
        variable num : integer := n + 1;
        variable is_prime : boolean;
        variable i : integer;
    begin
        while true loop
            is_prime := true;
            i := 2;
            while (i * i <= num) and is_prime loop
                if num mod i = 0 then
                    is_prime := false;
                end if;
                i := i + 1;
            end loop;
            if is_prime then
                return num;
            end if;
            num := num + 1;
        end loop;
    end function;
end package body;
```

### ۵.۲. `while` در Procedure

```vhdl
-- ===== Procedure با while =====
package proc_while_pkg is
    procedure divide(a, b : in integer; result, remainder : out integer);
    procedure reverse_array(arr : inout integer_vector);
end package;

package body proc_while_pkg is
    -- ===== تقسیم با while (بدون عملگر /) =====
    procedure divide(a, b : in integer; result, remainder : out integer) is
        variable x : integer := a;
        variable count : integer := 0;
    begin
        while x >= b loop
            x := x - b;
            count := count + 1;
        end loop;
        result := count;
        remainder := x;
    end procedure;
    
    -- ===== معکوس کردن آرایه با while =====
    procedure reverse_array(arr : inout integer_vector) is
        variable temp : integer;
        variable i : integer := arr'low;
        variable j : integer := arr'high;
    begin
        while i < j loop
            temp := arr(i);
            arr(i) := arr(j);
            arr(j) := temp;
            i := i + 1;
            j := j - 1;
        end loop;
    end procedure;
end package body;
```

## ۶. `while` vs `for`

### ۶.۱. جدول مقایسه

| ویژگی | `while` | `for` |
|--------|---------|-------|
| **شرط** | شرط boolean | range مشخص |
| **تعداد تکرار** | نامشخص (تا زمانی که شرط برقرار است) | مشخص (بر اساس range) |
| **کنترل** | باید خودتان متغیر را تغییر دهید | خودکار |
| **خطر حلقه بی‌نهایت** | ✅ وجود دارد | ❌ ندارد |
| **کاربرد** | الگوریتم‌های با تعداد تکرار نامشخص | پردازش آرایه‌ها و ساختارهای مشخص |
| **خوانایی** | برای الگوریتم‌های پیچیده | برای ساختارهای ساده |

### ۶.۲. چه زمانی از `while` استفاده کنیم؟

```vhdl
-- ===== ✅ استفاده از while =====
-- • تعداد تکرار مشخص نیست
-- • شرط پایان پیچیده است
-- • الگوریتم‌های تکراری (مثل Newton-Raphson)
-- • پردازش تا رسیدن به شرط خاص

-- ===== مثال: پیدا کردن عدد اول بعدی =====
num := n + 1;
while true loop
    if is_prime(num) then
        exit;
    end if;
    num := num + 1;
end loop;

-- ===== مثال: پردازش تا رسیدن به خطا =====
while (i < MAX) and (error = false) loop
    -- پردازش
    i := i + 1;
end loop;
```

### ۶.۳. تبدیل `for` به `while`

```vhdl
-- ===== for loop =====
for i in 0 to 10 loop
    sum := sum + i;
end loop;

-- ===== معادل while =====
i := 0;
while i <= 10 loop
    sum := sum + i;
    i := i + 1;
end loop;
```

### ۶.۴. تبدیل `while` به `for`

```vhdl
-- ===== while loop =====
i := 0;
while i < 10 loop
    sum := sum + i;
    i := i + 1;
end loop;

-- ===== معادل for =====
for i in 0 to 9 loop
    sum := sum + i;
end loop;
```

-- ===== ❌ خطرناک: حلقه بی‌نهایت =====
while true loop

while true loop

while (i < 10) and (not done) loop

i := 0;

i := 0;

constant MAX : integer := calculate_max_value(data);

## ۸. نکات پیشرفته حلقه `while`

### ۸.۱. `while` با multiple conditions

```vhdl
-- ===== while با چند شرط =====
process(clk)
    variable i : integer := 0;
    variable j : integer := 0;
    variable done : boolean := false;
begin
    if rising_edge(clk) then
        i := 0;
        j := 0;
        done := false;
        
        while (i < 10) and (j < 20) and (not done) loop
            i := i + 1;
            j := j + 2;
            if i * j > 100 then
                done := true;
            end if;
        end loop;
    end if;
end process;
```

### ۸.۲. `while` با `exit when`

```vhdl
-- ===== while با exit when =====
process(clk)
    variable i : integer := 0;
begin
    if rising_edge(clk) then
        i := 0;
        while i < 100 loop
            i := i + 1;
            exit when i > 50;  -- خروج زودهنگام
        end loop;
    end if;
end process;
```

### ۸.۳. `while` تو در تو

```vhdl
-- ===== while تو در تو =====
process(clk)
    variable i : integer := 0;
    variable j : integer := 0;
    variable found : boolean := false;
begin
    if rising_edge(clk) then
        i := 0;
        found := false;
        
        OUTER: while (i < 10) and (not found) loop
            i := i + 1;
            j := 0;
            
            INNER: while (j < 10) and (not found) loop
                j := j + 1;
                if i * j = 20 then
                    found := true;
                end if;
            end loop INNER;
        end loop OUTER;
    end if;
end process;
```

### ۸.۴. `while` با `assert`

```vhdl
-- ===== while با assert =====
process(clk)
    variable i : integer := 0;
begin
    if rising_edge(clk) then
        i := 0;
        while i < 10 loop
            i := i + 1;
            assert i <= 10
                report "i از محدوده خارج شد"
                severity error;
        end loop;
    end if;
end process;
```

i := 0;

while true loop

-- ===== ✅ راه‌حل =====

### ۹.۳. خطا: شرط همیشه false

### ۹.۴. خطا: استفاده از signal در شرط

```vhdl
-- ===== ❌ اشتباه =====
process(clk)
    signal i : integer := 0;  -- ❌ signal در Process
begin
    if rising_edge(clk) then

-- ===== ✅ راه‌حل =====
process(clk)
    variable i : integer := 0;  -- ✅ متغیر
begin
    if rising_edge(clk) then

            i := i + 1;    -- ✅ متغیر در حلقه

    end if;

```

    end loop;

### ۱۰.۱. جلوگیری از حلقه بی‌نهایت

```vhdl
-- ===== ✅ با شرط خروج =====
i := 0;
while i < MAX loop
    -- statements
    i := i + 1;
end loop;

-- ===== ✅ با exit =====
while true loop
    -- statements
    if condition then
        exit;
    end if;
end loop;

-- ===== ✅ با MAX counter =====
i := 0;
while (i < MAX) and (not done) loop
    -- statements
    i := i + 1;
end loop;
```

### ۱۰.۲. استفاده از label

```vhdl
-- ===== ✅ با label =====
SEARCH_LOOP: while not found loop
    -- statements
    if data = target then
        found := true;
    end if;
end loop SEARCH_LOOP;

-- ===== ❌ بدون label =====
while not found loop
    -- statements
    if data = target then
        found := true;
    end if;
end loop;
```

### ۱۰.۳. محدود کردن تو در تو

```vhdl
-- ===== ✅ تا ۳ سطح =====
OUTER: while i < 10 loop
    MIDDLE: while j < 10 loop
        INNER: while k < 10 loop
            -- statements
            k := k + 1;
        end loop INNER;
        j := j + 1;
    end loop MIDDLE;
    i := i + 1;
end loop OUTER;
```

### ۱۰.۴. مستندسازی

```vhdl
-- ===== ✅ با توضیحات =====
-- پیدا کردن ریشه مربع با روش Newton-Raphson
-- شرط: تا زمانی که خطا کمتر از epsilon باشد
while abs(guess * guess - x) > epsilon loop
    guess := (guess + x / guess) / 2;
end loop;
```

### ۱۰.۵. انتخاب بین `while` و `for`

```vhdl
-- ===== ✅ با while برای تعداد نامشخص =====
-- پیدا کردن اولین عدد اول
num := start;
while not is_prime(num) loop
    num := num + 1;
end loop;

-- ===== ✅ با for برای تعداد مشخص =====
-- پردازش آرایه
for i in arr'range loop
    sum := sum + arr(i);
end loop;
```

## ۱۱. خلاصه و جمع‌بندی

### جدول مقایسه حلقه‌ها

| ویژگی | `while` | `for` | `loop` |
|--------|---------|-------|--------|
| **شرط** | شرط boolean | range مشخص | بدون شرط |
| **تعداد تکرار** | نامشخص | مشخص | نامشخص |
| **کنترل** | دستی | خودکار | دستی |
| **خطر بی‌نهایت** | ✅ دارد | ❌ ندارد | ✅ دارد |
| **کاربرد** | الگوریتم‌های تکراری | پردازش آرایه‌ها | حلقه‌های بی‌نهایت |

### قوانین کلیدی

| قانون | توضیح |
|-------|-------|
| **تغییر شرط** | همیشه شرط را در حلقه تغییر دهید |
| **جلوگیری از بی‌نهایت** | از exit یا شرط خروج استفاده کنید |
| **متغیر** | از متغیرها (نه سیگنال‌ها) در حلقه استفاده کنید |
| **Label** | برای حلقه‌های تو در تو از label استفاده کنید |
| **سنتز** | while قابل سنتز است (با محدودیت‌هایی) |

### دستورات مهم

```vhdl
-- ===== while ساده =====
while condition loop
    -- statements
end loop;

-- ===== while با شرط ترکیبی =====
while (cond1) and (cond2) loop
    -- statements
end loop;

-- ===== while با label =====
LABEL: while condition loop
    -- statements
end loop LABEL;

-- ===== while با exit =====
while condition loop
    -- statements
    exit when exit_condition;
end loop;

-- ===== while با next =====
while condition loop
    -- statements
    next when skip_condition;
    -- statements
end loop;

-- ===== while تو در تو =====
OUTER: while cond1 loop
    INNER: while cond2 loop
        -- statements
        exit OUTER when exit_condition;
    end loop INNER;
end loop OUTER;
```

> **پیام نهایی:** حلقه **`while`** یک ابزار **قدرتمند** برای **تکرار شرطی** در VHDL است که به شما امکان می‌دهد **الگوریتم‌های پیچیده** با تعداد تکرار نامشخص را پیاده‌سازی کنید. با این حال، باید **بسیار دقت** کنید تا از **حلقه‌های بی‌نهایت** جلوگیری کنید. به یاد داشته باشید که `while` برای **تعداد تکرار نامشخص** و `for` برای **تعداد تکرار مشخص** مناسب است. انتخاب درست بین این دو، کلید طراحی **کارآمد** و **قابل اعتماد** در VHDL است.
