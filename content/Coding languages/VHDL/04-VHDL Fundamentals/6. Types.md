# تایپ Types در VHDL — تحلیل جامع و عمیق

## مقدمه: زبان مشترک داده‌ها در سخت‌افزار

در دنیای واقعی، انواع مختلفی از اطلاعات وجود دارد: اعداد، حروف، وضعیت‌ها، رنگ‌ها، و غیره. در VHDL نیز برای نمایش این اطلاعات متنوع، به **انواع داده (Types)** نیاز داریم. Typeها مشخص می‌کنند که یک Signal یا Variable چه **نوعی از اطلاعات** را می‌تواند ذخیره کند و چه **عملیاتی** روی آن مجاز است.

VHDL یک زبان **Strongly Typed** است — یعنی شما نمی‌توانید یک مقدار از یک نوع را به یک نوع دیگر اختصاص دهید مگر اینکه صریحاً آن را تبدیل کنید. این ویژگی باعث می‌شود کدهای شما **ایمن‌تر** و **قابل پیش‌بینی‌تر** باشند.

---

## ۱. Type چیست؟ تعریف جامع

**Type** در VHDL یک **مجموعه از مقادیر** و **عملیات مجاز** روی آن مقادیر را تعریف می‌کند. هر Signal، Variable، Constant یا Port در VHDL باید یک Type مشخص داشته باشد.

### تشبیه ساده

Type را مانند **قالب‌های مختلف** در یک کارخانه تصور کنید:
- قالب شماره ۱: برای ساخت قطعات گرد (مانند `integer`)
- قالب شماره ۲: برای ساخت قطعات مربع (مانند `std_logic`)
- قالب شماره ۳: برای ساخت قطعات مثلث (مانند `boolean`)

هر قالب فقط قطعاتی با شکل خاص خود تولید می‌کند — شما نمی‌توانید از قالب گرد برای ساخت قطعه مربع استفاده کنید.

## ۲. انواع Type در VHDL — دسته‌بندی کلی

### ۱. انواع اسکالر (Scalar Types)

| دسته | توضیح | مثال‌ها |
|------|-------|---------|
| **اعداد صحیح** | اعداد بدون اعشار | `integer`, `natural`, `positive` |
| **اعداد حقیقی** | اعداد با اعشار | `real` (کمتر در سنتز استفاده می‌شود) |
| **فیزیکی** | مقادیر فیزیکی | `time`, `length` |
| **انواع شمارشی** | مجموعه محدود از مقادیر نام‌گذاری‌شده | `enumeration types` |
| **بولی** | دو مقدار True/False | `boolean` |

### ۲. انواع ترکیبی (Composite Types)

| دسته | توضیح | مثال‌ها |
|------|-------|---------|
| **آرایه‌ها (Arrays)** | مجموعه‌ای از عناصر هم‌نوع | `std_logic_vector`, `integer array` |
| **رکوردها (Records)** | مجموعه‌ای از عناصر با انواع مختلف | `custom record` |

### ۳. انواع مرجع (Access Types)

| دسته | توضیح |
|------|-------|
| **اشاره‌گرها** | برای اشاره به اشیاء دیگر (شبیه Pointer در C) |

### ۴. انواع فایل (File Types)

| دسته | توضیح |
|------|-------|
| **فایل** | برای خواندن/نوشتن از/به فایل‌های خارجی |

## ۳. انواع استاندارد (Predefined Types)

### ۳.۱. `integer` — عدد صحیح

```vhdl
signal count : integer;
signal index : integer range 0 to 255;  -- با محدوده
signal value : integer := 10;
```

**محدوده پیش‌فرض:** `-(2³¹-1)` تا `2³¹-1`

**محدوده قابل تعریف:**
```vhdl
type small_int is range 0 to 15;
signal a : small_int;
```

**کاربردها:**
- شمارش‌گرها
- اندیس‌های Array
- محاسبات ریاضی ساده

---

### ۳.۲. `natural` و `positive`

```vhdl
signal count : natural := 0;    -- 0, 1, 2, ...
signal value : positive := 1;   -- 1, 2, 3, ...
```

**`natural`:** اعداد صحیح **غیرمنفی** (۰ و بزرگتر)
**`positive`:** اعداد صحیح **مثبت** (۱ و بزرگتر)

---

### ۳.۳. `boolean`

```vhdl
signal flag : boolean := false;
signal is_ready : boolean;

-- استفاده
if flag then
    -- کاری انجام بده
end if;
```

**مقادیر:** `true`, `false`

**کاربردها:**
- شرایط منطقی
- پرچم‌های وضعیت

---

### ۳.۴. `real` — عدد حقیقی

```vhdl
signal pi : real := 3.14159;
signal voltage : real range 0.0 to 5.0;
```

**توجه:** `real` در اکثر ابزارهای سنتز **پشتیبانی نمی‌شود** و فقط برای شبیه‌سازی استفاده می‌شود.

---

### ۳.۵. `character`

```vhdl
signal letter : character := 'A';
signal code : character;
```

**کاربردها:** فقط برای شبیه‌سازی و Testbench

---

### ۳.۶. `time` — زمان

```vhdl
signal period : time := 10 ns;
signal delay : time := 5 ms;
```

**واحدهای زمان:** `fs`, `ps`, `ns`, `us`, `ms`, `sec`

**کاربردها:** فقط برای شبیه‌سازی و Testbench

---

## ۴. انواع کتابخانه‌ای (Library Types)

### ۴.۱. `std_logic` — منطق ۹ حالته

```vhdl
library ieee;
use ieee.std_logic_1164.all;

signal clk : std_logic;
signal reset : std_logic;
signal data : std_logic_vector(7 downto 0);
```

**مقادیر `std_logic`:**

| مقدار | توضیح |
|-------|-------|
| `'U'` | Uninitialized (مقداردهی نشده) |
| `'X'` | Unknown (ناشناخته) |
| `'0'` | Logic 0 |
| `'1'` | Logic 1 |
| `'Z'` | High Impedance (امپدانس بالا) |
| `'W'` | Weak Unknown (ناشناخته ضعیف) |
| `'L'` | Weak 0 (صفر ضعیف) |
| `'H'` | Weak 1 (یک ضعیف) |
| `'-'` | Don't Care (بی‌اهمیت) |

**مهم‌ترین مقادیر:** `'0'`, `'1'`, `'Z'`

---

### ۴.۲. `std_logic_vector` — بردار منطقی

```vhdl
signal data : std_logic_vector(7 downto 0);
signal address : std_logic_vector(15 downto 0);
signal control : std_logic_vector(3 downto 0);
```

**اندیس‌گذاری:**
- **نزولی (downto):** مرسوم‌ترین
  ```vhdl
  data : std_logic_vector(7 downto 0);  -- MSB = 7, LSB = 0
  ```
- **صعودی (to):**
  ```vhdl
  data : std_logic_vector(0 to 7);  -- MSB = 0, LSB = 7
  ```

---

### ۴.۳. `unsigned` و `signed`

```vhdl
library ieee;
use ieee.numeric_std.all;

signal a : unsigned(7 downto 0);  -- عدد بدون علامت
signal b : signed(7 downto 0);    -- عدد با علامت (دو مکمل)
```

**تفاوت‌ها:**

| ویژگی | `unsigned` | `signed` | `std_logic_vector` |
|-------|------------|----------|-------------------|
| **تفسیر عددی** | دارد | دارد | ندارد |
| **عملیات ریاضی** | بله | بله | خیر |
| **مقایسه** | بله | بله | فقط بیتی |
| **نوع** | عددی | عددی | منطقی |

**مثال:**
```vhdl
a <= a + 1;              -- ✅ مجاز
b <= b - 10;             -- ✅ مجاز
data <= data + 1;        -- ❌ خطا (std_logic_vector)
```

---

### ۴.۴. `bit` و `bit_vector`

```vhdl
signal flag : bit := '0';
signal data : bit_vector(7 downto 0) := "10101010";
```

**مقادیر:** `'0'`, `'1'`

**توجه:** در طراحی‌های مدرن، به جای `bit` از `std_logic` استفاده می‌شود.

## ۵. انواع سفارشی (User-Defined Types)

### ۵.۱. Enumeration Types (انواع شمارشی)

```vhdl
type state_type is (IDLE, RUN, DONE, ERROR);
signal state : state_type := IDLE;
```

**مثال کامل:**
```vhdl
type traffic_light is (RED, GREEN, YELLOW);
signal light : traffic_light := RED;

process(clk)
begin
    if rising_edge(clk) then
        case light is
            when RED =>
                light <= GREEN;
            when GREEN =>
                light <= YELLOW;
            when YELLOW =>
                light <= RED;
        end case;
    end if;
end process;
```

**کاربردها:**
- Stateها در FSM
- وضعیت‌های سیستم
- کدهای عملیات

---

### ۵.۲. Integer Subtypes

```vhdl
subtype small_int is integer range 0 to 15;
subtype byte is integer range -128 to 127;
```

**کاربرد:** محدود کردن محدوده مجاز

---

### ۵.۳. Array Types (آرایه‌ها)

**آرایه یک‌بعدی:**
```vhdl
type int_array is array (0 to 7) of integer;
signal values : int_array;

type reg_array is array (0 to 15) of std_logic_vector(7 downto 0);
signal registers : reg_array;
```

**آرایه دو‌بعدی:**
```vhdl
type matrix is array (0 to 3, 0 to 3) of integer;
signal m : matrix;
```

**آرایه نامحدود:**
```vhdl
type int_vector is array (natural range <>) of integer;
signal v : int_vector(0 to 5);
```

---

### ۵.۴. Record Types (رکوردها)

```vhdl
type cpu_registers is record
    pc : std_logic_vector(15 downto 0);
    ir : std_logic_vector(7 downto 0);
    flags : std_logic_vector(3 downto 0);
    sp : std_logic_vector(15 downto 0);
end record;

signal cpu : cpu_registers;

-- استفاده
cpu.pc := x"1000";
cpu.flags(0) := '1';
```

**کاربردها:**
- بسته‌بندی اطلاعات مرتبط
- پروتکل‌های ارتباطی
- ساختارهای داده پیچیده

---

### ۵.۵. انواع ترکیبی

```vhdl
type memory is array (0 to 255) of std_logic_vector(7 downto 0);
type instruction is record
    opcode : std_logic_vector(3 downto 0);
    operand : std_logic_vector(11 downto 0);
end record;

type program is array (0 to 1023) of instruction;
```

## ۶. تبدیل Typeها (Type Conversion)

### ۶.۱. تبدیل `std_logic_vector` به `unsigned`/`signed`

```vhdl
library ieee;
use ieee.numeric_std.all;

signal slv : std_logic_vector(7 downto 0) := "10101010";
signal uns : unsigned(7 downto 0);
signal sig : signed(7 downto 0);

uns <= unsigned(slv);   -- تبدیل
sig <= signed(slv);     -- تبدیل
```

### ۶.۲. تبدیل `unsigned`/`signed` به `std_logic_vector`

```vhdl
slv <= std_logic_vector(uns);
slv <= std_logic_vector(sig);
```

### ۶.۳. تبدیل `integer` به `unsigned`

```vhdl
signal uns : unsigned(7 downto 0);
signal count : integer := 100;

uns <= to_unsigned(count, 8);
```

### ۶.۴. تبدیل `unsigned` به `integer`

```vhdl
count <= to_integer(uns);
```

### ۶.۵. تبدیل `std_logic_vector` به `integer`

```vhdl
count <= to_integer(unsigned(slv));
count <= to_integer(signed(slv));
```

## ۷. Type و Subtype — تفاوت

### Type (نوع اصلی)

یک **نوع کاملاً جدید** تعریف می‌کند که با انواع دیگر ناسازگار است.

```vhdl
type address_type is range 0 to 255;
type data_type is range 0 to 255;

signal addr : address_type;
signal data : data_type;

addr <= data;  -- ❌ خطا: انواع متفاوت
```

### Subtype (زیرنوع)

یک **محدودیت** روی یک نوع موجود اعمال می‌کند و با نوع اصلی سازگار است.

```vhdl
type integer is range -2147483648 to 2147483647;
subtype small_int is integer range 0 to 15;

signal a : integer;
signal b : small_int;

a <= b;  -- ✅ مجاز
b <= a;  -- ✅ اگر a در محدوده ۰ تا ۱۵ باشد
```

## ۸. انواع در Portها — مثال‌های عملی

### ۸.۱. استفاده از انواع استاندارد

```vhdl
entity my_circuit is
    port (
        clk   : in  std_logic;
        reset : in  std_logic;
        data  : in  std_logic_vector(7 downto 0);
        count : out integer range 0 to 255
    );
end entity;
```

### ۸.۲. استفاده از انواع سفارشی

```vhdl
package my_pkg is
    type state_type is (IDLE, RUN, DONE);
    type data_bus is array (0 to 7) of std_logic_vector(15 downto 0);
end package;

library ieee;
use ieee.std_logic_1164.all;
use work.my_pkg.all;

entity my_circuit is
    port (
        clk   : in  std_logic;
        state : out state_type;
        bus   : out data_bus
    );
end entity;
```

## ۹. اشتباهات رایج در Typeها

### اشتباه ۱: استفاده از `std_logic_vector` برای محاسبات ریاضی

**نادرست:**
```vhdl
signal a, b : std_logic_vector(7 downto 0);
signal sum : std_logic_vector(7 downto 0);

sum <= a + b;  -- ❌ خطا
```

**درست:**
```vhdl
signal a, b : unsigned(7 downto 0);
signal sum : unsigned(7 downto 0);

sum <= a + b;  -- ✅ مجاز
```

### اشتباه ۲: تبدیل نادرست Type

**نادرست:**
```vhdl
signal a : unsigned(7 downto 0);
signal b : integer;

b <= a;  -- ❌ خطا: انواع متفاوت
```

**درست:**
```vhdl
b <= to_integer(a);  -- ✅ تبدیل صریح
```

### اشتباه ۳: استفاده از `integer` بدون محدوده

```vhdl
signal count : integer;  -- ⚠️ ممکن است به سخت‌افزار زیادی نیاز داشته باشد
```

**بهتر:**
```vhdl
signal count : integer range 0 to 255;  -- ✅ محدوده مشخص
```

### اشتباه ۴: فراموش کردن کتابخانه

**نادرست:**
```vhdl
signal a : unsigned(7 downto 0);  -- ❌ کتابخانه numeric_std فراموش شده
```

**درست:**
```vhdl
library ieee;
use ieee.numeric_std.all;

signal a : unsigned(7 downto 0);  -- ✅
```

## ۱۰. تمرین‌های عملی

### تمرین ۱: انواع شمارشی

یک نوع شمارشی برای Stateهای یک ماشین لباسشویی تعریف کنید و یک Signal از آن نوع ایجاد کنید.

**پاسخ:**
```vhdl
type washing_state is (IDLE, FILL, WASH, RINSE, SPIN, DONE);
signal state : washing_state := IDLE;
```

### تمرین ۲: انواع Record

یک Record برای ذخیره اطلاعات یک دانشجو (نام، نمره، دانشکده) تعریف کنید.

**پاسخ:**
```vhdl
type student is record
    name : string(1 to 20);
    grade : integer range 0 to 20;
    faculty : string(1 to 30);
end record;

signal s1 : student;
```

### تمرین ۳: انواع Array

یک آرایه ۸ عنصری از نوع `std_logic_vector(7 downto 0)` تعریف کنید.

**پاسخ:**
```vhdl
type reg_file is array (0 to 7) of std_logic_vector(7 downto 0);
signal registers : reg_file;
```

## ۱۱. خلاصه و جمع‌بندی

### دسته‌بندی انواع

| دسته | مثال‌ها |
|------|---------|
| **اسکالر** | `integer`, `boolean`, `std_logic`, `enumeration` |
| **کامپوزیت** | `std_logic_vector`, `array`, `record` |
| **کتابخانه‌ای** | `unsigned`, `signed`, `bit_vector` |
| **سفارشی** | انواع تعریف‌شده توسط کاربر |

### جدول مقایسه انواع مهم

| Type | کتابخانه | کاربرد | محاسبات ریاضی |
|------|-----------|--------|---------------|
| `integer` | `std` | اعداد صحیح | ✅ |
| `std_logic` | `std_logic_1164` | منطق تک‌بیتی | ❌ |
| `std_logic_vector` | `std_logic_1164` | بردار منطقی | ❌ |
| `unsigned` | `numeric_std` | عدد بدون علامت | ✅ |
| `signed` | `numeric_std` | عدد با علامت | ✅ |

### فرمت اعلان Type

```vhdl
type <name> is <type_definition>;
```

### پیام نهایی

Typeها **زبان مشترک** داده‌ها در VHDL هستند. انتخاب Type مناسب:
- باعث **ایمنی** بیشتر کد می‌شود
- **خوانایی** را افزایش می‌دهد
- از **خطاهای رایج** جلوگیری می‌کند
- **سخت‌افزار بهینه‌تری** تولید می‌کند

> **به یاد داشته باشید:** در VHDL، هر داده باید یک Type مشخص داشته باشد. انتخاب Type مناسب، کلید طراحی موفق است.
