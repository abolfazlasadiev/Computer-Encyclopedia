# دستور case در VHDL — تحلیل جامع و عمیق

## مقدمه: انتخاب هوشمندانه در VHDL

تصور کنید در یک **رستوران** هستید و منوی غذا را نگاه می‌کنید. بر اساس شماره غذا، انتخاب می‌کنید که چه چیزی سفارش دهید: اگر شماره ۱ است، پیتزا؛ اگر شماره ۲ است، پاستا؛ اگر شماره ۳ است، سالاد؛ و غیره. این دقیقاً همان کاری است که دستور **`case`** در VHDL انجام می‌دهد — **انتخاب** بر اساس یک مقدار مشخص.

دستور `case` یکی از **دستورات ترتیبی** مهم در VHDL است که برای **انتخاب چندحالته** استفاده می‌شود و زمانی که تعداد حالت‌ها زیاد است، بسیار **خوانا** و **کارآمد**تر از `if/elsif` است.

---

## ۱. ساختار دستور `case`

### ۱.۱. ساختار کلی

```
┌─────────────────────────────────────────────────────────────────────┐
│                      CASE STATEMENT STRUCTURE                     │
├─────────────────────────────────────────────────────────────────────┤
│                                                                   │
│  ┌─────────────────────────────────────────────────────────────┐  │
│  │  case expression is                                       │  │
│  │  ┌─────────────────────────────────────────────────────┐  │  │
│  │  │  when choice_1 =>                                  │  │  │
│  │  │      -- statements for choice_1                   │  │  │
│  │  └─────────────────────────────────────────────────────┘  │  │
│  │  ┌─────────────────────────────────────────────────────┐  │  │
│  │  │  when choice_2 | choice_3 =>                       │  │  │
│  │  │      -- statements for choice_2 or choice_3       │  │  │
│  │  └─────────────────────────────────────────────────────┘  │  │
│  │  ┌─────────────────────────────────────────────────────┐  │  │
│  │  │  when choice_4 to choice_10 =>                     │  │  │
│  │  │      -- statements for range of choices           │  │  │
│  │  └─────────────────────────────────────────────────────┘  │  │
│  │  ┌─────────────────────────────────────────────────────┐  │  │
│  │  │  when others =>                                    │  │  │
│  │  │      -- statements for all other choices          │  │  │
│  │  └─────────────────────────────────────────────────────┘  │  │
│  │  end case;                                              │  │
│  └─────────────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────────────┘
```

### ۱.۲. انواع `case`

```vhdl
-- ===== 1. case با مقادیر منفرد =====
case expression is
    when value_1 =>
        -- statements
    when value_2 =>
        -- statements
    when value_3 =>
        -- statements
    when others =>
        -- statements
end case;

-- ===== 2. case با چند مقدار (OR) =====
case expression is
    when value_1 | value_2 | value_3 =>
        -- statements
    when value_4 =>
        -- statements
    when others =>
        -- statements
end case;

-- ===== 3. case با محدوده (Range) =====
case expression is
    when value_1 to value_5 =>
        -- statements
    when value_6 to value_10 =>
        -- statements
    when others =>
        -- statements
end case;

-- ===== 4. case با ترکیب OR و Range =====
case expression is
    when value_1 | value_2 to value_5 =>
        -- statements
    when value_6 | value_7 to value_9 =>
        -- statements
    when others =>
        -- statements
end case;
```

### ۱.۳. مثال‌های ساده

```vhdl
library ieee;
use ieee.std_logic_1164.all;
use ieee.numeric_std.all;

entity case_example is
    port (
        opcode  : in  std_logic_vector(2 downto 0);
        state   : in  std_logic_vector(1 downto 0);
        a, b    : in  integer;
        
        result  : out integer;
        control : out std_logic_vector(3 downto 0);
        flag    : out std_logic
    );
end entity;

architecture rtl of case_example is
    type color_t is (RED, GREEN, BLUE, YELLOW);
    signal color : color_t;
begin
    -- ===== case با مقادیر ثابت =====
    process(opcode, a, b)
    begin
        case opcode is
            when "000" => result <= a + b;
            when "001" => result <= a - b;
            when "010" => result <= a * b;
            when "011" => result <= a / b;
            when "100" => result <= a mod b;
            when "101" => result <= a rem b;
            when "110" => result <= a ** 2;
            when "111" => result <= 0;
            when others => result <= 0;  -- always have others
        end case;
    end process;
    
    -- ===== case با چند مقدار =====
    process(state)
    begin
        case state is
            when "00" | "01" => control <= "0001";
            when "10" | "11" => control <= "0010";
            when others => control <= "0000";
        end case;
    end process;
    
    -- ===== case با range =====
    process(opcode)
    begin
        case opcode is
            when "000" to "011" => flag <= '0';
            when "100" to "110" => flag <= '1';
            when "111" => flag <= '0';
            when others => flag <= '0';
        end case;
    end process;
    
    -- ===== case با enum =====
    process(color)
    begin
        case color is
            when RED => control <= "0001";
            when GREEN => control <= "0010";
            when BLUE => control <= "0100";
            when YELLOW => control <= "1000";
            when others => control <= "0000";
        end case;
    end process;
end architecture;
```

## ۲. انواع انتخاب‌ها در `case`

### ۲.۱. انتخاب منفرد (Single Choice)

```vhdl
-- ===== انتخاب منفرد =====
case opcode is
    when "000" => y <= a + b;
    when "001" => y <= a - b;
    when "010" => y <= a * b;
    when "011" => y <= a / b;
    when others => y <= 0;
end case;

-- ===== با enum =====
case state is
    when IDLE => next_state <= RUN;
    when RUN => next_state <= DONE;
    when DONE => next_state <= IDLE;
    when others => next_state <= IDLE;
end case;
```

### ۲.۲. انتخاب چندگانه (Multiple Choice with `|`)

```vhdl
-- ===== انتخاب چندگانه با OR =====
case opcode is
    when "000" | "001" | "010" =>  -- ADD, SUB, MUL
        y <= a + b;
    when "011" | "100" =>           -- DIV, MOD
        y <= a / b;
    when "101" | "110" | "111" =>   -- AND, OR, XOR
        y <= a and b;
    when others =>
        y <= 0;
end case;

-- ===== با enum =====
case state is
    when IDLE | ERROR =>
        next_state <= RUN;
    when RUN | DONE =>
        next_state <= IDLE;
    when others =>
        next_state <= IDLE;
end case;
```

### ۲.۳. انتخاب با محدوده (Range with `to`)

```vhdl
-- ===== انتخاب با محدوده =====
case opcode is
    when "000" to "011" =>  -- 0 تا 3
        y <= a + b;
    when "100" to "110" =>  -- 4 تا 6
        y <= a - b;
    when "111" =>           -- 7
        y <= a * b;
    when others =>
        y <= 0;
end case;

-- ===== با integer =====
case value is
    when 0 to 9 =>
        digit <= '0';
    when 10 to 19 =>
        digit <= '1';
    when 20 to 29 =>
        digit <= '2';
    when others =>
        digit <= 'X';
end case;
```

### ۲.۴. ترکیب OR و Range

```vhdl
-- ===== ترکیب OR و Range =====
case opcode is
    when "000" | "001" to "011" =>  -- 0 یا 1 تا 3
        y <= a + b;
    when "100" | "101" to "111" =>  -- 4 یا 5 تا 7
        y <= a - b;
    when others =>
        y <= 0;
end case;
```

## ۴. `case` در Processهای ترکیبی

### ۴.۱. Process ترکیبی با `case`

```vhdl
-- ===== Process ترکیبی با case =====
-- • بدون Clock
-- • خروجی فوراً به ورودی پاسخ می‌دهد
-- • همه ورودی‌ها در لیست حساسیت

library ieee;
use ieee.std_logic_1164.all;
use ieee.numeric_std.all;

entity comb_case is
    port (
        opcode  : in  std_logic_vector(2 downto 0);
        a, b    : in  std_logic_vector(7 downto 0);
        flags   : in  std_logic_vector(1 downto 0);
        
        result  : out std_logic_vector(7 downto 0);
        status  : out std_logic_vector(1 downto 0)
    );
end entity;

architecture rtl of comb_case is
begin
    COMB_PROC: process(opcode, a, b, flags)
    begin
        -- ===== مقدار پیش‌فرض (جلوگیری از Latch) =====
        result <= (others => '0');
        status <= "00";
        
        -- ===== منطق اصلی با case =====
        case opcode is
            when "000" =>
                result <= std_logic_vector(unsigned(a) + unsigned(b));
                status <= "01";
            
            when "001" =>
                result <= std_logic_vector(unsigned(a) - unsigned(b));
                status <= "01";
            
            when "010" =>
                result <= std_logic_vector(unsigned(a) * unsigned(b)(7 downto 0));
                status <= "10";
            
            when "011" =>
                if b = "00000000" then
                    result <= (others => '1');  -- Error
                    status <= "11";
                else
                    result <= std_logic_vector(unsigned(a) / unsigned(b));
                    status <= "10";
                end if;
            
            when "100" =>
                result <= a and b;
                status <= "01";
            
            when "101" =>
                result <= a or b;
                status <= "01";
            
            when "110" =>
                result <= a xor b;
                status <= "01";
            
            when "111" =>
                result <= not a;
                status <= "00";
            
            when others =>
                result <= (others => '0');
                status <= "00";
        end case;
    end process COMB_PROC;
end architecture;
```

### ۴.۲. جلوگیری از Latch در `case`

```vhdl
-- ===== ❌ اشتباه: Latch =====
process(opcode, a, b)
begin
    case opcode is
        when "00" =>
            y <= a;
        when "01" =>
            y <= b;
        -- "10" و "11" پوشش داده نشده‌اند → Latch
    end case;
end process;

-- ===== ✅ راه‌حل 1: استفاده از others =====
process(opcode, a, b)
begin
    case opcode is
        when "00" => y <= a;
        when "01" => y <= b;
        when others => y <= (others => '0');  -- مقدار پیش‌فرض
    end case;
end process;

-- ===== ✅ راه‌حل 2: مقدار پیش‌فرض =====
process(opcode, a, b)
begin
    y <= b;  -- مقدار پیش‌فرض
    case opcode is
        when "00" => y <= a;
        when "01" => y <= b;
        when "10" => y <= a + b;
        when "11" => y <= a - b;
    end case;
end process;
```

## ۵. `case` در Processهای سنکرون

### ۵.۱. Process سنکرون با `case`

```vhdl
-- ===== Process سنکرون با case =====
-- • با Clock
-- • خروجی در لبه Clock به‌روز می‌شود

library ieee;
use ieee.std_logic_1164.all;
use ieee.numeric_std.all;

entity sync_case is
    port (
        clk     : in  std_logic;
        rst     : in  std_logic;
        en      : in  std_logic;
        opcode  : in  std_logic_vector(1 downto 0);
        data    : in  std_logic_vector(7 downto 0);
        
        result  : out std_logic_vector(7 downto 0);
        count   : out std_logic_vector(7 downto 0)
    );
end entity;

architecture rtl of sync_case is
    signal reg : std_logic_vector(7 downto 0);
    signal counter : unsigned(7 downto 0);
begin
    SYNC_PROC: process(clk, rst)
    begin
        if rst = '1' then
            reg <= (others => '0');
            counter <= (others => '0');
            
        elsif rising_edge(clk) then
            if en = '1' then
                -- ===== case برای عملیات =====
                case opcode is
                    when "00" =>
                        reg <= data;
                        counter <= counter + 1;
                    
                    when "01" =>
                        reg <= std_logic_vector(unsigned(data) + 1);
                        counter <= counter + 2;
                    
                    when "10" =>
                        reg <= std_logic_vector(unsigned(data) - 1);
                        counter <= counter - 1;
                    
                    when "11" =>
                        reg <= not data;
                        counter <= counter + 3;
                    
                    when others =>
                        reg <= (others => '0');
                        counter <= (others => '0');
                end case;
            end if;
        end if;
    end process;
    
    result <= reg;
    count <= std_logic_vector(counter);
end architecture;
```

### ۵.۲. `case` در FSM

```vhdl
-- ===== FSM با case =====
library ieee;
use ieee.std_logic_1164.all;

entity fsm_case is
    port (
        clk     : in  std_logic;
        rst     : in  std_logic;
        start   : in  std_logic;
        done_in : in  std_logic;
        
        state   : out std_logic_vector(1 downto 0);
        done    : out std_logic
    );
end entity;

architecture rtl of fsm_case is
    type state_t is (IDLE, RUN, DONE);
    signal current_state : state_t;
    signal next_state : state_t;
begin
    -- ===== FSM با case =====
    FSM_PROC: process(clk, rst)
    begin
        if rst = '1' then
            current_state <= IDLE;
            done <= '0';
            
        elsif rising_edge(clk) then
            case current_state is
                when IDLE =>
                    done <= '0';
                    if start = '1' then
                        current_state <= RUN;
                    end if;
                
                when RUN =>
                    if done_in = '1' then
                        current_state <= DONE;
                    end if;
                
                when DONE =>
                    done <= '1';
                    current_state <= IDLE;
                
                when others =>
                    current_state <= IDLE;
                    done <= '0';
            end case;
        end if;
    end process;
    
    -- ===== تبدیل state به خروجی =====
    with current_state select
        state <= "00" when IDLE,
                 "01" when RUN,
                 "10" when DONE,
                 "11" when others;
end architecture;
```

## ۶. `case` vs `if`

### ۶.۱. جدول مقایسه

| ویژگی | `case` | `if` |
|--------|--------|------|
| **شرط** | یک عبارت با مقادیر مختلف | هر شرط boolean |
| **اولویت** | ندارد (همه هم‌تراز) | دارد (از بالا به پایین) |
| **خوانایی** | برای ۴+ حالت عالی | برای شرایط پیچیده عالی |
| **شرایط پیچیده** | ❌ مناسب نیست | ✅ مناسب |
| **مقادیر متعدد** | ✅ با `\|` و `to` | ❌ نیاز به elsif زیاد |
| **سنتز** | ✅ کاملاً قابل سنتز | ✅ کاملاً قابل سنتز |
| **زمان اجرا** | معمولاً سریع‌تر | معمولاً کندتر |

### ۶.۲. چه زمانی از `case` استفاده کنیم؟

```vhdl
-- ===== ✅ استفاده از case =====
-- • وقتی یک عبارت با مقادیر مختلف داریم
-- • تعداد حالت‌ها زیاد است (۴+ حالت)
-- • همه حالت‌ها هم‌تراز هستند
-- • انتخاب بر اساس یک مقدار (نه شرط)

-- ===== مثال خوب برای case =====
case opcode is
    when "000" => y <= a + b;
    when "001" => y <= a - b;
    when "010" => y <= a * b;
    when "011" => y <= a / b;
    when "100" => y <= a and b;
    when "101" => y <= a or b;
    when "110" => y <= a xor b;
    when "111" => y <= not a;
    when others => y <= 0;
end case;

-- ===== مثال خوب برای if =====
if (a > b) and (c < d) then
    y <= a + c;
elsif (a > b) or (c < d) then
    y <= a - c;
elsif (a = b) and (c = d) then
    y <= 0;
else
    y <= b + d;
end if;
```

### ۶.۳. ترکیب `case` و `if`

```vhdl
-- ===== ترکیب case و if =====
process(opcode, a, b, flags)
begin
    case opcode is
        when "000" =>  -- ADD
            if flags(0) = '1' then
                y <= a + b + 1;  -- با Carry
            else
                y <= a + b;
            end if;
        
        when "001" =>  -- SUB
            if flags(0) = '1' then
                y <= a - b - 1;  -- با Borrow
            else
                y <= a - b;
            end if;
        
        when "010" =>  -- MUL
            y <= a * b;
        
        when others =>
            y <= 0;
    end case;
end process;
```

## ۷. `case` در Function و Procedure

### ۷.۱. `case` در Function

```vhdl
-- ===== Function با case =====
package case_pkg is
    function decode(opcode : std_logic_vector(2 downto 0)) return integer;
    function to_hex(value : integer) return character;
end package;

package body case_pkg is
    -- ===== تابع با case =====
    function decode(opcode : std_logic_vector(2 downto 0)) return integer is
    begin
        case opcode is
            when "000" => return 0;
            when "001" => return 1;
            when "010" => return 2;
            when "011" => return 3;
            when "100" => return 4;
            when "101" => return 5;
            when "110" => return 6;
            when "111" => return 7;
            when others => return -1;
        end case;
    end function;
    
    -- ===== تابع با case و range =====
    function to_hex(value : integer) return character is
    begin
        case value is
            when 0 to 9 => return character'val(48 + value);  -- '0' تا '9'
            when 10 to 15 => return character'val(55 + value);  -- 'A' تا 'F'
            when others => return 'X';
        end case;
    end function;
end package body;
```

### ۷.۲. `case` در Procedure

```vhdl
-- ===== Procedure با case =====
package proc_case_pkg is
    procedure execute_instruction(opcode : std_logic_vector(2 downto 0);
                                  a, b : inout integer);
end package;

package body proc_case_pkg is
    procedure execute_instruction(opcode : std_logic_vector(2 downto 0);
                                  a, b : inout integer) is
    begin
        case opcode is
            when "000" =>
                a := a + b;
            when "001" =>
                a := a - b;
            when "010" =>
                a := a * b;
            when "011" =>
                if b /= 0 then
                    a := a / b;
                end if;
            when "100" =>
                a := a mod b;
            when "101" =>
                -- SWAP
                a := a + b;
                b := a - b;
                a := a - b;
            when others =>
                a := 0;
                b := 0;
        end case;
    end procedure;
end package body;
```

## ۸. نکات پیشرفته `case`

### ۸.۱. `case` با `others`

```vhdl
-- ===== استفاده از others =====
-- others همه حالت‌های پوشش داده نشده را پوشش می‌دهد

case opcode is
    when "000" => y <= a + b;
    when "001" => y <= a - b;
    when "010" => y <= a * b;
    when others => y <= 0;  -- همه حالت‌های دیگر
end case;

-- ===== others در enum کامل =====
type state_t is (IDLE, RUN, DONE);
case state is
    when IDLE => next_state <= RUN;
    when RUN => next_state <= DONE;
    when DONE => next_state <= IDLE;
    -- others ضروری نیست اما می‌توان داشت
    when others => next_state <= IDLE;
end case;
```

### ۸.۲. `case` با `null`

```vhdl
-- ===== case با null =====
case opcode is
    when "000" =>
        y <= a + b;
    when "001" =>
        y <= a - b;
    when "010" =>
        y <= a * b;
    when others =>
        null;  -- هیچ کاری نکن
end case;
```

### ۸.۳. `case` با انتخاب‌های تکراری (VHDL-2008)

```vhdl
-- ===== VHDL-2008: انتخاب‌های تکراری =====
case opcode is
    when "000" | "000" =>  -- ❌ تکراری (خطا)
        y <= a + b;
    when others =>
        y <= 0;
end case;
```

### ۸.۴. `case` با `?` (VHDL-2008)

```vhdl
-- ===== VHDL-2008: case با ? (Match Case) =====
process(opcode)
begin
    case? opcode is
        when "000" => y <= '0';
        when "001" => y <= '1';
        when "010" => y <= '1';
        when "011" => y <= '0';
        when "1--" => y <= '1';  -- بیت اول 1، بقیه don't care
        when "0-1" => y <= '0';  -- بیت اول 0، بیت سوم 1
        when others => y <= 'X';
    end case?;
end process;
```

### ۹.۱. خطا: انتخاب‌های تکراری

```vhdl

case opcode is
    when "000" => y <= a + b;
    when "000" => y <= a - b;  -- ❌ تکراری
    when others => y <= 0;
end case;

-- ===== ✅ راه‌حل =====
case opcode is
    when "000" => y <= a + b;
```

```vhdl
-- ===== ✅ راه‌حل =====
case opcode is
    when "000" to "001" => y <= a + b;

    when others => y <= 0;
```

### ۹.۳. خطا: انتخاب‌های نامعتبر

```vhdl
-- ===== ❌ اشتباه =====
case opcode is
    when "00" to "11" => y <= a + b;  -- ✅ range معتبر
    when "1X" => y <= a - b;          -- ❌ نامعتبر (std_logic_vector نمی‌تواند X داشته باشد)
```

### ۹.۴. خطا: نوع داده نامعتبر

```vhdl
if sel = '0' then
```

## ۱۰. بهترین‌نوشته‌ها (Best Practices)

### ۱۰.۱. استفاده از `others`

```vhdl
-- ===== ✅ همیشه others داشته باشید =====
case opcode is
    when "000" => y <= a + b;
    when "001" => y <= a - b;
    when "010" => y <= a * b;
    when others => y <= 0;  -- مقدار پیش‌فرض
end case;

-- ===== ❌ بدون others (ممکن است Latch ایجاد کند) =====
case opcode is
    when "000" => y <= a + b;
    when "001" => y <= a - b;
    when "010" => y <= a * b;
    -- "011" و سایر حالت‌ها پوشش داده نشده‌اند
end case;
```

### ۱۰.۲. سازماندهی `case`

```vhdl
-- ===== ✅ مرتب‌سازی منطقی =====
case opcode is
    -- Arithmetic operations
    when "000" => y <= a + b;
    when "001" => y <= a - b;
    when "010" => y <= a * b;
    when "011" => y <= a / b;
    
    -- Logical operations
    when "100" => y <= a and b;
    when "101" => y <= a or b;
    when "110" => y <= a xor b;
    
    -- Special operations
    when "111" => y <= not a;
    
    -- Default
    when others => y <= 0;
end case;
```

### ۱۰.۳. استفاده از `|` و `to`

```vhdl
-- ===== ✅ استفاده از | برای گروه‌بندی =====
case opcode is
    when "000" | "001" | "010" => y <= a + b;
    when "011" | "100" => y <= a - b;
    when others => y <= 0;
end case;

-- ===== ✅ استفاده از to برای محدوده =====
case value is
    when 0 to 9 => digit <= '0';
    when 10 to 19 => digit <= '1';
    when 20 to 29 => digit <= '2';
    when others => digit <= 'X';
end case;
```

### ۱۰.۴. انتخاب بین `case` و `if`

```vhdl
-- ===== ✅ با case برای انتخاب چندحالته =====
case opcode is
    when "000" => y <= a + b;
    when "001" => y <= a - b;
    when "010" => y <= a * b;
    when "011" => y <= a / b;
    when others => y <= 0;
end case;

-- ===== ✅ با if برای شرایط پیچیده =====
if (a > b) and (c < d) then
    y <= a + c;
elsif (a > b) or (c < d) then
    y <= a - c;
else
    y <= b + d;
end if;
```

### ۱۰.۵. مقداردهی در `case`

```vhdl
-- ===== ✅ مقداردهی به همه خروجی‌ها در همه شاخه‌ها =====
process(opcode, a, b)
begin
    y <= (others => '0');  -- مقدار پیش‌فرض
    flag <= '0';
    
    case opcode is
        when "000" =>
            y <= a + b;
            flag <= '1';
        when "001" =>
            y <= a - b;
            flag <= '1';
        when others =>
            y <= (others => '0');
            flag <= '0';
    end case;
end process;
```

## ۱۱. خلاصه و جمع‌بندی

### جدول انواع `case`

| نوع | ساختار | کاربرد |
|-----|--------|--------|
| **case ساده** | `case expr is when v1 => ... when v2 => ... end case;` | انتخاب منفرد |
| **case با `\|`** | `when v1 | v2 | v3 => ...` | انتخاب چندگانه |
| **case با `to`** | `when v1 to v10 => ...` | انتخاب با محدوده |
| **case با `others`** | `when others => ...` | مقدار پیش‌فرض |

### قوانین کلیدی

| قانون | توضیح |
|-------|-------|
| **همه حالت‌ها** | همه حالت‌ها باید پوشش داده شوند |
| **others** | همیشه others داشته باشید (مگر enum کامل) |
| **عدم همپوشانی** | انتخاب‌ها نباید همپوشان باشند |
| **عدم تکراری** | انتخاب‌ها نباید تکراری باشند |
| **نوع داده** | فقط انواع خاص قابل استفاده هستند |
| **others در آخر** | others باید آخرین انتخاب باشد |

### انتخاب بین `case` و `if`

```
┌─────────────────────────────────────────────────────────────────────┐
│  چه زمانی از case استفاده کنیم؟                                  │
│  • یک عبارت با مقادیر مختلف                                     │
│  • تعداد حالت‌ها زیاد است (۴+ حالت)                             │
│  • همه حالت‌ها هم‌تراز هستند                                    │
│  • انتخاب بر اساس یک مقدار (نه شرط)                             │
│  • کد خوانا و تمیز می‌خواهیم                                    │├─────────────────────────────────────────────────────────────────────┤
│  چه زمانی از if استفاده کنیم؟                                   │
│  • شرایط پیچیده (با AND, OR, NOT)                              │
│  • شرایط با مقادیر مختلف (مثلاً a > b)                         │
│  • اولویت بین شرایط وجود دارد                                   │
│  • تعداد حالت‌ها کم است (۲-۳ حالت)                              │
│  • شرط‌ها boolean هستند                                         │
└─────────────────────────────────────────────────────────────────────┘
```

### دستورات مهم

```vhdl
-- ===== case ساده =====
case expression is
    when value_1 =>
        -- statements
    when value_2 =>
        -- statements
    when others =>
        -- statements
end case;

-- ===== case با چند مقدار =====
case expression is
    when value_1 | value_2 | value_3 =>
        -- statements
    when value_4 to value_10 =>
        -- statements
    when others =>
        -- statements
end case;

-- ===== case در Process ترکیبی =====
process(all)
begin
    y <= (others => '0');  -- مقدار پیش‌فرض
    case opcode is
        when "00" => y <= a;
        when "01" => y <= b;
        when "10" => y <= a + b;
        when "11" => y <= a - b;
        when others => y <= (others => '0');
    end case;
end process;

-- ===== case در FSM =====
process(clk, rst)
begin
    if rst = '1' then
        state <= IDLE;
    elsif rising_edge(clk) then
        case state is
            when IDLE =>
                if start = '1' then
                    state <= RUN;
                end if;
            when RUN =>
                if done = '1' then
                    state <= DONE;
                end if;
            when DONE =>
                state <= IDLE;
            when others =>
                state <= IDLE;
        end case;
    end if;
end process;
```

> **پیام نهایی:** دستور **`case`** یک ابزار **قدرتمند** و **خوانا** برای پیاده‌سازی **انتخاب چندحالته** در VHDL است. با استفاده صحیح از `case`، می‌توانید کدهای **تمیز**، **سازمان‌یافته** و **کارآمد** بنویسید. به یاد داشته باشید که `case` برای **انتخاب بر اساس یک مقدار** مناسب است، در حالی که `if` برای **شرایط پیچیده** بهتر عمل می‌کند. انتخاب درست بین این دو، کلید طراحی **حرفه‌ای** در VHDL است.
