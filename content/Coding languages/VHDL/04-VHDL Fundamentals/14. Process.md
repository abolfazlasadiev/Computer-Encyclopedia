# Process در VHDL — تحلیل جامع و عمیق

## مقدمه: قلب تپنده طراحی VHDL

تصور کنید یک **کارخانه** را مدیریت می‌کنید. کارخانه دارای چندین بخش است که هر کدام **به طور همزمان** کار می‌کنند. اما درون هر بخش، کارها **به ترتیب** انجام می‌شوند. این دقیقاً همان چیزی است که **Process** در VHDL انجام می‌دهد.

**Process** یک **بلوک اجرایی** است که:
- دستورات **ترتیبی** را در خود جای می‌دهد
- می‌تواند **همزمان** با سایر Processها اجرا شود
- **قلب** منطق ترکیبی و ترتیبی در VHDL است
- تنها جایی است که می‌توان از دستورات ترتیبی استفاده کرد

---

## ۱. مفهوم و ساختار Process

### ۱.۱. ساختار کلی Process

```
┌─────────────────────────────────────────────────────────────────────┐
│                         PROCESS STRUCTURE                          │
├─────────────────────────────────────────────────────────────────────┤
│                                                                   │
│  ┌─────────────────────────────────────────────────────────────┐  │
│  │  [label:] process (sensitivity_list) [is]                  │  │
│  │  ┌──────────────────────────────────────────────────────┐  │  │
│  │  │  -- Declarations (اعلان‌ها)                         │  │  │
│  │  │  variable v1 : integer;                             │  │  │
│  │  │  variable v2 : std_logic_vector(7 downto 0);        │  │  │
│  │  │  constant c1 : integer := 10;                       │  │  │
│  │  └──────────────────────────────────────────────────────┘  │  │
│  │  begin                                                    │  │
│  │  ┌──────────────────────────────────────────────────────┐  │  │
│  │  │  -- Sequential Statements (دستورات ترتیبی)          │  │  │
│  │  │  wait until rising_edge(clk);                       │  │  │
│  │  │  if condition then                                  │  │  │
│  │  │      -- statements                                  │  │  │
│  │  │  end if;                                            │  │  │
│  │  │  case opcode is                                     │  │  │
│  │  │      when "00" => ...                               │  │  │
│  │  │  end case;                                          │  │  │
│  │  └──────────────────────────────────────────────────────┘  │  │
│  │  end process [label];                                     │  │
│  └─────────────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────────────┘
```

### ۱.۲. مثال ساده

```vhdl
library ieee;
use ieee.std_logic_1164.all;
use ieee.numeric_std.all;

entity process_example is
    port (
        clk   : in  std_logic;
        rst   : in  std_logic;
        en    : in  std_logic;
        data  : in  std_logic_vector(7 downto 0);
        count : out std_logic_vector(7 downto 0)
    );
end entity;

architecture rtl of process_example is
    signal counter : unsigned(7 downto 0);
begin
    -- ===== Process با Clock =====
    COUNTER_PROC: process(clk, rst)
        variable temp : integer;  -- متغیر محلی
    begin
        if rst = '1' then
            -- Reset: مقداردهی اولیه
            counter <= (others => '0');
            temp := 0;
            
        elsif rising_edge(clk) then
            -- منطق اصلی
            if en = '1' then
                counter <= counter + 1;
                temp := temp + 1;
            end if;
        end if;
    end process COUNTER_PROC;
    
    count <= std_logic_vector(counter);
end architecture;
```

## ۲. لیست حساسیت (Sensitivity List)

### ۲.۱. مفهوم لیست حساسیت

**لیست حساسیت** مشخص می‌کند که Process **چه زمانی** اجرا شود. Process فقط زمانی اجرا می‌شود که یکی از سیگنال‌های لیست حساسیت **تغییر** کند.

```vhdl
-- ===== Process با لیست حساسیت =====
COMB_PROC: process(a, b, sel)  -- به a, b, sel حساس است
begin
    if sel = '1' then
        y <= a;
    else
        y <= b;
    end if;
end process;

-- ===== Process بدون لیست حساسیت =====
SYNC_PROC: process  -- بدون لیست حساسیت
begin
    wait until rising_edge(clk);  -- با wait اجرا می‌شود
    y <= a;
end process;
```

### ۲.۲. قوانین لیست حساسیت

```vhdl
-- ===== قانون 1: برای Process ترکیبی، همه ورودی‌ها در لیست حساسیت =====
-- ✅ درست
COMB_OK: process(a, b, sel)
begin
    y <= a when sel = '1' else b;
end process;

-- ❌ غلط: sel در لیست حساسیت نیست
COMB_BAD: process(a, b)  -- sel مفقود است
begin
    y <= a when sel = '1' else b;  -- وقتی sel تغییر کند، Process اجرا نمی‌شود
end process;

-- ===== قانون 2: برای Process سنکرون، فقط Clock و Reset =====
SYNC_OK: process(clk, rst)  -- فقط clk و rst
begin
    if rst = '1' then
        y <= '0';
    elsif rising_edge(clk) then
        y <= a;
    end if;
end process;

-- ===== قانون 3: VHDL-2008 - process(all) =====
-- همه سیگنال‌های خوانده شده به لیست حساسیت اضافه می‌شوند
AUTO_PROC: process(all)
begin
    y <= a and b;
    if sel = '1' then
        z <= a;
    else
        z <= b;
    end if;
end process;
```

### ۲.۳. مقایسه انواع Process بر اساس لیست حساسیت

```vhdl
-- ===== 1. Process ترکیبی (Combinational) =====
-- • لیست حساسیت: همه ورودی‌ها
-- • بدون Clock
-- • خروجی فوراً به ورودی پاسخ می‌دهد

COMB: process(a, b, c)
begin
    y <= (a and b) or c;
end process;

-- ===== 2. Process سنکرون (Synchronous) =====
-- • لیست حساسیت: Clock و (اختیاری) Async Reset
-- • با Clock
-- • خروجی در لبه Clock به‌روز می‌شود

SYNC: process(clk, rst)
begin
    if rst = '1' then
        y <= '0';
    elsif rising_edge(clk) then
        y <= a;
    end if;
end process;

-- ===== 3. Process با Async Reset =====
-- • لیست حساسیت: Clock و Reset
-- • Reset در هر زمان (حتی بدون Clock) عمل می‌کند

ASYNC_RESET: process(clk, rst)
begin
    if rst = '1' then
        y <= '0';  -- Async Reset
    elsif rising_edge(clk) then
        y <= a;
    end if;
end process;

-- ===== 4. Process با Sync Reset =====
-- • لیست حساسیت: فقط Clock
-- • Reset فقط در لبه Clock عمل می‌کند

SYNC_RESET: process(clk)
begin
    if rising_edge(clk) then
        if rst = '1' then
            y <= '0';  -- Sync Reset
        else
            y <= a;
        end if;
    end if;
end process;
```

## ۳. متغیرها در Process

### ۳.۱. تعریف و استفاده از متغیر

```vhdl
-- ===== تعریف متغیر =====
process(clk)
    variable v1 : integer := 0;           -- مقدار اولیه
    variable v2 : std_logic_vector(7 downto 0);
    variable v3 : boolean := false;
    constant c1 : integer := 10;          -- ثابت محلی
begin
    -- استفاده از متغیر
    v1 := v1 + 1;
    v2 := std_logic_vector(to_unsigned(v1, 8));
    
    if v1 > c1 then
        v3 := true;
    else
        v3 := false;
    end if;
end process;
```

### ۳.۲. تفاوت متغیر و سیگنال در Process

```vhdl
-- ===== مثال 1: تفاوت در زمان به‌روزرسانی =====
process(clk)
    variable v : integer := 0;
    signal s : integer := 0;
begin
    if rising_edge(clk) then
        -- Variable: فوراً به‌روز می‌شود
        v := v + 1;     -- v = 1
        v := v + 2;     -- v = 3 (از مقدار 1 استفاده می‌کند)
        v := v + 3;     -- v = 6 (از مقدار 3 استفاده می‌کند)
        
        -- Signal: در انتهای Process به‌روز می‌شود
        s <= s + 1;     -- s = 1 (در انتها)
        s <= s + 2;     -- s = 2 (در انتها - از مقدار OLD استفاده می‌کند)
        s <= s + 3;     -- s = 3 (در انتها - فقط آخرین مقدار)
        -- نتیجه نهایی: s = 3 (نه 6!)
    end if;
end process;

-- ===== مثال 2: تفاوت در دسترسی به مقدار =====
process(clk)
    variable v : integer := 0;
    signal s : integer := 0;
begin
    if rising_edge(clk) then
        -- Variable: مقدار جدید فوراً در دسترس است
        v := v + 1;
        if v > 5 then  -- از مقدار جدید استفاده می‌کند
            y <= '1';
        end if;
        
        -- Signal: مقدار جدید در انتها در دسترس است
        s <= s + 1;
        if s > 5 then  -- از مقدار OLD استفاده می‌کند!
            z <= '1';
        end if;
    end if;
end process;
```

### ۳.۳. کاربردهای متغیر

```vhdl
-- ===== 1. محاسبات موقتی =====
process(clk)
    variable temp : integer;
begin
    if rising_edge(clk) then
        temp := a + b;          -- محاسبه موقتی
        temp := temp * 2;
        result <= std_logic_vector(to_unsigned(temp, 8));
    end if;
end process;

-- ===== 2. الگوریتم‌های پیچیده =====
process(clk)
    variable data : integer_vector(0 to 7);
    variable sum : integer := 0;
begin
    if rising_edge(clk) then
        -- بارگذاری داده
        for i in 0 to 7 loop
            data(i) := to_integer(unsigned(data_in(i*8+7 downto i*8)));
        end loop;
        
        -- محاسبه جمع
        sum := 0;
        for i in 0 to 7 loop
            sum := sum + data(i);
        end loop;
        
        result <= std_logic_vector(to_unsigned(sum, 32));
    end if;
end process;

-- ===== 3. FSM با متغیر =====
process(clk, rst)
    variable state : state_t := IDLE;  -- متغیر برای حالت
begin
    if rst = '1' then
        state := IDLE;
    elsif rising_edge(clk) then
        case state is
            when IDLE =>
                if start = '1' then
                    state := RUN;
                end if;
            when RUN =>
                if done = '1' then
                    state := DONE;
                end if;
            when DONE =>
                state := IDLE;
        end case;
    end if;
    current_state <= state;  -- خروجی به سیگنال
end process;
```

## ۴. انواع Process بر اساس کاربرد

### ۴.۱. Process ترکیبی (Combinational)

```vhdl
-- ===== Process ترکیبی =====
-- • بدون Clock
-- • خروجی فوراً به ورودی پاسخ می‌دهد
-- • همه ورودی‌ها در لیست حساسیت

library ieee;
use ieee.std_logic_1164.all;
use ieee.numeric_std.all;

entity comb_process is
    port (
        a, b : in  std_logic_vector(7 downto 0);
        sel  : in  std_logic_vector(1 downto 0);
        y    : out std_logic_vector(7 downto 0)
    );
end entity;

architecture rtl of comb_process is
begin
    COMB_PROC: process(a, b, sel)
        variable result : unsigned(7 downto 0);
    begin
        -- مقدار پیش‌فرض (جلوگیری از Latch)
        y <= (others => '0');
        result := (others => '0');
        
        -- منطق اصلی
        case sel is
            when "00" =>
                result := unsigned(a) + unsigned(b);
            when "01" =>
                result := unsigned(a) - unsigned(b);
            when "10" =>
                result := unsigned(a) * unsigned(b)(7 downto 0);
            when "11" =>
                result := unsigned(a) / unsigned(b)(7 downto 0);
            when others =>
                result := (others => '0');
        end case;
        
        y <= std_logic_vector(result);
    end process COMB_PROC;
end architecture;
```

### ۴.۲. Process سنکرون (Synchronous)

```vhdl
-- ===== Process سنکرون =====
-- • با Clock
-- • خروجی در لبه Clock به‌روز می‌شود
-- • لیست حساسیت: فقط Clock و (اختیاری) Reset

library ieee;
use ieee.std_logic_1164.all;
use ieee.numeric_std.all;

entity sync_process is
    port (
        clk   : in  std_logic;
        rst   : in  std_logic;
        en    : in  std_logic;
        data  : in  std_logic_vector(7 downto 0);
        q     : out std_logic_vector(7 downto 0)
    );
end entity;

architecture rtl of sync_process is
    signal reg : std_logic_vector(7 downto 0);
begin
    SYNC_PROC: process(clk)
    begin
        if rising_edge(clk) then
            if rst = '1' then
                reg <= (others => '0');
            elsif en = '1' then
                reg <= data;
            end if;
        end if;
    end process;
    
    q <= reg;
end architecture;
```

## ۵. Process برای FSM (ماشین‌های حالت)

### ۵.۱. FSM با دو Process

```vhdl
-- ===== FSM با دو Process =====
-- Process اول: منطق حالت بعدی (ترکیبی)
-- Process دوم: منطق خروجی و ثبت حالت (سنکرون)

library ieee;
use ieee.std_logic_1164.all;
use ieee.numeric_std.all;

entity fsm_two_process is
    port (
        clk   : in  std_logic;
        rst   : in  std_logic;
        start : in  std_logic;
        done  : out std_logic
    );
end entity;

architecture rtl of fsm_two_process is
    type state_t is (IDLE, RUN, DONE);
    signal current_state : state_t;
    signal next_state : state_t;
begin
    -- ===== Process 1: منطق حالت بعدی (ترکیبی) =====
    NEXT_STATE_PROC: process(current_state, start)
    begin
        case current_state is
            when IDLE =>
                if start = '1' then
                    next_state <= RUN;
                else
                    next_state <= IDLE;
                end if;
            
            when RUN =>
                -- منطق RUN
                next_state <= DONE;
            
            when DONE =>
                next_state <= IDLE;
            
            when others =>
                next_state <= IDLE;
        end case;
    end process;
    
    -- ===== Process 2: ثبت حالت (سنکرون) =====
    STATE_PROC: process(clk, rst)
    begin
        if rst = '1' then
            current_state <= IDLE;
        elsif rising_edge(clk) then
            current_state <= next_state;
        end if;
    end process;
    
    -- ===== منطق خروجی (ترکیبی) =====
    done <= '1' when current_state = DONE else '0';
end architecture;
```

### ۵.۲. FSM با یک Process

```vhdl
-- ===== FSM با یک Process =====
-- همه منطق در یک Process سنکرون

library ieee;
use ieee.std_logic_1164.all;

entity fsm_one_process is
    port (
        clk   : in  std_logic;
        rst   : in  std_logic;
        start : in  std_logic;
        done  : out std_logic
    );
end entity;

architecture rtl of fsm_one_process is
    type state_t is (IDLE, RUN, DONE);
    signal state : state_t;
begin
    FSM_PROC: process(clk, rst)
    begin
        if rst = '1' then
            state <= IDLE;
            done <= '0';
            
        elsif rising_edge(clk) then
            case state is
                when IDLE =>
                    done <= '0';
                    if start = '1' then
                        state <= RUN;
                    end if;
                
                when RUN =>
                    -- منطق RUN
                    state <= DONE;
                
                when DONE =>
                    done <= '1';
                    state <= IDLE;
                
                when others =>
                    state <= IDLE;
            end case;
        end if;
    end process;
end architecture;
```

### ۵.۳. FSM با متغیر (پیشرفته)

```vhdl
-- ===== FSM با متغیر برای حالت =====
library ieee;
use ieee.std_logic_1164.all;

entity fsm_variable is
    port (
        clk    : in  std_logic;
        rst    : in  std_logic;
        data   : in  std_logic_vector(7 downto 0);
        result : out std_logic_vector(7 downto 0)
    );
end entity;

architecture rtl of fsm_variable is
    type state_t is (IDLE, PROCESSING, OUTPUT);
begin
    FSM_PROC: process(clk, rst)
        variable state : state_t := IDLE;  -- متغیر برای حالت
        variable count : integer := 0;
        variable temp : std_logic_vector(7 downto 0);
    begin
        if rst = '1' then
            state := IDLE;
            count := 0;
            result <= (others => '0');
            
        elsif rising_edge(clk) then
            case state is
                when IDLE =>
                    if data /= "00000000" then
                        state := PROCESSING;
                        temp := data;
                        count := 0;
                    end if;
                
                when PROCESSING =>
                    count := count + 1;
                    temp := std_logic_vector(unsigned(temp) + 1);
                    if count > 10 then
                        state := OUTPUT;
                    end if;
                
                when OUTPUT =>
                    result <= temp;
                    state := IDLE;
            end case;
        end if;
    end process;
end architecture;
```

## ۶. نکات پیشرفته Process

### ۶.۱. Postponed Process

```vhdl
-- ===== Postponed Process =====
-- بعد از همه Processهای دیگر اجرا می‌شود
-- برای انجام کارهای "پس از پایان" مانند گزارش‌دهی

library ieee;
use ieee.std_logic_1164.all;

entity postponed_example is
    port (
        clk : in  std_logic;
        data : in  std_logic_vector(7 downto 0)
    );
end entity;

architecture rtl of postponed_example is
begin
    -- ===== Process عادی =====
    MAIN_PROC: process(clk)
    begin
        if rising_edge(clk) then
            -- منطق اصلی
            report "Main process executed";
        end if;
    end process;
    
    -- ===== Postponed Process =====
    POSTPONED_PROC: postponed process(clk)
    begin
        if rising_edge(clk) then
            -- بعد از همه Processهای دیگر اجرا می‌شود
            report "Postponed process executed";
        end if;
    end process;
end architecture;
```

### ۶.۲. Process با Wait

```vhdl
-- ===== Process با Wait =====
-- Process بدون لیست حساسیت، از wait استفاده می‌کند

library ieee;
use ieee.std_logic_1164.all;

entity wait_process is
    port (
        clk   : in  std_logic;
        rst   : in  std_logic;
        a, b  : in  std_logic_vector(7 downto 0);
        result : out std_logic_vector(7 downto 0)
    );
end entity;

architecture rtl of wait_process is
begin
    -- ===== Process با wait until =====
    SYNC_PROC: process
    begin
        wait until rising_edge(clk);  -- منتظر لبه Clock
        result <= a and b;
    end process;
    
    -- ===== Process با wait on =====
    COMB_PROC: process
    begin
        wait on a, b;  -- منتظر تغییر a یا b
        result <= a or b;
    end process;
    
    -- ===== Process با wait for (فقط Testbench) =====
    TEST_PROC: process
    begin
        wait for 10 ns;
        result <= "00000000";
        wait for 20 ns;
        result <= "11111111";
        wait;  -- forever
    end process;
end architecture;
```

## ۸. بهترین‌نوشته‌ها (Best Practices)

### ۸.۱. ساختار Process استاندارد

```vhdl
-- ===== Template برای Process سنکرون با Async Reset =====
SYNC_PROC: process(clk, rst)  -- 1. نام و لیست حساسیت
    -- 2. اعلان متغیرها
    variable v1 : integer := 0;
    variable v2 : std_logic_vector(7 downto 0);
begin
    -- 3. منطق Reset
    if rst = '1' then
        -- مقداردهی اولیه سیگنال‌ها
        sig1 <= (others => '0');
        sig2 <= '0';
        -- مقداردهی اولیه متغیرها
        v1 := 0;
        v2 := (others => '0');
        
    -- 4. منطق اصلی (در لبه Clock)
    elsif rising_edge(clk) then
        -- منطق اصلی
        if condition then
            -- ...
        end if;
    end if;
end process SYNC_PROC;

-- ===== Template برای Process ترکیبی =====
COMB_PROC: process(all)  -- VHDL-2008
    -- 2. اعلان متغیرها (اختیاری)
begin
    -- 3. مقدار پیش‌فرض برای همه خروجی‌ها
    y <= (others => '0');
    z <= '0';
    
    -- 4. منطق اصلی
    if sel = '1' then
        y <= a;
    else
        y <= b;
    end if;
end process COMB_PROC;
```

```vhdl
        y <= a;
    else
        y <= b;  -- مقدار پیش‌فرض
    end if;

begin
    y <= b;  -- مقدار پیش‌فرض
    if sel = '1' then
        y <= a;
    end if;
end process;

-- 3. استفاده از others در case
case opcode is
    when "00" => y <= a;
    when "01" => y <= b;
    when others => y <= (others => '0');  -- مقدار پیش‌فرض
end case;

-- 4. مقداردهی به همه سیگنال‌ها در همه مسیرها
process(a, b, sel)
begin
    y <= (others => '0');  -- مقدار پیش‌فرض
    z <= '0';
    if sel = '1' then
        y <= a;
        z <= '1';
    end if;
end process;
```

### ۸.۴. بهینه‌سازی Process

```vhdl
-- ===== بهینه‌سازی 1: کاهش محاسبات =====
-- ❌ ناکارآمد
process(clk)
begin
    if rising_edge(clk) then
        y <= a + b + c + d;  -- 3 جمع
    end if;
end process;

-- ✅ کارآمدتر
process(clk)
    variable temp : integer;
begin
    if rising_edge(clk) then
        temp := a + b;      -- جمع 1
        temp := temp + c;   -- جمع 2
        y <= temp + d;      -- جمع 3 (اما 2 جمع پشت سر هم)
    end if;
end process;

-- ===== بهینه‌سازی 2: استفاده از متغیر =====
-- ❌ ناکارآمد (از سیگنال برای محاسبات موقتی)
process(clk)
    signal s : integer;
begin
    if rising_edge(clk) then
        s <= a + b;    -- سیگنال
        y <= s + c;    -- از مقدار OLD s استفاده می‌کند!
    end if;
end process;

-- ✅ کارآمدتر (از متغیر)
process(clk)
    variable v : integer;
begin
    if rising_edge(clk) then
        v := a + b;    -- متغیر
        y <= v + c;    -- از مقدار جدید استفاده می‌کند
    end if;
end process;
```

## ۱۰. خلاصه و جمع‌بندی

### جدول انواع Process

| نوع Process | لیست حساسیت | Clock | Reset | کاربرد |
|-------------|-------------|-------|-------|--------|
| **ترکیبی** | همه ورودی‌ها | خیر | خیر | منطق ترکیبی |
| **سنکرون** | فقط Clock | بله | Sync Reset | منطق ترتیبی |
| **Async Reset** | Clock + Reset | بله | Async Reset | منطق ترتیبی با Reset فوری |
| **با Wait** | بدون لیست | بله | اختیاری | تولید کننده‌ها |
| **Postponed** | اختیاری | اختیاری | اختیاری | گزارش‌دهی |
| **process(all)** | خودکار | خیر | خیر | منطق ترکیبی (VHDL-2008) |

### قوانین کلیدی

| قانون | توضیح |
|-------|-------|
| **لیست حساسیت کامل** | همه سیگنال‌های ورودی را در لیست حساسیت قرار دهید |
| **جلوگیری از Latch** | به همه سیگنال‌ها در همه مسیرها مقدار دهید |
| **یک درایور** | هر سیگنال فقط در یک Process انتساب داده شود |
| **یک لبه Clock** | در هر Process فقط از یک لبه Clock استفاده کنید |
| **متغیر vs سیگنال** | از متغیر برای محاسبات موقتی و سیگنال برای ارتباط استفاده کنید |
| **Reset کامل** | در Reset همه سیگنال‌ها و متغیرها را مقداردهی کنید |

### انتخاب نوع Process

```
┌─────────────────────────────────────────────────────────────────────┐
│  چه نوع Process استفاده کنیم؟                                     │
├─────────────────────────────────────────────────────────────────────┤
│                                                                   │
│  ┌─────────────────────────────────────────────────────────────┐  │
│  │  COMBINATIONAL (ترکیبی)                                    │  │
│  │  • بدون Clock                                              │  │
│  │  • همه ورودی‌ها در لیست حساسیت                            │  │
│  │  • مثال: MUX, Decoder, ALU (بدون ثبت)                    │  │
│  └─────────────────────────────────────────────────────────────┘  │
│                                                                   │
│  ┌─────────────────────────────────────────────────────────────┐  │
│  │  SYNCHRONOUS (سنکرون)                                      │  │
│  │  • با Clock                                                │  │
│  │  • فقط Clock در لیست حساسیت (یا Clock + Reset Async)      │  │
│  │  • مثال: Register, Counter, FSM, Pipeline                │  │
│  └─────────────────────────────────────────────────────────────┘  │
│                                                                   │
│  ┌─────────────────────────────────────────────────────────────┐  │
│  │  MIXED (ترکیبی)                                            │  │
│  │  • هم منطق ترکیبی و هم سنکرون در یک Process               │  │
│  │  • مثال: Data Path با کنترل                                │  │
│  └─────────────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────────────┘
```

### دستورات مهم

```vhdl
-- ===== تعریف Process =====
label: process(sensitivity_list) [is]
    -- declarations
begin
    -- sequential statements
end process label;

-- ===== Process با Async Reset =====
process(clk, rst)
begin
    if rst = '1' then
        -- reset
    elsif rising_edge(clk) then
        -- logic
    end if;
end process;

-- ===== Process با Sync Reset =====
process(clk)
begin
    if rising_edge(clk) then
        if rst = '1' then
            -- reset
        else
            -- logic
        end if;
    end if;
end process;

-- ===== Process ترکیبی =====
process(all)  -- VHDL-2008
begin
    y <= (others => '0');  -- default
    -- combinational logic
end process;
```

> **پیام نهایی:** **Process** قلب تپنده طراحی VHDL است. درک صحیح از انواع Process، لیست حساسیت، تفاوت Signal و Variable، و قوانین سنتز، برای طراحی **حرفه‌ای** و **کارآمد** ضروری است. به یاد داشته باشید که Process تنها جایی است که می‌توانید از **دستورات ترتیبی** استفاده کنید و این قدرت را به شما می‌دهد تا **الگوریتم‌های پیچیده** و **ماشین‌های حالت** را در سخت‌افزار پیاده‌سازی کنید.
