# دستور Generate در VHDL — تحلیل جامع و عمیق

## مقدمه: کارخانه تولید ساختارهای تکراری

تصور کنید می‌خواهید یک **مجتمع مسکونی** با ۱۰۰ واحد یکسان بسازید. آیا نقشه هر واحد را جداگانه می‌کشید؟ خیر — یک **نقشه استاندارد** طراحی می‌کنید و سپس آن را **۱۰۰ بار تکرار** می‌کنید. این دقیقاً همان کاری است که دستور **`generate`** در VHDL انجام می‌دهد — **تولید ساختارهای تکراری** به صورت خودکار.

دستور `generate` یکی از **دستورات همزمان** مهم در VHDL است که برای:
- **تکرار** ساختارهای سخت‌افزاری
- **ایجاد** آرایه‌های از Componentها
- **ساخت** خطوط لوله (Pipeline)
- **پیاده‌سازی** ساختارهای شرطی در سطح معماری

---

## ۱. مفهوم و ساختار Generate

### ۱.۱. ساختار کلی

```
┌─────────────────────────────────────────────────────────────────────┐
│                    GENERATE STATEMENT STRUCTURE                   │
├─────────────────────────────────────────────────────────────────────┤
│                                                                   │
│  ┌─────────────────────────────────────────────────────────────┐  │
│  │  [label:] for parameter in range generate                 │  │
│  │  ┌──────────────────────────────────────────────────────┐  │  │
│  │  │  -- declarations (اختیاری)                          │  │  │
│  │  │  -- concurrent statements                           │  │  │
│  │  │  -- component instantiations                        │  │  │
│  │  │  -- process statements                              │  │  │
│  │  │  -- nested generate                                 │  │  │
│  │  └──────────────────────────────────────────────────────┘  │  │
│  │  end generate [label];                                   │  │
│  └─────────────────────────────────────────────────────────────┘  │
│                                                                   │
│  ┌─────────────────────────────────────────────────────────────┐  │
│  │  [label:] if condition generate                           │  │
│  │  ┌──────────────────────────────────────────────────────┐  │  │
│  │  │  -- concurrent statements                           │  │  │
│  │  └──────────────────────────────────────────────────────┘  │  │
│  │  end generate [label];                                   │  │
│  └─────────────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────────────┘
```

### ۱.۲. انواع Generate

```vhdl
-- ===== 1. for/generate (تولید تکراری) =====
GEN_LABEL: for i in 0 to 7 generate
    -- ساختارهای تکراری
end generate GEN_LABEL;

-- ===== 2. if/generate (تولید شرطی) =====
GEN_LABEL: if condition generate
    -- ساختارهای شرطی
end generate GEN_LABEL;

-- ===== 3. case/generate (VHDL-2008) =====
GEN_LABEL: case expression generate
    when choice_1 =>
        -- ساختارهای انتخاب 1
    when choice_2 =>
        -- ساختارهای انتخاب 2
end generate GEN_LABEL;
```

### ۱.۳. مثال‌های ساده

```vhdl
library ieee;
use ieee.std_logic_1164.all;

entity generate_example is
    generic (
        N : integer := 8
    );
    port (
        clk   : in  std_logic;
        rst   : in  std_logic;
        data_in  : in  std_logic_vector(N-1 downto 0);
        data_out : out std_logic_vector(N-1 downto 0)
    );
end entity;

architecture rtl of generate_example is
    signal reg : std_logic_vector(N-1 downto 0);
begin
    -- ===== for/generate برای ایجاد N D-Flip-Flop =====
    GEN_FF: for i in 0 to N-1 generate
        DFF_INST: process(clk, rst)
        begin
            if rst = '1' then
                reg(i) <= '0';
            elsif rising_edge(clk) then
                reg(i) <= data_in(i);
            end if;
        end process;
    end generate GEN_FF;
    
    data_out <= reg;
end architecture;
```

## ۲. for/generate

### ۲.۱. ساختار for/generate

```vhdl
-- ===== ساختار کلی =====
[label:] for parameter in range generate
    -- declarations (اختیاری)
    -- concurrent statements
    -- component instantiations
    -- process statements
    -- nested generate
end generate [label];

-- ===== مثال کامل =====
architecture rtl of example is
begin
    GEN: for i in 0 to 7 generate
        -- هر i یک بلوک مجزا ایجاد می‌کند
        U_FF: dff
            port map (
                clk => clk,
                rst => rst,
                d => data_in(i),
                q => data_out(i)
            );
    end generate GEN;
end architecture;
```

### ۲.۲. for/generate با Componentها

```vhdl
-- ===== برای ایجاد آرایه‌ای از Componentها =====
library ieee;
use ieee.std_logic_1164.all;

entity array_of_components is
    generic (
        N : integer := 8
    );
    port (
        clk   : in  std_logic;
        rst   : in  std_logic;
        data_in  : in  std_logic_vector(N-1 downto 0);
        data_out : out std_logic_vector(N-1 downto 0)
    );
end entity;

architecture structural of array_of_components is
    component dff is
        port (
            clk, rst, d : in  std_logic;
            q           : out std_logic
        );
    end component;
begin
    -- ===== ایجاد N D-Flip-Flop =====
    GEN_FF: for i in 0 to N-1 generate
        U_FF: dff
            port map (
                clk => clk,
                rst => rst,
                d => data_in(i),
                q => data_out(i)
            );
    end generate GEN_FF;
end architecture;
```

```vhdl
-- ===== برای ایجاد Processهای تکراری =====
```

## ۳. if/generate

### ۳.۱. ساختار if/generate

```vhdl
-- ===== ساختار کلی =====
[label:] if condition generate
    -- concurrent statements
    -- component instantiations
    -- process statements
end generate [label];

-- ===== مثال کامل =====
architecture rtl of example is
    generic (
        USE_PARITY : boolean := true;
        DATA_WIDTH : integer := 8
    );
begin
    -- ===== if/generate با Generic =====
    GEN_PARITY: if USE_PARITY generate
        U_PARITY: parity_check
            port map (
                data => data_in,
                parity => parity_out
            );
    end generate GEN_PARITY;
    
    GEN_NO_PARITY: if not USE_PARITY generate
        parity_out <= '0';
    end generate GEN_NO_PARITY;
end architecture;
```

### ۳.۲. if/generate با Generic

```vhdl
-- ===== استفاده از Generic برای تولید شرطی =====
library ieee;
use ieee.std_logic_1164.all;

entity conditional_generate is
    generic (
        DATA_WIDTH : integer := 8;
        USE_DEBUG  : boolean := false
    );
    port (
        clk   : in  std_logic;
        data  : in  std_logic_vector(DATA_WIDTH-1 downto 0);
        result : out std_logic_vector(DATA_WIDTH-1 downto 0)
    );
end entity;

architecture rtl of conditional_generate is
begin
    -- ===== بر اساس DATA_WIDTH =====
    GEN_8BIT: if DATA_WIDTH = 8 generate
        -- منطق مخصوص 8 بیت
        U_ALU: alu_8bit
            port map (
                a => data,
                b => data,
                y => result
            );
    end generate GEN_8BIT;
    
    GEN_16BIT: if DATA_WIDTH = 16 generate
        -- منطق مخصوص 16 بیت
        U_ALU: alu_16bit
            port map (
                a => data,
                b => data,
                y => result
            );
    end generate GEN_16BIT;
    
    -- ===== بر اساس USE_DEBUG =====
    GEN_DEBUG: if USE_DEBUG generate
        DEBUG_PROC: process(clk)
        begin
            if rising_edge(clk) then
                report "Data: " & to_string(data);
            end if;
        end process;
    end generate GEN_DEBUG;
end architecture;
```

### ۳.۳. if/generate با شرط پیچیده

```vhdl
-- ===== شرط‌های پیچیده در if/generate =====
architecture rtl of complex_generate is
    constant N : integer := 8;

            port map (
                data => data_in,
                result => alt_out
            );
    end generate GEN_ALTERNATIVE;
end architecture;
```

## ۴. case/generate (VHDL-2008)

### ۴.۱. ساختار case/generate

```vhdl
-- ===== VHDL-2008: case/generate =====
[label:] case expression generate
    when choice_1 =>
        -- concurrent statements
    when choice_2 =>
        -- concurrent statements
    when choice_3 | choice_4 =>
        -- concurrent statements
    when choice_5 to choice_10 =>
        -- concurrent statements
    when others =>
        -- concurrent statements
end generate [label];

-- ===== مثال =====
architecture rtl of example is
    type mode_t is (MODE_A, MODE_B, MODE_C);
    constant MODE : mode_t := MODE_A;
begin
    GEN_MODE: case MODE generate
        when MODE_A =>
            U_A: block_a
                port map (
                    data => data_in,
                    result => result_out
                );
        when MODE_B =>
            U_B: block_b
                port map (
                    data => data_in,
                    result => result_out
                );
        when MODE_C =>
            U_C: block_c
                port map (
                    data => data_in,
                    result => result_out
                );
    end generate GEN_MODE;
end architecture;
```

## ۵. Generate تو در تو

### ۵.۱. for/generate تو در تو

```vhdl
-- ===== for/generate تو در تو =====
architecture rtl of matrix is
    type matrix_t is array (0 to 3, 0 to 3) of std_logic;
    signal matrix : matrix_t;
begin
    -- ===== ماتریس 4x4 =====
    GEN_ROW: for row in 0 to 3 generate
        GEN_COL: for col in 0 to 3 generate
            U_CELL: cell
                port map (
                    row_in => row,
                    col_in => col,
                    data => matrix(row, col)
                );
        end generate GEN_COL;
    end generate GEN_ROW;
end architecture;
```

### ۵.۲. for/generate با if/generate

```vhdl
-- ===== ترکیب for و if =====
architecture rtl of conditional_array is
begin
    GEN_ARRAY: for i in 0 to 7 generate
        -- فقط برای i زوج
        if i mod 2 = 0 generate
            U_EVEN: even_block
                port map (
                    data => data_in(i),
                    q => data_out(i)
                );
        end generate;
        
        -- فقط برای i فرد
        if i mod 2 = 1 generate
            U_ODD: odd_block
                port map (
                    data => data_in(i),
                    q => data_out(i)
                );
        end generate;
    end generate GEN_ARRAY;
end architecture;
```

### ۵.۳. مثال: Pipeline با Generate

```vhdl
-- ===== Pipeline با generate =====
architecture rtl of pipeline is
    type stage_array is array (0 to STAGES-1) of std_logic_vector(7 downto 0);
    signal stage_data : stage_array;
begin
    -- ===== Stage اول (ورودی) =====
    stage_data(0) <= data_in;
    
    -- ===== Stageهای میانی =====
    GEN_STAGE: for i in 1 to STAGES-2 generate
        U_STAGE: process(clk, rst)
        begin
            if rst = '1' then
                stage_data(i) <= (others => '0');
            elsif rising_edge(clk) then
                stage_data(i) <= stage_data(i-1);
            end if;
        end process;
    end generate GEN_STAGE;
    
    -- ===== Stage آخر (خروجی) =====
    data_out <= stage_data(STAGES-2);
end architecture;
```

## ۶. کاربردهای پیشرفته Generate

### ۶.۱. ایجاد ساختارهای تکراری با شرط

```vhdl
-- ===== ساختارهای تکراری با شرط =====
architecture rtl of complex_structure is
    constant NUM_BITS : integer := 8;
    signal carry : std_logic_vector(NUM_BITS downto 0);
begin
    carry(0) <= '0';
    
    GEN_ADDER: for i in 0 to NUM_BITS-1 generate
        U_FA: full_adder
            port map (
                a => data_a(i),
                b => data_b(i),
                cin => carry(i),
                sum => result(i),
                cout => carry(i+1)
            );
    end generate GEN_ADDER;
    
    overflow <= carry(NUM_BITS);
end architecture;
```

### ۶.۲. ایجاد خطوط لوله (Pipeline)

```vhdl
-- ===== Pipeline با Stages مختلف =====
architecture rtl of deep_pipeline is
    type pipe_array is array (0 to DEPTH-1) of std_logic_vector(7 downto 0);
    signal pipe : pipe_array;
begin
    -- ===== Pipeline با Depth متغیر =====
    GEN_PIPE: for i in 0 to DEPTH-1 generate
        U_STAGE: process(clk, rst)
        begin
            if rst = '1' then
                pipe(i) <= (others => '0');
            elsif rising_edge(clk) then
                if i = 0 then
                    pipe(i) <= data_in;
                else
                    pipe(i) <= pipe(i-1);
                end if;
            end if;
        end process;
    end generate GEN_PIPE;
    
    data_out <= pipe(DEPTH-1);
end architecture;
```

### ۶.۳. ایجاد ساختارهای شرطی با Generic

```vhdl
-- ===== ساختارهای شرطی با Generic =====
architecture rtl of configurable_adder is
    generic (
        USE_CARRY_LOOKAHEAD : boolean := true;
        WIDTH : integer := 8
    );
begin
    -- ===== Adder با Carry Lookahead =====
    GEN_CLA: if USE_CARRY_LOOKAHEAD generate
        U_CLA: carry_lookahead_adder
            generic map (
                N => WIDTH
            )
            port map (
                a => data_a,
                b => data_b,
                sum => result
            );
    end generate GEN_CLA;
    
    -- ===== Adder ساده (Ripple Carry) =====
    GEN_RIPPLE: if not USE_CARRY_LOOKAHEAD generate
        U_RIPPLE: ripple_carry_adder
            generic map (
                N => WIDTH
            )
            port map (
                a => data_a,
                b => data_b,
                sum => result
            );
    end generate GEN_RIPPLE;
end architecture;
```

### ۶.۴. ایجاد ساختارهای ماژولار

```vhdl
-- ===== ساختارهای ماژولار =====
architecture rtl of modular_system is
    type module_array is array (0 to NUM_MODULES-1) of std_logic_vector(7 downto 0);

begin

    end generate GEN_MODULES;
end architecture;
```

```vhdl
architecture rtl of example is
```

### ۷.۳. Generate با توابع

```vhdl
-- ===== استفاده از توابع در Generate =====
package gen_pkg is
    function calc_width(n : integer) return integer;
end package;

package body gen_pkg is
    function calc_width(n : integer) return integer is
        variable result : integer := 1;
    begin
        while 2**result < n loop
            result := result + 1;
        end loop;
        return result;
    end function;
end package body;

architecture rtl of example is
    constant NUM_ELEMENTS : integer := 10;
    constant WIDTH : integer := calc_width(NUM_ELEMENTS);
begin
    GEN_ELEMENTS: for i in 0 to NUM_ELEMENTS-1 generate
        U_ELEMENT: element
            generic map (
                INDEX => i
            )
            port map (
                data => data_in,
                sel => sel_vector(WIDTH-1 downto 0)
            );
    end generate GEN_ELEMENTS;
end architecture;
```

```vhdl
begin
    GEN: for i in 0 to 7 generate
        U_FF: dff  -- ✅ نام با i خودکار است
            port map (
                d => data_in(i),
                q => data_out(i)
            );
    end generate GEN;
end architecture;
```

### ۸.۴. خطا: شرط ثابت نیست

```vhdl
-- ===== ❌ اشتباه =====
architecture rtl of example is
    function calc(n : integer) return boolean is
    begin
        return n > 0;
    end function;
begin
    GEN: if calc(5) generate  -- ❌ باید ثابت باشد
        U_BLOCK: block_a
            port map (
                data => data_in,
                result => result_out
            );
    end generate GEN;
end architecture;

-- ===== ✅ راه‌حل =====
architecture rtl of example is
    constant COND : boolean := true;  -- ✅ ثابت
begin
    GEN: if COND generate
        U_BLOCK: block_a
            port map (
                data => data_in,
                result => result_out
            );
    end generate GEN;
end architecture;
```

## ۹. بهترین‌نوشته‌ها (Best Practices)

### ۹.۱. استفاده از Label

```vhdl
-- ===== ✅ با label =====
GEN_FF: for i in 0 to 7 generate
    U_FF: dff
        port map (
            clk => clk,
            d => data_in(i),
            q => data_out(i)
        );
end generate GEN_FF;

-- ===== ❌ بدون label =====
for i in 0 to 7 generate
    U_FF: dff
        port map (
            clk => clk,
            d => data_in(i),
            q => data_out(i)
        );
end generate;
```

### ۹.۲. استفاده از Generic

```vhdl
-- ===== ✅ استفاده از Generic =====
architecture rtl of example is
    generic (
        N : integer := 8
    );
begin
    GEN: for i in 0 to N-1 generate
        U_FF: dff
            port map (
                clk => clk,
                d => data_in(i),
                q => data_out(i)
            );
    end generate GEN;
end architecture;

-- ===== ❌ استفاده از اعداد ثابت =====
architecture rtl of example is
begin
    GEN: for i in 0 to 7 generate  -- ❌ ثابت
        U_FF: dff
            port map (
                clk => clk,
                d => data_in(i),
                q => data_out(i)
            );
    end generate GEN;
end architecture;
```

### ۹.۳. مستندسازی

```vhdl
-- ===== ✅ با توضیحات =====
-- این Generate N D-Flip-Flop ایجاد می‌کند
-- هر Flip-Flop یک بیت از داده را ذخیره می‌کند
GEN_FF: for i in 0 to N-1 generate
    U_FF: dff
        port map (
            clk => clk,
            rst => rst,
            d => data_in(i),
            q => data_out(i)
        );
end generate GEN_FF;
```

### ۹.۴. محدود کردن تو در تو

```vhdl
-- ===== ✅ تا ۳ سطح =====
GEN_OUTER: for i in 0 to 5 generate
    GEN_MIDDLE: for j in 0 to 5 generate
        GEN_INNER: for k in 0 to 5 generate
            U_CELL: cell
                port map (
                    a => i,
                    b => j,
                    c => k,
                    y => data(i, j, k)
                );
        end generate GEN_INNER;
    end generate GEN_MIDDLE;
end generate GEN_OUTER;
```

### ۹.۵. استفاده از `'range` و `'length`

```vhdl
-- ===== ✅ با 'range =====
GEN: for i in data'range generate
    U_BIT: bit_processor
        port map (
            bit_in => data(i),
            bit_out => result(i)
        );
end generate GEN;

-- ===== ✅ با 'length =====
GEN: for i in 0 to data'length-1 generate
    U_BIT: bit_processor
        port map (
            bit_in => data(i),
            bit_out => result(i)
        );
end generate GEN;
```

## ۱۰. خلاصه و جمع‌بندی

### جدول انواع Generate

| نوع | ساختار | کاربرد |
|-----|--------|--------|
| **for/generate** | `for i in range generate` | تولید ساختارهای تکراری |
| **if/generate** | `if condition generate` | تولید شرطی |
| **case/generate** | `case expr generate` | تولید چندحالته (VHDL-2008) |
| **ترکیبی** | `for + if generate` | تولید شرطی تکراری |

### قوانین کلیدی

| قانون | توضیح |
|-------|-------|
| **Label** | همیشه از label استفاده کنید |
| **ثابت بودن شرط** | شرط در if/generate باید ثابت باشد |
| **نوع داده** | از Generic و Constant استفاده کنید |
| **نام‌ها** | نام‌ها خودکار با i ایجاد می‌شوند |
| **ترتیب** | for و if به هر ترتیبی می‌توانند باشند |
| **VHDL-2008** | case/generate فقط در VHDL-2008 پشتیبانی می‌شود |

### دستورات مهم

```vhdl
-- ===== for/generate =====
LABEL: for i in range generate
    -- declarations
    -- concurrent statements
end generate LABEL;

-- ===== if/generate =====
LABEL: if condition generate
    -- concurrent statements
end generate LABEL;

-- ===== case/generate (VHDL-2008) =====
LABEL: case expression generate
    when choice_1 =>
        -- concurrent statements
    when choice_2 =>
        -- concurrent statements
    when others =>
        -- concurrent statements
end generate LABEL;

-- ===== for/generate تو در تو =====
OUTER: for i in range generate
    INNER: for j in range generate
        -- concurrent statements
    end generate INNER;
end generate OUTER;

-- ===== for/generate با if =====
GEN: for i in range generate
    if condition generate
        -- concurrent statements
    end generate;
end generate GEN;
```

> **پیام نهایی:** دستور **`generate`** یک ابزار **قدرتمند** برای **تولید ساختارهای سخت‌افزاری تکراری** در VHDL است که به شما امکان می‌دهد کدهای **تمیز**، **ماژولار** و **قابل نگهداری** بنویسید. با استفاده صحیح از `generate`، می‌توانید **ساختارهای پیچیده** مانند آرایه‌های Component، Pipeline، و ماتریس‌ها را به سادگی پیاده‌سازی کنید. به یاد داشته باشید که `generate` در **سطح معماری** (Architecture) استفاده می‌شود و **دستورات همزمان** را تولید می‌کند.
