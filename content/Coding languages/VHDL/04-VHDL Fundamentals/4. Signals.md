# Signals در VHDL — تحلیل جامع و عمیق

## مقدمه: سیم‌های اتصال در دنیای سخت‌افزار

در دنیای فیزیکی، مدارهای دیجیتال از **سیم‌ها (Wires)** برای اتصال اجزای مختلف به یکدیگر استفاده می‌کنند. این سیم‌ها سیگنال‌های الکتریکی را از یک نقطه به نقطه دیگر منتقل می‌کنند.

در VHDL، **Signal** معادل همان سیم فیزیکی است — اما با قدرت بیشتر. Signalها نه تنها برای اتصال اجزای مختلف استفاده می‌شوند، بلکه می‌توانند **حالت (State)** را ذخیره کنند، **ارزش** را نگه دارند، و بین بخش‌های مختلف یک طراحی ارتباط برقرار کنند.

---

## ۱. Signal چیست؟ تعریف جامع

**Signal** در VHDL یک **نوع داده خاص** است که برای **ارتباط بین بخش‌های مختلف** یک طراحی و **ذخیره‌سازی موقت** مقادیر استفاده می‌شود. Signalها مانند سیم‌های فیزیکی در یک مدار عمل می‌کنند — آنها مقدار خود را حفظ می‌کنند و می‌توانند توسط چندین بخش از مدار خوانده یا نوشته شوند.

### تشبیه ساده

Signal را مانند **یک تابلوی اعلانات** در یک ساختمان تصور کنید:
- هر کس می‌تواند روی تابلو بنویسد (نوشتن Signal)
- هر کس می‌تواند از تابلو بخواند (خواندن Signal)
- تابلو مقدار خود را حفظ می‌کند تا زمانی که کسی آن را تغییر دهد
- چندین نفر می‌توانند همزمان از تابلو بخوانند (Multiple Readers)
- اما فقط یک نفر می‌تواند در یک زمان روی تابلو بنویسد (Single Driver)

## ۲. تفاوت Signal با Variable — تحلیل عمیق

### Signal (سیگنال)

```vhdl
architecture rtl of example is
    signal s : integer := 0;  -- Signal
begin
    process(clk)
    begin
        if rising_edge(clk) then
            s <= s + 1;  -- به‌روزرسانی در پایان Process
        end if;
    end process;
end architecture;
```

**ویژگی‌ها:**
- مقدار در **پایان** Process به‌روز می‌شود
- دارای **حافظه** (در سخت‌افزار معمولاً به Register تبدیل می‌شود)
- برای ارتباط بین Processها استفاده می‌شود
- در کل Architecture قابل دسترسی است
- انتساب با `<=` انجام می‌شود

### Variable (متغیر)

```vhdl
architecture rtl of example is
begin
    process(clk)
        variable v : integer := 0;  -- Variable
    begin
        if rising_edge(clk) then
            v := v + 1;  -- به‌روزرسانی فوری
        end if;
    end process;
end architecture;
```

**ویژگی‌ها:**
- مقدار **فوراً** به‌روز می‌شود
- **بدون حافظه** (در سخت‌افزار معمولاً به Wire تبدیل می‌شود)
- فقط در همان Process قابل استفاده است
- در سایر Processها قابل دسترسی نیست
- انتساب با `:=` انجام می‌شود

### جدول مقایسه

| ویژگی | Signal | Variable |
|-------|--------|----------|
| **به‌روزرسانی** | پایان Process | فوری |
| **حافظه** | دارد (Register) | ندارد (Wire) |
| **حوزه دسترسی** | کل Architecture | فقط همان Process |
| **سخت‌افزار** | Flip-Flop یا Wire | معمولاً Wire |
| **انتساب** | `<=` | `:=` |
| **Multiple Drivers** | ممکن است (با احتیاط) | ندارد |
| **قابل سنتز** | بله | بله |

## ۳. اعلان Signal — مکان‌های مختلف

### ۳.۱. در Architecture (بخش اعلان)

```vhdl
architecture rtl of my_circuit is
    signal temp : std_logic;
    signal data_bus : std_logic_vector(7 downto 0);
    signal count : integer range 0 to 255 := 0;
    signal state : state_type := IDLE;
begin
    -- استفاده از Signalها
    temp <= a and b;
    data_bus <= temp & "0000000";
end architecture;
```

### ۳.۲. در Package

```vhdl
package my_pkg is
    signal global_signal : std_logic;  -- ❌ توصیه نمی‌شود
    -- بهتر است از Constants و Types استفاده شود
end package;
```

**توصیه:** از اعلان Signal در Package خودداری کنید؛ از Constant یا Type استفاده کنید.

### ۳.۳. در Entity (به عنوان Port)

```vhdl
entity my_circuit is
    port (
        clk : in  std_logic;   -- این‌ها هم Signal هستند
        data: out std_logic_vector(7 downto 0)
    );
end entity;
```

library ieee;
use ieee.numeric_std.all;

## ۵. مقداردهی Signal — روش‌های مختلف

### ۵.۱. مقداردهی اولیه (در اعلان)

```vhdl
signal count : integer := 0;
signal data : std_logic_vector(7 downto 0) := "00000000";
signal state : state_type := IDLE;
signal flag : std_logic := '0';
```

### ۵.۲. مقداردهی در Process

```vhdl
process(clk, reset)
begin
    if reset = '1' then
        count <= 0;        -- مقداردهی
        data <= (others => '0');
        state <= IDLE;
    elsif rising_edge(clk) then
        -- منطق اصلی
    end if;
end process;
```

### ۵.۳. مقداردهی Concurrent

```vhdl
data_out <= data_in;  -- اتصال مستقیم
y <= a and b;         -- مقداردهی ترکیبی
```

## ۶. استفاده از Signal — تحلیل عمیق

### ۶.۱. خواندن Signal

```vhdl
process(clk)
begin
    if rising_edge(clk) then
        if count = 255 then  -- خواندن Signal
            count <= 0;
        else
            count <= count + 1;  -- خواندن و نوشتن
        end if;
    end if;
end process;
```

### ۶.۲. نوشتن Signal

```vhdl
-- در Process
process(clk)
begin
    if rising_edge(clk) then
        q <= d;  -- نوشتن Signal
    end if;
end process;

-- Concurrent
y <= a and b;  -- نوشتن Signal (در سطح Architecture)
```

### ۶.۳. استفاده از Signal در چندین Process

```vhdl
architecture rtl of example is
    signal shared_signal : std_logic;
begin
    -- Process 1 (نوشتن)
    process(clk)
    begin
        if rising_edge(clk) then
            shared_signal <= a and b;
        end if;
    end process;
    
    -- Process 2 (خواندن)
    process(clk)
    begin
        if rising_edge(clk) then
            if shared_signal = '1' then
                q <= data;
            end if;
        end if;
    end process;
end architecture;
```

### ۶.۴. Multiple Drivers — احتیاط!

```vhdl
architecture rtl of example is
    signal shared_signal : std_logic;
begin
    -- ❌ دو Driver برای یک Signal
    shared_signal <= a and b;  -- Driver 1
    shared_signal <= c or d;   -- Driver 2 → خطا!
end architecture;
```

**راه‌حل:** از یک Driver برای هر Signal استفاده کنید، یا از **Resolved Signal** مانند `std_logic` استفاده کنید (که می‌تواند Multiple Drivers داشته باشد).

## ۷. Signal و Delta Delay — مفهوم مهم

### مفهوم Delta Delay

در VHDL، وقتی یک Signal را تغییر می‌دهید، مقدار جدید **فوراً** قابل مشاهده نیست. این تغییر در یک **Delta Cycle** (زمان صفر شبیه‌سازی) اتفاق می‌افتد.

```vhdl
process(clk)
begin
    if rising_edge(clk) then
        a <= '1';
        b <= a;  -- b مقدار قدیمی a را می‌گیرد، نه مقدار جدید!
    end if;
end process;
```

### رفتار Delta Delay

```
زمان ۰: a = '0', b = '0'
Clock Edge: a <= '1' (برنامه‌ریزی شده)، b <= a (مقدار قدیمی a = '0')
Delta Cycle: a = '1', b = '0' (هر دو همزمان به‌روز می‌شوند)
```

### اهمیت Delta Delay

این رفتار برای **مدل‌سازی صحیح سخت‌افزار** ضروری است:
- Registerها مقدار جدید را در لبه بعدی نشان می‌دهند
- Pipelineها به درستی شبیه‌سازی می‌شوند
- از شرایط مسابقه (Race Conditions) جلوگیری می‌شود

## ۸. Signal در مقابل Wire در سخت‌افزار

### Signal به عنوان Wire

اگر Signal در یک Process **ترکیبی** استفاده شود، به **Wire** تبدیل می‌شود:

```vhdl
process(a, b, sel)
begin
    if sel = '0' then
        y <= a;
    else
        y <= b;
    end if;
end process;
-- y → Wire (Combinational Logic)
```

### Signal به عنوان Register

اگر Signal در یک Process **کلاک‌دار** استفاده شود، به **Register** تبدیل می‌شود:

```vhdl
process(clk)
begin
    if rising_edge(clk) then
        q <= d;
    end if;
end process;
-- q → Register (Flip-Flop)
```

## ۹. Signal در طراحی‌های بزرگ — الگوهای رایج

### ۹.۱. Signal برای اتصال Componentها

```vhdl
architecture structural of top is
    signal s1, s2 : std_logic;
    signal data_bus : std_logic_vector(7 downto 0);
begin
    u1: entity work.module1
        port map (a => s1, b => data_bus);
    
    u2: entity work.module2
        port map (c => s1, d => s2);
    
    u3: entity work.module3
        port map (e => s2, f => data_bus);
end architecture;
```

### ۹.۲. Signal برای Pipeline

```vhdl
architecture rtl of pipeline is
    signal stage1_out, stage2_out : std_logic_vector(7 downto 0);
begin
    -- Stage 1
    process(clk)
    begin
        if rising_edge(clk) then
            stage1_out <= input_data;
        end if;
    end process;
    
    -- Stage 2
    process(clk)
    begin
        if rising_edge(clk) then
            stage2_out <= stage1_out;  -- Pipeline register
        end if;
    end process;
    
    output <= stage2_out;
end architecture;
```

### ۹.۳. Signal برای State در FSM

```vhdl
architecture rtl of fsm is
    type state_type is (IDLE, RUN, DONE);
    signal state, next_state : state_type;
begin
    -- State Register
    process(clk, reset)
    begin
        if reset = '1' then
            state <= IDLE;
        elsif rising_edge(clk) then
            state <= next_state;
        end if;
    end process;
    
    -- Next-State Logic
    process(state, input)
    begin
        next_state <= state;
        case state is
            when IDLE =>
                if input = '1' then
                    next_state <= RUN;
                end if;
            -- ...
        end case;
    end process;
end architecture;
```

## ۱۰. اشتباهات رایج در Signalها

### اشتباه ۱: استفاده از Signal به جای Variable در محاسبات فوری

**نادرست:**
```vhdl
process(clk)
    signal temp : integer;  -- ❌ Signal
begin
    if rising_edge(clk) then
        temp <= temp + 1;
        y <= temp;  -- مقدار قدیمی temp را می‌گیرد!
    end if;
end process;
```

**درست:**
```vhdl
process(clk)
    variable temp : integer;  -- ✅ Variable
begin
    if rising_edge(clk) then
        temp := temp + 1;
        y <= temp;  -- مقدار جدید temp را می‌گیرد
    end if;
end process;
```

### اشتباه ۲: Multiple Drivers

**نادرست:**
```vhdl
architecture rtl of example is
    signal y : std_logic;
begin
    y <= a and b;  -- ❌ Driver 1
    y <= c or d;   -- ❌ Driver 2 → خطا
end architecture;
```

**درست:**
```vhdl
architecture rtl of example is
    signal y : std_logic;
begin
    y <= (a and b) or (c and d);  -- ✅ یک Driver
end architecture;
```

### اشتباه ۳: فراموش کردن مقداردهی اولیه

**نادرست:**
```vhdl
signal count : integer;  -- مقدار اولیه نامشخص
```

**درست:**
```vhdl
signal count : integer := 0;  -- مقدار اولیه مشخص
```

### اشتباه ۴: استفاده از Signal در لیست حساسیت Process

**نادرست (ممکن است Process اجرا نشود):**
```vhdl
process(clk)  -- فقط clk در لیست است
begin
    if a = '1' then  -- a تغییر می‌کند اما Process اجرا نمی‌شود
        y <= b;
    end if;
end process;
```

**درست:**
```vhdl
process(clk, a, b)  -- همه ورودی‌ها در لیست
begin
    if a = '1' then
        y <= b;
    end if;
end process;
```

## ۱۱. تمرین‌های عملی

### تمرین ۱: اعلان Signal

یک Architecture برای یک مدار ساده بنویسید که دارای:
- دو Signal داخلی `temp1` و `temp2` از نوع `std_logic`
- یک Signal داخلی `result` از نوع `std_logic_vector(7 downto 0)`

**پاسخ:**
```vhdl
architecture rtl of my_circuit is
    signal temp1, temp2 : std_logic;
    signal result : std_logic_vector(7 downto 0);
begin
    temp1 <= a and b;
    temp2 <= c or d;
    result <= temp1 & temp2 & "000000";
end architecture;
```

### تمرین ۲: Signal در Process

یک D Flip-Flop با استفاده از Signal داخلی برای خروجی بنویسید.

**پاسخ:**
```vhdl
architecture rtl of dff is
    signal q_int : std_logic;
begin
    q <= q_int;
    
    process(clk, reset)
    begin
        if reset = '1' then
            q_int <= '0';
        elsif rising_edge(clk) then
            q_int <= d;
        end if;
    end process;
end architecture;
```

### تمرین ۳: Pipeline با Signal

یک Pipeline دو مرحله‌ای با استفاده از Signalهای داخلی طراحی کنید.

**پاسخ:**
```vhdl
architecture rtl of pipeline is
    signal stage1, stage2 : std_logic_vector(7 downto 0);
begin
    -- Stage 1
    process(clk, reset)
    begin
        if reset = '1' then
            stage1 <= (others => '0');
        elsif rising_edge(clk) then
            stage1 <= input_data;
        end if;
    end process;
    
    -- Stage 2
    process(clk, reset)
    begin
        if reset = '1' then
            stage2 <= (others => '0');
        elsif rising_edge(clk) then
            stage2 <= stage1;
        end if;
    end process;
    
    output <= stage2;
end architecture;
```

## ۱۲. خلاصه و جمع‌بندی

### نکات کلیدی

| مفهوم | توضیح |
|-------|-------|
| **Signal** | برای ارتباط بین بخش‌های مختلف طراحی |
| **به‌روزرسانی** | در پایان Process (Delta Delay) |
| **حافظه** | می‌تواند Register یا Wire باشد |
| **حوزه** | کل Architecture |
| **انتساب** | با `<=` |
| **Multiple Drivers** | ممکن است (با احتیاط) |

### Signal در مقابل Variable

| ویژگی | Signal | Variable |
|-------|--------|----------|
| **به‌روزرسانی** | پایان Process | فوری |
| **حوزه** | Architecture | Process |
| **سخت‌افزار** | Register/Wire | Wire |
| **انتساب** | `<=` | `:=` |

### فرمت اعلان Signal

```vhdl
signal <name> : <type> [:= <initial_value>];
```

### پیام نهایی

Signalها **شریان‌های حیاتی** هر طراحی VHDL هستند. درک صحیح رفتار، حوزه، و کاربرد Signalها برای طراحی مدارهای دیجیتال کارآمد و صحیح ضروری است.

با تسلط بر Signalها، شما می‌توانید:
- ارتباط بین بخش‌های مختلف طراحی را مدیریت کنید
- Pipelineهای کارآمد طراحی کنید
- Stateها را در FSM ذخیره کنید
- داده‌ها را بین Processها منتقل کنید

> **به یاد داشته باشید:** Signalها مانند سیم‌های فیزیکی هستند — آنها مقدار خود را حفظ می‌کنند و می‌توانند توسط بخش‌های مختلف خوانده یا نوشته شوند.
