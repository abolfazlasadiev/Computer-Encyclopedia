# Ports در VHDL — تحلیل جامع و عمیق

## مقدمه: دروازه‌های ارتباط با دنیای خارج

در دنیای سخت‌افزار، هیچ مداری به‌تنهایی کار نمی‌کند. هر مدار برای انجام وظیفه خود نیاز به **ارتباط با دنیای خارج** دارد — باید سیگنال‌ها را دریافت کند، آنها را پردازش کند، و نتایج را به خروجی بفرستد.

در VHDL، این ارتباط از طریق **Ports (درگاه‌ها)** انجام می‌شود. Portها مانند **دروازه‌های ورودی و خروجی** یک مدار هستند که مشخص می‌کنند چه سیگنال‌هایی وارد مدار می‌شوند و چه سیگنال‌هایی از آن خارج می‌شوند.

---

## ۱. Port چیست؟ تعریف جامع

**Port** در VHDL، یک **رابط (Interface)** بین Entity (ماژول) و دنیای خارج است. Port مشخص می‌کند که:
- چه سیگنال‌هایی **وارد** مدار می‌شوند (ورودی‌ها)
- چه سیگنال‌هایی **خارج** می‌شوند (خروجی‌ها)
- چه سیگنال‌هایی **دوطرفه** هستند (ورودی/خروجی)

### تشبیه ساده

Portها مانند **پایه‌های یک تراشه** هستند:
- پایه‌های ورودی (Input): سیگنال را از خارج دریافت می‌کنند
- پایه‌های خروجی (Output): سیگنال را به خارج می‌فرستند
- پایه‌های دوطرفه (Inout): هم سیگنال دریافت و هم ارسال می‌کنند

---

## ۲. ساختار Port — تحلیل کامل

### فرمت کلی

```vhdl
port (
    <نام_پورت> : <جهت> <نوع_داده> [:= <مقدار_پیش‌فرض>];
    <نام_پورت> : <جهت> <نوع_داده> [:= <مقدار_پیش‌فرض>];
    ...
);
```

### اجزای Port

| جزء | توضیح | مثال |
|-----|-------|------|
| **نام** | شناسه منحصر‌به‌فرد برای پورت | `clk`, `data_in`, `led` |
| **جهت (Mode)** | ورودی، خروجی، دوطرفه، بافر | `in`, `out`, `inout`, `buffer` |
| **نوع (Type)** | نوع داده سیگنال | `std_logic`, `integer`, `std_logic_vector` |
| **مقدار پیش‌فرض** | مقدار اولیه (اختیاری) | `:= '0'`, `:= (others => '0')` |

## ۳. جهات Port — تحلیل عمیق

### ۳.۱. `in` — ورودی

**تعریف:** سیگنالی که از **خارج** وارد **داخل** مدار می‌شود.

**ویژگی‌ها:**
- فقط قابل **خواندن** است (در داخل مدار)
- نمی‌توان به آن **نوشت** (مقدار داد)
- معمولاً برای سنسورها، کلیدها، دکمه‌ها، کلاک و داده‌های ورودی

**مثال:**
```vhdl
entity input_example is
    port (
        clk   : in  std_logic;   -- کلاک ورودی
        reset : in  std_logic;   -- ریست ورودی
        data  : in  std_logic_vector(7 downto 0);  -- داده ورودی
        button : in  std_logic   -- دکمه ورودی
    );
end entity;
```

**استفاده در داخل:**
```vhdl
architecture rtl of input_example is
begin
    process(clk, reset)
    begin
        if reset = '1' then
            -- مقداردهی
        elsif rising_edge(clk) then
            -- خواندن data و button
            if button = '1' then
                q <= data;
            end if;
        end if;
    end process;
end architecture;
```

---

### ۳.۲. `out` — خروجی

**تعریف:** سیگنالی که از **داخل** به **خارج** مدار فرستاده می‌شود.

**ویژگی‌ها:**
- فقط قابل **نوشتن** است (در داخل مدار)
- نمی‌توان از آن **خواند** (مگر با استفاده از سیگنال میانی)
- معمولاً برای LEDها، نمایشگرها، موتورها و داده‌های خروجی

**مثال:**
```vhdl
entity output_example is
    port (
        led   : out std_logic;   -- LED خروجی
        seg   : out std_logic_vector(6 downto 0);  -- ۷-سگمنت
        data  : out std_logic_vector(7 downto 0)   -- داده خروجی
    );
end entity;
```

**استفاده در داخل:**
```vhdl
architecture rtl of output_example is
begin
    led <= '1' when state = RUN else '0';
    seg <= "1111110" when digit = 0 else "0110000" when digit = 1 else ...
end architecture;
```

**مشکل: خواندن `out` در داخل**

```vhdl
-- این کد خطا می‌دهد چون نمی‌توان از q (که out است) خواند
process(clk)
begin
    if rising_edge(clk) then
        if q = x"FF" then  -- ❌ خطا: q را نمی‌توان خواند
            q <= (others => '0');
        else
            q <= q + 1;
        end if;
    end if;
end process;
```

**راه‌حل: استفاده از سیگنال میانی**

```vhdl
architecture rtl of output_example is
    signal q_int : std_logic_vector(7 downto 0);  -- سیگنال میانی
begin
    q <= q_int;  -- اتصال به خروجی
    
    process(clk)
    begin
        if rising_edge(clk) then
            if q_int = x"FF" then  -- ✅ خواندن از q_int
                q_int <= (others => '0');
            else
                q_int <= q_int + 1;
            end if;
        end if;
    end process;
end architecture;
```

---

### ۳.۳. `inout` — دوطرفه

**تعریف:** سیگنالی که هم می‌تواند **وارد** و هم **خارج** شود.

**ویژگی‌ها:**
- هم قابل **خواندن** و هم قابل **نوشتن**
- معمولاً برای **باس‌های داده** که چندین دستگاه به آنها متصل هستند
- نیاز به **مدیریت دقیق‌تر** (کنترل Tri-State)

**مثال:**
```vhdl
entity bidirectional_example is
    port (
        data_bus : inout std_logic_vector(7 downto 0);  -- باس دوطرفه
        rd_en    : in  std_logic;    -- فعال‌سازی خواندن
        wr_en    : in  std_logic     -- فعال‌سازی نوشتن
    );
end entity;
```

**استفاده در داخل (با Tri-State):**
```vhdl
architecture rtl of bidirectional_example is
    signal internal_data : std_logic_vector(7 downto 0);
begin
    -- نوشتن به باس (خروجی)
    data_bus <= internal_data when wr_en = '1' else (others => 'Z');
    
    -- خواندن از باس (ورودی)
    process(clk)
    begin
        if rising_edge(clk) then
            if rd_en = '1' then
                internal_data <= data_bus;  -- خواندن از باس
            end if;
        end if;
    end process;
end architecture;
```

**نکات مهم در مورد `inout`:**
1. **حتماً از Tri-State استفاده کنید:** وقتی نمی‌خواهید داده بفرستید، باید `'Z'` (High-Z) قرار دهید
2. **مدیریت همزمان:** نباید دو دستگاه همزمان به باس بنویسند
3. **در FPGA:** استفاده از `inout` در داخل FPGA محدود است؛ بیشتر در I/Oها استفاده می‌شود

---

### ۳.۴. `buffer` — بافر

**تعریف:** مانند `out` است با این تفاوت که می‌توان از آن **در داخل** نیز **خواند**.

**ویژگی‌ها:**
- هم قابل **نوشتن** و هم قابل **خواندن** (در داخل)
- نوعی `out` با قابلیت بازخورد
- در طراحی‌های مدرن **کمتر استفاده** می‌شود (بهتر است از سیگنال میانی استفاده شود)

**مثال:**
```vhdl
entity buffer_example is
    port (
        q : buffer std_logic_vector(7 downto 0)  -- خروجی با قابلیت خواندن
    );
end entity;

architecture rtl of buffer_example is
begin
    process(clk)
    begin
        if rising_edge(clk) then
            if q = x"FF" then  -- ✅ می‌توان از q خواند (چون buffer است)
                q <= (others => '0');
            else
                q <= q + 1;
            end if;
        end if;
    end process;
end architecture;
```

**توصیه:** بهتر است به جای `buffer` از `out` به همراه یک سیگنال میانی استفاده کنید.

## ۴. انواع داده در Portها

### ۴.۱. `std_logic` — تک‌بیتی

```vhdl
port (
    clk : in  std_logic;
    led : out std_logic;
    btn : in  std_logic
);
```

### ۴.۲. `std_logic_vector` — بردار بیتی

```vhdl
port (
    data_in  : in  std_logic_vector(7 downto 0);
    data_out : out std_logic_vector(7 downto 0);
    addr     : in  std_logic_vector(3 downto 0)
);
```

### ۴.۳. `integer` — عدد صحیح

```vhdl
port (
    count : out integer range 0 to 255;
    value : in  integer range -128 to 127
);
```

### ۴.۴. `unsigned` / `signed` — اعداد بدون علامت/با علامت

```vhdl
library ieee;
use ieee.numeric_std.all;

entity numeric_example is
    port (
        a : in  unsigned(7 downto 0);
        b : in  unsigned(7 downto 0);
        sum : out unsigned(7 downto 0)
    );
end entity;
```

### ۴.۵. انواع سفارشی

```vhdl
-- تعریف نوع در Package
package my_types is
    type state_type is (IDLE, RUN, DONE);
end package;

-- استفاده در Port
library ieee;
use ieee.std_logic_1164.all;
use work.my_types.all;

entity fsm_example is
    port (
        clk  : in  std_logic;
        reset: in  std_logic;
        state: out state_type  -- نوع سفارشی
    );
end entity;
```

## ۵. Vectorها در Port — تحلیل عمیق

### ۵.۱. اندیس نزولی (downto) — مرسوم‌ترین

```vhdl
data : in std_logic_vector(7 downto 0);
-- MSB = bit 7, LSB = bit 0
```

### ۵.۲. اندیس صعودی (to)

```vhdl
data : in std_logic_vector(0 to 7);
-- MSB = bit 0, LSB = bit 7
```

### ۵.۳. برش (Slicing)

```vhdl
-- دسترسی به بخشی از Vector
upper_byte <= data_in(15 downto 8);
lower_byte <= data_in(7 downto 0);
middle_bits <= data_in(5 downto 2);
```

### ۵.۴. اتصال (Concatenation)

```vhdl
-- ترکیب چند Vector
full_data <= high_byte & low_byte;
combined <= a & b & c;  -- a, b, c هر کدام می‌توانند چند بیت باشند
```

## ۶. مقداردهی اولیه Portها

### مقداردهی در Entity

```vhdl
entity counter is
    port (
        clk   : in  std_logic;
        reset : in  std_logic := '0';  -- مقدار پیش‌فرض
        q     : out std_logic_vector(3 downto 0) := "0000"  -- مقدار پیش‌فرض
    );
end entity;
```

### مقداردهی در Instantiation

```vhdl
-- مقداردهی در زمان استفاده
u1: entity work.counter
    port map (
        clk   => clk_signal,
        reset => reset_signal,  -- مقداردهی در اینجا
        q     => q_signal
    );
```

## ۷. Port Mapping — اتصال Portها

### ۷.۱. Positional Mapping (اتصال موقعیتی)

**توجه:** به ترتیب Portها در Entity و Instantiation باید یکسان باشد.

```vhdl
-- Entity
entity and_gate is
    port (a, b : in std_logic; y : out std_logic);
end entity;

-- Instantiation (Positional)
u1: entity work.and_gate port map (sig_a, sig_b, sig_y);
--         a = sig_a, b = sig_b, y = sig_y
```

**معایب:** اگر ترتیب Portها تغییر کند، کد خراب می‌شود.

### ۷.۲. Named Mapping (اتصال نامی) — توصیه شده

```vhdl
u1: entity work.and_gate
    port map (
        a => sig_a,
        b => sig_b,
        y => sig_y
    );
```

**مزایا:**
- ترتیب مهم نیست
- خوانایی بهتر
- مقاوم در برابر تغییرات

### ۷.۳. Open Ports (پورت‌های باز)

اگر یک Port را به جایی متصل نکنید، از کلمه کلیدی `open` استفاده کنید.

```vhdl
u1: entity work.full_adder
    port map (
        a    => sig_a,
        b    => sig_b,
        cin  => '0',
        sum  => sig_sum,
        cout => open  -- خروجی استفاده نمی‌شود
    );
```

## ۸. Portها در Component Declaration

### Component با Portها

```vhdl
-- Component Declaration
component and_gate is
    port (
        a : in  std_logic;
        b : in  std_logic;
        y : out std_logic
    );
end component;

-- استفاده
u1: and_gate
    port map (
        a => signal_a,
        b => signal_b,
        y => signal_y
    );
```

### Generic در Component

```vhdl
component register_generic is
    generic (
        WIDTH : positive := 8
    );
    port (
        clk : in  std_logic;
        d   : in  std_logic_vector(WIDTH-1 downto 0);
        q   : out std_logic_vector(WIDTH-1 downto 0)
    );
end component;

-- استفاده با Generic Map
u1: register_generic
    generic map (
        WIDTH => 16
    )
    port map (
        clk => clk_signal,
        d   => data_in,
        q   => data_out
    );
```

## ۹. اشتباهات رایج در Portها

### اشتباه ۱: استفاده از جهت اشتباه

**نادرست:**
```vhdl
port (
    clk : out std_logic;  -- ❌ کلاک باید in باشد
    led : in  std_logic   -- ❌ LED باید out باشد
);
```

**درست:**
```vhdl
port (
    clk : in  std_logic;
    led : out std_logic
);
```

### اشتباه ۲: فراموش کردن `;` بین Portها

**نادرست:**
```vhdl
port (
    a : in std_logic
    b : in std_logic  -- ❌ ';' فراموش شده
    y : out std_logic
);
```

**درست:**
```vhdl
port (
    a : in std_logic;
    b : in std_logic;
    y : out std_logic
);
```

### اشتباه ۳: خواندن از `out`

**نادرست:**
```vhdl
port (q : out std_logic_vector(7 downto 0));
...
process(clk)
begin
    if rising_edge(clk) then
        if q = x"FF" then  -- ❌ نمی‌توان از out خواند
            ...
        end if;
    end if;
end process;
```

**درست (استفاده از سیگنال میانی):**
```vhdl
port (q : out std_logic_vector(7 downto 0));
...
signal q_int : std_logic_vector(7 downto 0);
begin
    q <= q_int;
    process(clk)
    begin
        if rising_edge(clk) then
            if q_int = x"FF" then  -- ✅ خواندن از سیگنال میانی
                ...
            end if;
        end if;
    end process;
```

### اشتباه ۴: استفاده از `inout` بدون Tri-State

**نادرست:**
```vhdl
port (data_bus : inout std_logic_vector(7 downto 0));
...
data_bus <= internal_data;  -- ❌ بدون Tri-State، تداخل ایجاد می‌شود
```

**درست:**
```vhdl
data_bus <= internal_data when enable = '1' else (others => 'Z');
```

### اشتباه ۵: استفاده از `buffer` به جای سیگنال میانی

**توصیه:** از `buffer` استفاده نکنید؛ به جای آن از `out` + سیگنال میانی استفاده کنید.

```vhdl
-- ❌ روش قدیمی (کمتر توصیه می‌شود)
port (q : buffer std_logic_vector(7 downto 0));

-- ✅ روش مدرن
port (q : out std_logic_vector(7 downto 0));
signal q_int : std_logic_vector(7 downto 0);
...
q <= q_int;
```

## ۱۰. تمرین‌های عملی

### تمرین ۱: طراحی Portها

یک Entity برای **Full Adder** طراحی کنید که دارای:
- ۳ ورودی: a, b, cin (هر کدام `std_logic`)
- ۲ خروجی: sum, cout (هر کدام `std_logic`)

**پاسخ:**
```vhdl
entity full_adder is
    port (
        a    : in  std_logic;
        b    : in  std_logic;
        cin  : in  std_logic;
        sum  : out std_logic;
        cout : out std_logic
    );
end entity;
```

### تمرین ۲: Port با Vector

یک Entity برای **Register 8-bit** با ورودی و خروجی Vector طراحی کنید.

**پاسخ:**
```vhdl
entity register_8bit is
    port (
        clk   : in  std_logic;
        reset : in  std_logic;
        en    : in  std_logic;
        d     : in  std_logic_vector(7 downto 0);
        q     : out std_logic_vector(7 downto 0)
    );
end entity;
```

### تمرین ۳: Port با Generic

یک Entity برای **Counter** با Generic برای عرض و مقدار ماکزیمم طراحی کنید.

**پاسخ:**
```vhdl
entity counter is
    generic (
        WIDTH : positive := 8;
        MAX   : positive := 255
    );
    port (
        clk   : in  std_logic;
        reset : in  std_logic;
        en    : in  std_logic;
        count : out std_logic_vector(WIDTH-1 downto 0);
        carry : out std_logic
    );
end entity;
```

### تمرین ۴: Port دوطرفه

یک Entity برای **Memory Interface** با باس داده دوطرفه طراحی کنید.

**پاسخ:**
```vhdl
entity memory_interface is
    port (
        clk    : in  std_logic;
        addr   : in  std_logic_vector(15 downto 0);
        data   : inout std_logic_vector(7 downto 0);
        wr_en  : in  std_logic;
        rd_en  : in  std_logic;
        ready  : out std_logic
    );
end entity;
```

## ۱۱. خلاصه و جمع‌بندی

### جدول جهات Port

| جهت | کلمه کلیدی | خواندن | نوشتن | کاربرد |
|-----|-----------|--------|--------|--------|
| **ورودی** | `in` | ✅ | ❌ | سنسور، کلاک، دکمه |
| **خروجی** | `out` | ❌ (مگر با سیگنال میانی) | ✅ | LED، نمایشگر |
| **دوطرفه** | `inout` | ✅ | ✅ | باس داده |
| **بافر** | `buffer` | ✅ | ✅ | خروجی با بازخورد |

### نکات کلیدی

| نکته | توضیح |
|------|-------|
| **جهت صحیح** | ورودی‌ها `in`، خروجی‌ها `out` |
| **سیگنال میانی** | برای خواندن از `out` از سیگنال میانی استفاده کنید |
| **Tri-State** | برای `inout` حتماً از `'Z'` استفاده کنید |
| **Named Mapping** | برای اتصال Portها از Named Mapping استفاده کنید |
| **Generic** | برای انعطاف‌پذیری از Generic استفاده کنید |
| **Vector** | برای باس‌ها از `std_logic_vector` استفاده کنید |

### فرمت کامل Entity با Portها

```vhdl
entity <name> is
    generic (
        <param> : <type> := <default>
    );
    port (
        <signal_in>  : in  <type>;
        <signal_out> : out <type>;
        <signal_bus> : inout <type>  -- در صورت نیاز
    );
end entity <name>;
```

### پیام نهایی

Portها **دروازه‌های ارتباط** هر طراحی VHDL هستند. درک صحیح جهات، انواع داده و نحوه اتصال Portها، پایه‌ای محکم برای طراحی ماژول‌های حرفه‌ای و قابل استفاده مجدد ایجاد می‌کند. با تسلط بر Portها، شما می‌توانید:
- ماژول‌هایی با رابط واضح و مستند طراحی کنید
- از Componentهای موجود به درستی استفاده کنید
- طراحی‌های پیچیده را به ماژول‌های کوچک‌تر تقسیم کنید
- کدهای قابل حمل و استاندارد بنویسید
