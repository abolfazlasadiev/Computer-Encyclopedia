# دستور if در VHDL — تحلیل جامع و عمیق

## مقدمه: قدرت تصمیم‌گیری در VHDL

تصور کنید در یک **چهارراه** ایستاده‌اید. بسته به رنگ چراغ راهنمایی، تصمیم می‌گیرید: اگر چراغ **سبز** است، حرکت کنید؛ اگر **قرمز** است، بایستید؛ اگر **زرد** است، آماده شوید. این دقیقاً همان کاری است که دستور **`if`** در VHDL انجام می‌دهد — **تصمیم‌گیری** بر اساس شرایط.

دستور `if` یکی از **مهم‌ترین** و **پرکاربردترین** دستورات ترتیبی در VHDL است که به شما امکان می‌دهد:
- بر اساس شرایط، مسیرهای مختلف اجرا کنید
- منطق شرطی پیاده‌سازی کنید
- ماشین‌های حالت کنترل کنید
- داده‌ها را مقایسه و انتخاب کنید

## ۱. ساختار دستور `if`

### ۱.۱. ساختار کلی

```
┌─────────────────────────────────────────────────────────────────────┐
│                      IF STATEMENT STRUCTURE                       │
├─────────────────────────────────────────────────────────────────────┤
│                                                                   │
│  ┌─────────────────────────────────────────────────────────────┐  │
│  │  if condition_1 then                                       │  │
│  │      -- statements for condition_1                         │  │
│  │  ┌─────────────────────────────────────────────────────┐  │  │
│  │  │  elsif condition_2 then                            │  │  │
│  │  │      -- statements for condition_2                 │  │  │
│  │  └─────────────────────────────────────────────────────┘  │  │
│  │  ┌─────────────────────────────────────────────────────┐  │  │
│  │  │  elsif condition_3 then                            │  │  │
│  │  │      -- statements for condition_3                 │  │  │
│  │  └─────────────────────────────────────────────────────┘  │  │
│  │  ┌─────────────────────────────────────────────────────┐  │  │
│  │  │  else                                              │  │  │
│  │  │      -- statements for all other conditions        │  │  │
│  │  └─────────────────────────────────────────────────────┘  │  │
│  │  end if;                                                 │  │
│  └─────────────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────────────┘
```

### ۱.۲. انواع `if`

```vhdl
-- ===== 1. if ساده (بدون else) =====
if condition then
    -- statements
end if;

-- ===== 2. if با else =====
if condition then
    -- statements for true
else
    -- statements for false
end if;

-- ===== 3. if با elsif =====
if condition_1 then
    -- statements for condition_1
elsif condition_2 then
    -- statements for condition_2
elsif condition_3 then
    -- statements for condition_3
end if;

-- ===== 4. if کامل با elsif و else =====
if condition_1 then
    -- statements for condition_1
elsif condition_2 then
    -- statements for condition_2
elsif condition_3 then
    -- statements for condition_3
else
    -- statements for all other conditions
end if;
```

### ۱.۳. مثال‌های ساده

```vhdl
library ieee;
use ieee.std_logic_1164.all;
use ieee.numeric_std.all;

entity if_example is
    port (
        a, b    : in  integer;
        sel     : in  std_logic;
        data    : in  std_logic_vector(7 downto 0);
        clk     : in  std_logic;
        rst     : in  std_logic;
        
        y       : out integer;
        flag    : out std_logic
    );
end entity;

architecture rtl of if_example is
begin
    process(clk, rst)
    begin
        if rst = '1' then
            -- Reset
            y <= 0;
            flag <= '0';
            
        elsif rising_edge(clk) then
            -- ===== if ساده =====
            if a > b then
                y <= a;
            end if;
            -- اگر a > b نباشد، y مقدار قبلی را نگه می‌دارد
            
            -- ===== if با else =====
            if sel = '1' then
                flag <= '1';
            else
                flag <= '0';
            end if;
            
            -- ===== if با elsif =====
            if data = "00000000" then
                y <= 0;
            elsif data(7) = '1' then
                y <= -1;
            elsif data = "11111111" then
                y <= 255;
            end if;
        end if;
    end process;
end architecture;
```

## ۲. شرایط در `if`

### ۲.۱. انواع شرایط

```vhdl
-- ===== 1. مقایسه اعداد =====
if a > b then           -- بزرگتر
if a >= b then          -- بزرگتر یا مساوی
if a < b then           -- کوچکتر
if a <= b then          -- کوچکتر یا مساوی
if a = b then           -- مساوی
if a /= b then          -- نامساوی

-- ===== 2. مقایسه std_logic =====
if sel = '1' then       -- برابر با '1'
if sel = '0' then       -- برابر با '0'
if sel /= '1' then      -- نامساوی با '1'

-- ===== 3. مقایسه std_logic_vector =====
if data = "00000000" then        -- برابر با صفر
if data /= "11111111" then       -- نامساوی با همه یک
if unsigned(data) > 100 then     -- تبدیل به unsigned برای مقایسه عددی
if signed(data) < 0 then         -- تبدیل به signed برای مقایسه با علامت

-- ===== 4. شرایط ترکیبی =====
if (a > b) and (c < d) then      -- AND
if (a > b) or (c < d) then       -- OR
if (a > b) and not (c < d) then  -- AND با NOT
if (a > b) or (c < d) and (e = f) then  -- ترکیبی با اولویت

-- ===== 5. شرایط boolean =====
if flag = true then
if flag then            -- معادل flag = true
if not flag then        -- معادل flag = false

-- ===== 6. شرایط با تابع =====
if rising_edge(clk) then        -- لبه بالارونده Clock
if falling_edge(clk) then       -- لبه پایین‌رونده Clock
if is_x(data) then              -- بررسی حالت نامشخص
```

### ۲.۲. مثال‌های کامل

```vhdl
library ieee;
use ieee.std_logic_1164.all;
use ieee.numeric_std.all;

entity if_conditions is
    port (
        a, b    : in  integer;
        c, d    : in  std_logic_vector(7 downto 0);
        sel     : in  std_logic_vector(1 downto 0);
        en      : in  std_logic;
        clk     : in  std_logic;
        
        result  : out integer;
        flag    : out std_logic
    );
end entity;

architecture rtl of if_conditions is
    signal temp : integer;
begin
    process(clk)
    begin
        if rising_edge(clk) then
            -- ===== 1. مقایسه اعداد =====
            if a > b then
                result <= a;
            elsif a = b then
                result <= 0;
            else
                result <= b;
            end if;
            
            -- ===== 2. مقایسه std_logic_vector با unsigned =====
            if unsigned(c) > unsigned(d) then
                flag <= '1';
            else
                flag <= '0';
            end if;
            
            -- ===== 3. مقایسه std_logic_vector با signed =====
            if signed(c) < 0 then
                temp := -1;
            else
                temp := 1;
            end if;
            
            -- ===== 4. شرایط ترکیبی =====
            if (a > 0) and (b > 0) and (en = '1') then
                result <= a + b;
            elsif (a < 0) or (b < 0) then
                result <= a - b;
            else
                result <= 0;
            end if;
            
            -- ===== 5. شرط با boolean =====
            if (a = b) then
                flag <= '1';
            end if;
            
            -- ===== 6. شرط با تابع =====
            if is_x(c) then
                result <= -1;  -- داده نامشخص
            else
                result <= to_integer(unsigned(c));
            end if;
        end if;
    end process;
end architecture;
```

### ۲.۳. نکات مهم در شرایط

```vhdl
-- ===== نکته 1: شرط‌ها باید boolean باشند =====
-- ✅ درست
if a = b then
if a > b then
if sel = '1' then

-- ❌ غلط
if a then           -- ❌ a integer است، boolean نیست
if sel then         -- ❌ sel std_logic است، boolean نیست
if data then        -- ❌ data std_logic_vector است، boolean نیست

-- ===== نکته 2: تبدیل به boolean =====
-- ✅ راه‌حل برای std_logic
if sel = '1' then   -- تبدیل به boolean با مقایسه
if sel = '0' then

-- ✅ راه‌حل در VHDL-2008
if ?? sel then      -- تبدیل std_logic به boolean

-- ===== نکته 3: اولویت عملگرها =====
-- ❌ ممکن است گیج‌کننده باشد
if a > b and c < d then  -- وضوح کم

-- ✅ بهتر با پرانتز
if (a > b) and (c < d) then  -- واضح‌تر

-- ===== نکته 4: مقایسه std_logic_vector =====
-- ❌ غلط: std_logic_vector از < پشتیبانی نمی‌کند
if data < "00001000" then

-- ✅ درست: تبدیل به unsigned
if unsigned(data) < 8 then

-- ✅ درست: تبدیل به signed
if signed(data) < 0 then
```

## ۳. `if` در Processهای ترکیبی

### ۳.۱. Process ترکیبی با `if`

```vhdl
-- ===== Process ترکیبی =====
-- • بدون Clock
-- • خروجی فوراً به ورودی پاسخ می‌دهد
-- • همه ورودی‌ها در لیست حساسیت

library ieee;
use ieee.std_logic_1164.all;
use ieee.numeric_std.all;

entity comb_if is
    port (
        a, b    : in  std_logic_vector(7 downto 0);
        sel     : in  std_logic_vector(1 downto 0);
        op      : in  std_logic;
        
        y       : out std_logic_vector(7 downto 0);
        flag    : out std_logic
    );
end entity;

architecture rtl of comb_if is
begin
    COMB_PROC: process(a, b, sel, op)
        variable result : unsigned(7 downto 0);
    begin
        -- ===== مقدار پیش‌فرض (جلوگیری از Latch) =====
        y <= (others => '0');
        flag <= '0';
        result := (others => '0');
        
        -- ===== منطق اصلی =====
        if op = '1' then
            -- عملیات حسابی
            if sel = "00" then
                result := unsigned(a) + unsigned(b);
            elsif sel = "01" then
                result := unsigned(a) - unsigned(b);
            elsif sel = "10" then
                result := unsigned(a) * unsigned(b)(7 downto 0);
            else
                result := unsigned(a) / unsigned(b)(7 downto 0);
            end if;
            
            -- بررسی Overflow
            if result > 255 then
                flag <= '1';
            end if;
            
        else
            -- عملیات منطقی
            if sel = "00" then
                result := unsigned(a and b);
            elsif sel = "01" then
                result := unsigned(a or b);
            elsif sel = "10" then
                result := unsigned(a xor b);
            else
                result := unsigned(a nand b);
            end if;
        end if;
        
        y <= std_logic_vector(result);
    end process COMB_PROC;
end architecture;
```

### ۳.۲. جلوگیری از Latch

```vhdl
-- ===== ❌ اشتباه: Latch =====
process(a, b, sel)
begin
    if sel = '1' then
        y <= a;
    end if;
    -- وقتی sel = '0'، y مقدار قبلی را نگه می‌دارد (Latch)
end process;

-- ===== ✅ راه‌حل 1: استفاده از else =====
process(a, b, sel)
begin
    if sel = '1' then
        y <= a;
    else
        y <= b;
    end if;
end process;

-- ===== ✅ راه‌حل 2: مقدار پیش‌فرض =====
process(a, b, sel)
begin
    y <= b;  -- مقدار پیش‌فرض
    if sel = '1' then
        y <= a;
    end if;
end process;

-- ===== ✅ راه‌حل 3: مقداردهی در همه شاخه‌ها =====
process(a, b, sel)
begin
    if sel = '1' then
        y <= a;
        z <= '1';
    else
        y <= b;
        z <= '0';
    end if;
end process;
```

## ۴. `if` در Processهای سنکرون

### ۴.۱. Process سنکرون با `if`

```vhdl
-- ===== Process سنکرون =====
-- • با Clock
-- • خروجی در لبه Clock به‌روز می‌شود

library ieee;
use ieee.std_logic_1164.all;
use ieee.numeric_std.all;

entity sync_if is
    port (
        clk     : in  std_logic;
        rst     : in  std_logic;
        en      : in  std_logic;
        data    : in  std_logic_vector(7 downto 0);
        up_down : in  std_logic;
        
        count   : out std_logic_vector(7 downto 0);
        done    : out std_logic
    );
end entity;

architecture rtl of sync_if is
    signal counter : unsigned(7 downto 0);
    signal done_sig : std_logic;
begin
    SYNC_PROC: process(clk, rst)
    begin
        if rst = '1' then
            -- Reset
            counter <= (others => '0');
            done_sig <= '0';
            
        elsif rising_edge(clk) then
            -- ===== if ساده =====
            if en = '1' then
                -- ===== if تو در تو =====
                if up_down = '1' then
                    counter <= counter + 1;
                else
                    counter <= counter - 1;
                end if;
            end if;
            
            -- ===== if با شرایط متعدد =====
            if counter = 0 then
                done_sig <= '1';
            elsif counter = 255 then
                done_sig <= '1';
            else
                done_sig <= '0';
            end if;
        end if;
    end process;
    
    count <= std_logic_vector(counter);
    done <= done_sig;
end architecture;
```

begin

## ۵. `if` vs `case`

### ۵.۱. مقایسه `if` و `case`

| ویژگی | `if` | `case` |
|--------|------|--------|
| **شرط** | هر شرط boolean | انتخاب بر اساس یک عبارت |
| **اولویت** | دارد (از بالا به پایین) | ندارد (همه هم‌تراز) |
| **شرایط پیچیده** | ✅ مناسب | ❌ مناسب نیست |
| **مقادیر متعدد** | ❌ نامناسب (elsif زیاد) | ✅ مناسب |
| **تعداد حالت‌ها** | برای ۲-۳ حالت | برای ۴+ حالت |
| **کد خوانایی** | برای شرایط پیچیده | برای انتخاب چندحالته |
| **سنتز** | قابل سنتز | قابل سنتز |

### ۵.۲. مثال مقایسه

```vhdl
-- ===== استفاده از if =====
process(opcode, a, b)
begin
    if opcode = "000" then
        y <= a + b;
    elsif opcode = "001" then
        y <= a - b;
    elsif opcode = "010" then
        y <= a * b;
    elsif opcode = "011" then
        y <= a / b;
    else
        y <= 0;
    end if;
end process;

-- ===== استفاده از case (بهتر برای این مثال) =====
process(opcode, a, b)
begin
    case opcode is
        when "000" => y <= a + b;
        when "001" => y <= a - b;
        when "010" => y <= a * b;
        when "011" => y <= a / b;
        when others => y <= 0;
    end case;
end process;

-- ===== استفاده از if برای شرایط پیچیده =====
process(a, b, c, d, sel)
begin
    if (a > b) and (c < d) then
        y <= a + c;
    elsif (a > b) or (c < d) then
        y <= a - c;
    elsif (a = b) and (c = d) then
        y <= 0;
    else
        y <= b + d;
    end if;
end process;
```

## ۶. `if` برای FSM

### ۶.۱. FSM با `if`

```vhdl
-- ===== FSM با if =====
library ieee;
use ieee.std_logic_1164.all;

entity fsm_if is
    port (
        clk   : in  std_logic;
        rst   : in  std_logic;
        start : in  std_logic;
        stop  : in  std_logic;
        data  : in  std_logic_vector(7 downto 0);
        
        done  : out std_logic;
        count : out integer
    );
end entity;

architecture rtl of fsm_if is
    type state_t is (IDLE, RUN, DONE);
    signal state : state_t;
    signal counter : integer := 0;
begin
    FSM_PROC: process(clk, rst)
    begin
        if rst = '1' then
            state <= IDLE;
            counter <= 0;
            done <= '0';
            
        elsif rising_edge(clk) then
            -- ===== منطق FSM با if =====
            if state = IDLE then
                done <= '0';
                if start = '1' then
                    state <= RUN;
                    counter <= 0;
                end if;
                
            elsif state = RUN then
                if counter < 100 then
                    counter <= counter + 1;
                else
                    state <= DONE;
                end if;
                
                -- منطق شرطی
                if data = "00000000" then
                    counter <= 0;
                elsif data(7) = '1' then
                    counter <= counter + 2;
                end if;
                
            elsif state = DONE then
                done <= '1';
                if stop = '1' then
                    state <= IDLE;
                end if;
            end if;
        end if;
    end process;
end architecture;
```

### ۶.۲. FSM با `if` و `case` ترکیبی

```vhdl
-- ===== FSM ترکیبی if و case =====
FSM_PROC: process(clk, rst)
begin
    if rst = '1' then
        state <= IDLE;
        
    elsif rising_edge(clk) then
        -- ===== استفاده از if برای Reset و شرایط خاص =====
        if error = '1' then
            state <= ERROR;
            
        else
            -- ===== استفاده از case برای منطق اصلی =====
            case state is
                when IDLE =>
                    if start = '1' then
                        state <= RUN;
                    end if;
                
                when RUN =>
                    if done = '1' then
                        state <= DONE;
                    elsif abort = '1' then
                        state <= ABORT;
                    end if;
                
                when DONE =>
                    state <= IDLE;
                
                when ERROR =>
                    if reset_error = '1' then
                        state <= IDLE;
                    end if;
                
                when others =>
                    state <= IDLE;
            end case;
        end if;
    end if;
end process;
```

## ۷. `if` در Function و Procedure

### ۷.۱. `if` در Function

```vhdl
-- ===== Function با if =====
package if_pkg is
    function max_val(a, b : integer) return integer;
    function clamp(value, min_val, max_val : integer) return integer;
    function to_string(slv : std_logic_vector) return string;
end package;

package body if_pkg is
    -- ===== تابع با if ساده =====
    function max_val(a, b : integer) return integer is
    begin
        if a > b then
            return a;
        else
            return b;
        end if;
    end function;
    
    -- ===== تابع با if کامل =====
    function clamp(value, min_val, max_val : integer) return integer is
    begin
        if value < min_val then
            return min_val;
        elsif value > max_val then
            return max_val;
        else
            return value;
        end if;
    end function;
    
    -- ===== تابع با if تو در تو =====
    function to_string(slv : std_logic_vector) return string is
        variable result : string(1 to slv'length);
    begin
        for i in slv'range loop
            if slv(i) = '1' then
                result(i+1) := '1';
            elsif slv(i) = '0' then
                result(i+1) := '0';
            else
                result(i+1) := 'X';
            end if;
        end loop;
        return result;
    end function;
end package body;
```

### ۷.۲. `if` در Procedure

```vhdl
-- ===== Procedure با if =====
package proc_pkg is
    procedure sort_array(arr : inout integer_vector);
    procedure log_if(condition : boolean; msg : string);
end package;

package body proc_pkg is
    -- ===== Procedure با if =====
    procedure sort_array(arr : inout integer_vector) is
        variable temp : integer;
    begin
        for i in arr'range loop
            for j in i+1 to arr'high loop
                if arr(i) > arr(j) then
                    temp := arr(i);
                    arr(i) := arr(j);
                    arr(j) := temp;
                end if;
            end loop;
        end loop;
    end procedure;
    
    -- ===== Procedure با شرط =====
    procedure log_if(condition : boolean; msg : string) is
    begin
        if condition then
            report msg severity note;
        else
            report "Condition false: " & msg severity warning;
        end if;
    end procedure;
end package body;
```

## ۸. نکات پیشرفته `if`

### ۸.۱. `if` با Conditions چندگانه

```vhdl
-- ===== شرایط چندگانه =====
process(a, b, c, d, e, f)
begin
    -- ===== AND ترکیبی =====
    if (a > b) and (c < d) and (e = f) then
        y <= a + c + e;
    end if;
    
    -- ===== OR ترکیبی =====
    if (a > b) or (c < d) or (e = f) then
        y <= a - c - e;
    end if;
    
    -- ===== ترکیب AND و OR =====
    if (a > b) and (c < d) or (e = f) then
        y <= a + c;
    end if;
    -- ⚠️ اولویت: AND قبل از OR
    -- معادل: ((a > b) and (c < d)) or (e = f)
    
    -- ===== با پرانتز برای وضوح =====
    if ((a > b) and (c < d)) or (e = f) then
        y <= a + c;
    end if;
end process;
```

### ۸.۲. `if` با `in` (VHDL-2008)

```vhdl
-- ===== VHDL-2008: if with in =====
process(data)
begin

        y <= 1;
    elsif data in 20 to 30 then
        y <= 2;
    else
        y <= 0;
    end if;
    
    -- ===== بررسی عضویت در enum =====
    if state in (IDLE, DONE) then
        flag <= '1';
    else
        flag <= '0';
    end if;
end process;
```

process(data)

## ۹. خطاهای رایج در `if`

### ۹.۱. خطا: Latch ناخواسته

```vhdl
-- ===== ❌ اشتباه =====
process(a, b, sel)
begin
    if sel = '1' then
        y <= a;
    end if;
    -- وقتی sel = '0'، y مقدار قبلی را نگه می‌دارد
end process;

-- ===== ✅ راه‌حل =====
process(a, b, sel)
begin
    y <= b;  -- مقدار پیش‌فرض
    if sel = '1' then
        y <= a;
    end if;
end process;
```

### ۹.۲. خطا: شرط نامعتبر

```vhdl
-- ===== ❌ اشتباه =====
process(a, b)
begin
    if a then  -- ❌ a integer است، boolean نیست
        y <= b;
    end if;
end process;

-- ===== ✅ راه‌حل =====
process(a, b)
begin
    if a > 0 then  -- ✅
        y <= b;
    end if;
end process;
```

### ۹.۳. خطا: مقایسه std_logic_vector

```vhdl
-- ===== ❌ اشتباه =====
process(data)
begin
    if data < "00001000" then  -- ❌ std_logic_vector از < پشتیبانی نمی‌کند
        y <= '1';
    end if;
end process;

-- ===== ✅ راه‌حل =====
process(data)
begin
    if unsigned(data) < 8 then  -- ✅ تبدیل به unsigned
        y <= '1';
    end if;
end process;
```

### ۹.۴. خطا: `else if` به جای `elsif`

```vhdl
-- ===== ❌ اشتباه =====
if a = 1 then
    y <= 10;
else if a = 2 then  -- ❌ else if مجاز نیست
    y <= 20;
end if;

-- ===== ✅ راه‌حل =====
if a = 1 then
    y <= 10;
elsif a = 2 then  -- ✅
    y <= 20;
end if;
```

### ۹.۵. خطا: `end if` فراموش شده

```vhdl
-- ===== ❌ اشتباه =====
if a = 1 then
    y <= 10;
-- end if فراموش شده!

-- ===== ✅ راه‌حل =====
if a = 1 then
    y <= 10;
end if;  -- ✅
```

## ۱۰. بهترین‌نوشته‌ها (Best Practices)

### ۱۰.۱. ساختار `if`

```vhdl
-- ===== ✅ Good Practice =====
if condition_1 then
    -- statements for condition_1
elsif condition_2 then
    -- statements for condition_2
elsif condition_3 then
    -- statements for condition_3
else
    -- statements for all other conditions
end if;

-- ===== ❌ Bad Practice =====
if condition_1 then
    -- statements
end if;
if condition_2 then  -- ❌ استفاده از if جداگانه به جای elsif
    -- statements
end if;
if condition_3 then
    -- statements
end if;
```

### ۱۰.۲. استفاده از مقدار پیش‌فرض

```vhdl
-- ===== ✅ Good Practice =====
process(a, b, sel)
begin
    y <= b;  -- مقدار پیش‌فرض
    if sel = '1' then
        y <= a;
    end if;
end process;

-- ===== ❌ Bad Practice =====
process(a, b, sel)
begin
    if sel = '1' then
        y <= a;
    -- else مفقود است → Latch
    end if;
end process;
```

### ۱۰.۳. استفاده از پرانتز

```vhdl
-- ===== ✅ با پرانتز (واضح‌تر) =====
if (a > b) and (c < d) then
    y <= a + c;
end if;

-- ===== ❌ بدون پرانتز (گیج‌کننده) =====
if a > b and c < d then
    y <= a + c;
end if;
```

### ۱۰.۴. محدود کردن تو در تو

```vhdl
-- ===== ❌ تو در تو زیاد (غیرقابل خواندن) =====
if condition_1 then
    if condition_2 then
        if condition_3 then
            if condition_4 then
                y <= a;
            end if;
        end if;
    end if;
end if;

-- ===== ✅ استفاده از ترکیب شرایط =====
if condition_1 and condition_2 and condition_3 and condition_4 then
    y <= a;
end if;
```

### ۱۰.۵. انتخاب بین `if` و `case`

```vhdl
-- ===== استفاده از if برای ۲-۳ حالت =====
if sel = "00" then
    y <= a;
elsif sel = "01" then
    y <= b;
else
    y <= c;
end if;

-- ===== استفاده از case برای ۴+ حالت =====
case sel is
    when "00" => y <= a;
    when "01" => y <= b;
    when "10" => y <= c;
    when "11" => y <= d;
    when others => y <= (others => '0');
end case;
```

## ۱۱. خلاصه و جمع‌بندی

### جدول انواع `if`

| نوع | ساختار | کاربرد |
|-----|--------|--------|
| **if ساده** | `if condition then ... end if;` | یک شرط ساده |
| **if/else** | `if condition then ... else ... end if;` | دو مسیر |
| **if/elsif** | `if c1 then ... elsif c2 then ... end if;` | چند شرط |
| **if/elsif/else** | `if c1 then ... elsif c2 then ... else ... end if;` | چند شرط با پیش‌فرض |

### قوانین کلیدی

| قانون | توضیح |
|-------|-------|
| **شرط boolean** | شرط باید boolean باشد |
| **else برای جلوگیری از Latch** | در Process ترکیبی حتماً else داشته باشید |
| **اولویت** | `if` از بالا به پایین بررسی می‌شود |
| **elsif** | از `elsif` استفاده کنید، نه `else if` |
| **تو در تو** | از تو در تو بیش از حد خودداری کنید |
| **پرانتز** | برای وضوح از پرانتز استفاده کنید |

### انتخاب بین `if` و `case`

```
┌─────────────────────────────────────────────────────────────────────┐
│  چه زمانی از if استفاده کنیم؟                                    │
│  • شرایط پیچیده (با AND, OR, NOT)                               │
│  • شرایط با مقادیر مختلف (مثلاً a > b)                          │
│  • اولویت بین شرایط وجود دارد                                   │
│  • تعداد حالت‌ها کم است (2-3 حالت)                              │
├─────────────────────────────────────────────────────────────────────┤
│  چه زمانی از case استفاده کنیم؟                                 │
│  • یک عبارت با مقادیر مختلف                                     │
│  • تعداد حالت‌ها زیاد است (4+ حالت)                             │
│  • همه حالت‌ها هم‌تراز هستند                                    │
│  • انتخاب بر اساس یک مقدار (نه شرط)                             │
└─────────────────────────────────────────────────────────────────────┘
```

### دستورات مهم

```vhdl
-- ===== if ساده =====
if condition then
    -- statements
end if;

-- ===== if با else =====
if condition then
    -- statements for true
else
    -- statements for false
end if;

-- ===== if با elsif =====
if condition_1 then
    -- statements
elsif condition_2 then
    -- statements
elsif condition_3 then
    -- statements
else
    -- statements (اختیاری)
end if;

-- ===== if تو در تو =====
if condition_1 then
    if condition_2 then
        -- statements
    end if;
end if;
```

> **پیام نهایی:** دستور **`if`** یکی از **قدرتمندترین** و **پرکاربردترین** دستورات در VHDL است که به شما امکان می‌دهد **منطق شرطی** پیچیده را پیاده‌سازی کنید. درک صحیح از نحوه استفاده از `if`، تفاوت آن با `case`، و قوانین جلوگیری از Latch، برای طراحی **حرفه‌ای** و **قابل سنتز** ضروری است. به یاد داشته باشید که `if` در **Processهای ترکیبی** نیاز به مقدار پیش‌فرض دارد تا از Latch جلوگیری شود، و در **Processهای سنکرون** باید در ساختار Reset و Clock به درستی استفاده شود.
