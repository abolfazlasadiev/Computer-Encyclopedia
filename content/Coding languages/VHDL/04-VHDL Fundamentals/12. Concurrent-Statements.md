# دستورات همزمان در VHDL — تحلیل جامع و عمیق

## مقدمه: جهان همزمان VHDL

تصور کنید یک کارخانه تولیدی با چندین دستگاه دارید که **همه به طور همزمان** کار می‌کنند. هر دستگاه مستقل از دیگران فعالیت می‌کند، اما همه با هم محصول نهایی را تولید می‌کنند. این دقیقاً همان چیزی است که در VHDL به آن **دستورات همزمان (Concurrent Statements)** می‌گوییم.

در VHDL، **همه چیز به طور همزمان اجرا می‌شود** مگر اینکه به صراحت بگوییم ترتیبی باشد. این با زبان‌های برنامه‌نویسی معمولی که دستورات را خط به خط اجرا می‌کنند، تفاوت اساسی دارد.

## ۱. مفاهیم پایه

### ۱.۱. تفاوت Concurrent و Sequential

```
┌─────────────────────────────────────────────────────────────────────┐
│                    VHDL EXECUTION MODEL                           │
├─────────────────────────────────────────────────────────────────────┤
│                                                                   │
│  ┌─────────────────────────────────────────────────────────────┐  │
│  │            CONCURRENT (همزمان)                             │  │
│  │  ┌──────────┐  ┌──────────┐  ┌──────────┐                │  │
│  │  │ Signal   │  │ Process  │  │ Process  │                │  │
│  │  │ Assign   │  │    A     │  │    B     │                │  │
│  │  │          │  │          │  │          │                │  │
│  │  │ x <= a;  │  │ if ...   │  │ case ... │                │  │
│  │  └──────────┘  └──────────┘  └──────────┘                │  │
│  │       ↓             ↓             ↓                       │  │
│  │    همه به طور همزمان اجرا می‌شوند                          │  │
│  └─────────────────────────────────────────────────────────────┘  │
│                                                                   │
│  ┌─────────────────────────────────────────────────────────────┐  │

│  │  │  Step 2:  y := x + 1;  ← منتظر Step 1 می‌ماند     │  │  │
│  │  │  Step 3:  z := y * 2;  ← منتظر Step 2 می‌ماند     │  │  │
│  │  └──────────────────────────────────────────────────────┘  │  │
│  └─────────────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────────────┘
```

### ۱.۲. دستورات همزمان اصلی

| دستور | توضیح | کاربرد |
|-------|-------|---------|
| **Signal Assignment** | `signal <= expression` | ساده‌ترین دستور همزمان |
| **Concurrent Signal Assignment** | با `when/else` یا `with/select` | MUX و انتخاب شرطی |
| **Process** | `process (sensitivity) ... end process;` | بلوک‌های ترتیبی |
| **Component Instantiation** | `label: component port map(...)` | استفاده از ماژول‌ها |
| **Generate** | `for/generate` یا `if/generate` | ایجاد ساختارهای تکراری |
| **Block** | `block ... end block;` | گروه‌بندی منطقی |

## ۲. انتساب سیگنال همزمان (Concurrent Signal Assignment)

### ۲.۱. انتساب ساده

```vhdl
library ieee;
use ieee.std_logic_1164.all;

entity concurrent_assign is
    port (
        a, b : in  std_logic;
        c, d : in  std_logic_vector(3 downto 0);
        
        -- خروجی‌ها
        and_out : out std_logic;
        or_out  : out std_logic;
        xor_out : out std_logic_vector(3 downto 0);
        not_out : out std_logic_vector(3 downto 0)
    );
end entity;

architecture rtl of concurrent_assign is
begin
    -- ===== انتساب ساده =====
    and_out <= a and b;      -- همه این دستورات به طور همزمان اجرا می‌شوند
    or_out  <= a or b;       -- مستقل از هم
    xor_out <= c xor d;      -- هیچ ترتیبی بین آنها نیست
    not_out <= not c;        -- همزمان با دیگران
    
    -- ===== انتساب با محاسبه =====
    -- می‌توانید از عملگرها و توابع استفاده کنید
    process(a, b, c, d)
        variable temp : std_logic_vector(3 downto 0);
    begin
        -- محاسبات در اینجا انجام می‌شود
    end process;
end architecture;
```

### ۲.۲. انتساب شرطی با `when/else`

```vhdl
library ieee;
use ieee.std_logic_1164.all;
use ieee.numeric_std.all;

entity conditional_assignment is
    port (
        a, b    : in  std_logic_vector(7 downto 0);
        sel     : in  std_logic_vector(1 downto 0);
        clk     : in  std_logic;
        rst     : in  std_logic;
        enable  : in  std_logic;
        
        -- خروجی‌ها
        mux_out : out std_logic_vector(7 downto 0);
        max_out : out std_logic_vector(7 downto 0);
        state   : out std_logic;
        data    : out std_logic_vector(7 downto 0)
    );
end entity;

architecture rtl of conditional_assignment is
    signal internal_data : std_logic_vector(7 downto 0);
begin
    -- ===== MUX 4 به 1 با when/else =====
    mux_out <= a when sel = "00" else
               b when sel = "01" else
               a when sel = "10" else
               b when sel = "11" else
               (others => '0');
    
    -- ===== پیدا کردن ماکزیمم =====
    max_out <= a when unsigned(a) > unsigned(b) else b;
    
    -- ===== تشخیص صفر =====
    state <= '1' when unsigned(a) = 0 else '0';
    
    -- ===== شرط با enable =====
    data <= a when enable = '1' else (others => '0');
    
    -- ===== زنجیره طولانی =====
    internal_data <= a when unsigned(a) < 100 else
                     b when unsigned(b) < 200 else
                     std_logic_vector(unsigned(a) + unsigned(b)) when enable = '1' else
                     (others => '0');
end architecture;
```

### ۲.۳. انتساب انتخابی با `with/select`

```vhdl
library ieee;
use ieee.std_logic_1164.all;

entity selected_assignment is
    port (
        opcode   : in  std_logic_vector(2 downto 0);
        data_in  : in  std_logic_vector(7 downto 0);
        data_in2 : in  std_logic_vector(7 downto 0);
        sel      : in  std_logic_vector(1 downto 0);
        
        -- خروجی‌ها
        result   : out std_logic_vector(7 downto 0);
        control  : out std_logic_vector(2 downto 0)
    );
end entity;

architecture rtl of selected_assignment is
    constant OP_ADD : std_logic_vector(2 downto 0) := "000";
    constant OP_SUB : std_logic_vector(2 downto 0) := "001";
    constant OP_MUL : std_logic_vector(2 downto 0) := "010";
    constant OP_DIV : std_logic_vector(2 downto 0) := "011";
    constant OP_AND : std_logic_vector(2 downto 0) := "100";
    constant OP_OR  : std_logic_vector(2 downto 0) := "101";
    constant OP_XOR : std_logic_vector(2 downto 0) := "110";
begin
    -- ===== with/select با مقادیر ثابت =====
    with opcode select
        result <= data_in when OP_ADD,
                  data_in when OP_SUB,
                  std_logic_vector(unsigned(data_in) + unsigned(data_in2)) when OP_MUL,
                  (others => '0') when OP_DIV,
                  data_in and data_in2 when OP_AND,
                  data_in or data_in2 when OP_OR,
                  data_in xor data_in2 when OP_XOR,
                  (others => '0') when others;
    
    -- ===== با چند مقدار =====
    with sel select
        control <= "000" when "00" | "01",
                   "001" when "10",
                   "010" when "11",
                   "111" when others;
    
    -- ===== با range =====
    with opcode select
        result <= (others => '1') when "000" to "010",
                  (others => '0') when "011" to "101",
                  data_in when others;
end architecture;
```

## ۳. دستور Process

### ۳.۱. ساختار Process

```vhdl
-- ===== ساختار کلی =====
[label:] process (sensitivity_list) [is]
    -- declarations (متغیرها، ثابت‌ها، انواع)
begin
    -- sequential statements (دستورات ترتیبی)
end process [label];

-- ===== مثال کامل =====
library ieee;
use ieee.std_logic_1164.all;
use ieee.numeric_std.all;

entity process_example is
    port (
        clk   : in  std_logic;
        rst   : in  std_logic;
        enable: in  std_logic;
        data  : in  std_logic_vector(7 downto 0);
        count : out std_logic_vector(7 downto 0)
    );
end entity;

architecture rtl of process_example is
    signal counter : unsigned(7 downto 0);
begin
    -- ===== Process با Clock =====
    COUNTER_PROC: process(clk, rst)
        variable temp : integer := 0;  -- متغیر محلی
    begin
        if rst = '1' then
            counter <= (others => '0');
            temp := 0;
        elsif rising_edge(clk) then
            if enable = '1' then
                counter <= counter + 1;
                temp := temp + 1;
            end if;
        end if;
    end process COUNTER_PROC;
    
    count <= std_logic_vector(counter);
end architecture;
```

### ۳.۲. انواع Process

```vhdl
-- ===== 1. Process حساس به Clock (سنتزپذیر) =====
SYNC_PROC: process(clk, rst)
begin
    if rst = '1' then
        -- Reset
        reg <= (others => '0');
    elsif rising_edge(clk) then
        -- منطق همزمان
        reg <= data_in;
    end if;
end process SYNC_PROC;

-- ===== 2. Process ترکیبی (بدون Clock) =====
COMB_PROC: process(a, b, sel)
begin
    if sel = '1' then
        y <= a;
    else
        y <= b;
    end if;
end process COMB_PROC;

-- ===== 3. Process با چندین سیگنال =====
MULTI_PROC: process(a, b, c, d, sel)
begin
    case sel is
        when "00" => y <= a;
        when "01" => y <= b;
        when "10" => y <= c;
        when "11" => y <= d;
        when others => y <= (others => '0');
    end case;
end process MULTI_PROC;

-- ===== 4. Process با حساسیت به همه چیز (VHDL-2008) =====
ALL_PROC: process(all)
begin
    -- همه سیگنال‌های خوانده شده در Process به لیست حساسیت اضافه می‌شوند
    y <= a and b;
end process ALL_PROC;
```

### ۳.۳. قوانین مهم در Process

```vhdl
-- ===== قانون 1: لیست حساسیت =====
-- ✅ درست: همه سیگنال‌های ورودی در لیست حساسیت
COMB_OK: process(a, b, sel)
begin
    if sel = '1' then
        y <= a;
    else
        y <= b;
    end if;
end process COMB_OK;

-- ❌ غلط: بعضی سیگنال‌ها در لیست حساسیت نیستند
COMB_BAD: process(a, b)  -- sel در لیست حساسیت نیست!
begin
    if sel = '1' then    -- وقتی sel تغییر کند، Process اجرا نمی‌شود
        y <= a;
    else
        y <= b;
    end if;
end process COMB_BAD;

-- ===== قانون 2: انتساب به سیگنال =====
-- ✅ درست: سیگنال در یک Process
SIG_PROC: process(clk)
begin
    if rising_edge(clk) then
        sig1 <= a;  -- انتساب به سیگنال
    end if;
end process;

-- ❌ غلط: انتساب به سیگنال در دو Process مختلف
process(clk)
begin
    if rising_edge(clk) then
        sig1 <= a;  -- Process اول
    end if;
end process;

process(clk)  -- Process دوم
begin
    if rising_edge(clk) then
        sig1 <= b;  -- ❌ خطا: چندین درایور برای sig1
    end if;
end process;

-- ===== قانون 3: استفاده از متغیر =====
VAR_PROC: process(clk)
    variable v : integer := 0;  -- متغیر محلی
begin
    if rising_edge(clk) then
        v := v + 1;  -- متغیر فوراً به‌روز می‌شود
        sig <= v;    -- سیگنال بعد از پایان Process به‌روز می‌شود
    end if;
end process;
```

## ۴. Component Instantiation

### ۴.۱. تعریف و استفاده از Component

```vhdl
-- ===== 1. تعریف Component در Package =====
library ieee;
use ieee.std_logic_1164.all;

package components_pkg is
    -- ===== Component و NOT =====
    component and_gate
        port (
            a, b : in  std_logic;
            y    : out std_logic
        );
    end component;
    
    -- ===== Component و OR =====
    component or_gate
        port (
            a, b : in  std_logic;
            y    : out std_logic
        );
    end component;
    
    -- ===== Component Flip-Flop =====
    component dff
        port (
            clk, rst, d : in  std_logic;
            q           : out std_logic
        );
    end component;
    
    -- ===== Component با Generic =====
    component register_n
        generic (
            N : integer := 8
        );
        port (
            clk, rst, en : in  std_logic;
            d            : in  std_logic_vector(N-1 downto 0);
            q            : out std_logic_vector(N-1 downto 0)
        );
    end component;
end package components_pkg;

-- ===== 2. استفاده از Component =====
library ieee;
use ieee.std_logic_1164.all;
use work.components_pkg.all;

entity top is
    port (
        clk : in  std_logic;
        rst : in  std_logic;
        a   : in  std_logic;
        b   : in  std_logic;
        d   : in  std_logic_vector(7 downto 0);
        
        -- خروجی‌ها
        q   : out std_logic_vector(7 downto 0)
    );
end entity;

architecture struct of top is
    signal and_out : std_logic;
    signal or_out  : std_logic;
    signal dff_out : std_logic;
begin
    -- ===== Instantiation با پورت‌های نام‌گذاری شده =====
    U1: and_gate
        port map (
            a => a,
            b => b,
            y => and_out
        );
    
    U2: or_gate
        port map (
            a => a,
            b => b,
            y => or_out
        );
    
    -- ===== Instantiation با ترتیب پورت‌ها =====
    U3: dff
        port map (
            clk => clk,
            rst => rst,
            d   => and_out,
            q   => dff_out
        );
    
    -- ===== Instantiation با Generic =====
    U4: register_n
        generic map (
            N => 8
        )
        port map (
            clk => clk,
            rst => rst,
            en  => '1',
            d   => d,
            q   => q
        );
end architecture;
```

### ۴.۲. انواع Port Map

```vhdl
-- ===== 1. Port Map با نام =====
U1: component_name
    port map (
        port1 => signal1,
        port2 => signal2,
        port3 => signal3
    );

-- ===== 2. Port Map با ترتیب =====
U2: component_name
    port map (signal1, signal2, signal3);
    -- ترتیب باید دقیقاً مطابق تعریف Component باشد

-- ===== 3. Port Map با مقادیر ثابت =====
U3: component_name
    port map (
        port1 => '1',        -- مقدار ثابت
        port2 => signal2,
        port3 => open        -- پورت باز (بدون اتصال)
    );

-- ===== 4. Port Map با اتصال مستقیم =====
U4: component_name
    port map (
        port1 => clk,
        port2 => a and b,    -- ✅ مجاز: محاسبه مستقیم
        port3 => data(7 downto 0)
    );

-- ===== 5. Port Map با Generic =====
U5: register_n
    generic map (
        N => 16,
        INIT => (others => '0')
    )
    port map (
        clk => clk,
        d   => data_in,
        q   => data_out
    );
```

## ۵. دستور Generate

### ۵.۱. `for/generate` (تولید تکراری)

```vhdl
library ieee;
use ieee.std_logic_1164.all;
use ieee.numeric_std.all;

entity generate_example is
    generic (
        N : integer := 8
    );
    port (
        clk      : in  std_logic;
        rst      : in  std_logic;
        data_in  : in  std_logic_vector(N-1 downto 0);
        data_out : out std_logic_vector(N-1 downto 0)
    );
end entity;

architecture rtl of generate_example is
    signal temp : std_logic_vector(N-1 downto 0);
begin
    -- ===== 1. Generate برای ساخت بیت‌های تکراری =====
    GEN_REG: for i in 0 to N-1 generate
        -- هر بیت یک D-Flip-Flop جداگانه دارد
        DFF_INST: process(clk, rst)
        begin
            if rst = '1' then
                temp(i) <= '0';
            elsif rising_edge(clk) then
                temp(i) <= data_in(i);
            end if;
        end process;
    end generate GEN_REG;
    
    data_out <= temp;
    
    -- ===== 2. Generate برای ساخت Componentهای تکراری =====
    GEN_AND: for i in 0 to 3 generate
        U_AND: and_gate
            port map (
                a => data_in(i),
                b => data_in(i+4),
                y => temp(i)
            );
    end generate GEN_AND;
    
    -- ===== 3. Generate تو در تو =====
    GEN_MATRIX: for row in 0 to 3 generate
        GEN_COL: for col in 0 to 3 generate
            -- ایجاد ماتریس 4x4 از Componentها
        end generate GEN_COL;
    end generate GEN_MATRIX;
end architecture;
```

### ۵.۲. `if/generate` (تولید شرطی)

```vhdl
library ieee;
use ieee.std_logic_1164.all;

entity conditional_generate is
    generic (
        USE_PARITY   : boolean := true;
        DATA_WIDTH   : integer := 8;
        USE_DEBUG    : boolean := false
    );
    port (
        clk   : in  std_logic;
        data  : in  std_logic_vector(DATA_WIDTH-1 downto 0);
        parity : out std_logic
    );
end entity;

architecture rtl of conditional_generate is
begin
    -- ===== Generate شرطی با if =====
    GEN_PARITY: if USE_PARITY generate
        -- اگر پارامتر USE_PARITY = true باشد، این بخش ساخته می‌شود
        parity <= xor data;
    end generate GEN_PARITY;
    
    GEN_NO_PARITY: if not USE_PARITY generate
        -- اگر USE_PARITY = false باشد، این بخش ساخته می‌شود
        parity <= '0';
    end generate GEN_NO_PARITY;
    
    -- ===== Generate با شرط Generic =====
    GEN_DEBUG: if USE_DEBUG generate
        -- اگر USE_DEBUG = true باشد
        DEBUG_PROC: process(clk)
        begin
            if rising_edge(clk) then
                report "Data: " & to_string(data);
            end if;
        end process;
    end generate GEN_DEBUG;
    
    -- ===== Generate با شرط DATA_WIDTH =====
    GEN_8BIT: if DATA_WIDTH = 8 generate
        -- فقط برای DATA_WIDTH = 8
        signal temp : std_logic_vector(7 downto 0);
    begin
        -- منطق مخصوص 8 بیت
    end generate GEN_8BIT;
    
    GEN_16BIT: if DATA_WIDTH = 16 generate
        -- فقط برای DATA_WIDTH = 16
        signal temp : std_logic_vector(15 downto 0);
    begin
        -- منطق مخصوص 16 بیت
    end generate GEN_16BIT;
end architecture;
```

## ۶. دستور Block

### ۶.۱. Block ساده

```vhdl
library ieee;
use ieee.std_logic_1164.all;

entity block_example is
    port (
        clk   : in  std_logic;
        rst   : in  std_logic;
        a, b  : in  std_logic_vector(7 downto 0);
        sel   : in  std_logic;
        
        y     : out std_logic_vector(7 downto 0)
    );
end entity;

architecture rtl of block_example is
    signal internal : std_logic_vector(7 downto 0);
begin
    -- ===== Block اصلی =====
    MAIN_BLOCK: block
        signal mux_out : std_logic_vector(7 downto 0);
    begin
        -- منطق درون Block
        mux_out <= a when sel = '1' else b;
        y <= mux_out;
    end block MAIN_BLOCK;
    
    -- ===== Block با Guard =====
    GATED_BLOCK: block (clk = '1')
        signal gated_data : std_logic_vector(7 downto 0);
    begin
        -- فقط زمانی که clk = '1' باشد اجرا می‌شود
        gated_data <= a and b;
        -- استفاده از gated_data
    end block GATED_BLOCK;
end architecture;
```

### ۶.۲. Block با Port و Generic

```vhdl
library ieee;
use ieee.std_logic_1164.all;

entity block_with_ports is
    port (
        clk : in  std_logic;
        rst : in  std_logic;
        data_in : in  std_logic_vector(15 downto 0);
        data_out : out std_logic_vector(15 downto 0)
    );
end entity;

architecture rtl of block_with_ports is
begin
    -- ===== Block با Generic =====
    ALU_BLOCK: block
        generic (
            WIDTH : integer := 16
        );
        generic map (
            WIDTH => 16
        );
        port (
            clk_i  : in  std_logic;
            rst_i  : in  std_logic;
            a_i    : in  std_logic_vector(WIDTH-1 downto 0);
            b_i    : in  std_logic_vector(WIDTH-1 downto 0);
            result : out std_logic_vector(WIDTH-1 downto 0)
        );
        port map (
            clk_i  => clk,
            rst_i  => rst,
            a_i    => data_in,
            b_i    => data_in,
            result => data_out
        );
    begin
        -- منطق Block
        process(clk_i, rst_i)
        begin
            if rst_i = '1' then
                result <= (others => '0');
            elsif rising_edge(clk_i) then
                result <= a_i + b_i;
            end if;
        end process;
    end block ALU_BLOCK;
end architecture;
```

## ۸. مقایسه Concurrent vs Sequential

### ۸.۱. جدول مقایسه

| ویژگی | Concurrent | Sequential (Process) |
|--------|------------|---------------------|
| **نحوه اجرا** | همزمان با همه | ترتیبی (درون Process) |
| **ترتیب** | بدون ترتیب | از بالا به پایین |
| **انتساب سیگنال** | ✅ مجاز | ✅ مجاز |
| **انتساب متغیر** | ❌ مجاز نیست | ✅ مجاز |
| **انتساب چندگانه** | ❌ مجاز نیست | ✅ مجاز (آخرین مقدار) |
| **حساسیت** | خودکار به سیگنال‌های ورودی | لیست حساسیت |
| **Loop** | ❌ مجاز نیست | ✅ مجاز |
| **If/Else** | ❌ مجاز نیست (فقط when/else) | ✅ مجاز |
| **Case** | ❌ مجاز نیست (فقط with/select) | ✅ مجاز |
| **Synthesis** | ✅ کاملاً قابل سنتز | ✅ کاملاً قابل سنتز |

### ۸.۲. تبدیل Concurrent به Sequential

```vhdl
-- ===== معادل‌های Concurrent =====

-- 1. انتساب ساده
-- Concurrent:
y <= a and b;

-- Sequential (Process):
process(a, b)
begin
    y <= a and b;
end process;

-- 2. when/else
-- Concurrent:
y <= a when sel = '1' else b;

-- Sequential (Process):
process(a, b, sel)
begin
    if sel = '1' then
        y <= a;
    else
        y <= b;
    end if;
end process;

-- 3. with/select
-- Concurrent:
with opcode select
    y <= a when "00",
         b when "01",
         c when others;

-- Sequential (Process):
process(opcode, a, b, c)
begin
    case opcode is
        when "00" => y <= a;
        when "01" => y <= b;
        when others => y <= c;
    end case;
end process;
```

## ۹. اشتباهات رایج

### ۹.۱. اشتباه: لیست حساسیت ناقص

```vhdl
-- ===== ❌ اشتباه =====
process(a, b)  -- sel در لیست حساسیت نیست
begin
    if sel = '1' then
        y <= a;
    else
        y <= b;
    end if;
end process;
-- وقتی sel تغییر کند، Process اجرا نمی‌شود

-- ===== ✅ راه‌حل =====
process(a, b, sel)  -- همه ورودی‌ها در لیست حساسیت
begin
    if sel = '1' then
        y <= a;
    else
        y <= b;
    end if;
end process;
```

### ۹.۲. اشتباه: انتساب به یک سیگنال در چند Process

```vhdl
-- ===== ❌ اشتباه =====
process(clk)
begin
    if rising_edge(clk) then
        y <= a;  -- Process اول
    end if;
end process;

process(clk)
begin
    if rising_edge(clk) then
        y <= b;  -- ❌ Process دوم: چندین درایور
    end if;
end process;

-- ===== ✅ راه‌حل 1: ترکیب در یک Process =====
process(clk)
begin
    if rising_edge(clk) then
        if sel = '1' then
            y <= a;
        else
            y <= b;
        end if;
    end if;
end process;

-- ===== ✅ راه‌حل 2: استفاده از سه‌حالته =====
process(clk, a, en_a)
begin
    if en_a = '1' then
        y <= a;
    else
        y <= 'Z';  -- سه‌حالته
    end if;
end process;
```

### ۹.۳. اشتباه: Latch ناخواسته

```vhdl
-- ===== ❌ اشتباه: Latch ناخواسته =====
process(a, b, sel)
begin
    if sel = '1' then
        y <= a;
    -- else مفقود است!
    end if;
end process;
-- وقتی sel = '0'، y مقدار قبلی خود را نگه می‌دارد (Latch)

-- ===== ✅ راه‌حل =====
process(a, b, sel)
begin
    if sel = '1' then
        y <= a;
    else
        y <= b;  -- همه حالت‌ها پوشش داده شده
    end if;
end process;

-- ===== یا مقدار پیش‌فرض =====
process(a, b, sel)
begin
    y <= b;  -- مقدار پیش‌فرض
    if sel = '1' then
        y <= a;
    end if;
end process;
```

### ۹.۴. اشتباه: استفاده از مقدار سیگنال قبل از به‌روزرسانی

```vhdl
-- ===== ❌ اشتباه =====
process(clk)
begin
    if rising_edge(clk) then
        y <= a;      -- y مقدار جدید می‌گیرد
        z <= y + 1;  -- از مقدار OLD y استفاده می‌شود!
    end if;
end process;

-- ===== ✅ راه‌حل 1: استفاده از متغیر =====
process(clk)
    variable v : integer;
begin
    if rising_edge(clk) then
        v := a;          -- متغیر فوراً به‌روز می‌شود
        z <= v + 1;      -- از مقدار جدید v استفاده می‌شود
        y <= v;
    end if;
end process;

-- ===== ✅ راه‌حل 2: استفاده از سیگنال کمکی =====
process(clk)
begin
    if rising_edge(clk) then
        y <= a;
        z <= a + 1;  -- استفاده از a (ورودی) به جای y
    end if;
end process;
```

## ۱۰. بهترین‌نوشته‌ها (Best Practices)

### ۱۰.۱. سازماندهی Processها

```vhdl
-- ===== ✅ Good Practice =====
architecture rtl of entity_name is
begin
    -- 1. Processهای سنکرون (با Clock)
    SYNC_PROC: process(clk, rst)
    begin
        if rst = '1' then
            -- Reset
        elsif rising_edge(clk) then
            -- منطق همزمان
        end if;
    end process;
    
    -- 2. Processهای ترکیبی (بدون Clock)
    COMB_PROC: process(a, b, sel)
    begin
        -- منطق ترکیبی
    end process;
    
    -- 3. انتساب‌های همزمان ساده
    y <= a and b;
    
    -- 4. Generateها
    GEN: for i in 0 to 7 generate
        -- ...
    end generate;
end architecture;
```

### ۱۰.۲. نام‌گذاری Processها

```vhdl
-- ===== ✅ با نام واضح =====
COUNTER_PROC: process(clk, rst)
begin
    -- ...
end process COUNTER_PROC;

ALU_CONTROL_PROC: process(opcode, flags)
begin
    -- ...
end process ALU_CONTROL_PROC;

-- ===== ❌ بدون نام یا نام نامفهوم =====
P1: process(clk, rst)  -- نام واضح نیست
begin
    -- ...
end process P1;
```

### ۱۰.۳. استفاده از `process(all)`

```vhdl
-- ===== VHDL-2008: process(all) =====
-- نیازی به لیست حساسیت کامل نیست
COMB_PROC: process(all)
begin
    -- همه سیگنال‌های خوانده شده به لیست حساسیت اضافه می‌شوند
    y <= a and b;
    if sel = '1' then
        z <= a;
    else
        z <= b;
    end if;
end process;
```

### ۱۰.۴. رعایت قوانین سنتز

```vhdl
-- ===== قوانین برای سنتزپذیری =====

-- 1. Reset باید در لیست حساسیت باشد
SYNC_PROC: process(clk, rst)  -- ✅ شامل rst
begin
    if rst = '1' then
        -- Reset
    elsif rising_edge(clk) then
        -- ...
    end if;
end process;

-- 2. یک Process نباید هم Clock و هم Async Reset داشته باشد
-- ✅ درست: فقط یک Clock
SYNC_PROC: process(clk)
begin
    if rising_edge(clk) then
        -- ...
    end if;
end process;

-- ✅ درست: با Async Reset
SYNC_PROC: process(clk, rst)
begin
    if rst = '1' then
        -- Async Reset
    elsif rising_edge(clk) then
        -- ...
    end if;
end process;

-- 3. از rising_edge() و falling_edge() استفاده کنید
if rising_edge(clk) then  -- ✅
    -- ...
end if;

if clk'event and clk = '1' then  -- ❌ قدیمی و کمتر خوانا
    -- ...
end if;
```

## ۱۱. خلاصه و جمع‌بندی

### دستورات همزمان اصلی

| دستور | کاربرد | مثال |
|-------|--------|-------|
| **Signal Assignment** | انتساب ساده | `y <= a and b;` |
| **Conditional Assignment** | MUX و انتخاب شرطی | `y <= a when sel='1' else b;` |
| **Selected Assignment** | انتخاب با حالت‌های متعدد | `with opcode select y <= ...` |
| **Process** | بلوک‌های ترتیبی | `process(clk) begin ... end process;` |
| **Component Instantiation** | استفاده از ماژول‌ها | `U1: and_gate port map(...);` |
| **Generate** | ایجاد ساختارهای تکراری | `for i in 0 to 7 generate ...` |
| **Block** | گروه‌بندی منطقی | `BLOCK: block ... end block;` |

### نکات کلیدی

| نکته | توضیح |
|------|-------|
| **همزمانی** | همه دستورات همزمان به طور موازی اجرا می‌شوند |
| **Process** | تنها جایی که دستورات ترتیبی مجاز هستند |
| **لیست حساسیت** | برای Process ترکیبی، همه ورودی‌ها در لیست حساسیت |
| **انتساب سیگنال** | در انتهای Process به‌روز می‌شود |
| **متغیر** | فوراً به‌روز می‌شود (در Process) |
| **سنتزپذیری** | رعایت قوانین سنتز برای طراحی‌های سخت‌افزاری |

### انتخاب بین Concurrent و Sequential

```
┌─────────────────────────────────────────────────────────────┐
│  چه زمانی از Concurrent استفاده کنیم؟                      │
│  • انتساب‌های ساده                                        │
│  • MUX با چند ورودی                                       │
│  • Component Instantiation                                │
│  • ساختارهای تکراری با Generate                          │
│  • منطق ترکیبی ساده                                      │
├─────────────────────────────────────────────────────────────┤
│  چه زمانی از Process استفاده کنیم؟                        │
│  • منطق با Clock (Flip-Flop, Register)                   │
│  • منطق با Reset                                          │
│  • منطق شرطی پیچیده (if/else, case)                     │
│  • حلقه‌ها (loop)                                         │
│  • منطق ترکیبی پیچیده                                     │
│  • توابع و رویه‌ها                                        │
└─────────────────────────────────────────────────────────────┘
```

> **پیام نهایی:** درک تفاوت بین دستورات همزمان و ترتیبی، **کلید اصلی** طراحی موفق در VHDL است. به یاد داشته باشید که سخت‌افزار ذاتاً **همزمان** است و VHDL این ماهیت را به خوبی منعکس می‌کند. با تسلط بر دستورات همزمان، می‌توانید طراحی‌های **کارآمد**، **قابل سنتز** و **حرفه‌ای** ایجاد کنید.
