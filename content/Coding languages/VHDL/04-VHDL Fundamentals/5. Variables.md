# Variables در VHDL — تحلیل جامع و عمیق

## مقدمه: متغیرهای موقت در دنیای سخت‌افزار

در زبان‌های برنامه‌نویسی مانند C یا Python، **متغیرها (Variables)** برای ذخیره‌سازی موقت مقادیر استفاده می‌شوند. در VHDL نیز Variables وجود دارند، اما با تفاوت‌های اساسی--- برای **توصیف سخت‌افزار** طراحی شده‌اند، نه برای اجرای نرم‌افزار.

Variables در VHDL مانند **یادداشت‌های موقت** روی یک کاغذ هستند: شما می‌توانید چیزی را یادداشت کنید، آن را تغییر دهید، و از آن استفاده کنید، اما پس از پایان کار (پایان Process)، آن یادداشت‌ها از بین می‌روند.

---

## ۱. Variable چیست؟ تعریف جامع

**Variable** در VHDL یک **نوع داده محلی** است که فقط در داخل یک **Process**, **Function**, یا **Procedure** تعریف و استفاده می‌شود. Variableها برای **محاسبات موقت** و **ذخیره‌سازی مقادیر میانی** استفاده می‌شوند.

### تشبیه ساده

Variable را مانند **یک تخته‌سفید کوچک در یک اتاق** تصور کنید:
- فقط کسی که در اتاق است (Process) می‌تواند روی آن بنویسد
- هر کس دیگری (Process دیگر) نمی‌تواند آن را ببیند
- وقتی از اتاق خارج می‌شوید (پایان Process)، تخته‌سفید پاک می‌شود
- می‌توانید هر چند بار که بخواهید روی آن بنویسید و پاک کنید

## ۲. تفاوت Variable با Signal — تحلیل عمیق

### Variable (متغیر)

```vhdl
architecture rtl of example is
begin
    process(clk)
        variable v : integer := 0;  -- Variable
    begin
        if rising_edge(clk) then
            v := v + 1;  -- به‌روزرسانی فوری
            y <= v;      -- مقدار جدید v را می‌گیرد
        end if;
    end process;
end architecture;
```

**ویژگی‌ها:**
- مقدار **فوراً** به‌روز می‌شود
- **بدون حافظه** (در سخت‌افزار به Wire تبدیل می‌شود)
- فقط در همان Process قابل استفاده است
- در سایر Processها قابل دسترسی نیست
- انتساب با `:=` انجام می‌شود

### Signal (سیگنال)

```vhdl
architecture rtl of example is
    signal s : integer := 0;  -- Signal
begin
    process(clk)
    begin
        if rising_edge(clk) then
            s <= s + 1;  -- به‌روزرسانی در پایان Process
            y <= s;      -- مقدار قدیمی s را می‌گیرد!
        end if;
    end process;
end architecture;
```

**ویژگی‌ها:**
- مقدار در **پایان** Process به‌روز می‌شود
- دارای **حافظه** (در سخت‌افزار به Register تبدیل می‌شود)
- در کل Architecture قابل دسترسی است
- انتساب با `<=` انجام می‌شود

### جدول مقایسه کامل

| ویژگی | Variable | Signal |
|-------|----------|--------|
| **به‌روزرسانی** | فوری | پایان Process |
| **حافظه** | ندارد (Wire) | دارد (Register/Wire) |
| **حوزه دسترسی** | فقط همان Process | کل Architecture |
| **ارتباط بین Processها** | خیر | بله |
| **انتساب** | `:=` | `<=` |
| **سخت‌افزار** | معمولاً Wire | Register یا Wire |
| **قابل سنتز** | بله | بله |
| **مقداردهی اولیه** | در اعلان یا قبل از استفاده | در اعلان یا Reset |

## ۳. اعلان Variable — ساختار و مکان‌ها

### ۳.۱. در Process (متداول‌ترین)

```vhdl
process(clk, reset)
    variable count : integer := 0;
    variable temp : std_logic_vector(7 downto 0);
    variable flag : boolean := false;
begin
    -- استفاده از Variableها
    count := count + 1;
    temp := data_in;
    flag := (count > 10);
end process;
```

### ۳.۲. در Function

```vhdl
function add_numbers(a, b : integer) return integer is
    variable result : integer;  -- Variable در Function
begin
    result := a + b;
    return result;
end function;
```

### ۳.۳. در Procedure

```vhdl
procedure increment(signal count : inout integer) is
    variable temp : integer;  -- Variable در Procedure
begin
    temp := count + 1;
    count <= temp;
end procedure;
```

## ۴. انواع Variable — تحلیل کامل

### ۴.۱. Variable از نوع `integer`

```vhdl
process(clk)
    variable count : integer range 0 to 255 := 0;
begin
    if rising_edge(clk) then
        count := count + 1;
        if count = 255 then
            count := 0;
        end if;
    end if;
end process;
```

### ۴.۲. Variable از نوع `std_logic_vector`

```vhdl
process(clk)
    variable temp : std_logic_vector(7 downto 0);
begin
    if rising_edge(clk) then
        temp := data_in;
        temp(3 downto 0) := "0000";  -- تغییر بخشی از Vector
        data_out <= temp;
    end if;
end process;
```

### ۴.۳. Variable از نوع `unsigned` / `signed`

```vhdl
library ieee;
use ieee.numeric_std.all;

process(clk)
    variable count : unsigned(7 downto 0) := (others => '0');
    variable result : signed(7 downto 0);
begin
    if rising_edge(clk) then
        count := count + 1;
        result := signed(count) - 10;
    end if;
end process;
```

### ۴.۴. Variable از نوع Array

```vhdl
process(clk)
    type int_array is array (0 to 7) of integer;
    variable values : int_array;
begin
    if rising_edge(clk) then
        for i in 0 to 7 loop
            values(i) := i * 2;
        end loop;
    end if;
end process;
```

### ۴.۵. Variable از نوع Record

```vhdl
type cpu_state is record
    pc : std_logic_vector(15 downto 0);
    ir : std_logic_vector(7 downto 0);
    flags : std_logic_vector(3 downto 0);
end record;

process(clk)
    variable cpu : cpu_state;
begin
    if rising_edge(clk) then
        cpu.pc := pc_in;
        cpu.ir := ir_in;
        cpu.flags := flags_in;
    end if;
end process;
```

## ۵. رفتار Variable — تحلیل عمیق

### ۵.۱. به‌روزرسانی فوری

```vhdl
process(clk)
    variable a, b : integer := 0;
begin
    if rising_edge(clk) then
        a := 5;
        b := a + 1;  -- b = 6 (از مقدار جدید a استفاده می‌کند)
        y <= b;      -- y = 6
    end if;
end process;
```

### ۵.۲. استفاده در چند مرحله

```vhdl
process(clk)
    variable temp : integer := 0;
begin
    if rising_edge(clk) then
        temp := 10;
        temp := temp * 2;  -- temp = 20
        temp := temp + 5;  -- temp = 25
        result <= temp;    -- result = 25
    end if;
end process;
```

### ۵.۳. Variable و Delta Delay

برخلاف Signalها، Variableها **بدون Delta Delay** به‌روز می‌شوند:

```vhdl
process(clk)
    variable v : integer := 0;
begin
    if rising_edge(clk) then
        v := v + 1;  -- v = 1 (فوری)
        v := v + 1;  -- v = 2 (فوری)
        v := v + 1;  -- v = 3 (فوری)
        y <= v;      -- y = 3
    end if;
end process;
```

اگر این کد با Signal نوشته می‌شد، فقط یک بار افزایش می‌یافت.

## ۶. Variable در مقابل Signal — مثال‌های عملی

### مثال ۱: محاسبه مجموع

**با Variable (درست):**
```vhdl
process(clk)
    variable sum : integer := 0;
begin
    if rising_edge(clk) then
        sum := 0;
        for i in 0 to 7 loop
            sum := sum + data_in(i);
        end loop;
        result <= sum;
    end if;
end process;
```

**با Signal (نادرست برای این مورد):**
```vhdl
process(clk)
begin
    if rising_edge(clk) then
        sum <= 0;
        for i in 0 to 7 loop
            sum <= sum + data_in(i);  -- ❌ فقط آخرین مقدار ثبت می‌شود
        end loop;
        result <= sum;
    end if;
end process;
```

### مثال ۲: Pipeline

**با Signal (درست برای Pipeline):**
```vhdl
process(clk)
begin
    if rising_edge(clk) then
        stage1 <= data_in;
        stage2 <= stage1;
        stage3 <= stage2;
        output <= stage3;
    end if;
end process;
```

**با Variable (نادرست برای Pipeline):**
```vhdl
process(clk)
    variable v1, v2, v3 : std_logic_vector(7 downto 0);
begin
    if rising_edge(clk) then
        v1 := data_in;    -- v1 = data_in
        v2 := v1;         -- v2 = data_in (نه مقدار قبلی)
        v3 := v2;         -- v3 = data_in (نه مقدار قبلی)
        output <= v3;     -- output = data_in (بدون تأخیر!)
    end if;
end process;
```

## ۷. Variable در طراحی‌های واقعی — الگوهای رایج

### ۷.۱. محاسبات پیچیده

```vhdl
process(clk)
    variable temp : integer;
    variable result : integer;
begin
    if rising_edge(clk) then
        -- محاسبه مرحله به مرحله
        temp := a * b;
        temp := temp + c;
        result := temp / d;
        output <= result;
    end if;
end process;
```

### ۷.۲. شمارش در یک Process

```vhdl
process(clk, reset)
    variable bit_count : integer range 0 to 8 := 0;
begin
    if reset = '1' then
        bit_count := 0;
    elsif rising_edge(clk) then
        if bit_count < 8 then
            data_shift <= data_shift(6 downto 0) & data_in;
            bit_count := bit_count + 1;
        else
            data_valid <= '1';
            bit_count := 0;
        end if;
    end if;
end process;
```

### ۷.۳. حلقه‌ها (Loops)

```vhdl
process(clk)
    variable temp : integer := 0;
begin
    if rising_edge(clk) then
        temp := 0;
        for i in 0 to 7 loop
            if data_in(i) = '1' then
                temp := temp + 1;
            end if;
        end loop;
        ones_count <= temp;
    end if;
end process;
```

### ۷.۴. فیلترهای دیجیتال

```vhdl
process(clk)
    type int_array is array (0 to 3) of integer;
    variable history : int_array := (others => 0);
    variable sum : integer := 0;
begin
    if rising_edge(clk) then
        -- Shift history
        history(3) := history(2);
        history(2) := history(1);
        history(1) := history(0);
        history(0) := data_in;
        
        -- Calculate moving average
        sum := 0;
        for i in 0 to 3 loop
            sum := sum + history(i);
        end loop;
        
        filtered <= sum / 4;
    end if;
end process;
```

## ۸. Variable و سنتز — نکات مهم

### ۸.۱. Variable به عنوان Wire

در بیشتر موارد، Variableها در سنتز به **Wire** (سیم ترکیبی) تبدیل می‌شوند:

```vhdl
process(a, b, sel)
    variable temp : std_logic;
begin
    if sel = '0' then
        temp := a;
    else
        temp := b;
    end if;
    y <= temp;
end process;
-- y → Wire (Combinational)
```

### ۸.۲. Variable به عنوان Register

اگر Variable در یک Process کلاک‌دار استفاده شود، ممکن است به **Register** تبدیل شود:

```vhdl
process(clk)
    variable temp : std_logic;
begin
    if rising_edge(clk) then
        temp := d;  -- temp یک Register می‌شود
        q <= temp;
    end if;
end process;
```

### ۸.۳. نکات سنتز

- **همه Variableها باید مقداردهی شوند** قبل از استفاده
- **از Variableها برای توصیف مسیرهای ترکیبی** استفاده کنید
- **برای Registerها از Signal استفاده کنید** (یا Variable با احتیاط)

## ۹. اشتباهات رایج در Variableها

### اشتباه ۱: استفاده از Variable بین Processها

**نادرست:**
```vhdl
architecture rtl of example is
    -- ❌ Variable نمی‌تواند در Architecture اعلان شود
    variable v : integer;  -- خطا!
begin
    process1: process(clk)
    begin
        v := v + 1;
    end process;
    
    process2: process(clk)
    begin
        q <= v;  -- ❌ v در اینجا قابل دسترسی نیست
    end process;
end architecture;
```

**درست:**
```vhdl
architecture rtl of example is
    signal s : integer;  -- ✅ از Signal استفاده کنید
begin
    process1: process(clk)
    begin
        s <= s + 1;
    end process;
    
    process2: process(clk)
    begin
        q <= s;  -- ✅ Signal قابل دسترسی است
    end process;
end architecture;
```

### اشتباه ۲: فراموش کردن مقداردهی اولیه

**نادرست:**
```vhdl
process(clk)
    variable count : integer;  -- ❌ مقدار اولیه نامشخص
begin
    if rising_edge(clk) then
        count := count + 1;  -- ❌ از مقدار نامشخص استفاده می‌کند
    end if;
end process;
```

**درست:**
```vhdl
process(clk)
    variable count : integer := 0;  -- ✅ مقدار اولیه مشخص
begin
    if rising_edge(clk) then
        count := count + 1;
    end if;
end process;
```

### اشتباه ۳: انتساب با `<=` به Variable

**نادرست:**
```vhdl
process(clk)
    variable v : integer;
begin
    v <= v + 1;  -- ❌ باید از := استفاده کنید
end process;
```

**درست:**
```vhdl
process(clk)
    variable v : integer;
begin
    v := v + 1;  -- ✅
end process;
```

### اشتباه ۴: انتساب Signal با `:=`

**نادرست:**
```vhdl
process(clk)
begin
    q := d;  -- ❌ q یک Signal است، باید از <= استفاده کنید
end process;
```

**درست:**
```vhdl
process(clk)
begin
    q <= d;  -- ✅
end process;
```

### اشتباه ۵: استفاده از Variable برای Pipeline

**نادرست:**
```vhdl
process(clk)
    variable v1, v2 : std_logic_vector(7 downto 0);
begin
    if rising_edge(clk) then
        v1 := data_in;
        v2 := v1;  -- ❌ این Pipeline نیست، v1 بلافاصله به‌روز می‌شود
        output <= v2;
    end if;
end process;
```

**درست:**
```vhdl
process(clk)
    signal s1, s2 : std_logic_vector(7 downto 0);  -- ✅ Signal
begin
    if rising_edge(clk) then
        s1 <= data_in;
        s2 <= s1;
        output <= s2;
    end if;
end process;
```

## ۱۰. تمرین‌های عملی

### تمرین ۱: Variable برای محاسبه

یک Process بنویسید که با استفاده از Variable، مجموع ۴ عدد ورودی را محاسبه کند.

**پاسخ:**
```vhdl
process(clk)
    variable sum : integer := 0;
begin
    if rising_edge(clk) then
        sum := 0;
        sum := sum + a;
        sum := sum + b;
        sum := sum + c;
        sum := sum + d;
        total <= sum;
    end if;
end process;
```

### تمرین ۲: Variable برای شمارش بیت‌های ۱

یک Process بنویسید که تعداد بیت‌های ۱ در یک ورودی ۸ بیتی را با استفاده از Variable بشمارد.

**پاسخ:**
```vhdl
process(clk)
    variable count : integer := 0;
begin
    if rising_edge(clk) then
        count := 0;
        for i in 0 to 7 loop
            if data_in(i) = '1' then
                count := count + 1;
            end if;
        end loop;
        ones_count <= count;
    end if;
end process;
```

### تمرین ۳: Variable برای تبدیل

یک Process بنویسید که با استفاده از Variable، یک عدد ۴ بیتی را به BCD تبدیل کند.

**پاسخ:**
```vhdl
process(clk)
    variable temp : integer;
    variable ones, tens : integer;
begin
    if rising_edge(clk) then
        temp := binary_in;
        tens := temp / 10;
        ones := temp mod 10;
        bcd_out <= std_logic_vector(to_unsigned(tens, 4)) &
                   std_logic_vector(to_unsigned(ones, 4));
    end if;
end process;
```

## ۱۱. خلاصه و جمع‌بندی

### نکات کلیدی

| مفهوم | توضیح |
|-------|-------|
| **Variable** | برای محاسبات موقت در داخل Process |
| **به‌روزرسانی** | فوری (بدون Delta Delay) |
| **حوزه** | فقط همان Process |
| **انتساب** | با `:=` |
| **سخت‌افزار** | معمولاً Wire (ترکیبی) |
| **قابل سنتز** | بله |

### Variable در مقابل Signal

| ویژگی | Variable | Signal |
|-------|----------|--------|
| **به‌روزرسانی** | فوری | پایان Process |
| **حوزه** | Process | Architecture |
| **ارتباط بین Processها** | خیر | بله |
| **انتساب** | `:=` | `<=` |
| **سخت‌افزار** | Wire | Register/Wire |

### فرمت اعلان Variable

```vhdl
variable <name> : <type> [:= <initial_value>];
```

### قوانین طلایی

1. **از Variable برای محاسبات موقت استفاده کنید**
2. **از Signal برای ارتباط بین Processها استفاده کنید**
3. **همیشه Variableها را مقداردهی کنید**
4. **برای Pipeline از Signal استفاده کنید، نه Variable**
5. **در Processهای ترکیبی از Variable استفاده کنید**

### پیام نهایی

Variableها **ابزاری قدرتمند** برای محاسبات پیچیده در داخل Processها هستند. با درک صحیح تفاوت Variable و Signal، می‌توانید کدهای VHDL بهینه‌تر و قابل فهم‌تری بنویسید.

> **به یاد داشته باشید:** Variableها مانند **کاغذ یادداشت** هستند — مفید برای محاسبات موقت، اما برای ارتباط بین بخش‌های مختلف طراحی، از Signalها استفاده کنید.
