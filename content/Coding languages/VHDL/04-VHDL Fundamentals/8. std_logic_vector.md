# std_logic_vector در VHDL — تحلیل جامع و عمیق

## مقدمه: باس‌های داده، زبان مشترک سخت‌افزار

در دنیای واقعی، مدارهای دیجیتال به ندرت با یک بیت منفرد کار می‌کنند. یک پردازنده با **کلمه‌های (Words)** ۸، ۱۶، ۳۲ یا ۶۴ بیتی کار می‌کند. یک حافظه با **باس‌های آدرس (Address Buses)** ۱۶ یا ۳۲ بیتی آدرس‌دهی می‌شود. یک سنسور داده‌های ۱۲ بیتی تولید می‌کند.

برای مدل‌سازی این **گروه‌های بیتی** در VHDL، از `std_logic_vector` استفاده می‌کنیم. `std_logic_vector` یک **آرایه** از `std_logic` است که امکان کار با **باس‌های داده**، **ثبات‌ها**، **آدرس‌ها** و هر مجموعه‌ای از بیت‌ها را فراهم می‌کند.

---

## ۱. std_logic_vector چیست؟ تعریف جامع

**std_logic_vector** یک **نوع داده آرایه‌ای** در کتابخانه `std_logic_1164` است که برای نمایش **گروه‌هایی از سیگنال‌های منطقی** استفاده می‌شود. هر عنصر این آرایه از نوع `std_logic` است و بنابراین می‌تواند یکی از ۹ حالت منطقی را داشته باشد.

### تشبیه ساده

`std_logic_vector` را مانند **یک کابل چندرشته‌ای** تصور کنید:
- هر رشته یک سیم مجزا است (یک `std_logic`)
- همه رشته‌ها با هم یک باس (Bus) را تشکیل می‌دهند
- می‌توانید به تک‌رشته‌ها دسترسی داشته باشید یا کل باس را یکجا مدیریت کنید

---

## ۲. تعریف std_logic_vector — ساختار و نحو

### فرمت کلی

```vhdl
signal <name> : std_logic_vector(<range>);
```

### محدوده‌ها (Ranges)

**۱. نزولی (downto) — مرسوم‌ترین:**
```vhdl
signal data : std_logic_vector(7 downto 0);
-- MSB = bit 7, LSB = bit 0
```

**۲. صعودی (to):**
```vhdl
signal data : std_logic_vector(0 to 7);
-- MSB = bit 0, LSB = bit 7
```

### مثال‌ها

```vhdl
signal byte : std_logic_vector(7 downto 0);      -- ۸ بیت
signal word : std_logic_vector(15 downto 0);     -- ۱۶ بیت
signal dword : std_logic_vector(31 downto 0);    -- ۳۲ بیت
signal addr : std_logic_vector(11 downto 0);     -- ۱۲ بیت
signal nibble : std_logic_vector(3 downto 0);    -- ۴ بیت
signal bus_8 : std_logic_vector(7 downto 0) := (others => '0');
```

## ۳. انتخاب Range — `downto` در مقابل `to`

### `downto` (نزولی) — توصیه شده

```vhdl
signal data : std_logic_vector(7 downto 0);
```

| اندیس | ۷ | ۶ | ۵ | ۴ | ۳ | ۲ | ۱ | ۰ |
|-------|---|---|---|---|---|---|---|---|
| **اهمیت** | MSB | | | | | | | LSB |

**مزایا:**
- MSB در سمت چپ (طبیعی‌تر)
- سازگار با عملیات ریاضی
- استاندارد در اکثر طراحی‌ها

---

### `to` (صعودی)

```vhdl
signal data : std_logic_vector(0 to 7);
```

| اندیس | ۰ | ۱ | ۲ | ۳ | ۴ | ۵ | ۶ | ۷ |
|-------|---|---|---|---|---|---|---|---|
| **اهمیت** | MSB | | | | | | | LSB |

**کاربردها:**
- برخی پروتکل‌های خاص
- باس‌هایی که بیت‌ها به ترتیب خاصی ارسال می‌شوند

**توصیه:** در بیشتر موارد از `downto` استفاده کنید.

## ۴. مقداردهی به std_logic_vector

### ۴.۱. مقداردهی با رشته باینری

```vhdl
signal data : std_logic_vector(7 downto 0) := "10101010";
signal addr : std_logic_vector(3 downto 0) := "1100";
```

### ۴.۲. مقداردهی با هگزادسیمال

```vhdl
signal data : std_logic_vector(7 downto 0) := x"AA";
signal word : std_logic_vector(15 downto 0) := x"F0F0";
```

### ۴.۳. مقداردهی با `others`

```vhdl
signal data : std_logic_vector(7 downto 0) := (others => '0');   -- همه صفر
signal data : std_logic_vector(7 downto 0) := (others => '1');   -- همه یک
```

### ۴.۴. مقداردهی ترکیبی

```vhdl
signal data : std_logic_vector(7 downto 0) := (7 => '1', others => '0');
-- 10000000

signal data : std_logic_vector(7 downto 0) := (3 => '1', 5 => '1', others => '0');
-- 00101000
```

### ۴.۵. مقداردهی با اعداد صحیح (با تبدیل)

```vhdl
library ieee;
use ieee.numeric_std.all;

signal data : std_logic_vector(7 downto 0);
data <= std_logic_vector(to_unsigned(255, 8));  -- "11111111"
```

## ۵. عملیات روی std_logic_vector

### ۵.۱. دسترسی به عناصر (Indexing)

```vhdl
signal data : std_logic_vector(7 downto 0) := "10101010";

-- دسترسی به بیت‌ها
bit7 <= data(7);  -- '1' (MSB)
bit0 <= data(0);  -- '0' (LSB)
bit3 <= data(3);  -- '0'
```

### ۵.۲. برش (Slicing)

```vhdl
signal data : std_logic_vector(7 downto 0) := "10101010";

-- گرفتن بخش‌هایی از Vector
high_nibble <= data(7 downto 4);  -- "1010"
low_nibble <= data(3 downto 0);   -- "1010"
middle_bits <= data(5 downto 2);  -- "1010"

-- هر دو نوع برش مجاز است
data(7 downto 4) <= "0000";  -- تغییر بخش بالایی
```

### ۵.۳. اتصال (Concatenation) — `&`

```vhdl
signal a : std_logic_vector(3 downto 0) := "1010";
signal b : std_logic_vector(3 downto 0) := "0101";
signal c : std_logic_vector(7 downto 0);

c <= a & b;  -- "10100101"
```

**مثال‌های بیشتر:**
```vhdl
-- اتصال با بیت‌های منفرد
full <= a(3 downto 2) & '1' & b(1 downto 0);
-- a(3), a(2), '1', b(1), b(0)

-- اتصال چندین بخش
combined <= a & b & c;  -- a, b, c پشت سر هم
```

### ۵.۴. مقایسه (Comparison)

```vhdl
if data = "11111111" then
    -- همه بیت‌ها یک هستند
end if;

if data /= "00000000" then
    -- حداقل یک بیت یک است
end if;

if data(7 downto 4) = "1010" then
    -- نیبل بالایی برابر "1010" است
end if;
```

### ۵.۵. تغییر بیت‌ها

```vhdl
signal data : std_logic_vector(7 downto 0) := "10101010";

-- تغییر یک بیت
data(3) <= '1';

-- تغییر چند بیت
data(7 downto 4) <= "1111";
data(3 downto 0) <= "0000";

-- تغییر با استفاده از others
data <= (3 => '1', 5 => '0', others => '1');
```

## ۶. std_logic_vector در مقابل انواع عددی

### مقایسه با `unsigned` و `signed`

| عملیات | `std_logic_vector` | `unsigned`/`signed` |
|---------|-------------------|---------------------|
| **منطقی (AND, OR, NOT)** | ✅ | ✅ |
| **ریاضی (+، -، *) **| ❌ | ✅ |
| **مقایسه عددی (>، <)** | ❌ | ✅ |
| **شیفت** | ✅ (با `&`) | ✅ |
| **تفسیر عددی** | ندارد | دارد |

### مثال: تفاوت

```vhdl
-- با std_logic_vector
signal a, b : std_logic_vector(7 downto 0);
signal sum : std_logic_vector(7 downto 0);

sum <= a + b;  -- ❌ خطا

-- با unsigned
signal a, b : unsigned(7 downto 0);
signal sum : unsigned(7 downto 0);

sum <= a + b;  -- ✅ مجاز
```

### تبدیل

```vhdl
library ieee;
use ieee.numeric_std.all;

signal slv : std_logic_vector(7 downto 0);
signal uns : unsigned(7 downto 0);
signal sig : signed(7 downto 0);

-- std_logic_vector → unsigned/signed
uns <= unsigned(slv);
sig <= signed(slv);

-- unsigned/signed → std_logic_vector
slv <= std_logic_vector(uns);
slv <= std_logic_vector(sig);

-- integer → std_logic_vector
slv <= std_logic_vector(to_unsigned(255, 8));
```

## ۸. std_logic_vector در Architecture

### ۸.۱. Signalهای داخلی

```vhdl
architecture rtl of my_circuit is
    signal temp : std_logic_vector(7 downto 0);
    signal reg_file : std_logic_vector(31 downto 0) := (others => '0');
begin
    temp <= data_in;
    data_out <= temp;
end architecture;
```

### ۸.۲. در Process

```vhdl
process(clk, reset)
    variable temp : std_logic_vector(7 downto 0);
begin
    if reset = '1' then
        q <= (others => '0');
    elsif rising_edge(clk) then
        temp := d;
        temp(7) := '0';  -- پاک کردن MSB
        q <= temp;
    end if;
end process;
```

### ۸.۳. استفاده در Case

```vhdl
process(data_in)
begin
    case data_in is
        when "00000000" => y <= "0001";
        when "00000001" => y <= "0010";
        when "00000010" => y <= "0100";
        when "00000011" => y <= "1000";
        when others => y <= "0000";
    end case;
end process;
```

## ۹. std_logic_vector — مثال‌های عملی

### ۹.۱. Register 8-bit

```vhdl
entity register_8bit is
    port (
        clk   : in  std_logic;
        reset : in  std_logic;
        en    : in  std_logic;
        d     : in  std_logic_vector(7 downto 0);
        q     : out std_logic_vector(7 downto 0)
    );
end entity;

architecture rtl of register_8bit is
begin
    process(clk, reset)
    begin
        if reset = '1' then
            q <= (others => '0');
        elsif rising_edge(clk) then
            if en = '1' then
                q <= d;
            end if;
        end if;
    end process;
end architecture;
```

### ۹.۲. Shift Register

```vhdl
architecture rtl of shift_register is
    signal reg : std_logic_vector(7 downto 0);
begin
    process(clk, reset)
    begin
        if reset = '1' then
            reg <= (others => '0');
        elsif rising_edge(clk) then
            reg <= reg(6 downto 0) & si;  -- شیفت چپ
        end if;
    end process;
    q <= reg;
end architecture;
```

### ۹.۳. Multiplexer

```vhdl
architecture rtl of mux is
begin
    y <= a when sel = '0' else b;
end architecture;
```

### ۹.۴. Decoder

```vhdl
architecture rtl of decoder is
begin
    with a select
        y <= "0001" when "00",
             "0010" when "01",
             "0100" when "10",
             "1000" when "11",
             "0000" when others;
end architecture;
```

## ۱۰. std_logic_vector و Tri-State

### باس داده با Tri-State

```vhdl
architecture rtl of tri_state_bus is
    signal internal_data : std_logic_vector(7 downto 0);
begin
    -- نوشتن به باس
    data_bus <= internal_data when write_en = '1' else (others => 'Z');
    
    -- خواندن از باس
    process(clk)
    begin
        if rising_edge(clk) then
            if read_en = '1' then
                internal_data <= data_bus;
            end if;
        end if;
    end process;
end architecture;
```

## ۱۱. اشتباهات رایج در std_logic_vector

### اشتباه ۱: فراموش کردن کتابخانه

**نادرست:**
```vhdl
entity example is
    port (
        data : in std_logic_vector(7 downto 0)  -- ❌ std_logic_vector تعریف نشده
    );
end entity;
```

**درست:**
```vhdl
library ieee;
use ieee.std_logic_1164.all;

entity example is
    port (
        data : in std_logic_vector(7 downto 0)  -- ✅
    );
end entity;
```

### اشتباه ۲: عملیات ریاضی روی std_logic_vector

**نادرست:**
```vhdl
signal a, b : std_logic_vector(7 downto 0);
signal sum : std_logic_vector(7 downto 0);

sum <= a + b;  -- ❌ خطا
```

**درست:**
```vhdl
signal a, b : unsigned(7 downto 0);
signal sum : unsigned(7 downto 0);

sum <= a + b;  -- ✅
```

### اشتباه ۳: عدم تطابق اندازه در اتصال

**نادرست:**
```vhdl
signal a : std_logic_vector(7 downto 0);
signal b : std_logic_vector(3 downto 0);

a <= b;  -- ❌ اندازه‌ها برابر نیستند
```

**درست:**
```vhdl
a(3 downto 0) <= b;
a(7 downto 4) <= (others => '0');
```

### اشتباه ۴: فراموش کردن `&` در اتصال

**نادرست:**
```vhdl
c <= a b;  -- ❌ خطای نحوی
```

**درست:**
```vhdl
c <= a & b;  -- ✅
```

### اشتباه ۵: استفاده از `'Z'` در std_logic_vector بدون others

**نادرست:**
```vhdl
data_bus <= internal_data when enable = '1';  -- ❌ وقتی enable=0، مقدار نامشخص
```

**درست:**
```vhdl
data_bus <= internal_data when enable = '1' else (others => 'Z');  -- ✅
```

## ۱۲. تمرین‌های عملی

### تمرین ۱: تعریف و مقداردهی

یک Signal 8 بیتی با مقدار `"10101010"` تعریف کنید.

**پاسخ:**
```vhdl
signal data : std_logic_vector(7 downto 0) := "10101010";
```

### تمرین ۲: برش (Slicing)

از Signal `data : std_logic_vector(15 downto 0)` نیبل‌های ۴ بیتی استخراج کنید.

**پاسخ:**
```vhdl
nibble3 <= data(15 downto 12);
nibble2 <= data(11 downto 8);
nibble1 <= data(7 downto 4);
nibble0 <= data(3 downto 0);
```

### تمرین ۳: اتصال (Concatenation)

دو Signal 4 بیتی را به یک Signal 8 بیتی متصل کنید.

**پاسخ:**
```vhdl
signal a, b : std_logic_vector(3 downto 0);
signal c : std_logic_vector(7 downto 0);

c <= a & b;
```

### تمرین ۴: Register با Generic

یک Register با عرض قابل تنظیم بنویسید.

**پاسخ:**
```vhdl
entity register_generic is
    generic (WIDTH : positive := 8);
    port (
        clk : in std_logic;
        d : in std_logic_vector(WIDTH-1 downto 0);
        q : out std_logic_vector(WIDTH-1 downto 0)
    );
end entity;

architecture rtl of register_generic is
begin
    process(clk)
    begin
        if rising_edge(clk) then
            q <= d;
        end if;
    end process;
end architecture;
```

## ۱۳. خلاصه و جمع‌بندی

### نکات کلیدی

| مفهوم | توضیح |
|-------|-------|
| **تعریف** | `std_logic_vector(7 downto 0)` |
| **کتابخانه** | `ieee.std_logic_1164.all` |
| **مقداردهی** | `"1010"`, `x"AA"`, `(others => '0')` |
| **دسترسی** | `data(3)` |
| **برش** | `data(7 downto 4)` |
| **اتصال** | `a & b` |
| **مقایسه** | `if a = b then` |
| **محدوده** | معمولاً `downto` (نزولی) |

### جدول عملیات

| عملیات | نحو | مثال |
|--------|-----|-------|
| **تعریف** | `std_logic_vector(7 downto 0)` | `signal data : std_logic_vector(7 downto 0);` |
| **مقداردهی** | `<= "1010"` | `data <= "10101010";` |
| **هگز** | `<= x"AA"` | `data <= x"AA";` |
| **others** | `(others => '0')` | `data <= (others => '0');` |
| **دسترسی** | `data(index)` | `bit <= data(3);` |
| **برش** | `data(range)` | `nibble <= data(7 downto 4);` |
| **اتصال** | `&` | `full <= high & low;` |
| **مقایسه** | `=` `/=`, `>`, `<` | `if data = "1111" then` |

### کتابخانه‌های مورد نیاز

```vhdl
-- برای std_logic و std_logic_vector
library ieee;
use ieee.std_logic_1164.all;

-- برای تبدیل به unsigned/signed
use ieee.numeric_std.all;
```

### پیام نهایی

`std_logic_vector` **ابزار اصلی** برای کار با باس‌های داده، ثبات‌ها، آدرس‌ها و هر مجموعه‌ای از بیت‌ها در VHDL است. با تسلط بر این نوع داده، شما می‌توانید:
- **باس‌های داده** با هر عرضی طراحی کنید
- **ثبات‌ها** و **حافظه** را مدل‌سازی کنید
- **پروتکل‌های ارتباطی** را پیاده‌سازی کنید
- **پردازنده‌های ساده** طراحی کنید

> **به یاد داشته باشید:** `std_logic_vector` یک آرایه از `std_logic` است. برای عملیات ریاضی، از `unsigned` یا `signed` استفاده کنید و در صورت نیاز تبدیل کنید.
