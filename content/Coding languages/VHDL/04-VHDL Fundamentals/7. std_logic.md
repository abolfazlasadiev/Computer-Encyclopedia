# std_logic در VHDL — تحلیل جامع و عمیق

## مقدمه: منطق ۹ حالته، قلب طراحی دیجیتال مدرن

در دنیای واقعی، سیگنال‌های دیجیتال فقط دو حالت ساده ۰ و ۱ ندارند. یک سیم در مدار ممکن است:

- **قطع** باشد (نه ۰ و نه ۱)
- **اتصال کوتاه** داشته باشد (هر دو راننده فعال)
- **مقداردهی نشده** باشد (در شبیه‌سازی)
- **نوسان** داشته باشد (نویز)

در VHDL، نوع داده `std_logic` این ۹ حالت مختلف را پوشش می‌دهد و ابزاری قدرتمند برای **شبیه‌سازی** و **طراحی** مدارهای دیجیتال فراهم می‌کند.

---

## ۱. std_logic چیست؟ تعریف جامع

**std_logic** یک **نوع داده استاندارد** در کتابخانه `std_logic_1164` است که برای نمایش **سیگنال‌های منطقی** در طراحی‌های دیجیتال استفاده می‌شود. این نوع داده ۹ حالت مختلف دارد که امکان مدل‌سازی دقیق‌تر رفتار سخت‌افزار را فراهم می‌کند.

### تشبیه ساده

`std_logic` را مانند **یک چراغ راهنمایی پیشرفته** تصور کنید:
- چراغ قرمز = `'0'` (خاموش)
- چراغ سبز = `'1'` (روشن)
- چراغ چشمک‌زن = `'X'` (ناشناخته)
- چراغ خراب = `'Z'` (قطع)
- چراغ کم‌نور = `'L'` یا `'H'` (ضعیف)
- چراغ خاموش قبل از نصب = `'U'` (مقداردهی نشده)

---

## ۲. ۹ حالت std_logic — تحلیل کامل

| مقدار | نام | توضیح | کاربرد |
|-------|-----|-------|--------|
| `'U'` | Uninitialized | مقداردهی نشده | تشخیص سیگنال‌های مقداردهی‌نشده در شبیه‌سازی |
| `'X'` | Unknown | ناشناخته | زمانی که چندین Driver با مقادیر مختلف وجود دارد |
| `'0'` | Logic 0 | صفر منطقی | حالت LOW |
| `'1'` | Logic 1 | یک منطقی | حالت HIGH |
| `'Z'` | High Impedance | امپدانس بالا | قطع بودن (Tri-State) |
| `'W'` | Weak Unknown | ناشناخته ضعیف | ناشناخته با مقاومت بالا |
| `'L'` | Weak 0 | صفر ضعیف | صفر با مقاومت بالا |
| `'H'` | Weak 1 | یک ضعیف | یک با مقاومت بالا |
| `'-'` | Don't Care | بی‌اهمیت | در شبیه‌سازی، هر مقدار مجاز است |

---

## ۳. `'U'` — Uninitialized (مقداردهی نشده)

### توضیح

`'U'` یعنی Signal **مقداردهی اولیه** نشده است. این معمولاً در شبیه‌سازی رخ می‌دهد و نشان‌دهنده خطا در طراحی است.

### مثال

```vhdl
signal clk : std_logic;  -- ❌ مقداردهی نشده → 'U'
signal reset : std_logic := '0';  -- ✅ مقداردهی شده
```

### در شبیه‌سازی

```
simulation time 0 ns:
clk = 'U'
reset = '0'
```

### چرا `'U'` خطرناک است؟

اگر از یک Signal با مقدار `'U'` در محاسبات استفاده کنید، همه نتایج `'X'` می‌شوند:

```vhdl
y <= a and b;  -- اگر a = 'U' باشد، y = 'X'
```

### راه‌حل

همیشه Signalها را مقداردهی کنید:

```vhdl
signal clk : std_logic := '0';
signal data : std_logic_vector(7 downto 0) := (others => '0');
```

---

## ۴. `'X'` — Unknown (ناشناخته)

### توضیح

`'X'` یعنی مقدار Signal **ناشناخته** است. این معمولاً زمانی رخ می‌دهد که:
- چندین Driver به یک Signal متصل هستند و مقادیر متفاوتی تولید می‌کنند
- یک Signal از یک مقدار `'U'` محاسبه می‌شود
- یک مقدار `'Z'` با مقدار دیگر ترکیب می‌شود

### مثال: Multiple Drivers

```vhdl
architecture rtl of example is
    signal y : std_logic;
begin
    y <= a and b;  -- Driver 1
    y <= c or d;   -- Driver 2 → y = 'X' (هر دو فعال)
end architecture;
```

### در شبیه‌سازی

```
اگر a=1, b=1 → y=1 از Driver 1
اگر c=0, d=0 → y=0 از Driver 2
نتیجه: y = 'X' (تعارض)
```

### راه‌حل

از **Tri-State** استفاده کنید:

```vhdl
y <= (a and b) when enable1 = '1' else 'Z';
y <= (c or d) when enable2 = '1' else 'Z';
```

---

## ۵. `'0'` و `'1'` — منطق استاندارد

### توضیح

`'0'` و `'1'` **مهم‌ترین** و **پرکاربردترین** مقادیر `std_logic` هستند. این دو مقدار نشان‌دهنده **وضعیت واقعی** سیگنال‌های دیجیتال هستند.

### مثال‌ها

```vhdl
signal clk : std_logic := '0';
signal led : std_logic;

-- کلید
if button = '1' then
    led <= '1';
else
    led <= '0';
end if;
```

### در سخت‌افزار

- `'0'` → ولتاژ LOW (معمولاً ۰ ولت)
- `'1'` → ولتاژ HIGH (معمولاً ولتاژ تغذیه)

---

## ۶. `'Z'` — High Impedance (امپدانس بالا)

### توضیح

`'Z'` یعنی Signal **قطع** است و هیچ راننده‌ای آن را کنترل نمی‌کند. این معادل **Tri-State** یا **باز بودن** یک مدار است.

### کاربردها

- **باس‌های داده مشترک** (Shared Buses)
- **خروجی‌های با قابلیت Tri-State**
- **بافرهای سه‌حالته**

### مثال: باس داده مشترک

```vhdl
-- دستگاه ۱
data_bus <= internal_data_1 when enable_1 = '1' else (others => 'Z');

-- دستگاه ۲
data_bus <= internal_data_2 when enable_2 = '1' else (others => 'Z');
```

### در شبیه‌سازی

```
زمان ۰: enable_1 = '1', enable_2 = '0' → data_bus = internal_data_1
زمان ۱: enable_1 = '0', enable_2 = '1' → data_bus = internal_data_2
زمان ۲: enable_1 = '0', enable_2 = '0' → data_bus = "ZZZZZZZZ"
```

---

## ۷. `'W'`، `'L'` و `'H'` — مقادیر ضعیف

### توضیح

این مقادیر برای مدل‌سازی سیگنال‌هایی با **مقاومت بالا** یا **راننده ضعیف** استفاده می‌شوند.

| مقدار | توضیح |
|-------|-------|
| `'W'` | Weak Unknown (ناشناخته ضعیف) |
| `'L'` | Weak 0 (صفر ضعیف) |
| `'H'` | Weak 1 (یک ضعیف) |

### کاربردها

- مدل‌سازی Pull-up / Pull-down resistors
- شبیه‌سازی مدارهای با مقاومت بالا
- تحلیل مدارهای آنالوگ-دیجیتال

### مثال

```vhdl
-- Pull-up resistor مدل‌سازی شده با 'H'
signal line : std_logic := 'H';
```

---

## ۸. `'-'` — Don't Care

### توضیح

`'-'` یعنی مقدار Signal برای طراحی **بی‌اهمیت** است. این مقدار در **Case statements** و **جدول درستی** استفاده می‌شود.

### مثال: Case با Don't Care

```vhdl
case state is
    when "00" => y <= '1';
    when "01" => y <= '0';
    when "10" => y <= '1';
    when "11" => y <= '0';
    when others => y <= '-';  -- برای حالت‌های دیگر
end case;
```

### در شبیه‌سازی

Don't Care در شبیه‌سازی معمولاً به عنوان **هر مقداری** تفسیر می‌شود.

## ۹. جداول Resolution — تصمیم‌گیری بین Driverها

وقتی چندین Driver به یک Signal متصل هستند، VHDL از یک **جدول Resolution** برای تعیین مقدار نهایی استفاده می‌کند.

### جدول Resolution برای std_logic

| | 'U' | 'X' | '0' | '1' | 'Z' | 'W' | 'L' | 'H' | '-' |
|---|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|:---:|
| **'U'** | U | U | U | U | U | U | U | U | U |
| **'X'** | U | X | X | X | X | X | X | X | X |
| **'0'** | U | X | 0 | X | 0 | 0 | 0 | X | X |
| **'1'** | U | X | X | 1 | 1 | 1 | X | 1 | X |
| **'Z'** | U | X | 0 | 1 | Z | W | L | H | X |
| **'W'** | U | X | 0 | 1 | W | W | W | W | X |
| **'L'** | U | X | 0 | X | L | W | L | W | X |
| **'H'** | U | X | X | 1 | H | W | W | H | X |
| **'-'** | U | X | X | X | X | X | X | X | X |

### تفسیر جدول

- اگر دو Driver `'0'` و `'1'` باشند → نتیجه `'X'` (تعارض)
- اگر دو Driver `'0'` و `'Z'` باشند → نتیجه `'0'`
- اگر دو Driver `'1'` و `'Z'` باشند → نتیجه `'1'`
- اگر دو Driver `'Z'` و `'Z'` باشند → نتیجه `'Z'`

## ۱۰. std_logic در مقابل bit

### مقایسه

| ویژگی | `std_logic` | `bit` |
|-------|-------------|-------|
| **تعداد حالت‌ها** | ۹ | ۲ (`'0'`, `'1'`) |
| **شبیه‌سازی** | دقیق‌تر | ساده‌تر |
| **Multiple Drivers** | پشتیبانی (با Resolution) | پشتیبانی نمی‌کند |
| **Tri-State** | پشتیبانی (`'Z'`) | پشتیبانی نمی‌کند |
| **کاربرد** | طراحی حرفه‌ای | آموزش و مدل‌سازی ساده |

### چرا std_logic برتر است؟

```vhdl
-- با std_logic
signal bus : std_logic_vector(7 downto 0);
bus <= data1 when en1 = '1' else (others => 'Z');
bus <= data2 when en2 = '1' else (others => 'Z');
-- ✅ شبیه‌سازی دقیق

-- با bit (امکان‌پذیر نیست)
signal bus : bit_vector(7 downto 0);
bus <= data1 when en1 = '1';  -- ❌ نمی‌توان 'Z' داشت
bus <= data2 when en2 = '1';  -- ❌ Multiple Drivers
```

## ۱۱. std_logic در VHDL — مثال‌های عملی

### ۱۱.۱. ورودی‌ها و خروجی‌ها

```vhdl
entity my_circuit is
    port (
        clk   : in  std_logic;
        reset : in  std_logic;
        data  : in  std_logic_vector(7 downto 0);
        led   : out std_logic;
        bus   : inout std_logic_vector(7 downto 0)
    );
end entity;
```

### ۱۱.۲. منطق ترکیبی

```vhdl
architecture rtl of my_circuit is
    signal temp : std_logic;
begin
    temp <= a and b;
    y <= temp or c;
end architecture;
```

### ۱۱.۳. منطق ترتیبی

```vhdl
process(clk, reset)
begin
    if reset = '1' then
        q <= '0';
    elsif rising_edge(clk) then
        q <= d;
    end if;
end process;
```

### ۱۱.۴. Tri-State

```vhdl
architecture rtl of tri_state is
begin
    data_out <= internal_data when enable = '1' else (others => 'Z');
end architecture;
```

## ۱۲. std_logic_vector — آرایه‌ای از std_logic

### تعریف

```vhdl
signal data : std_logic_vector(7 downto 0);
signal address : std_logic_vector(15 downto 0);
signal control : std_logic_vector(3 downto 0);
```

### عملیات روی std_logic_vector

**۱. انتساب:**
```vhdl
data <= "10101010";
data <= x"AA";  -- هگزادسیمال
```

**۲. برش (Slicing):**
```vhdl
high_byte <= data(7 downto 4);
low_byte <= data(3 downto 0);
```

**۳. اتصال (Concatenation):**
```vhdl
full <= high_byte & low_byte;
```

**۴. مقایسه:**
```vhdl
if data = "11111111" then
    -- ...
end if;
```

**۵. تغییر بیت‌ها:**
```vhdl
data(3 downto 0) <= "0000";
data(7) <= '1';
```

### کتابخانه‌های مورد نیاز

```vhdl
library ieee;
use ieee.std_logic_1164.all;  -- برای std_logic و std_logic_vector
```

## ۱۳. اشتباهات رایج در std_logic

### اشتباه ۱: فراموش کردن کتابخانه

**نادرست:**
```vhdl
entity example is
    port (
        clk : in std_logic  -- ❌ std_logic تعریف نشده
    );
end entity;
```

**درست:**
```vhdl
library ieee;
use ieee.std_logic_1164.all;

entity example is
    port (
        clk : in std_logic  -- ✅
    );
end entity;
```

### اشتباه ۲: استفاده از `std_logic` برای محاسبات ریاضی

**نادرست:**
```vhdl
signal a, b : std_logic;
signal sum : std_logic;

sum <= a + b;  -- ❌ خطا
```

**درست:**
```vhdl
signal a, b : unsigned(7 downto 0);
signal sum : unsigned(7 downto 0);

sum <= a + b;  -- ✅
```

### اشتباه ۳: Multiple Drivers بدون Tri-State

**نادرست:**
```vhdl
y <= a and b;  -- Driver 1
y <= c or d;   -- Driver 2 → y = 'X'
```

**درست:**
```vhdl
y <= (a and b) when en1 = '1' else 'Z';
y <= (c or d) when en2 = '1' else 'Z';
```

### اشتباه ۴: فراموش کردن `(others => 'Z')`

**نادرست:**
```vhdl
data_bus <= internal_data when enable = '1';  -- ❌ وقتی enable=0، مقدار نامشخص
```

**درست:**
```vhdl
data_bus <= internal_data when enable = '1' else (others => 'Z');  -- ✅
```

## ۱۴. تمرین‌های عملی

### تمرین ۱: تعریف Signal

یک Signal از نوع `std_logic` با مقدار اولیه `'0'` تعریف کنید.

**پاسخ:**
```vhdl
signal flag : std_logic := '0';
```

### تمرین ۲: Tri-State Buffer

یک Tri-State Buffer با ورودی `data_in`، خروجی `data_out` و Enable `en` طراحی کنید.

**پاسخ:**
```vhdl
data_out <= data_in when en = '1' else 'Z';
```

### تمرین ۳: تشخیص Multiple Drivers

کد زیر را تحلیل کنید و مشکل آن را پیدا کنید:

```vhdl
signal y : std_logic;
y <= a and b;
y <= c or d;
```

**پاسخ:** دو Driver برای y وجود دارد که باعث `'X'` می‌شود. باید از Tri-State استفاده شود یا منطق ترکیب شود.

## ۱۵. خلاصه و جمع‌بندی

### ۹ حالت std_logic

| مقدار | نام | توضیح |
|-------|-----|-------|
| `'U'` | Uninitialized | مقداردهی نشده |
| `'X'` | Unknown | ناشناخته |
| `'0'` | Logic 0 | صفر منطقی |
| `'1'` | Logic 1 | یک منطقی |
| `'Z'` | High Impedance | امپدانس بالا |
| `'W'` | Weak Unknown | ناشناخته ضعیف |
| `'L'` | Weak 0 | صفر ضعیف |
| `'H'` | Weak 1 | یک ضعیف |
| `'-'` | Don't Care | بی‌اهمیت |

### کتابخانه مورد نیاز

```vhdl
library ieee;
use ieee.std_logic_1164.all;
```

### نکات کلیدی

| نکته | توضیح |
|------|-------|
| **مهم‌ترین مقادیر** | `'0'`, `'1'`, `'Z'` |
| **Multiple Drivers** | با `'Z'` مدیریت کنید |
| **مقداردهی** | همیشه مقداردهی کنید تا `'U'` نداشته باشید |
| **Vector** | از `std_logic_vector` برای باس‌ها استفاده کنید |

### پیام نهایی

`std_logic` **قلب** طراحی دیجیتال مدرن در VHDL است. این نوع داده با ۹ حالت خود، امکان مدل‌سازی دقیق‌تر و شبیه‌سازی واقعی‌تر مدارهای دیجیتال را فراهم می‌کند.

> **به یاد داشته باشید:** `std_logic` فقط یک نوع داده نیست — زبانی است که سخت‌افزار با آن صحبت می‌کند.
