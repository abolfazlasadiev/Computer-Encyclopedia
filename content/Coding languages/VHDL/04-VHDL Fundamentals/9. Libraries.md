# Libraries در VHDL — تحلیل جامع و عمیق

## مقدمه: کتابخانه‌ها، انبار دانش طراحی

تصور کنید می‌خواهید یک خانه بسازید. آیا همه مصالح را خودتان از صفر می‌سازید؟ خیر — شما از مصالح آماده‌ای استفاده می‌کنید که دیگران ساخته‌اند: آجر، سیمان، تیرآهن، و غیره.

در VHDL نیز همین اصل برقرار است. شما نیازی ندارید که همه چیز را از صفر تعریف کنید. **کتابخانه‌ها (Libraries)** مجموعه‌ای از **تعاریف آماده** هستند که می‌توانید در طراحی خود از آنها استفاده کنید: انواع داده، توابع، عملگرها، و Componentهای آماده.

---

## ۱. Library چیست؟ تعریف جامع

**Library** در VHDL یک **مجموعه سازمان‌یافته** از **Packageها**، **Entityها**، **Architectureها** و **Componentها** است که می‌توان در طراحی‌های مختلف از آنها استفاده کرد.

### تشبیه ساده

کتابخانه VHDL را مانند **یک کتابخانه عمومی** تصور کنید:
- کتاب‌های مختلفی دارد (Packageها)
- هر کتاب شامل فصل‌های مختلفی است (توابع، انواع، Componentها)
- شما می‌توانید از هر کتابی که نیاز دارید استفاده کنید
- برخی کتاب‌ها استاندارد هستند (همه جا موجودند)
- برخی کتاب‌ها تخصصی هستند (فقط در پروژه‌های خاص)

## ۳. کتابخانه‌های استاندارد VHDL

### ۳.۱. Library `std`

**کتابخانه پایه VHDL** که به‌صورت خودکار در دسترس است.

| Package | توضیح | کاربرد |
|---------|-------|--------|
| `standard` | انواع پایه VHDL | `integer`, `boolean`, `bit`, `character` |
| `textio` | ورودی/خروجی متنی | Testbench, File I/O |

**استفاده:**
```vhdl
-- نیازی به استفاده صریح نیست (به‌صورت خودکار موجود است)
-- اما می‌توانید:
library std;
use std.standard.all;
```

---

### ۳.۲. Library `ieee`

**مهم‌ترین کتابخانه** برای طراحی دیجیتال مدرن.

| Package | توضیح | کاربرد |
|---------|-------|--------|
| `std_logic_1164` | انواع چندحالته | `std_logic`, `std_logic_vector` |
| `numeric_std` | عملیات ریاضی | `unsigned`, `signed` |
| `numeric_bit` | عملیات ریاضی با `bit` | `unsigned`, `signed` (با `bit`) |
| `std_logic_arith` | (قدیمی) عملیات ریاضی | استفاده نشود (قدیمی) |
| `std_logic_unsigned` | (قدیمی) اعداد بدون علامت | استفاده نشود (قدیمی) |
| `std_logic_signed` | (قدیمی) اعداد با علامت | استفاده نشود (قدیمی) |

**استفاده:**
```vhdl
library ieee;
use ieee.std_logic_1164.all;
use ieee.numeric_std.all;
```

---

### ۳.۳. Library `work`

**کتابخانه کاری** که تمام Entityها، Architectureها و Packageهای طراحی شما در آن ذخیره می‌شوند.

**استفاده:**
```vhdl
-- خودکار در دسترس است
use work.my_package.all;  -- برای استفاده از Packageهای خود
```

## ۴. Package — محتویات کتابخانه

### ۴.۱. ساختار Package

```vhdl
-- Package Declaration
package <name> is
    -- اعلان انواع
    -- اعلان ثابت‌ها
    -- اعلان توابع (بدنه)
    -- اعلان Componentها
end package <name>;

-- Package Body (اختیاری)
package body <name> is
    -- پیاده‌سازی توابع
    -- پیاده‌سازی رویه‌ها
end package body <name>;
```

### ۴.۲. Package سفارشی

```vhdl
-- ===== my_pkg.vhd =====
library ieee;
use ieee.std_logic_1164.all;

package my_pkg is
    -- انواع سفارشی
    type state_type is (IDLE, RUN, DONE);
    type reg_array is array (0 to 7) of std_logic_vector(7 downto 0);
    
    -- ثابت‌ها
    constant DATA_WIDTH : integer := 8;
    constant MAX_COUNT : integer := 255;
    
    -- Componentها
    component and_gate
        port (a, b : in std_logic; y : out std_logic);
    end component;
    
    -- تابع
    function max(a, b : integer) return integer;
end package my_pkg;

package body my_pkg is
    function max(a, b : integer) return integer is
    begin
        if a > b then
            return a;
        else
            return b;
        end if;
    end function max;
end package body my_pkg;
```

## ۵. کتابخانه `ieee.std_logic_1164` — تحلیل عمیق

### محتویات

```vhdl
library ieee;
use ieee.std_logic_1164.all;
```

**انواع:**
- `std_logic`
- `std_logic_vector`
- `std_ulogic`
- `std_ulogic_vector`

**توابع:**
- `rising_edge(signal)`
- `falling_edge(signal)`
- `to_stdlogicvector(bit_vector)`
- `to_bitvector(std_logic_vector)`

**عملگرها:**
- `and`, `or`, `nand`, `nor`, `xor`, `xnor`
- `not`
- `sll`, `srl`, `sla`, `sra`, `rol`, `ror` (شیفت)

### مثال

```vhdl
library ieee;
use ieee.std_logic_1164.all;

entity example is
    port (clk : in std_logic);
end entity;

architecture rtl of example is
    signal data : std_logic_vector(7 downto 0);
begin
    process(clk)
    begin
        if rising_edge(clk) then  -- از std_logic_1164
            data <= data(6 downto 0) & '0';
        end if;
    end process;
end architecture;
```

## ۶. کتابخانه `ieee.numeric_std` — تحلیل عمیق

### محتویات

```vhdl
library ieee;
use ieee.numeric_std.all;
```

**انواع:**
- `unsigned` (عدد بدون علامت)
- `signed` (عدد با علامت - دو مکمل)

**توابع اصلی:**
- `to_unsigned(int, size)` → `unsigned`
- `to_signed(int, size)` → `signed`
- `to_integer(unsigned)` → `integer`
- `to_integer(signed)` → `integer`
- `to_integer(std_logic_vector)` (غیرمستقیم)

**عملگرها:**
- جمع: `+`
- تفریق: `-`
- ضرب: `*`
- تقسیم: `/`
- مقایسه: `=`, `/=`, `>`, `<`, `>=`, `<=`
- شیفت: `sll`, `srl`, `sla`, `sra`, `rol`, `ror`

**توابع کمکی:**
- `resize(value, size)` — تغییر اندازه
- `shift_left(value, amount)`
- `shift_right(value, amount)`
- `rotate_left(value, amount)`
- `rotate_right(value, amount)`

### مثال

```vhdl
library ieee;
use ieee.numeric_std.all;

entity counter is
    port (clk : in std_logic; q : out unsigned(7 downto 0));
end entity;

architecture rtl of counter is
    signal count : unsigned(7 downto 0) := (others => '0');
begin
    process(clk)
    begin
        if rising_edge(clk) then
            count <= count + 1;  -- عملیات ریاضی با unsigned
        end if;
    end process;
    q <= count;
end architecture;
```


### جایگزین صحیح

```vhdl

use ieee.numeric_std.all;  -- ✅ استاندارد و قابل اعتماد
```

## ۸. استفاده از Library و Use

### دستورات

```vhdl
library <library_name>;     -- معرفی کتابخانه
use <library_name>.<package_name>.all;  -- استفاده از همه محتویات
use <library_name>.<package_name>.<item>;  -- استفاده از یک آیتم خاص
```

### مثال‌ها

```vhdl
-- معرفی کتابخانه‌ها
library ieee;
library work;
library my_lib;

-- استفاده از Packageها
use ieee.std_logic_1164.all;
use ieee.numeric_std.all;
use work.my_pkg.all;
use my_lib.special_pkg.constants;

-- استفاده از آیتم خاص
use ieee.std_logic_1164.rising_edge;
```

## ۹. ایجاد کتابخانه سفارشی

### ساختار کتابخانه

```
project/
├── src/
│   ├── my_pkg.vhd
│   ├── my_lib.vhd
│   └── ...
└── sim/
    └── ...
```

### Package سفارشی کامل

```vhdl
-- ===== my_lib.vhd =====
library ieee;
use ieee.std_logic_1164.all;
use ieee.numeric_std.all;

package my_lib is
    -- ===== Types =====
    type state_type is (IDLE, RUN, DONE, ERROR);
    type reg_array is array (0 to 15) of std_logic_vector(7 downto 0);
    type memory is array (0 to 255) of std_logic_vector(7 downto 0);
    
    -- ===== Constants =====
    constant DATA_WIDTH : integer := 8;
    constant ADDR_WIDTH : integer := 8;
    constant MEMORY_SIZE : integer := 256;
    constant CLK_PERIOD : time := 10 ns;
    
    -- ===== Components =====
    component dff
        port (clk, reset, d : in std_logic; q : out std_logic);
    end component;
    
    component register_8bit
        port (clk, reset, en : in std_logic; 
              d : in std_logic_vector(7 downto 0);
              q : out std_logic_vector(7 downto 0));
    end component;
    
    -- ===== Functions =====
    function log2(n : integer) return integer;
    function max(a, b : integer) return integer;
    function min(a, b : integer) return integer;
    function to_string(slv : std_logic_vector) return string;
    
    -- ===== Procedures =====
    procedure increment(signal count : inout unsigned(7 downto 0));
    
end package my_lib;

package body my_lib is
    -- ===== Functions Implementation =====
    function log2(n : integer) return integer is
        variable result : integer := 0;
        variable temp : integer := n;
    begin
        while temp > 1 loop
            temp := temp / 2;
            result := result + 1;
        end loop;
        return result;
    end function log2;
    
    function max(a, b : integer) return integer is
    begin
        if a > b then
            return a;
        else
            return b;
        end if;
    end function max;
    
    function min(a, b : integer) return integer is
    begin
        if a < b then
            return a;
        else
            return b;
        end if;
    end function min;
    
    function to_string(slv : std_logic_vector) return string is
        variable result : string(1 to slv'length);
        variable index : integer := 1;
    begin
        for i in slv'range loop
            if slv(i) = '1' then
                result(index) := '1';
            elsif slv(i) = '0' then
                result(index) := '0';
            else
                result(index) := 'X';
            end if;
            index := index + 1;
        end loop;
        return result;
    end function to_string;
    
    -- ===== Procedures Implementation =====
    procedure increment(signal count : inout unsigned(7 downto 0)) is
    begin
        count <= count + 1;
    end procedure increment;
    
end package body my_lib;
```

### استفاده از کتابخانه سفارشی

```vhdl
library ieee;
use ieee.std_logic_1164.all;
use ieee.numeric_std.all;
use work.my_lib.all;  -- استفاده از کتابخانه سفارشی

entity top is
    port (clk : in std_logic; data : out std_logic_vector(7 downto 0));
end entity;

architecture rtl of top is
    signal count : unsigned(7 downto 0);
begin
    -- استفاده از تابع max از کتابخانه
    data <= std_logic_vector(to_unsigned(max(10, 20), 8));
    
    -- استفاده از Component
    u1: dff port map (clk => clk, reset => reset, d => data_in, q => data_out);
    
    -- استفاده از Procedure
    process(clk)
    begin
        if rising_edge(clk) then
            increment(count);
        end if;
    end process;
end architecture;
```

### اشتباه ۱: فراموش کردن کتابخانه std_logic_1164

**نادرست:**
```vhdl
entity example is
    port (
        clk : in std_logic  -- ❌ std_logic تعریف نشده
    );
```

**درست:**
```vhdl
library ieee;
use ieee.std_logic_1164.all;

entity example is
    port (
        clk : in std_logic  -- ✅
    );
end entity;
```

### اشتباه ۲: استفاده از کتابخانه‌های قدیمی

**نادرست:**
```vhdl
use ieee.std_logic_arith.all;  -- ❌ قدیمی
use ieee.std_logic_unsigned.all;  -- ❌ قدیمی
```

**درست:**
```vhdl
use ieee.numeric_std.all;  -- ✅ استاندارد
```

### اشتباه ۳: فراموش کردن `library` قبل از `use`

**نادرست:**
```vhdl
use ieee.std_logic_1164.all;  -- ❌ library ieee معرفی نشده
```

**درست:**
```vhdl
library ieee;
use ieee.std_logic_1164.all;  -- ✅
```

### اشتباه ۴: استفاده از `all` بدون نیاز

```vhdl
use ieee.std_logic_1164.all;  -- ✅ خوب
use ieee.numeric_std.all;     -- ✅ خوب

-- اما اگر فقط به یک آیتم نیاز دارید:
use ieee.std_logic_1164.rising_edge;  -- ✅ بهتر
```

## ۱۱. خلاصه و جمع‌بندی

### کتابخانه‌های اصلی

| کتابخانه | Package | کاربرد |
|----------|---------|--------|
| `ieee` | `std_logic_1164` | `std_logic`, `std_logic_vector` |
| `ieee` | `numeric_std` | `unsigned`, `signed`, ریاضی |
| `std` | `standard` | انواع پایه (خودکار) |
| `std` | `textio` | ورودی/خروجی (Testbench) |
| `work` | (متغیر) | طراحی‌های خودتان |

### دستورات

```vhdl
library <name>;                    -- معرفی کتابخانه
use <name>.<package>.all;          -- استفاده از همه
use <name>.<package>.<item>;       -- استفاده از یک آیتم
```

### نکات کلیدی

| نکته | توضیح |
|-------|-------|
| **همیشه** | `std_logic_1164.all` را استفاده کنید |
| **برای ریاضی** | از `numeric_std.all` استفاده کنید |
| **از کتابخانه‌های قدیمی** | خودداری کنید |
| **کتابخانه‌های سفارشی** | در `work` ذخیره می‌شوند |
| **Packageها** | محتوای کتابخانه‌ها را سازمان‌دهی می‌کنند |

### پیام نهایی

کتابخانه‌ها و Packageها **زیرساخت** طراحی VHDL هستند. با استفاده صحیح از کتابخانه‌های استاندارد و ایجاد کتابخانه‌های سفارشی، می‌توانید:
- کدهای **استاندارد** و **قابل حمل** بنویسید
- از **توابع آماده** استفاده کنید
- **Componentهای قابل استفاده مجدد** ایجاد کنید
- طراحی‌های **سازمان‌یافته** و **حرفه‌ای** داشته باشید

> **به یاد داشته باشید:** `std_logic_1164` و `numeric_std` دو کتابخانه‌ای هستند که در هر طراحی VHDL به آنها نیاز دارید. آنها را فراموش نکنید!
