# دستورات ترتیبی در VHDL — تحلیل جامع و عمیق

## مقدمه: دنیای ترتیبی در دل سخت‌افزار همزمان

تصور کنید یک **دستور پخت غذا** را دنبال می‌کنید: اول مواد را آماده می‌کنید، سپس آنها را مخلوط می‌کنید، بعد حرارت می‌دهید، و در نهایت سرو می‌کنید. هر مرحله **به ترتیب** و **پس از اتمام** مرحله قبلی انجام می‌شود. این دقیقاً همان چیزی است که در VHDL به آن **دستورات ترتیبی (Sequential Statements)** می‌گوییم.

با وجود اینکه VHDL یک زبان **همزمان** است، اما برای توصیف رفتارهای **ترتیبی** مانند الگوریتم‌ها، ماشین‌های حالت، و منطق کنترل، به دستورات ترتیبی نیاز داریم. این دستورات **فقط درون** `Process`، `Function` و `Procedure` قابل استفاده هستند.

## ۱. مفاهیم پایه

### ۱.۱. تفاوت Signal و Variable در دستورات ترتیبی

```
┌─────────────────────────────────────────────────────────────────────┐
│              SIGNAL vs VARIABLE در Sequential Statements           │
├─────────────────────────────────────────────────────────────────────┤
│                                                                   │
│  ┌─────────────────────────────────────────────────────────────┐  │
│  │  SIGNAL (سیگنال)                                           │  │
│  │  ┌──────────────────────────────────────────────────────┐  │  │
│  │  │  • در کل معماری (Architecture) قابل دسترسی است      │  │  │
│  │  │  • در انتهای Process به‌روز می‌شود                  │  │  │
│  │  │  • دارای تاریخچه (History) و زمان                   │  │  │
│  │  │  • برای ارتباط بین Processها استفاده می‌شود         │  │  │
│  │  │  • با <= مقداردهی می‌شود                            │  │  │
│  │  └──────────────────────────────────────────────────────┘  │  │
│  └─────────────────────────────────────────────────────────────┘  │
│                                                                   │
│  ┌─────────────────────────────────────────────────────────────┐  │
│  │  VARIABLE (متغیر)                                           │  │
│  │  ┌──────────────────────────────────────────────────────┐  │  │
│  │  │  • فقط درون Process یا Subprogram قابل دسترسی است    │  │  │
│  │  │  • فوراً به‌روز می‌شود                              │  │  │

│  │  │  • با := مقداردهی می‌شود                            │  │  │

│  └─────────────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────────────┘
```

### ۱.۲. تفاوت انتساب Signal و Variable

```vhdl
-- ===== مثال تفاوت =====
process(clk)
    variable v : integer := 0;  -- متغیر
    signal s : integer := 0;    -- سیگنال
begin
    if rising_edge(clk) then
        -- متغیر: فوراً به‌روز می‌شود
        v := v + 1;     -- v = 1
        v := v + 1;     -- v = 2 (از مقدار به‌روز شده استفاده می‌کند)
        
        -- سیگنال: در انتهای Process به‌روز می‌شود
        s <= s + 1;     -- s = 1 (در انتها)
        s <= s + 1;     -- s = 1 (از مقدار OLD استفاده می‌کند)
        -- نتیجه نهایی: s = 1 (فقط آخرین انتساب اعمال می‌شود)
    end if;
end process;
```

## ۲. دستور `if`

### ۲.۱. ساختار `if`

```vhdl
-- ===== ساختار کلی =====
if condition_1 then
    -- statements
elsif condition_2 then
    -- statements
elsif condition_3 then
    -- statements
else
    -- statements
end if;

-- ===== مثال کامل =====
library ieee;
use ieee.std_logic_1164.all;
use ieee.numeric_std.all;

entity if_example is
    port (
        a, b     : in  integer;
        sel      : in  std_logic_vector(1 downto 0);
        data     : in  std_logic_vector(7 downto 0);
        clk      : in  std_logic;
        rst      : in  std_logic;
        
        result   : out integer;
        max_val  : out integer;
        min_val  : out integer;
        flag     : out std_logic
    );
end entity;

architecture rtl of if_example is
    signal internal : integer;
begin
    process(clk, rst)
        variable temp : integer;
    begin
        if rst = '1' then
            -- Reset: همه سیگنال‌ها مقدار اولیه می‌گیرند
            result <= 0;
            max_val <= 0;
            min_val <= 0;
            flag <= '0';
            
        elsif rising_edge(clk) then
            -- ===== if ساده =====
            if a > b then
                max_val <= a;
            else
                max_val <= b;
            end if;
            
            -- ===== if با elsif =====
            if sel = "00" then
                result <= a + b;
            elsif sel = "01" then
                result <= a - b;
            elsif sel = "10" then
                result <= a * b;
            else
                result <= a / b;
            end if;
            
            -- ===== if تو در تو =====
            if a > 0 then
                if b > 0 then
                    temp := a + b;
                else
                    temp := a - b;
                end if;
            else
                if b > 0 then
                    temp := b - a;
                else
                    temp := a + b;
                end if;
            end if;
            
            -- ===== if با شرط ترکیبی =====
            if (a > 0 and b > 0) or (a < 0 and b < 0) then
                flag <= '1';
            else
                flag <= '0';
            end if;
            
            -- ===== if با مقداردهی به متغیر =====
            if data = "00000000" then
                temp := 0;
            elsif data(7) = '1' then
                temp := -to_integer(signed(data));
            else
                temp := to_integer(unsigned(data));
            end if;
            
            min_val <= temp;
        end if;
    end process;
end architecture;
```

### ۲.۲. نکات مهم در `if`

```vhdl
-- ===== نکته 1: شرط‌ها باید boolean باشند =====
if a = b then        -- ✅ صحیح
    -- ...
end if;

if a and b then      -- ❌ خطا: std_logic نمی‌تواند شرط باشد
    -- ...
end if;

-- ✅ راه‌حل: تبدیل به boolean
if (a and b) = '1' then
    -- ...
end if;

-- یا در VHDL-2008
if ?? (a and b) then
    -- ...
end if;

-- ===== نکته 2: else الزامی نیست =====
process(a, b)
begin
    if a > b then
        y <= a;
    end if;
    -- اگر شرط false باشد، y مقدار قبلی خود را نگه می‌دارد
    -- ⚠️ این می‌تواند Latch ایجاد کند!
end process;

-- ✅ برای جلوگیری از Latch، همیشه else داشته باشید
process(a, b)
begin
    if a > b then
        y <= a;
    else
        y <= b;  -- مقدار پیش‌فرض
    end if;
end process;

-- ===== نکته 3: elsif به جای else if =====
-- ✅ درست
if a = 1 then
    -- ...
elsif a = 2 then
    -- ...
elsif a = 3 then
    -- ...
else
    -- ...
end if;

-- ❌ غلط (در VHDL)
if a = 1 then
    -- ...
else if a = 2 then  -- ❌ else if مجاز نیست
    -- ...
end if;
```

## ۳. دستور `case`

### ۳.۱. ساختار `case`

```vhdl
-- ===== ساختار کلی =====
case expression is
    when choice_1 =>
        -- statements
    when choice_2 =>
        -- statements
    when choice_3 | choice_4 =>
        -- statements
    when choice_5 to choice_10 =>
        -- statements
    when others =>
        -- statements
end case;

-- ===== مثال کامل =====
library ieee;
use ieee.std_logic_1164.all;
use ieee.numeric_std.all;

entity case_example is
    port (
        opcode   : in  std_logic_vector(2 downto 0);
        state    : in  std_logic_vector(1 downto 0);
        a, b     : in  integer;
        
        result   : out integer;
        control  : out std_logic_vector(3 downto 0);
        next_state : out std_logic_vector(1 downto 0)
    );
end entity;

architecture rtl of case_example is
    type color_t is (RED, GREEN, BLUE, YELLOW);
    signal color : color_t;
begin
    -- ===== case با مقادیر ثابت =====
    process(opcode, a, b)
    begin
        case opcode is
            when "000" => result <= a + b;
            when "001" => result <= a - b;
            when "010" => result <= a * b;
            when "011" => result <= a / b;
            when "100" => result <= a mod b;
            when "101" => result <= a rem b;
            when "110" => result <= a ** 2;
            when "111" => result <= 0;
            when others => result <= 0;  -- همیشه others داشته باشید
        end case;
    end process;
    
    -- ===== case با چند مقدار =====
    process(state)
    begin
        case state is
            when "00" | "01" => next_state <= "10";
            when "10" | "11" => next_state <= "00";
            when others => next_state <= "00";
        end case;
    end process;
    
    -- ===== case با range =====
    process(opcode)
    begin
        case opcode is
            when "000" to "011" => control <= "0001";
            when "100" to "110" => control <= "0010";
            when "111" => control <= "0100";
            when others => control <= "1000";
        end case;
    end process;
    
    -- ===== case با نوع enum =====
    process(color)
    begin
        case color is
            when RED => control <= "0001";
            when GREEN => control <= "0010";
            when BLUE => control <= "0100";
            when YELLOW => control <= "1000";
            when others => control <= "0000";
        end case;
    end process;
end architecture;
```

### ۳.۲. نکات مهم در `case`

```vhdl
-- ===== نکته 1: همه حالت‌ها باید پوشش داده شوند =====
-- ✅ درست: همه حالت‌ها پوشش داده شده
case opcode is
    when "00" => ...
    when "01" => ...
    when "10" => ...
    when "11" => ...
end case;

-- ✅ درست: با others
case opcode is
    when "00" => ...
    when "01" => ...
    when others => ...  -- پوشش "10" و "11"
end case;

-- ❌ غلط: همه حالت‌ها پوشش داده نشده
case opcode is
    when "00" => ...
    when "01" => ...
    -- "10" و "11" پوشش داده نشده‌اند!
end case;

-- ===== نکته 2: انتخاب‌ها باید منحصر‌به‌فرد باشند =====
-- ❌ غلط: انتخاب‌های تکراری
case opcode is
    when "00" => ...
    when "00" => ...  -- ❌ تکراری
    when others => ...
end case;

-- ===== نکته 3: others باید آخرین انتخاب باشد =====
-- ✅ درست
case opcode is
    when "00" => ...
    when "01" => ...
    when others => ...
end case;

-- ❌ غلط: others در وسط
case opcode is
    when "00" => ...
    when others => ...  -- ❌ others در وسط
    when "01" => ...
end case;

-- ===== نکته 4: انتخاب‌های با range =====
case opcode is
    when "000" to "011" => ...  -- ✅ range
    when "100" to "110" => ...
    when others => ...
end case;

-- ⚠️ range فقط برای انواع عددی یا enumerated
```

## ۴. دستور `loop`

### ۴.۱. انواع حلقه

```vhdl
-- ===== 1. حلقه for (تعداد مشخص) =====
for variable in range loop
    -- statements
end loop;

-- ===== 2. حلقه while (شرطی) =====
while condition loop
    -- statements
end loop;

-- ===== 3. حلقه infinite (بی‌نهایت) =====
loop
    -- statements
    exit when condition;  -- شرط خروج
end loop;

-- ===== 4. حلقه با next و exit =====
loop
    -- statements
    next when condition;   -- رفتن به تکرار بعدی
    -- statements
    exit when condition;   -- خروج از حلقه
end loop;
```

### ۴.۲. مثال‌های حلقه

```vhdl
library ieee;
use ieee.std_logic_1164.all;
use ieee.numeric_std.all;

entity loop_example is
    port (
        clk      : in  std_logic;
        rst      : in  std_logic;
        data_in  : in  std_logic_vector(7 downto 0);
        
        sum_out  : out integer;
        max_out  : out integer;
        count_ones : out integer;
        factorial : out integer
    );
end entity;

architecture rtl of loop_example is
begin
    process(clk, rst)
        variable sum : integer := 0;
        variable max_val : integer := 0;
        variable ones : integer := 0;
        variable fact : integer := 1;
        variable i : integer;
    begin
        if rst = '1' then
            sum_out <= 0;
            max_out <= 0;
            count_ones <= 0;
            factorial <= 1;
            
        elsif rising_edge(clk) then
            -- ===== 1. حلقه for =====
            sum := 0;
            for i in 0 to 7 loop
                if data_in(i) = '1' then
                    sum := sum + (2 ** i);
                end if;
            end loop;
            sum_out <= sum;
            
            -- ===== 2. حلقه with range =====
            max_val := 0;
            for i in 0 to 7 loop
                if to_integer(unsigned(data_in)) > max_val then
                    max_val := to_integer(unsigned(data_in));
                end if;
            end loop;
            max_out <= max_val;
            
            -- ===== 3. شمارش بیت‌های 1 =====
            ones := 0;
            for i in data_in'range loop
                if data_in(i) = '1' then
                    ones := ones + 1;
                end if;
            end loop;
            count_ones <= ones;
            
            -- ===== 4. حلقه با exit =====
            fact := 1;
            for i in 1 to 10 loop
                fact := fact * i;
                exit when i = 5;  -- فقط تا 5 محاسبه می‌کند
            end loop;
            factorial <= fact;
            
            -- ===== 5. حلقه while =====
            i := 0;
            sum := 0;
            while i < 8 loop
                if data_in(i) = '1' then
                    sum := sum + 1;
                end if;
                i := i + 1;
            end loop;
            -- sum برابر با تعداد بیت‌های 1 است
        end if;
    end process;
end architecture;
```

### ۴.۳. نکات پیشرفته حلقه

```vhdl
-- ===== 1. حلقه با next =====
process(clk)
    variable v : integer := 0;
begin
    if rising_edge(clk) then
        v := 0;
        for i in 0 to 10 loop
            if i mod 2 = 0 then  -- اگر i زوج باشد
                next;            -- به تکرار بعدی برو
            end if;
            v := v + i;          -- فقط اعداد فرد جمع می‌شوند
        end loop;
        -- v = 1 + 3 + 5 + 7 + 9 = 25
    end if;
end process;

-- ===== 2. حلقه تو در تو =====
process(clk)
    variable sum : integer := 0;
begin
    if rising_edge(clk) then
        sum := 0;
        for i in 0 to 3 loop
            for j in 0 to 3 loop
                sum := sum + (i * j);
            end loop;
        end loop;
        -- sum = 0 + 0 + 0 + 0 + ... = 36
    end if;
end process;

-- ===== 3. حلقه با نام =====
OUTER_LOOP: for i in 0 to 3 loop
    INNER_LOOP: for j in 0 to 3 loop
        exit OUTER_LOOP when i = 2;  -- خروج از حلقه بیرونی
        -- ...
    end loop INNER_LOOP;
end loop OUTER_LOOP;

-- ===== 4. حلقه while با شرط متغیر =====
process(clk)
    variable count : integer := 0;
    variable done : boolean := false;
begin
    if rising_edge(clk) then
        count := 0;
        done := false;
        while not done loop
            count := count + 1;
            if count > 100 then
                done := true;
            end if;
        end loop;
    end if;
end process;
```

## ۵. دستورات `wait`

### ۵.۱. انواع `wait`

```vhdl
-- ===== 1. wait on (حساس به سیگنال) =====
wait on signal_1, signal_2, ...;

-- ===== 2. wait until (شرط) =====
wait until condition;

-- ===== 3. wait for (زمان) =====
wait for time_expression;

-- ===== 4. ترکیبی =====
wait on signal until condition for time;
```

### ۵.۲. مثال‌های `wait`

```vhdl
library ieee;
use ieee.std_logic_1164.all;
use ieee.numeric_std.all;

entity wait_example is
    port (
        clk   : in  std_logic;
        rst   : in  std_logic;
        a, b  : in  std_logic_vector(7 downto 0);
        
        result : out std_logic_vector(7 downto 0)
    );
end entity;

architecture rtl of wait_example is
begin
    -- ===== 1. Process با wait until (معادل rising_edge) =====
    SYNC_PROC: process
    begin
        wait until rising_edge(clk);  -- منتظر لبه بالارونده
        result <= a;                  -- سپس اجرا می‌شود
    end process;
    
    -- ===== 2. Process با wait on =====
    COMB_PROC: process
    begin
        wait on a, b;  -- منتظر تغییر a یا b
        result <= a and b;
    end process;
    
    -- ===== 3. Process با wait for (فقط برای Testbench) =====
    TEST_PROC: process
    begin
        wait for 10 ns;  -- 10 نانوثانیه صبر کن
        result <= "00000000";
        wait for 20 ns;
        result <= "11111111";
        wait for 10 ns;
        result <= "00000000";
        wait;
    end process;
    
    -- ===== 4. ترکیب wait on و wait for =====
    TIMEOUT_PROC: process
    begin
        wait on a until a = "11111111" for 100 ns;
        -- منتظر بمان تا a = "11111111" شود یا 100 ns بگذرد
        if a = "11111111" then
            result <= a;
        else
            result <= (others => '0');  -- Timeout
        end if;
    end process;
end architecture;
```

### ۵.۳. استفاده از `wait` در Testbench

```vhdl
library ieee;
use ieee.std_logic_1164.all;
use ieee.numeric_std.all;

entity testbench is
end entity;

architecture tb of testbench is
    signal clk : std_logic := '0';
    signal rst : std_logic := '0';
    signal data : std_logic_vector(7 downto 0);
begin
    -- ===== تولید Clock با wait =====
    CLOCK_PROC: process
    begin
        clk <= '0';
        wait for 5 ns;
        clk <= '1';
        wait for 5 ns;
    end process;
    
    -- ===== Reset با wait =====
    RESET_PROC: process
    begin
        rst <= '1';
        wait for 20 ns;
        rst <= '0';
        wait;
    end process;
    
    -- ===== تولید داده با wait =====
    DATA_PROC: process
    begin
        data <= "00000000";
        wait for 10 ns;
        data <= "00000001";
        wait for 10 ns;
        data <= "00000010";
        wait for 10 ns;
        data <= "00000100";
        wait for 10 ns;
        data <= "00001000";
        wait for 10 ns;
        data <= "00010000";
        wait for 10 ns;
        data <= "00100000";
        wait for 10 ns;
        data <= "01000000";
        wait for 10 ns;
        data <= "10000000";
        wait for 10 ns;
        wait;  -- forever wait
    end process;
    
    -- ===== پاسخ‌دهی به داده =====
    RESPONSE_PROC: process
    begin
        wait until data = "00000001";
        report "Data is 1";
        wait until data = "10000000";
        report "Data is 128";
    end process;
end architecture;
```

## ۶. دستورات `null` و `assert`

### ۶.۱. دستور `null`

```vhdl
-- ===== null =====
-- هیچ کاری انجام نمی‌دهد. برای حالت‌های غیرضروری استفاده می‌شود.

process(opcode)
begin
    case opcode is
        when "000" => y <= a;
        when "001" => y <= b;
        when others => null;  -- هیچ کاری نکن
    end case;
end process;

-- ===== کاربرد دیگر =====
if condition then
    -- do something
else
    null;  -- هیچ کاری نکن
end if;
```

### ۶.۲. دستور `assert`

```vhdl
-- ===== ساختار =====
assert condition
    report "message"
    severity severity_level;

-- ===== سطوح severity =====
-- • note    : اطلاعاتی (تست‌ها)
-- • warning : هشدار
-- • error   : خطا (ادامه می‌دهد)
-- • failure : خطای بحرانی (متوقف می‌شود)

-- ===== مثال‌ها =====
process
begin
    -- ===== بررسی ورودی‌ها =====
    assert a >= 0 and a <= 255
        report "a خارج از محدوده است!"
        severity error;
    
    -- ===== بررسی شرط =====
    assert (a + b) = c
        report "جمع اشتباه است!"
        severity warning;
    
    -- ===== پیام اطلاعاتی =====
    assert false
        report "شروع فرآیند..."
        severity note;
    
    -- ===== تست در Testbench =====
    assert data_out = expected
        report "Test failed! Expected: " & to_string(expected) & 
               " Got: " & to_string(data_out)
        severity error;
    
    -- ===== توقف شبیه‌سازی =====
    assert false
        report "پایان شبیه‌سازی"
        severity failure;
    
    wait;
end process;
```

## ۷. دستورات `return` و `next` و `exit`

### ۷.۱. `return`

```vhdl
-- ===== return در Function =====
function add(a, b : integer) return integer is
begin
    return a + b;  -- مقدار را برمی‌گرداند
end function;

-- ===== return در Procedure =====
procedure log(msg : string) is
begin
    report msg;
    return;  -- بازگشت زودهنگام
end procedure;

-- ===== return در Process =====
process(clk)
begin
    if rst = '1' then
        -- ...
        return;  -- خروج از Process
    end if;
    -- اگر rst = '1' باشد، این قسمت اجرا نمی‌شود
    if rising_edge(clk) then
        -- ...
    end if;
end process;
```

### ۷.۲. `next` و `exit`

```vhdl
-- ===== next =====
-- رفتن به تکرار بعدی حلقه

process(clk)
    variable sum : integer := 0;
begin
    if rising_edge(clk) then
        for i in 0 to 10 loop
            if i mod 2 = 0 then
                next;  -- اعداد زوج را رد کن
            end if;
            sum := sum + i;  -- فقط اعداد فرد
        end loop;
    end if;
end process;

-- ===== exit =====
-- خروج از حلقه

process(clk)
    variable i : integer := 0;
begin
    if rising_edge(clk) then
        i := 0;
        loop
            i := i + 1;
            if i > 100 then
                exit;  -- خروج از حلقه
            end if;
        end loop;
    end if;
end process;

-- ===== next/exit با label =====
OUTER: for i in 0 to 5 loop
    INNER: for j in 0 to 5 loop
        if i = j then
            next INNER;  -- ادامه حلقه داخلی
        end if;
        if i > j then
            exit OUTER;  -- خروج از حلقه بیرونی
        end if;
    end loop INNER;
end loop OUTER;
```

## ۸. دستورات در Function و Procedure

### ۸.۱. Function

```vhdl
-- ===== Function ساده =====
function max_value(a, b : integer) return integer is
begin
    if a > b then
        return a;
    else
        return b;
    end if;
end function;

-- ===== Function با چند پارامتر =====
function calculate(a, b : integer; op : std_logic) return integer is
begin
    if op = '0' then
        return a + b;
    else
        return a - b;
    end if;
end function;

-- ===== Function با آرایه =====
function sum_array(arr : integer_vector) return integer is
    variable sum : integer := 0;
begin
    for i in arr'range loop
        sum := sum + arr(i);
    end loop;
    return sum;
end function;

-- ===== استفاده =====
process(clk)
    variable result : integer;
begin
    if rising_edge(clk) then
        result := max_value(a, b);
        result := calculate(a, b, '0');
        result := sum_array(my_array);
    end if;
end process;
```

### ۸.۲. Procedure

```vhdl
-- ===== Procedure ساده =====
procedure swap(a, b : inout integer) is
    variable temp : integer;
begin
    temp := a;
    a := b;
    b := temp;
end procedure;

-- ===== Procedure با پارامترهای مختلف =====
procedure increment_vector(signal vec : inout std_logic_vector(7 downto 0);
                           signal clk : in std_logic) is
begin
    wait until rising_edge(clk);
    vec <= std_logic_vector(unsigned(vec) + 1);
end procedure;

-- ===== Procedure با مقادیر پیش‌فرض =====
procedure log_message(msg : string := "Info";
                     level : severity_level := note) is
begin
    report msg severity level;
end procedure;

-- ===== استفاده =====
process
    variable a, b : integer := 10;
begin
    swap(a, b);  -- a = 10, b = 10 (در این حالت تغییری نمی‌کند)
    
    -- استفاده از procedure با سیگنال
    increment_vector(my_signal, clk);
    
    -- استفاده از procedure با مقدار پیش‌فرض
    log_message;  -- "Info" با severity note
    log_message("Error!", error);
    
    wait;
end process;
```

## ۹. مقایسه کامل Signal vs Variable

### ۹.۱. جدول مقایسه

| ویژگی | Signal | Variable |
|--------|--------|----------|
| **محدوده** | کل معماری (Architecture) | فقط درون Process/Subprogram |
| **مقداردهی** | `<=` (انتساب) | `:=` (انتساب) |
| **زمان به‌روزرسانی** | در انتهای Process | فوراً |
| **تاریخچه** | دارد (قابل استفاده برای تأخیر) | ندارد |
| **چندین انتساب** | فقط آخرین مقدار اعمال می‌شود | همه اعمال می‌شوند |
| **قابلیت سنتز** | ✅ کاملاً قابل سنتز | ✅ کاملاً قابل سنتز |
| **استفاده در Testbench** | برای تولید سیگنال‌ها | برای محاسبات موقتی |

### ۹.۲. مثال تفاوت‌ها

```vhdl
-- ===== تفاوت در چندین انتساب =====
process(clk)
    variable v : integer := 0;
    signal s : integer := 0;
begin
    if rising_edge(clk) then
        -- Variable: همه انتساب‌ها اعمال می‌شوند
        v := v + 1;  -- v = 1
        v := v + 2;  -- v = 3 (از مقدار 1 استفاده می‌کند)
        v := v + 3;  -- v = 6 (از مقدار 3 استفاده می‌کند)
        
        -- Signal: فقط آخرین انتساب اعمال می‌شود
        s <= s + 1;  -- s = 1 (در انتها)
        s <= s + 2;  -- s = 2 (در انتها - از مقدار OLD استفاده می‌کند)
        s <= s + 3;  -- s = 3 (در انتها - فقط این یکی اعمال می‌شود)
        -- نتیجه نهایی: s = 3 (نه 6!)
    end if;
end process;

-- ===== تفاوت در استفاده از مقدار =====
process(clk)
    variable v : integer := 0;
    signal s : integer := 0;
begin
    if rising_edge(clk) then
        -- Variable: مقدار جدید فوراً در دسترس است
        v := v + 1;
        if v > 5 then  -- از مقدار جدید استفاده می‌کند
            -- ...
        end if;
        
        -- Signal: مقدار جدید در انتها در دسترس است
        s <= s + 1;
        if s > 5 then  -- از مقدار OLD استفاده می‌کند!
            -- ⚠️ این ممکن است منطق مورد نظر نباشد
        end if;
    end if;
end process;
```

## ۱۱. بهترین‌نوشته‌ها (Best Practices)

### ۱۱.۱. انتخاب Signal یا Variable

```vhdl
-- ===== راهنمای انتخاب =====

-- ✅ از Signal استفاده کنید وقتی:
-- • نیاز به ارتباط بین Processها دارید
-- • نیاز به تاریخچه سیگنال دارید (برای تأخیر)
-- • سیگنال خروجی از بلوک شماست

-- ✅ از Variable استفاده کنید وقتی:
-- • محاسبات موقتی انجام می‌دهید
-- • نیاز به مقداردهی فوری دارید
-- • الگوریتم‌های پیچیده پیاده‌سازی می‌کنید
-- • می‌خواهید از مقدار به‌روز شده در همان Process استفاده کنید

-- ===== مثال =====
process(clk)
    variable temp : integer;  -- برای محاسبه موقتی
    variable sum : integer;
begin
    if rising_edge(clk) then
        temp := a + b;
        sum := temp * 2;
        result <= sum;  -- نتیجه به Signal
    end if;
end process;
```

### ۱۱.۲. ساختار Process استاندارد

```vhdl
-- ===== Template برای Process سنکرون =====
SYNC_PROC: process(clk, rst)
    -- متغیرهای محلی
    variable v1 : integer := 0;
    variable v2 : std_logic_vector(7 downto 0);
begin
    if rst = '1' then
        -- Reset: همه سیگنال‌ها
        sig1 <= (others => '0');
        sig2 <= '0';
        -- Reset: متغیرها
        v1 := 0;
        v2 := (others => '0');
        
    elsif rising_edge(clk) then
        -- منطق اصلی
        if condition then
            -- ...
        end if;
    end if;
end process SYNC_PROC;

-- ===== Template برای Process ترکیبی =====
COMB_PROC: process(all)  -- VHDL-2008
    -- متغیرهای محلی
begin
    -- مقدار پیش‌فرض (جلوگیری از Latch)
    sig1 <= '0';
    sig2 <= (others => '0');
    
    -- منطق اصلی
    if condition then
        -- ...
    end if;
end process COMB_PROC;
```

### ۱۱.۳. رعایت قوانین سنتز

```vhdl
-- ===== قوانین مهم برای سنتز =====

-- 1. Reset باید در لیست حساسیت باشد
process(clk, rst)  -- ✅ شامل rst
begin
    if rst = '1' then
        -- ...
    elsif rising_edge(clk) then
        -- ...
    end if;
end process;

-- 2. از دو لبه Clock در یک Process استفاده نکنید
-- ❌ غلط
process(clk)
begin
    if rising_edge(clk) then
        -- ...
    elsif falling_edge(clk) then  -- ❌
        -- ...
    end if;
end process;

-- 3. از چندین Clock در یک Process استفاده نکنید
-- ❌ غلط
process(clk1, clk2)  -- ❌
begin
    if rising_edge(clk1) then
        -- ...
    elsif rising_edge(clk2) then
        -- ...
    end if;
end process;

-- 4. مقداردهی به همه سیگنال‌ها در همه مسیرها
-- ❌ غلط: Latch
process(a, b, sel)
begin
    if sel = '1' then
        y <= a;
    end if;
end process;

-- ✅ درست
process(a, b, sel)
begin
    y <= b;  -- مقدار پیش‌فرض
    if sel = '1' then
        y <= a;
    end if;
end process;
```

## ۱۲. خلاصه و جمع‌بندی

### جدول دستورات ترتیبی

| دستور | کاربرد | مثال |
|-------|--------|-------|
| `if` | انتخاب شرطی | `if a > b then ... end if;` |
| `case` | انتخاب چندحالته | `case opcode is when "00" => ...` |
| `loop` | تکرار | `for i in 0 to 7 loop ... end loop;` |
| `next` | رفتن به تکرار بعدی | `next when condition;` |
| `exit` | خروج از حلقه | `exit when condition;` |
| `wait` | توقف و انتظار | `wait until rising_edge(clk);` |
| `assert` | بررسی شرط | `assert condition report "msg";` |
| `null` | هیچ کاری | `null;` |
| `return` | بازگشت از Subprogram | `return value;` |

### نکات کلیدی

| نکته | توضیح |
|------|-------|
| **Signal vs Variable** | Signal در انتهای Process، Variable فوراً به‌روز می‌شود |
| **if vs case** | if برای شرایط پیچیده، case برای انتخاب چندحالته |
| **Latch** | همیشه به همه سیگنال‌ها در همه مسیرها مقدار دهید |
| **Loop** | فقط در Process، Function و Procedure قابل استفاده است |
| **wait** | فقط در Process (بدون لیست حساسیت) قابل استفاده است |
| **Synthesis** | همه دستورات ترتیبی قابل سنتز هستند (به جز wait for) |

### مقایسه Signal و Variable

```
┌─────────────────────────────────────────────────────────────────────┐
│  SIGNAL                                    VARIABLE                │
├─────────────────────────────────────────────────────────────────────┤
│  • در Architecture تعریف می‌شود            • در Process تعریف می‌شود│
│  • با <= مقداردهی می‌شود                   • با := مقداردهی می‌شود   │
│  • در انتهای Process به‌روز می‌شود         • فوراً به‌روز می‌شود     │
│  • دارای تاریخچه است                        • بدون تاریخچه          │
│  • برای ارتباط بین Processها                • برای محاسبات موقتی     │
│  • قابل سنتز است                            • قابل سنتز است         │
└─────────────────────────────────────────────────────────────────────┘
```

> **پیام نهایی:** دستورات ترتیبی **قلب** منطق کنترل و الگوریتم‌ها در VHDL هستند. درک صحیح تفاوت بین Signal و Variable، و نحوه استفاده از `if`، `case`، و `loop`، برای طراحی **حرفه‌ای** و **کارآمد** ضروری است. به یاد داشته باشید که اگرچه این دستورات **ترتیبی** نوشته می‌شوند، اما درون یک **محیط همزمان** (Process) اجرا می‌شوند و باید با ماهیت سخت‌افزار سازگار باشند.
