# Packages در VHDL — تحلیل جامع و عمیق

## مقدمه: Package چیست؟

**Package** در VHDL یک **واحد ذخیره‌سازی** است که مجموعه‌ای از **اعلان‌های قابل استفاده مجدد** را در خود جای می‌دهد. Package مانند **یک جعبه ابزار** است که شامل انواع داده، ثابت‌ها، توابع، رویه‌ها و Componentهای آماده می‌باشد.

### تشبیه ساده

Package را مانند **یک کتاب آشپزی** تصور کنید:
- شامل دستورهای مختلف است (توابع و رویه‌ها)
- مواد اولیه را تعریف می‌کند (انواع و ثابت‌ها)
- ابزارهای خاص را معرفی می‌کند (Componentها)
- هر کسی می‌تواند از آن استفاده کند

## ۲. Package Declaration (بخش اعلان)

### ۲.۱. Syntax کامل

```vhdl
package package_name is
    -- ===== 1. کتابخانه‌های مورد نیاز =====
    -- (اختیاری، اما معمولاً در اینجا قرار می‌گیرند)
    
    -- ===== 2. انواع داده سفارشی =====
    type type_name is ...;
    subtype subtype_name is type_name range ...;
    
    -- ===== 3. ثابت‌ها =====
    constant constant_name : type := value;
    
    -- ===== 4. آرایه‌ها و رکوردها =====
    type array_type is array (range) of element_type;
    type record_type is record
        field1 : type1;
        field2 : type2;
    end record;
    
    -- ===== 5. Componentها =====
    component component_name is
        port ( ... );
    end component;
    
    -- ===== 6. توابع (فقط امضا) =====
    function function_name (parameters) return return_type;
    
    -- ===== 7. رویه‌ها (فقط امضا) =====
    procedure procedure_name (parameters);
    
    -- ===== 8. ویژگی‌ها =====
    attribute attribute_name : type;
    attribute attribute_name of target : class is value;
    
end package package_name;
```

### ۲.۲. مثال کامل بخش اعلان

```vhdl

    -- ===== 4. آرایه‌ها =====
    type int_array is array (natural range <>) of integer;

    function to_hex(slv : std_logic_vector) return string;

    -- ===== 7. رویه‌ها =====
    procedure swap(a, b : inout integer);
```

```vhdl
package body package_name is

    end function function_name;

    procedure procedure_name (parameters) is
        -- متغیرهای محلی

        -- بدنه رویه
    end procedure procedure_name;

```

### ۳.۲. مثال کامل بخش پیاده‌سازی

```vhdl
-- ===== math_pkg.vhd (ادامه) =====
package body math_pkg is
    -- ===== پیاده‌سازی توابع =====
    
    function factorial(n : integer) return integer is
        variable result : integer := 1;
    begin
        if n < 0 then
            return 0;
        elsif n = 0 or n = 1 then
            return 1;
        else
            for i in 2 to n loop
                result := result * i;
            end loop;
            return result;
        end if;
    end function factorial;
    
    function gcd(a, b : integer) return integer is
        variable x : integer := abs(a);
        variable y : integer := abs(b);
        variable temp : integer;
    begin
        while y /= 0 loop
            temp := y;
            y := x mod y;
            x := temp;
        end loop;
        return x;
    end function gcd;
    
    function is_prime(n : integer) return boolean is
    begin
        if n < 2 then
            return false;
        end if;
        for i in 2 to n/2 loop
            if n mod i = 0 then
                return false;
            end if;
        end loop;
        return true;
    end function is_prime;
    
    function to_hex(slv : std_logic_vector) return string is
        constant hex_chars : string := "0123456789ABCDEF";
        variable result    : string(1 to slv'length / 4);
        variable temp      : integer;
    begin
        for i in 0 to slv'length/4 - 1 loop
            temp := 0;
            for j in 0 to 3 loop
                if slv(i*4 + j) = '1' then
                    temp := temp + 2**(3-j);
                end if;
            end loop;
            result(i+1) := hex_chars(temp+1);
        end loop;
        return result;
    end function to_hex;
    
    function average(arr : int_array) return integer is
        variable sum : integer := 0;
    begin
        for i in arr'range loop
            sum := sum + arr(i);
        end loop;
        return sum / arr'length;
    end function average;
    
    -- ===== پیاده‌سازی رویه‌ها =====
    
    procedure swap(a, b : inout integer) is
        variable temp : integer;
    begin
        temp := a;
        a := b;
        b := temp;
    end procedure swap;
    
    procedure sort(arr : inout int_array) is
        variable temp : integer;
    begin
        for i in arr'range loop
            for j in i+1 to arr'high loop
                if arr(i) > arr(j) then
                    temp := arr(i);
                    arr(i) := arr(j);
                    arr(j) := temp;
                end if;
            end loop;
        end loop;
    end procedure sort;
    
    procedure log_message(msg : string) is
    begin
        report "LOG: " & msg severity note;
    end procedure log_message;
    
end package body math_pkg;
```

## ۵. Componentها در Package

Componentها در Package به شما امکان می‌دهند **قابلیت استفاده مجدد** از بلوک‌های سخت‌افزاری را داشته باشید.

### ۵.۱. تعریف Component در Package

```vhdl
package components_pkg is
    -- ===== Basic Components =====
    
    component and_gate
        port (
            a, b : in  std_logic;
            y    : out std_logic
        );
    end component;
    
    component or_gate
        port (
            a, b : in  std_logic;
            y    : out std_logic
        );
    end component;
    
    component not_gate
        port (
            a : in  std_logic;
            y : out std_logic
        );
    end component;
    
    -- ===== Flip-Flops =====
    component dff
        port (
            clk, reset, d : in  std_logic;
            q             : out std_logic
        );
    end component;
    
    component dff_en
        port (
            clk, reset, en, d : in  std_logic;
            q                 : out std_logic
        );
    end component;
    
    -- ===== Register Bank =====
    component register_file
        generic (
            DATA_WIDTH : integer := 32;
            REG_COUNT  : integer := 16
        );
        port (
            clk   : in  std_logic;
            read_addr1  : in  std_logic_vector(3 downto 0);
            read_addr2  : in  std_logic_vector(3 downto 0);

    component multiplier_n
```

## ۶. Package برای Testbench

### ۶.۱. Package Test Helpers

```vhdl
-- ===== test_helpers_pkg.vhd =====
library ieee;
use ieee.std_logic_1164.all;
use ieee.numeric_std.all;
use std.textio.all;

package test_helpers_pkg is
    -- ===== Types for Test =====
    type test_case_t is record
        name    : string(1 to 20);
        input   : std_logic_vector(7 downto 0);
        expected : std_logic_vector(7 downto 0);
    end record;
    
    type test_case_array is array (natural range <>) of test_case_t;
    
    -- ===== Test Functions =====
    function run_test_case(test : test_case_t; 
                           dut_result : std_logic_vector) return boolean;
    
    procedure run_tests(tests : test_case_array; 
                        signal dut_input : out std_logic_vector;
                        signal dut_result : in std_logic_vector);
    
    procedure log_result(test_name : string; passed : boolean);
    
    procedure generate_test_clock(signal clk : out std_logic; 
                                  constant period : time := 10 ns);
    
    procedure apply_vector(signal target : out std_logic_vector; 
                           value : std_logic_vector;
                           signal clk : in std_logic);
    
    function to_hex_string(slv : std_logic_vector) return string;
    function to_bin_string(slv : std_logic_vector) return string;
    
end package test_helpers_pkg;

package body test_helpers_pkg is
    -- ===== Implementation =====
    
    function run_test_case(test : test_case_t; 
                           dut_result : std_logic_vector) return boolean is
    begin
        if dut_result = test.expected then
            report "Test '" & test.name & "' PASSED" severity note;
            return true;
        else
            report "Test '" & test.name & "' FAILED. Expected: " & 
                   to_hex_string(test.expected) & ", Got: " & 
                   to_hex_string(dut_result) severity error;
            return false;
        end if;
    end function;
    
    procedure run_tests(tests : test_case_array; 
                        signal dut_input : out std_logic_vector;
                        signal dut_result : in std_logic_vector) is
        variable pass_count : integer := 0;
    begin
        for i in tests'range loop
            dut_input <= tests(i).input;
            wait for 10 ns;
            if run_test_case(tests(i), dut_result) then
                pass_count := pass_count + 1;
            end if;
        end loop;
        report "Tests completed: " & integer'image(pass_count) & 
               "/" & integer'image(tests'length) & " passed" severity note;
    end procedure;
    
    procedure log_result(test_name : string; passed : boolean) is
    begin
        if passed then
            report test_name & " ✅ PASSED" severity note;
        else
            report test_name & " ❌ FAILED" severity error;
        end if;
    end procedure;
    
    procedure generate_test_clock(signal clk : out std_logic; 
                                  constant period : time := 10 ns) is
    begin
        loop
            clk <= '0';
            wait for period/2;
            clk <= '1';
            wait for period/2;
        end loop;
    end procedure;
    
    procedure apply_vector(signal target : out std_logic_vector; 
                           value : std_logic_vector;
                           signal clk : in std_logic) is
    begin
        wait until rising_edge(clk);
        target <= value;
        wait until falling_edge(clk);
    end procedure;
    
    function to_hex_string(slv : std_logic_vector) return string is
        constant hex : string := "0123456789ABCDEF";
        variable result : string(1 to slv'length/4);
        variable temp : integer;
    begin
        for i in 0 to slv'length/4 - 1 loop
            temp := 0;
            for j in 0 to 3 loop
                if slv(i*4 + j) = '1' then
                    temp := temp + 2**(3-j);
                end if;
            end loop;
            result(i+1) := hex(temp+1);
        end loop;
        return result;
    end function;
    
    function to_bin_string(slv : std_logic_vector) return string is
        variable result : string(1 to slv'length);
    begin
        for i in slv'range loop
            if slv(i) = '1' then
                result(i+1) := '1';
            else
                result(i+1) := '0';
            end if;
        end loop;
        return result;
    end function;
    
end package body test_helpers_pkg;
```

```vhdl
        DIV, AND_OP, OR_OP, XOR_OP, SHIFT,
        JUMP, JUMP_IF, CALL, RET, HALT
    );
    
    type instruction_t is record
        opcode   : opcode_t;
        dest     : integer range 0 to 15;
        src1     : integer range 0 to 15;
        src2     : integer range 0 to 15;
        immediate : integer;
    end record;
    
    type reg_file_t is array (0 to 15) of std_logic_vector(31 downto 0);
    
    -- ===== Constants =====
    constant DATA_WIDTH : integer := 32;
    constant REG_COUNT  : integer := 16;
    constant MEM_SIZE   : integer := 1024;
    
    -- ===== Functions =====
    function decode_instruction(opcode : std_logic_vector(3 downto 0)) return opcode_t;
    function execute_instruction(inst : instruction_t; 
                                 regs : reg_file_t) return std_logic_vector;
    
    -- ===== Components =====
    component alu
        port (
            op      : in  opcode_t;
            a, b    : in  std_logic_vector(31 downto 0);
            result  : out std_logic_vector(31 downto 0);
            zero    : out std_logic;
            carry   : out std_logic
        );
    end component;
    
    component register_file
        port (
            clk      : in  std_logic;
            read_addr1  : in  integer range 0 to 15;
            read_addr2  : in  integer range 0 to 15;
            write_addr  : in  integer range 0 to 15;
            write_data  : in  std_logic_vector(31 downto 0);
            write_en    : in  std_logic;
            read_data1  : out std_logic_vector(31 downto 0);
            read_data2  : out std_logic_vector(31 downto 0)
        );
    end component;
    
end package cpu_pkg;

package body cpu_pkg is
    function decode_instruction(opcode : std_logic_vector(3 downto 0)) return opcode_t is
    begin
        case opcode is
            when "0000" => return NOP;
            when "0001" => return LOAD;
            when "0010" => return STORE;
            when "0011" => return ADD;
            when "0100" => return SUB;
            when "0101" => return MUL;
            when "0110" => return DIV;
            when "0111" => return AND_OP;
            when "1000" => return OR_OP;
            when "1001" => return XOR_OP;
            when "1010" => return SHIFT;
            when "1011" => return JUMP;
            when "1100" => return JUMP_IF;
            when "1101" => return CALL;
            when "1110" => return RET;
            when "1111" => return HALT;
            when others => return NOP;
        end case;
    end function;
    
    function execute_instruction(inst : instruction_t; 
                                 regs : reg_file_t) return std_logic_vector is
        variable result : std_logic_vector(31 downto 0);
    begin
        case inst.opcode is
            when ADD =>
                result := std_logic_vector(unsigned(regs(inst.src1)) + 
                                          unsigned(regs(inst.src2)));
            when SUB =>
                result := std_logic_vector(unsigned(regs(inst.src1)) - 
                                          unsigned(regs(inst.src2)));
            when MUL =>
                result := std_logic_vector(unsigned(regs(inst.src1)) * 
                                          unsigned(regs(inst.src2)));
            when others =>
                result := (others => '0');
        end case;
        return result;
    end function;
end package body cpu_pkg;
```

### ۸.۲. استفاده از Package در طراحی اصلی

```vhdl
-- ===== cpu_top.vhd =====
library ieee;
use ieee.std_logic_1164.all;
use ieee.numeric_std.all;
use work.cpu_pkg.all;  -- استفاده از Package سفارشی

entity cpu_top is
    port (
        clk     : in  std_logic;
        reset   : in  std_logic;
        mem_addr : out std_logic_vector(15 downto 0);
        mem_data : inout std_logic_vector(31 downto 0)
    );
end entity;

architecture rtl of cpu_top is
    signal regs : reg_file_t;
    signal alu_result : std_logic_vector(31 downto 0);
    signal zero_flag, carry_flag : std_logic;
    signal current_op : opcode_t;
    
begin
    -- استفاده از Component از Package
    alu_inst: alu
        port map (
            op      => current_op,
            a       => regs(0),
            b       => regs(1),
            result  => alu_result,
            zero    => zero_flag,
            carry   => carry_flag
        );
    
    -- استفاده از توابع Package
    process(clk)
        variable inst : instruction_t;
    begin
        if rising_edge(clk) then
            if reset = '1' then
                -- reset logic
            else
                -- decode instruction
                inst.opcode := decode_instruction(mem_data(3 downto 0));
                inst.dest := to_integer(unsigned(mem_data(7 downto 4)));
                inst.src1 := to_integer(unsigned(mem_data(11 downto 8)));
                inst.src2 := to_integer(unsigned(mem_data(15 downto 12)));
                
                -- execute
                current_op <= inst.opcode;
                if inst.opcode = ADD or inst.opcode = SUB or inst.opcode = MUL then
                    regs(inst.dest) <= alu_result;
                end if;
            end if;
        end if;
    end process;
    
end architecture;
```

### ۹.۳. Unconstrained Package

```vhdl
-- ===== unconstrained_pkg.vhd =====
package unconstrained_pkg is
    -- ===== Unconstrained Arrays =====
    type slv_array_t is array (natural range <>) of std_logic_vector;
    type int_array_t is array (natural range <>) of integer;
    
    -- ===== Functions with Unconstrained Arrays =====
    function sum_elements(arr : int_array_t) return integer;
    function xor_all(slv : std_logic_vector) return std_logic;
    function concat_arrays(arr1, arr2 : slv_array_t) return slv_array_t;
    
end package unconstrained_pkg;

package body unconstrained_pkg is
    function sum_elements(arr : int_array_t) return integer is
        variable sum : integer := 0;
    begin
        for i in arr'range loop
            sum := sum + arr(i);
        end loop;
        return sum;
    end function;
    
    function xor_all(slv : std_logic_vector) return std_logic is
        variable result : std_logic := '0';
    begin
        for i in slv'range loop
            result := result xor slv(i);
        end loop;
        return result;
    end function;
    
    function concat_arrays(arr1, arr2 : slv_array_t) return slv_array_t is
        variable result : slv_array_t(0 to arr1'length + arr2'length - 1);
        variable idx : integer := 0;
    begin
        for i in arr1'range loop
            result(idx) := arr1(i);
            idx := idx + 1;
        end loop;
        for i in arr2'range loop
            result(idx) := arr2(i);
            idx := idx + 1;
        end loop;
        return result;
    end function;
end package body unconstrained_pkg;
```

```vhdl
package my_pkg is
```

### ۱۰.۴. محدود کردن Visibility

```vhdl
package visibility_pkg is
    -- ===== Public Interface =====
    -- قابل استفاده برای کاربران Package
    
    type public_type_t is (...);
    function public_func(...) return ...;
    
    -- ===== Private Interface =====
    -- فقط در Package Body قابل استفاده است
    -- (در بخش اعلان قابل مشاهده نیست)
end package visibility_pkg;

package body visibility_pkg is
    -- ===== Private Functions =====
    -- فقط در Package Body قابل استفاده است
    
    function private_helper(...) return ... is
    begin
        -- implementation
    end function;
    
    -- ===== Public Function Implementation =====
    function public_func(...) return ... is
    begin
        -- می‌تواند از توابع خصوصی استفاده کند
        return private_helper(...);
    end function;
end package body visibility_pkg;
```

## ۱۱. خلاصه و جمع‌بندی

### مزایای استفاده از Package

| مزیت | توضیح |
|------|-------|
| **قابلیت استفاده مجدد** | یک بار نوشتن، استفاده در پروژه‌های متعدد |
| **سازمان‌دهی کد** | گروه‌بندی منطقی انواع، توابع و Componentها |
| **کاهش تکرار** | جلوگیری از کد نویسی تکراری |
| **استانداردسازی** | ایجاد استانداردهای طراحی در تیم |
| **قابلیت نگهداری** | تغییر در یک مکان، اعمال در کل پروژه |
| **ماژولار بودن** | جداسازی Interface از Implementation |

### ساختار Package استاندارد

```vhdl
-- ===== Template برای Package =====
-- 1. بخش اعلان
package <name> is
    -- Types
    -- Constants
    -- Functions (signatures)
    -- Procedures (signatures)
    -- Components
end package <name>;

-- 2. بخش پیاده‌سازی
package body <name> is
    -- Private functions
    -- Private procedures
    -- Public functions implementation
    -- Public procedures implementation
end package body <name>;
```

### نکات کلیدی

| نکته | توضیح |
|------|-------|
| **Package Declaration** | همیشه ضروری است |
| **Package Body** | فقط در صورت وجود توابع/رویه‌ها لازم است |
| **Visibility** | محتویات Package Declaration عمومی هستند |
| **Context** | Package Body می‌تواند شامل محتویات خصوصی باشد |
| **Library** | Package در یک Library ذخیره می‌شود |
| **Use Clause** | برای دسترسی به Package نیاز است |

### دستورات مهم

```vhdl
-- کتابخانه را معرفی کنید
library <library_name>;

-- از Package استفاده کنید (همه محتویات)
use <library_name>.<package_name>.all;

-- از یک آیتم خاص استفاده کنید
use <library_name>.<package_name>.<item_name>;

-- از چند Package استفاده کنید
use <library_name>.<package_name1>.all;
use <library_name>.<package_name2>.all;
```

---

> **پیام نهایی:** Packageها **قلب** قابلیت استفاده مجدد در VHDL هستند. با تسلط بر Packageها، می‌توانید طراحی‌های **حرفه‌ای**، **سازمان‌یافته** و **قابل نگهداری** ایجاد کنید. از Packageهای استاندارد بهره ببرید و Packageهای سفارشی خود را برای پروژه‌های خود ایجاد کنید.
