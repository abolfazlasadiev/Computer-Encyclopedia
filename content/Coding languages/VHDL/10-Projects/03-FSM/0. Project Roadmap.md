# Level 4 — Finite State Machines (FSM)

در Level 3 یاد گرفتید که یک مدار می‌تواند **State یا وضعیت** داشته باشد و با Clock از یک وضعیت به وضعیت دیگر برود.

حالا قرار است از همین مفهوم برای ساخت **سیستم‌های کنترلی واقعی** استفاده کنید.

در این Level دیگر هدف اصلی شما ساخت Counter نیست.

هدف این است که بتوانید مسئله‌ای مثل:

> «اگر کارت وارد شد، در را باز کن؛ اگر رمز اشتباه بود، اجازه ورود نده؛ اگر زمان تمام شد، دوباره به حالت اولیه برگرد.»

را به یک **ماشین حالت** تبدیل کنید و سپس آن را با VHDL پیاده‌سازی کنید.

# Project 31 — Traffic Light Controller

## هدف پروژه

اولین FSM واقعی شما یک **کنترلر چراغ راهنمایی** است.

هدف این نیست که فقط سه LED را روشن و خاموش کنید.

هدف این است که یاد بگیرید:

> چگونه رفتار یک سیستم را به چند State تقسیم کنیم.

---

## مسئله

یک چراغ راهنمایی معمولاً حالت‌هایی مانند:

```text
RED
GREEN
YELLOW
```

دارد.

سیستم باید به صورت مشخص بین این حالت‌ها حرکت کند.

مثلاً:

```text
RED
 ↓
GREEN
 ↓
YELLOW
 ↓
RED
```

---

## State چیست؟

در این پروژه هر حالت نشان‌دهنده وضعیت فعلی چراغ است.

مثلاً:

```text
State = RED
```

یعنی:

```text
Red    = ON
Yellow = OFF
Green  = OFF
```

---

## ساختار

```text
             ┌──────────────┐
             │              │
             ▼              │
          ┌───────┐         │
          │  RED  │         │
          └───┬───┘         │
              ↓             │
          ┌───────┐         │
          │ GREEN │         │
          └───┬───┘         │
              ↓             │
          ┌────────┐        │
          │ YELLOW │────────┘
          └────────┘
```

---

## چه چیزی یاد می‌گیرید؟

- State
    
- State Transition
    
- FSM
    
- Clock
    
- Output Logic
    
- Next-State Logic
    
- Enumerated Types
    
- Moore FSM
    

---

## از شما چه می‌خواهد؟

باید:

1. Stateهای سیستم را مشخص کنید.
    
2. State Transition را مشخص کنید.
    
3. مشخص کنید هر State چه خروجی دارد.
    
4. Clock را تعریف کنید.
    
5. Reset طراحی کنید.
    
6. FSM را در VHDL پیاده‌سازی کنید.
    
7. Testbench بسازید.
    
8. Transitionها را در Waveform بررسی کنید.
    

---

## نکته مهم

نباید مستقیم شروع به نوشتن VHDL کنید.

اول باید روی کاغذ بنویسید:

```text
States:
RED
GREEN
YELLOW
```

بعد:

```text
Transitions:
RED → GREEN
GREEN → YELLOW
YELLOW → RED
```

بعد خروجی‌ها را مشخص کنید.

این روش در تمام FSMهای بعدی استفاده خواهد شد.

# یک نکته بسیار مهم درباره FSM

در این Level باید یاد بگیرید که FSM معمولاً از **سه بخش مفهومی** تشکیل می‌شود:

```text
              ┌───────────────────┐
              │   State Register  │
              └─────────┬─────────┘
                        │
                     Current
                      State
                        │
                        ▼
Input ─────────► Next-State Logic
                        │
                        ▼
                    Next State
                        │
                        └────► State Register
```

و خروجی‌ها نیز بر اساس State و در بعضی طراحی‌ها Input تولید می‌شوند.

---

# Moore و Mealy

در این Level باید با دو مدل اصلی هم آشنا شوید.

## Moore FSM

خروجی عمدتاً تابع State است:

```text
Output = f(State)
```

مثلاً:

```text
RED State
 ↓
Red LED = 1
```

---

## Mealy FSM

خروجی می‌تواند تابع State و Input باشد:

```text
Output = f(State, Input)
```

این تفاوت را ابتدا روی پروژه‌های ساده مثل Sequence Detector تمرین می‌کنید و بعد در پروژه‌های پیچیده‌تر استفاده می‌کنید.

این مهارت بسیار مهم است، چون از اینجا به بعد پروژه‌ها دیگر فقط «یک مدار» نیستند؛ بلکه **سیستم‌هایی با رفتار مشخص در طول زمان** هستند.

در **Level 5 — Real Digital Systems**، همین FSMها را با Counter، Timer، UART، SPI، PWM و بخش‌های دیگر ترکیب می‌کنید تا پروژه‌هایی مثل **Digital Clock، Stopwatch، Reaction Timer، PWM Generator، Servo Controller و UART Communication System** بسازید.
