# Level 5 — Real Digital Systems

تا اینجا مسیر شما این بود:

```text
Level 1
Logic Gates
   ↓
Level 2
Combinational Circuits
   ↓
Level 3
Sequential Circuits
   ↓
Level 4
Finite State Machines
```

در Level 5 قرار است همه این مهارت‌ها را **در قالب سیستم‌های دیجیتال واقعی‌تر** ترکیب کنید.

دیگر پروژه صرفاً یک `Adder` یا یک `Counter` نیست.

مثلاً می‌خواهید:

> یک Stopwatch بسازید که با دکمه Start شروع شود، با Stop متوقف شود، Reset داشته باشد و زمان را روی نمایشگر نشان دهد.

برای انجام آن باید چند مفهوم را با هم ترکیب کنید:

```text
Button
   ↓
Control FSM
   ↓
Counter
   ↓
Clock Divider
   ↓
Display Decoder
   ↓
Seven Segment
```

پس هدف اصلی این Level:

> **یادگیری طراحی یک سیستم دیجیتال چندبخشی و قابل استفاده است.**

# Project 45 — PWM Generator

این پروژه بسیار مهم است.

## هدف پروژه

تولید سیگنال PWM.

PWM یعنی:

**Pulse Width Modulation**

یک سیگنال دیجیتال داریم که Duty Cycle آن تغییر می‌کند.

مثلاً:

```text
25% Duty Cycle
```

یا:

```text
50%
```

یا:

```text
75%
```

---

## شکل مفهومی

```text
25%:

██░░░░░░
██░░░░░░
██░░░░░░
```

درصد زمان High نسبت به کل Period را Duty Cycle می‌گوییم.

---

## ساختار ساده

یک Counter داشته باشید:

```text
Counter
0 → 1 → 2 → ... → MAX
```

و یک مقدار مقایسه:

```text
Duty
```

اگر:

```text
Counter < Duty
```

باشد:

```text
PWM = 1
```

وگرنه:

```text
PWM = 0
```

---

## چه چیزی یاد می‌گیرید؟

- PWM
    
- Duty Cycle
    
- Counter
    
- Comparator
    
- Timing
    
- Digital Control
    

---

## از شما چه می‌خواهد؟

باید بتوانید:

```text
Frequency
Duty Cycle
Resolution
```

را تعریف کنید.

مثلاً یک PWM با:

```text
8-bit Resolution
```

بسازید.

در این صورت Duty می‌تواند مقادیر مختلفی داشته باشد.

# نتیجه نهایی Level 5

اگر این ۱۰ پروژه را کامل انجام دهید، دیگر فقط VHDL را به‌عنوان یک زبان توصیف سخت‌افزار نمی‌بینید.

دید شما به شکل زیر خواهد شد:

```text
                VHDL
                  │
        ┌─────────┼─────────┐
        ↓         ↓         ↓
     Logic      Timing   Communication
        │         │         │
        ↓         ↓         ↓
      ALU       Counter    UART
                  │          │
                  ↓          ↓
                 FSM        SPI
                  │
                  ↓
              Controller
                  │
                  ↓
            Digital System
```

و این دقیقاً مقدمه ورود به **Level 6 — Advanced VHDL** است؛ جایی که دیگر روی خود زبان و روش‌های حرفه‌ای طراحی تمرکز می‌کنید: **Generics، Packages، Records، Arrays، Functions، Procedures، Components، Generate، Hierarchical Design، RTL Coding و Coding Styles**.
