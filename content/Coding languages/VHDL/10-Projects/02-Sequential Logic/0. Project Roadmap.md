# Level 3 — Sequential Circuits

در دو Level قبلی، مدارهایی ساختید که خروجی آنها فقط به **ورودی فعلی** وابسته بود.

مثلاً در AND Gate:

```text
A + B
 ↓
AND
 ↓
Y
```

اگر ورودی‌ها تغییر کنند، خروجی هم تغییر می‌کند.

اما در این Level با یک مفهوم کاملاً جدید روبه‌رو می‌شوید:

> **حافظه**

مدار شما حالا می‌تواند چیزی از گذشته را نگه دارد.

مسیر این Level:

```text
Clock
  ↓
D Flip-Flop
  ↓
Register
  ↓
Shift Register
  ↓
Counter
  ↓
Up/Down Counter
  ↓
Ring Counter
  ↓
Johnson Counter
  ↓
Frequency Divider
  ↓
Digital Clock
```

پروژه‌های این Level:

```text
21 — D Flip-Flop
22 — Register
23 — Shift Register
24 — Up Counter
25 — Down Counter
26 — Up/Down Counter
27 — Ring Counter
28 — Johnson Counter
29 — Frequency Divider
30 — Digital Clock
```

# Project 21 — D Flip-Flop

## هدف پروژه

این پروژه اولین برخورد شما با **Sequential Logic** است.

در مدارهای قبلی خروجی فقط به ورودی فعلی وابسته بود.

اما D Flip-Flop می‌تواند یک بیت اطلاعات را **ذخیره کند**.

یعنی:

```text
Input
  ↓
D Flip-Flop
  ↓
Stored Value
```

---

## مفهوم اصلی

یک D Flip-Flop معمولاً با Clock کار می‌کند.

```text
        ┌───────────┐
D ─────►│           │
CLK ───►│ D FlipFlop├──► Q
        │           │
        └───────────┘
```

در یک لبه مشخص Clock، مقدار `D` در `Q` ذخیره می‌شود.

---

## چرا Clock مهم است؟

تا اینجا مدارها تقریباً بلافاصله نسبت به تغییر ورودی واکنش نشان می‌دادند.

اما در مدار Sequential، Clock تعیین می‌کند:

> چه زمانی اجازه داریم وضعیت مدار تغییر کند؟

به صورت مفهومی:

```text
D = 1
   ↓
Clock Edge
   ↓
Q = 1
```

---

## چه چیزهایی یاد می‌گیرید؟

- Sequential Logic
    
- Clock
    
- Clock Edge
    
- State
    
- Memory
    
- D Flip-Flop
    
- Signal Timing
    
- Reset
    

---

## از شما چه می‌خواهد؟

باید:

1. مفهوم Flip-Flop را بفهمید.
    
2. تفاوت آن با Logic Gate را توضیح دهید.
    
3. Clock تعریف کنید.
    
4. رفتار D و Q را مشخص کنید.
    
5. Reset را در طراحی بررسی کنید.
    
6. VHDL بنویسید.
    
7. Testbench بسازید.
    
8. Clock تولید کنید.
    
9. Waveform را بررسی کنید.
    

---

## در Simulation چه چیزی باید ببینید؟

اگر:

```text
D = 1
```

باشد، لزوماً Q همان لحظه تغییر نمی‌کند.

باید رفتار آن نسبت به Clock را مشاهده کنید.

این اولین جایی است که باید به **Timing** توجه کنید.

# مهم‌ترین چیزی که باید از این Level یاد بگیرید

تا Level 2 سؤال اصلی شما این بود:

> «اگر ورودی‌ها این باشند، خروجی چه می‌شود؟»

اما در Level 3 سؤال جدیدی اضافه می‌شود:

> **«مدار الان در چه وضعیتی است و Clock بعدی چه تغییری در وضعیت آن ایجاد می‌کند؟»**

این تغییر طرز فکر بسیار مهم است.

از اینجا به بعد وارد دنیای واقعی‌تر طراحی دیجیتال می‌شوید:

```text
Combinational Logic
       +
Memory
       +
Clock
       ↓
Sequential System
```

و همین موضوع زمینه را برای **Level 4 — Finite State Machines** آماده می‌کند؛ جایی که دیگر به‌جای اینکه فقط Counter بسازید، به مدار می‌گویید:

```text
State A
  ↓
شرط
  ↓
State B
  ↓
شرط
  ↓
State C
```

و از اینجا VHDL کم‌کم وارد طراحی **کنترلرهای واقعی** مثل چراغ راهنمایی، دستگاه فروش، قفل دیجیتال و آسانسور می‌شود.
