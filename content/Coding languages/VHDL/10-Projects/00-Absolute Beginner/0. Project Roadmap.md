# Project 08 — 2:1 Multiplexer

اینجا یک تغییر مهم اتفاق می‌افتد.

تا پروژه 07 شما بیشتر روی **Logic Gates** کار می‌کردید.

---

# هدف پروژه

یاد می‌گیرید چگونه از بین چند ورودی، **یکی را انتخاب کنید**.

یک Multiplexer یا MUX را می‌توانید مانند یک انتخاب‌کننده تصور کنید.

---

## ساختار

یک MUX دو ورودی داده دارد:

```text
D0
D1
```

یک Select دارد:

```text
S
```

و یک خروجی:

```text
Y
```

به شکل مفهومی:

```text
       ┌─────────┐
D0 ───►│         │
       │   MUX   ├─── Y
D1 ───►│         │
       │         │
S  ───►│ Select  │
       └─────────┘
```

---

## رفتار

اگر:

```text
S = 0
```

خروجی باید:

```text
Y = D0
```

باشد.

اگر:

```text
S = 1
```

خروجی باید:

```text
Y = D1
```

باشد.

---

## Truth Table

|S|Y|
|---|---|
|0|D0|
|1|D1|

توجه کنید که اینجا جدول Truth Table کمی متفاوت از گیت‌های قبلی است، چون خروجی به مقدار ورودی انتخاب‌شده وابسته است.

---

## چرا این پروژه مهم است؟

چون برای اولین بار با مفهوم:

**Selection**

آشنا می‌شوید.

تا الان گیت‌ها فقط بر اساس ورودی‌ها یک خروجی منطقی تولید می‌کردند.

اما MUX می‌گوید:

> «از بین چند مسیر، یکی را انتخاب کن.»

این مفهوم در تقریباً تمام سیستم‌های دیجیتال بزرگ وجود دارد.

---

## چه چیزهایی یاد می‌گیرید؟

- Multiplexer
    
- Select Signal
    
- Data Input
    
- Conditional Logic
    
- ساخت مدار از چند گیت
    
- Boolean Expression
    
- VHDL Data Selection
    

---

## کاری که باید انجام دهید

باید:

1. مفهوم MUX را توضیح دهید.
    
2. ورودی‌های `D0` و `D1` را مشخص کنید.
    
3. Select را مشخص کنید.
    
4. رفتار خروجی را مشخص کنید.
    
5. مدار منطقی را طراحی کنید.
    
6. VHDL بنویسید.
    
7. Testbench ایجاد کنید.
    
8. حالت‌های مختلف Data و Select را تست کنید.
    
9. Waveform را بررسی کنید.
    

---

## نکته مهم در Testbench

در گیت‌های قبلی چهار حالت کافی بود.

اما در MUX باید علاوه بر Select، **مقدار داده‌ها** را نیز تغییر دهید.

مثلاً:

```text
D0 = 0
D1 = 1
S  = 0

Y باید 0 باشد.
```

سپس:

```text
D0 = 0
D1 = 1
S  = 1

Y باید 1 باشد.
```

بنابراین Testbench شما باید رفتار انتخاب مسیر را به‌خوبی نشان دهد.

# Project 09 — 4:1 Multiplexer

# هدف پروژه

در پروژه قبلی بین:

```text
D0
D1
```

یکی را انتخاب می‌کردید.

حالا باید بین چهار ورودی انتخاب کنید:

```text
D0
D1
D2
D3
```

برای انتخاب چهار ورودی به **دو Select Bit** نیاز دارید:

```text
S1

```

---

## ساختار

```text
D0 ─────┐
D1 ─────┤
D2 ─────┤──► 4:1 MUX ───► Y
```

---

## رفتار

دو بیت Select مشخص می‌کنند کدام ورودی به خروجی وصل شود:

|S1|S0|Y|
|---|---|---|
|0|0|D0|
|0|1|D1|
|1|0|D2|
|1|1|D3|

---

# چرا این پروژه مهم است؟

اینجا برای اولین بار با یک مفهوم بسیار مهم مواجه می‌شوید:

> تعداد Selectها تعیین می‌کند چند ورودی را می‌توان انتخاب کرد.

برای دو Select:

```text
2² = 4
```

بنابراین چهار ورودی داریم.

این مفهوم بعدها در طراحی‌های بسیار بزرگ‌تر استفاده می‌شود.

# کاری که باید انجام دهید

ابتدا باید مشخص کنید:

```text
D0
D1
D2
D3
```

چه هستند.

سپس:

```text
S1
S0
```

را به‌عنوان Select در نظر بگیرید.

بعد Truth Table را بسازید:

|S1|S0|Selected Input|
|---|---|---|
|0|0|D0|
|0|1|D1|
|1|0|D2|
|1|1|D3|

سپس باید مدار را با VHDL توصیف کنید.

---

# Testbench این پروژه

در Testbench باید نشان دهید که هر چهار مقدار قابل انتخاب هستند.

برای مثال:

```text
D0 = 0
D1 = 1
D2 = 0
D3 = 1
```

سپس:

```text
S1 S0
 00 → Y = D0
 01 → Y = D1
 10 → Y = D2
 11 → Y = D3
```

بعد باید مقادیر Data را هم تغییر دهید تا مطمئن شوید MUX واقعاً ورودی انتخاب‌شده را منتقل می‌کند.

# Challenge پیشنهادی

بعد از اینکه 4:1 MUX را ساختید، سعی کنید آن را با چند **2:1 MUX** بسازید.

ایده:

```text
D0 ──┐
     ├─ 2:1 ──┐
D1 ──┘        │
              ├─ 2:1 ── Y
D2 ──┐        │
     ├─ 2:1 ──┘
D3 ──┘
```

این Challenge بسیار مهم است، چون برای اولین بار با **ساخت یک Component بزرگ‌تر از Componentهای کوچک‌تر** مواجه می‌شوید.

---

# مسیر یادگیری این ۹ پروژه

حالا اگر کل Level را نگاه کنید، مسیر شما این است:

```text
01 AND
 │
 ├── یادگیری اولین Logic Gate
 │
 ▼
02 OR
 │
 ├── Logic دیگری
 │
 ▼
03 NOT
 │
 ├── Inversion
 │
 ▼
04 NAND
 │
 ├── ترکیب AND + NOT
 │
 ▼
05 NOR
 │
 ├── ترکیب OR + NOT
 │
 ▼
06 XOR
 │
 ├── Difference Logic
 │
 ▼
07 XNOR
 │
 ├── Equality Logic
 │
 ▼
08 2:1 MUX
 │
 ├── Selection
 │
 ▼
09 4:1 MUX
 │
 └── Multiple Selection
```

بنابراین این ۹ پروژه فقط ۹ مدار تصادفی نیستند.

آنها یک مسیر آموزشی هستند:

```text
Simple Logic
     ↓
Logic Combination
     ↓
Comparison Logic
     ↓
Selection
     ↓
Digital Components
```

# بعد از این ۹ پروژه چه چیزی بلد هستید؟

اگر این Level را درست انجام دهید، باید بتوانید:

### از نظر منطق دیجیتال

- AND را توضیح دهید.
    
- OR را توضیح دهید.
    
- NOT را توضیح دهید.
    
- NAND و NOR را تحلیل کنید.
    
- XOR و XNOR را تحلیل کنید.
    
- مفهوم Multiplexer را توضیح دهید.
    
- Truth Table بسازید.
    
- Boolean Expression بنویسید.
    
- مدارهای ساده را از گیت‌ها ترکیب کنید.
    

### از نظر VHDL

با مفاهیم پایه زیر آشنا شده‌اید:

```text
Entity
Architecture
Port
Input
Output
std_logic
Signal
Concurrent Assignment
Logic Operators
```

### از نظر Verification

می‌توانید:

```text
Testbench
   ↓
Stimulus
   ↓
Simulation
   ↓
Waveform
   ↓
Verification
```

را انجام دهید.

# مهم‌تر از همه: طرز فکر شما تغییر می‌کند

در ابتدای Level ممکن است با خودتان بگویید:

> «باید کد AND Gate را یاد بگیرم.»

اما در پایان این ۹ پروژه باید به این مرحله برسید:

> «من اول رفتار سخت‌افزار را مشخص می‌کنم، بعد آن را به منطق تبدیل می‌کنم، سپس با VHDL توصیفش می‌کنم و در نهایت با Testbench بررسی می‌کنم.»

این دقیقاً همان طرز فکری است که برای پروژه‌های بعدی لازم دارید.

---

# چیزی که در Level بعدی تغییر می‌کند

بعد از این ۹ پروژه، دیگر قرار نیست فقط گیت بسازید.

در **Level 2 — Basic Digital Design** وارد مدارهایی می‌شوید که از همین گیت‌ها و مفاهیم ساخته می‌شوند:

```text
Half Adder
     ↓
Full Adder
     ↓
4-bit Adder
     ↓
Subtractor
     ↓
Comparator
     ↓
Priority Encoder
     ↓
ALU
```

یعنی دانشجو برای اولین بار از:

**«یک گیت منطقی»**

به:

**«یک مدار دیجیتال واقعی که چند بخش دارد»**

حرکت می‌کند.
