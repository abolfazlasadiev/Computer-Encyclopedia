# Project 03 — NOT Gate

## 1. Goal

در این پروژه سومین مدار دیجیتال خود را با **VHDL** طراحی می‌کنیم: گیت `NOT`.

تا اینجا:

```text
AND Gate → دو ورودی، یک خروجی
OR Gate  → دو ورودی، یک خروجی
```

اما NOT Gate متفاوت است:

```text
NOT Gate → یک ورودی، یک خروجی
```

هدف پروژه این است که یاد بگیریم چگونه یک سیگنال را **معکوس (Invert)** کنیم.

در پایان پروژه می‌توانیم:

- عملکرد NOT Gate را توضیح دهیم.
    
- Truth Table آن را بنویسیم.
    
- مفهوم Inversion را درک کنیم.
    
- یک NOT Gate با VHDL طراحی کنیم.
    
- برای آن Testbench بنویسیم.
    
- Simulation و Waveform را بررسی کنیم.

# 3. What Is a NOT Gate?

NOT Gate یک گیت منطقی با **یک ورودی** و **یک خروجی** است.

```text
A ─────► NOT ─────► Y
```

وظیفه آن بسیار ساده است:

> اگر ورودی `0` باشد، خروجی `1` می‌شود؛ و اگر ورودی `1` باشد، خروجی `0` می‌شود.

یعنی خروجی همیشه **معکوس ورودی** است.

---

# 4. Symbol

نمایش ساده:

```text
        ┌─────┐
A ─────►│ NOT ├────► Y
        └─────┘
```

در مدارهای منطقی معمولاً NOT Gate را با یک مثلث یا شکل گیت همراه با یک دایره کوچک در خروجی نمایش می‌دهند.

آن دایره کوچک مفهوم **Inversion** را نشان می‌دهد.

---

# 5. Truth Table

از آنجا که NOT Gate فقط یک ورودی دارد، فقط دو حالت ممکن داریم:

|A|Y|
|---|---|
|0|1|
|1|0|

بنابراین:

```text
A = 0 → Y = 1
A = 1 → Y = 0
```

---

# 6. Boolean Equation

معادله منطقی NOT:

```text
Y = NOT A
```

یا:

```text
Y = Ā
```

در VHDL از operator زیر استفاده می‌کنیم:

```vhdl
not
```

بنابراین:

```vhdl
Y <= not A;
```

این مهم‌ترین خط این پروژه است.

---

# 7. Hardware View

از دید سخت‌افزار:

```text
A ─────┐
       │
      NOT ───── Y
       │
```

اما رفتار آن این است:

```text
0 → 1
1 → 0
```

پس اگر:

```text
A = 0
```

خروجی:

```text
Y = 1
```

و اگر:

```text
A = 1
```

خروجی:

```text
Y = 0
```

# 8. VHDL Design

کد کامل NOT Gate:

```vhdl
library ieee;
use ieee.std_logic_1164.all;

entity not_gate is
    port (
        A : in  std_logic;
        Y : out std_logic
    );
end entity not_gate;

architecture rtl of not_gate is
begin

    Y <= not A;

end architecture rtl;
```

# 19. AND, OR, NOT

حالا سه گیت اول را کنار هم قرار دهیم:

```text
AND
A ───┐
     AND ─── Y
B ───┘
```

```text
OR
A ───┐
     OR ─── Y
B ───┘
```

```text
NOT
A ─── NOT ─── Y
```

و در VHDL:

```vhdl
-- AND
Y <= A and B;

-- OR
Y <= A or B;

-- NOT
Y <= not A;
```

این سه operator از مهم‌ترین operatorهای منطقی VHDL هستند.

# 20. NOT به‌عنوان Inverter

یکی از نام‌های رایج NOT Gate:

> **Inverter**

است.

چرا؟

چون سیگنال را معکوس می‌کند:

```text
Logic 0 → Logic 1
Logic 1 → Logic 0
```

به همین دلیل ممکن است در منابع مختلف به جای:

```text
NOT Gate
```

عبارت:

```text
Inverter
```

را نیز ببینید.

---

# 21. Double Inversion

یک مفهوم جالب:

اگر یک سیگنال را دو بار NOT کنیم، دوباره به مقدار اصلی می‌رسیم.

مثلاً:

```text
A = 0

NOT A → 1

NOT 1 → 0
```

یا:

```text
A = 1

NOT A → 0

NOT 0 → 1
```

در VHDL:

```vhdl
Y <= not (not A);
```

از نظر منطقی:

```text
NOT(NOT(A)) = A
```

این مفهوم در طراحی مدارهای منطقی بسیار مهم است.

# 22. Common Mistakes

## اشتباه 1 — استفاده از `not` روی چند ورودی

NOT Gate فقط یک ورودی منطقی دارد.

درست:

```vhdl
Y <= not A;
```

---

## اشتباه 2 — فراموش کردن inversion

اگر بنویسیم:

```vhdl
Y <= A;
```

این دیگر NOT Gate نیست.

این فقط ورودی را مستقیماً به خروجی متصل می‌کند.

```text
A = 0 → Y = 0
A = 1 → Y = 1
```

اما NOT باید:

```text
A = 0 → Y = 1
A = 1 → Y = 0
```

باشد.

---

## اشتباه 3 — اشتباه گرفتن `not` با `!=`

در VHDL برای NOT منطقی از:

```vhdl
not
```

استفاده می‌کنیم:

```vhdl
Y <= not A;
```
