# مدارهای ترکیبی (Combinational Circuits) — نسخه کامل و جامع

## مقدمه: از گیت‌ها تا سیستم‌ها

تا اینجا یاد گرفته‌اید که:
- **باینری (Binary)** به ما گفت داده‌ها از ۰ و ۱ تشکیل شده‌اند
- **گیت‌های منطقی (Logic Gates)** به ما گفت چگونه با ۰ و ۱ عملیات منطقی انجام دهیم
- **جدول درستی (Truth Table)** به ما گفت چگونه رفتار یک مدار را مشخص کنیم
- **جبر بولی (Boolean Algebra)** به ما گفت چگونه عبارات منطقی را ساده کنیم

اما سوال اساسی اینجاست: **چگونه از این اجزای ساده، سیستم‌های مفید و کاربردی بسازیم؟**

پاسخ در **مدارهای ترکیبی (Combinational Circuits)** نهفته است. مدارهای ترکیبی، بلوک‌های سازنده اصلی تمام سیستم‌های دیجیتال هستند. از یک ماشین‌حساب ساده تا یک پردازنده قدرتمند، همه از ترکیب مدارهای ترکیبی ساخته می‌شوند.

---

## ۱. مدار ترکیبی چیست؟ تعریف جامع

**مدار ترکیبی (Combinational Circuit)** مداری است که در آن **خروجی‌ها فقط به مقدار فعلی ورودی‌ها بستگی دارند** و هیچ حافظه‌ای از ورودی‌های قبلی ندارند.

### تعریف ریاضی

یک مدار ترکیبی را می‌توان به صورت یک **تابع** در نظر گرفت:

```
Y = F(X₁, X₂, ..., Xₙ)
```

که در آن:
- X₁, X₂, ..., Xₙ = ورودی‌های فعلی
- Y = خروجی فعلی
- F = یک تابع منطقی (ترکیبی از گیت‌ها)

### ویژگی‌های کلیدی

1. **بدون حافظه (Memoryless):** خروجی به گذشته بستگی ندارد
2. **بدون Clock:** نیازی به سیگنال ساعت ندارد (در حالت ایده‌آل)
3. **تأخیر ثابت:** خروجی پس از یک تأخیر مشخص (Propagation Delay) تغییر می‌کند
4. **قابل توصیف با جدول درستی:** می‌توان تمام حالت‌ها را لیست کرد

### قیاس با دنیای واقعی

یک مدار ترکیبی مانند **یک دستگاه فروش ساده** است:
- ورودی: سکه‌ای که وارد می‌کنید
- خروجی: نوشیدنی که دریافت می‌کنید
- هیچ حافظه‌ای: هر بار که سکه وارد می‌شود، نوشیدنی خارج می‌شود

در مقابل، یک ماشین‌حساب که تعداد سکه‌ها را به خاطر می‌سپارد، یک مدار **ترتیبی (Sequential)** است.

## ۲. مدار ترکیبی در مقابل مدار ترتیبی

این تفاوت اساسی‌ترین مفهوم در طراحی دیجیتال است:

| ویژگی | مدار ترکیبی (Combinational) | مدار ترتیبی (Sequential) |
|-------|---------------------------|-------------------------|
| **حافظه** | ندارد | دارد |
| **وابستگی به گذشته** | خیر | بله |
| **سیگنال Clock** | معمولاً ندارد | دارد |
| **خروجی** | تابع ورودی‌های فعلی | تابع ورودی‌ها + حالت فعلی |
| **مثال** | AND Gate, Adder, MUX | Flip-Flop, Register, Counter |
| **پیچیدگی** | ساده‌تر | پیچیده‌تر |
| **طراحی** | با جدول درستی و جبر بولی | با جدول حالت و نمودار حالت |

### تصویر مفهومی

**مدار ترکیبی:**
```
ورودی‌ها ────→ [گیت‌های منطقی] ────→ خروجی‌ها
                  (بدون حافظه)
```

**مدار ترتیبی:**
```
ورودی‌ها ────→ [گیت‌های منطقی] ────→ خروجی‌ها
                  ↑        ↓
                  └── [حافظه/State] ──┘
```

## ۳. مدل‌سازی ریاضی مدارهای ترکیبی

### ۳.۱. تابع چندمتغیره

یک مدار ترکیبی با n ورودی و m خروجی را می‌توان به صورت m تابع مجزا در نظر گرفت:

```
Y₁ = F₁(X₁, X₂, ..., Xₙ)
Y₂ = F₂(X₁, X₂, ..., Xₙ)
...
Yₘ = Fₘ(X₁, X₂, ..., Xₙ)
```

### ۳.۲. حداقل و حداکثر تأخیر

در یک مدار ترکیبی، خروجی **بلافاصله** تغییر نمی‌کند. بین تغییر ورودی و تغییر خروجی، یک تأخیر به نام **تأخیر انتشار (Propagation Delay)** وجود دارد.

```
ورودی: ──┐  ┌──────────
          │  │
خروجی: ──┴──┴──────────
          │
          │← t_pd →
```

### ۳.۳. مسیر بحرانی (Critical Path)

در یک مدار ترکیبی، **طولانی‌ترین مسیر** از ورودی به خروجی را **مسیر بحرانی** می‌نامند. این مسیر، حداکثر تأخیر مدار را تعیین می‌کند.

```
ورودی ──→ [گیت ۱] ──→ [گیت ۲] ──→ [گیت ۳] ──→ خروجی
          ↑                    ↑
          └── مسیر بحرانی ──────┘
```

## ۴. روش طراحی مدارهای ترکیبی

### فرآیند گام‌به‌گام

```
مرحله ۱: تعریف مسئله
    ↓
مرحله ۲: شناسایی ورودی‌ها و خروجی‌ها
    ↓
مرحله ۳: رسم جدول درستی
    ↓
مرحله ۴: استخراج عبارت بولی (SOP/POS)
    ↓
مرحله ۵: ساده‌سازی (جبر بولی یا K-Map)
    ↓
مرحله ۶: طراحی مدار با گیت‌ها
    ↓
مرحله ۷: پیاده‌سازی در VHDL
    ↓
مرحله ۸: شبیه‌سازی و تأیید
```

### مثال کامل: تشخیص عدد زوج

**مسئله:** مداری طراحی کنید که تشخیص دهد یک عدد ۳ بیتی زوج است یا فرد.

**مرحله ۱:** ورودی‌ها = A, B, C (عدد ۳ بیتی)، خروجی = Y (۱ اگر زوج)

**مرحله ۲:** جدول درستی

| A | B | C | عدد | Y (زوج؟) |
|---|---|---|---|:---:|
| ۰ | ۰ | ۰ | ۰ | ۱ |
| ۰ | ۰ | ۱ | ۱ | ۰ |
| ۰ | ۱ | ۰ | ۲ | ۱ |
| ۰ | ۱ | ۱ | ۳ | ۰ |
| ۱ | ۰ | ۰ | ۴ | ۱ |
| ۱ | ۰ | ۱ | ۵ | ۰ |
| ۱ | ۱ | ۰ | ۶ | ۱ |
| ۱ | ۱ | ۱ | ۷ | ۰ |

**مرحله ۳:** عبارت بولی
```
Y = ¬C
```

**مرحله ۴:** مدار
```
C ──── NOT ──── Y
```

## ۵. مدارهای ترکیبی پایه

### ۵.۱. Half Adder (نیم‌جمع‌کننده)

Half Adder دو بیت را جمع می‌کند و دو خروجی دارد: Sum و Carry.

| A | B | Sum | Carry |
|---|---|:---:|:---:|
| ۰ | ۰ | ۰ | ۰ |
| ۰ | ۱ | ۱ | ۰ |
| ۱ | ۰ | ۱ | ۰ |
| ۱ | ۱ | ۰ | ۱ |

**معادلات:**
```
Sum   = A ⊕ B
Carry = A · B
```

**مدار:**
```
A ────┬──── XOR ──── Sum
      │
B ────┼──── AND ──── Carry
```

**VHDL:**
```vhdl
sum   <= a xor b;
carry <= a and b;
```

---

### ۵.۲. Full Adder (جمع‌کننده کامل)

Full Adder سه بیت را جمع می‌کند: دو بیت ورودی + نقلی ورودی.

| A | B | Cin | Sum | Cout |
|---|---|:---:|:---:|:---:|
| ۰ | ۰ | ۰ | ۰ | ۰ |
| ۰ | ۰ | ۱ | ۱ | ۰ |
| ۰ | ۱ | ۰ | ۱ | ۰ |
| ۰ | ۱ | ۱ | ۰ | ۱ |
| ۱ | ۰ | ۰ | ۱ | ۰ |
| ۱ | ۰ | ۱ | ۰ | ۱ |
| ۱ | ۱ | ۰ | ۰ | ۱ |
| ۱ | ۱ | ۱ | ۱ | ۱ |

**معادلات:**
```
Sum   = A ⊕ B ⊕ Cin
Cout  = (A · B) + (A · Cin) + (B · Cin)
```

**VHDL:**
```vhdl
sum  <= a xor b xor cin;
cout <= (a and b) or (a and cin) or (b and cin);
```

---

### ۵.۳. ساخت Adder چندبیتی (Ripple Carry Adder)

با اتصال چند Full Adder به صورت زنجیره‌ای، می‌توان یک جمع‌کننده چندبیتی ساخت.

```
A₀ ────┐
B₀ ────┤ Full    ──── S₀
Cin ───┤ Adder   ──── C₁
       └─────────┘
            │
            ↓
A₁ ────┐
B₁ ────┤ Full    ──── S₁
C₁ ───┤ Adder   ──── C₂
       └─────────┘
            │
            ↓
           ...
```

**مشکل Ripple Carry Adder:** تأخیر زیاد چون نقلی باید از یک مرحله به مرحله بعد منتقل شود.

**راه‌حل:** Carry Lookahead Adder (که تأخیر کمتری دارد).

**VHDL برای ۴ بیتی:**
```vhdl
library ieee;
use ieee.std_logic_1164.all;

entity adder_4bit is
    port (
        a, b : in  std_logic_vector(3 downto 0);
        cin  : in  std_logic;
        sum  : out std_logic_vector(3 downto 0);
        cout : out std_logic
    );
end entity;

architecture structural of adder_4bit is
    component full_adder
        port (a, b, cin : in std_logic; sum, cout : out std_logic);
    end component;
    signal c : std_logic_vector(4 downto 0);
begin
    c(0) <= cin;
    gen: for i in 0 to 3 generate
        fa: full_adder
            port map (a(i), b(i), c(i), sum(i), c(i+1));
    end generate;
    cout <= c(4);
end architecture;
```

### ۵.۴. Half Subtractor (نیم‌تفریق‌کننده)

Full Subtractor سه بیت را تفریق می‌کند.

| A | B | Bin | Diff | Bout |
|---|---|:---:|:---:|:---:|
| ۰ | ۰ | ۰ | ۰ | ۰ |

## ۶. Multiplexer (MUX) — انتخاب‌گر

### ۶.۱. MUX ۲ به ۱

یک MUX ۲ به ۱ دو ورودی داده (A و B) و یک ورودی انتخاب (S) دارد.

| S | Y |
|---|:---:|
| ۰ | A |
| ۱ | B |

**معادله:**
```
Y = ¬S · A + S · B
```

**مدار:**
```
A ───┐
     │
     AND ──┐
¬S ──┘     │
           OR ─── Y
S ───┐     │
     │
     AND ──┘
B ───┘
```

**VHDL:**
```vhdl
y <= a when s = '0' else b;
```

یا:
```vhdl
y <= (not s and a) or (s and b);
```

---

### ۶.۲. MUX ۴ به ۱

یک MUX ۴ به ۱ چهار ورودی داده و دو ورودی انتخاب دارد.

| S₁ | S₀ | Y |
|:--:|:--:|:---:|
| ۰ | ۰ | D₀ |
| ۰ | ۱ | D₁ |
| ۱ | ۰ | D₂ |
| ۱ | ۱ | D₃ |

**معادله:**
```
Y = ¬S₁·¬S₀·D₀ + ¬S₁·S₀·D₁ + S₁·¬S₀·D₂ + S₁·S₀·D₃
```

**VHDL:**
```vhdl
with s select
    y <= d0 when "00",
         d1 when "01",
         d2 when "10",
         d3 when "11";
```

---

### ۶.۳. کاربردهای MUX

۱. **انتخاب منبع داده:** انتخاب بین چندین ورودی
۲. **مسیریابی داده:** هدایت داده به مسیرهای مختلف
۳. **پیاده‌سازی توابع منطقی:** هر تابع بولی را می‌توان با MUX پیاده‌سازی کرد
۴. **پردازنده‌ها:** انتخاب بین ثبات‌ها، انتخاب عملیات ALU
۵. **حافظه:** انتخاب بین بانک‌های حافظه

## ۷. Demultiplexer (DEMUX) — توزیع‌کننده

DEMUX برعکس MUX عمل می‌کند: یک ورودی را به یکی از چندین خروجی هدایت می‌کند.

### DEMUX ۱ به ۴

| S₁ | S₀ | خروجی فعال |
|:--:|:--:|:---------:|
| ۰ | ۰ | Y₀ |
| ۰ | ۱ | Y₁ |
| ۱ | ۰ | Y₂ |
| ۱ | ۱ | Y₃ |

**معادلات:**
```
Y₀ = ¬S₁·¬S₀·D
Y₁ = ¬S₁·S₀·D
Y₂ = S₁·¬S₀·D
Y₃ = S₁·S₀·D
```

## ۸. Decoder (رمزگشا)

Decoder یک ورودی n بیتی را به ۲ⁿ خروجی تبدیل می‌کند. در هر لحظه فقط یک خروجی فعال است.

### ۲-to-۴ Decoder

| A | B | Y₀ | Y₁ | Y₂ | Y₃ |
|---|---|:---:|:---:|:---:|:---:|
| ۰ | ۰ | ۱ | ۰ | ۰ | ۰ |
| ۰ | ۱ | ۰ | ۱ | ۰ | ۰ |
| ۱ | ۰ | ۰ | ۰ | ۱ | ۰ |
| ۱ | ۱ | ۰ | ۰ | ۰ | ۱ |

**معادلات:**
```
Y₀ = ¬A·¬B
Y₁ = ¬A·B
Y₂ = A·¬B
Y₃ = A·B
```

**کاربردها:**
- **آدرس‌دهی حافظه:** انتخاب یک خانه حافظه خاص
- **دیکدر ۷-سگمنت:** تبدیل BCD به نمایش ۷-سگمنت
- **تولید سیگنال کنترل:** فعال کردن مسیرهای مختلف در CPU

## ۹. Encoder (رمزگذار)

Encoder برعکس Decoder عمل می‌کند: ورودی‌های ۲ⁿ را به خروجی n بیتی تبدیل می‌کند.

### ۴-to-۲ Encoder

| D₀ | D₁ | D₂ | D₃ | A | B |
|:--:|:--:|:--:|:--:|:---:|:---:|
| ۱ | ۰ | ۰ | ۰ | ۰ | ۰ |
| ۰ | ۱ | ۰ | ۰ | ۰ | ۱ |
| ۰ | ۰ | ۱ | ۰ | ۱ | ۰ |
| ۰ | ۰ | ۰ | ۱ | ۱ | ۱ |

**معادلات:**
```
A = D₂ + D₃
B = D₁ + D₃
```

---

### Priority Encoder (رمزگذار اولویت‌دار)

در Encoder معمولی، اگر چند ورودی همزمان فعال باشند، خروجی نامشخص است. Priority Encoder اولویت را مشخص می‌کند.

**مثال: ۴-to-۲ Priority Encoder (با اولویت D₃ > D₂ > D₁ > D₀)**

| D₃ | D₂ | D₁ | D₀ | A | B | Valid |
|:--:|:--:|:--:|:--:|:---:|:---:|:---:|
| ۰ | ۰ | ۰ | ۰ | X | X | ۰ |
| ۰ | ۰ | ۰ | ۱ | ۰ | ۰ | ۱ |
| ۰ | ۰ | ۱ | X | ۰ | ۱ | ۱ |
| ۰ | ۱ | X | X | ۱ | ۰ | ۱ |
| ۱ | X | X | X | ۱ | ۱ | ۱ |

**معادلات:**
```
A = D₂ + D₃
B = D₁·¬D₂ + D₃
Valid = D₀ + D₁ + D₂ + D₃
```

## ۱۰. Comparator (مقایسه‌کننده)

Comparator دو عدد را مقایسه می‌کند.

### مقایسه‌کننده ۱ بیتی

| A | B | A>B | A=B | A<B |
|---|---|:---:|:---:|:---:|
| ۰ | ۰ | ۰ | ۱ | ۰ |
| ۰ | ۱ | ۰ | ۰ | ۱ |
| ۱ | ۰ | ۱ | ۰ | ۰ |
| ۱ | ۱ | ۰ | ۱ | ۰ |

**معادلات:**
```
A>B = A · ¬B
A=B = ¬(A ⊕ B) = A·B + ¬A·¬B
A<B = ¬A · B
```

### مقایسه‌کننده ۴ بیتی

برای مقایسه دو عدد ۴ بیتی A[3:0] و B[3:0]:

```
A>B = (A₃>B₃) + (A₃=B₃)·(A₂>B₂) + (A₃=B₃)·(A₂=B₂)·(A₁>B₁) + ...
A=B = (A₃=B₃)·(A₂=B₂)·(A₁=B₁)·(A₀=B₀)
A<B = (A₃<B₃) + (A₃=B₃)·(A₂<B₂) + ...
```

**VHDL:**
```vhdl
process(a, b)
begin
    if a > b then
        agtb <= '1'; aeqb <= '0'; altb <= '0';
    elsif a < b then
        agtb <= '0'; aeqb <= '0'; altb <= '1';
    else
        agtb <= '0'; aeqb <= '1'; altb <= '0';
    end if;
end process;
```

## ۱۱. Parity Generator و Parity Checker

### Parity Generator

یک بیت Parity به داده اضافه می‌کند تا تعداد ۱ها زوج یا فرد شود.

**Parity Generator زوج (Even) برای ۳ بیت:**
```
P = A ⊕ B ⊕ C
```

| A | B | C | P (Even) | تعداد ۱ها |
|---|---|---|:---:|:---:|
| ۰ | ۰ | ۰ | ۰ | ۰ |
| ۰ | ۰ | ۱ | ۱ | ۲ |
| ۰ | ۱ | ۰ | ۱ | ۲ |
| ۰ | ۱ | ۱ | ۰ | ۲ |
| ۱ | ۰ | ۰ | ۱ | ۲ |
| ۱ | ۰ | ۱ | ۰ | ۲ |
| ۱ | ۱ | ۰ | ۰ | ۲ |
| ۱ | ۱ | ۱ | ۱ | ۴ |

### Parity Checker

بررسی می‌کند که Parity دریافتی با داده مطابقت دارد یا خیر.

**Parity Checker زوج:**
```
Error = A ⊕ B ⊕ C ⊕ P
```
اگر Error = ۱، خطا رخ داده است.

## ۱۲. Seven-Segment Decoder

یک دیکدر ۷-سگمنت یک عدد BCD (۴ بیتی) را به سیگنال‌های نمایشگر ۷-سگمنت تبدیل می‌کند.

### بخش‌های نمایشگر ۷-سگمنت

```
     a
   ┌────┐
 f │    │ b
   ├────┤
   │    │
 e │    │ c
   └────┘
     d
```

### جدول درستی (برای نمایش اعداد ۰-۹)

| عدد | a | b | c | d | e | f | g |
|:---:|:-:|:-:|:-:|:-:|:-:|:-:|:-:|
| ۰ | ۱ | ۱ | ۱ | ۱ | ۱ | ۱ | ۰ |
| ۱ | ۰ | ۱ | ۱ | ۰ | ۰ | ۰ | ۰ |
| ۲ | ۱ | ۱ | ۰ | ۱ | ۱ | ۰ | ۱ |
| ۳ | ۱ | ۱ | ۱ | ۱ | ۰ | ۰ | ۱ |
| ۴ | ۰ | ۱ | ۱ | ۰ | ۰ | ۱ | ۱ |
| ۵ | ۱ | ۰ | ۱ | ۱ | ۰ | ۱ | ۱ |
| ۶ | ۱ | ۰ | ۱ | ۱ | ۱ | ۱ | ۱ |
| ۷ | ۱ | ۱ | ۱ | ۰ | ۰ | ۰ | ۰ |
| ۸ | ۱ | ۱ | ۱ | ۱ | ۱ | ۱ | ۱ |
| ۹ | ۱ | ۱ | ۱ | ۱ | ۰ | ۱ | ۱ |

### VHDL برای Seven-Segment Decoder

```vhdl
library ieee;
use ieee.std_logic_1164.all;

entity seven_seg_decoder is
    port (
        bcd : in  std_logic_vector(3 downto 0);
        seg : out std_logic_vector(6 downto 0)  -- a, b, c, d, e, f, g
    );
end entity;

architecture rtl of seven_seg_decoder is
begin
    process(bcd)
    begin
        case bcd is
            when "0000" => seg <= "1111110";  -- 0
            when "0001" => seg <= "0110000";  -- 1
            when "0010" => seg <= "1101101";  -- 2
            when "0011" => seg <= "1111001";  -- 3
            when "0100" => seg <= "0110011";  -- 4
            when "0101" => seg <= "1011011";  -- 5
            when "0110" => seg <= "1011111";  -- 6
            when "0111" => seg <= "1110000";  -- 7
            when "1000" => seg <= "1111111";  -- 8
            when "1001" => seg <= "1111011";  -- 9
            when others => seg <= "0000000";  -- غیرفعال
        end case;
    end process;
end architecture;
```

## ۱۳. Barrel Shifter (شیفت‌دهنده بشکه‌ای)

Barrel Shifter یک مدار ترکیبی است که می‌تواند یک عدد را به هر تعداد بیت (۰ تا n-1) در یک چرخه شیفت دهد.

**مشخصات:**
- ورودی: عدد n بیتی
- خروجی: عدد شیفت‌یافته
- کنترل: تعداد بیت‌های شیفت

**ساختار با MUX:**

```
            ┌─────┐
Input ─────→│ MUX │──→ Shift by 1
            └─────┘
                  │
            ┌─────┐
            │ MUX │──→ Shift by 2
            └─────┘
                  │
            ┌─────┐
            │ MUX │──→ Shift by 4
            └─────┘
                  │
                 Output
```

## ۱۴. ALU (Arithmetic Logic Unit)

ALU قلب هر پردازنده است. یک ALU ساده می‌تواند عملیات‌های زیر را انجام دهد:

- **محاسباتی:** ADD, SUBTRACT
- **منطقی:** AND, OR, XOR, NOT
- **مقایسه‌ای:** COMPARE

### معماری ساده ALU

```
A ────────┐
B ────────┤
          │    ┌──────────────┐
          ├───→│  Arithmetic  │
          │    │    Unit      │
          │    └──────────────┘
          │
          │    ┌──────────────┐
          ├───→│  Logic       │
          │    │  Unit        │
          │    └──────────────┘
          │
          │    ┌──────────────┐
          └───→│  Comparator  │
               └──────────────┘
                    │
                    ↓
              ┌─────────────┐
Opcode ──────→│    MUX      │───→ Result
              └─────────────┘
                    │
                    ↓
              ┌─────────────┐
              │  Status     │───→ Flags
              │  (Carry,    │
              │   Zero,     │
              │   Negative) │
              └─────────────┘
```

### VHDL برای ALU ساده

```vhdl
library ieee;
use ieee.std_logic_1164.all;
use ieee.numeric_std.all;

entity alu is
    port (
        a, b : in  std_logic_vector(7 downto 0);
        op   : in  std_logic_vector(2 downto 0);  -- کد عملیات
        res  : out std_logic_vector(7 downto 0);
        zero : out std_logic;
        carry : out std_logic
    );
end entity;

architecture rtl of alu is
    signal result : unsigned(7 downto 0);
    signal a_uns, b_uns : unsigned(7 downto 0);
begin
    a_uns <= unsigned(a);
    b_uns <= unsigned(b);
    
    process(a_uns, b_uns, op)
    begin
        case op is
            when "000" => result <= a_uns + b_uns;      -- ADD
            when "001" => result <= a_uns - b_uns;      -- SUB
            when "010" => result <= a_uns and b_uns;    -- AND
            when "011" => result <= a_uns or b_uns;     -- OR
            when "100" => result <= a_uns xor b_uns;    -- XOR
            when "101" => result <= not a_uns;          -- NOT
            when "110" => result <= a_uns + 1;          -- INC
            when "111" => result <= a_uns - 1;          -- DEC
            when others => result <= (others => '0');
        end case;
    end process;
    
    res <= std_logic_vector(result);
    zero <= '1' when result = 0 else '0';
    carry <= '1' when (op = "000" and a_uns + b_uns > 255) 
                or (op = "001" and a_uns < b_uns) else '0';
end architecture;
```

## ۱۵. طراحی مدارهای ترکیبی در VHDL

### ۱۵.۱. Concurrent Assignment (ساده)

```vhdl
y <= (a and b) or (not c);
```

### ۱۵.۲. Conditional Assignment (با شرط)

```vhdl
y <= a when sel = '0' else b;
```

### ۱۵.۳. Selected Assignment (با انتخاب)

```vhdl
with sel select
    y <= a when "00",
         b when "01",
         c when "10",
         d when "11";
```

### ۱۵.۴. Process (برای منطق پیچیده‌تر)

```vhdl
process(a, b, sel)
begin
    if sel = '0' then
        y <= a;
    else
        y <= b;
    end if;
end process;
```

### ۱۵.۵. ترکیب ساختاری (Structural)

```vhdl
architecture structural of adder_4bit is
    component full_adder
        port (a, b, cin : in std_logic;
              sum, cout : out std_logic);
    end component;
    signal carry : std_logic_vector(3 downto 0);
begin
    fa0: full_adder port map (a(0), b(0), cin, sum(0), carry(0));
    fa1: full_adder port map (a(1), b(1), carry(0), sum(1), carry(1));
    fa2: full_adder port map (a(2), b(2), carry(1), sum(2), carry(2));
    fa3: full_adder port map (a(3), b(3), carry(2), sum(3), carry(3));
    cout <= carry(3);
end architecture;
```

## ۱۶. اشتباهات رایج در مدارهای ترکیبی

### اشتباه ۱: ایجاد Latch ناخواسته

**کد مشکل‌دار:**
```vhdl
process(a, b)
begin
    if a = '1' then
        y <= b;
    end if;
end process;
```

**مشکل:** وقتی a=0، y مقدار جدیدی نمی‌گیرد و مقدار قبلی را نگه می‌دارد → Latch

**راه‌حل:**
```vhdl
process(a, b)
begin
    y <= '0';  -- مقدار پیش‌فرض
    if a = '1' then
        y <= b;
    end if;
end process;
```

### اشتباه ۲: فراموش کردن سیگنال‌های حساسیت

```vhdl
process(a)  -- فقط a در لیست حساسیت است
begin
    y <= a and b;  -- b تغییر می‌کند اما process اجرا نمی‌شود!
end process;
```

**راه‌حل:** همه ورودی‌ها را در لیست حساسیت قرار دهید:
```vhdl
process(a, b)
begin
    y <= a and b;
end process;
```

### اشتباه ۳: استفاده از تاخیر

```vhdl
y <= a and b after 10 ns;
```
این در سنتز پشتیبانی نمی‌شود و فقط برای شبیه‌سازی است.

## ۱۹. جمع‌بندی نهایی

### آنچه باید به خاطر بسپارید

۱. **مدار ترکیبی** = خروجی فقط به ورودی فعلی بستگی دارد، بدون حافظه
۲. **مدار ترتیبی** = خروجی به ورودی فعلی + حالت قبلی بستگی دارد
۳. **Half Adder** = جمع دو بیت (Sum = XOR, Carry = AND)
۴. **Full Adder** = جمع سه بیت (Sum = XOR XOR, Carry = AB + AC + BC)
۵. **MUX** = انتخابگر: یک ورودی را از بین چندین ورودی انتخاب می‌کند
۶. **Decoder** = n ورودی → ۲ⁿ خروجی
۷. **Encoder** = ۲ⁿ ورودی → n خروجی
۸. **Comparator** = مقایسه دو عدد
۹. **ALU** = ترکیبی از چندین مدار ترکیبی
۱۰. **در VHDL، مدارهای ترکیبی** با `process` حساس به همه ورودی‌ها توصیف می‌شوند

### زنجیره طراحی

```
مسئله → جدول درستی → عبارت بولی → ساده‌سازی → مدار → VHDL → شبیه‌سازی → تأیید
```

### پیام نهایی

مدارهای ترکیبی **قلب** سیستم‌های دیجیتال هستند. هر مدار دیجیتال، چه ساده و چه پیچیده، از ترکیب مدارهای ترکیبی ساخته شده است. با تسلط بر مدارهای ترکیبی، شما نه تنها می‌توانید مدارهای مفید طراحی کنید، بلکه پایه‌ای محکم برای ورود به دنیای **مدارهای ترتیبی** و در نهایت **طراحی پردازنده** خواهید داشت.

پروژه بعدی شما باید **Half Adder** باشد — اولین مدار واقعی که از چند گیت ساده ساخته شده و کاری مفید انجام می‌دهد.
