# Flip-Flops — فلیپ‌فلاپ‌ها

فلیپ‌فلاپ‌ها یکی از **اساسی‌ترین عناصر حافظه در مدارهای دیجیتال** هستند. اگر در `Combinational Circuits` با مدارهایی کار می‌کردیم که فقط به ورودی فعلی وابسته بودند، اینجا با عنصری روبه‌رو می‌شویم که می‌تواند **یک بیت از اطلاعات را ذخیره کند**.

مسیر مفهومی این بخش:

```text
Logic Gates
    ↓
Latch
    ↓
Flip-Flop
    ↓
Register
    ↓
Counter
    ↓
State
    ↓
FSM
```

---

# 1. Flip-Flop چیست؟

یک Flip-Flop یک عنصر حافظه است که معمولاً می‌تواند یک بیت را نگه دارد:

```text
0
```

یا:

```text
1
```

مدل ساده:

```text
        ┌─────────────┐
D ─────→│             │─────→ Q
CLK ───→│ Flip-Flop   │
        │             │─────→ Q̅
        └─────────────┘
```

خروجی `Q` وضعیت ذخیره‌شده را نشان می‌دهد.

اگر:

```text
Q = 1
```

باشد، Flip-Flop در وضعیت `1` قرار دارد.

اگر:

```text
Q = 0
```

باشد، در وضعیت `0` قرار دارد.

---

# 2. چرا Flip-Flop مهم است؟

بدون عناصر حافظه، ساختن بسیاری از سیستم‌های دیجیتال ممکن نیست.

مثلاً:

```text
Register
Counter
Timer
Digital Clock
CPU
FSM
Pipeline
Memory Interface
```

همگی به نوعی از عناصر ذخیره‌کننده استفاده می‌کنند.

به زبان ساده:

> **Flip-Flop یکی از سلول‌های پایه‌ای برای ساخت حافظه و State در سیستم دیجیتال است.**

---

# 3. Latch در مقابل Flip-Flop

قبل از Flip-Flop بهتر است دانشجو مفهوم **Latch** را بشناسد.

هر دو عنصر می‌توانند اطلاعات را ذخیره کنند، اما رفتارشان متفاوت است.

### Latch

معمولاً **Level-sensitive** است.

یعنی تا زمانی که یک Enable فعال است، ورودی می‌تواند روی خروجی اثر بگذارد.

```text
Enable = 1
     ↓
D ───────→ Q
```

---

### Flip-Flop

معمولاً **Edge-triggered** است.

یعنی در یک Edge مشخص از Clock نمونه‌برداری می‌کند:

```text
D ─────→ Flip-Flop ─────→ Q
              ↑
             CLK
```

مثلاً:

```text
Rising Edge:
0 → 1
```

در این لحظه مقدار `D` ثبت می‌شود.

---

# 4. Edge-Triggered یعنی چه؟

فرض کنیم:

```text
D = 1
```

اما Clock هنوز به Edge نرسیده است.

```text
D ───────────── 1 ─────────────

CLK _________/‾‾‾‾‾‾‾
             ↑
       Rising Edge
```

در Rising Edge مقدار `D` ذخیره می‌شود:

```text
Q ← 1
```

بعد اگر `D` تغییر کند:

```text
D = 0
```

`Q` لزوماً بلافاصله تغییر نمی‌کند.

تا Edge بعدی:

```text
Q = 1
```

باقی می‌ماند.

این تفاوت با مدار ترکیبی بسیار مهم است.

---

# 5. Rising Edge و Falling Edge

دو نوع Edge اصلی داریم.

### Rising Edge

```text
0 → 1
```

در نمودار:

```text
    ┌────
    │
────┘
    ↑
 Rising
 Edge
```

در VHDL:

```vhdl
rising_edge(clk)
```

---

### Falling Edge

```text
1 → 0
```

در VHDL:

```vhdl
falling_edge(clk)
```

برای بیشتر طراحی‌های مقدماتی FPGA، **Rising-Edge Triggered Design** انتخاب اصلی است.

---

# 6. D Flip-Flop

مهم‌ترین Flip-Flop برای شروع VHDL، **D Flip-Flop** است.

ساختار:

```text
        ┌─────────────┐
D ─────→│ D           │────→ Q
CLK ───→│     FF      │
        └─────────────┘
```

قانون آن بسیار ساده است:

```text
Q(next) = D
```

اما فقط هنگام Clock Edge.

---

# 7. Truth Table — D Flip-Flop

برای Rising Edge:

|Clock Event|D|Q(next)|
|---|--:|--:|
|↑|0|0|
|↑|1|1|

اگر Edge اتفاق نیفتد:

|Clock|D|Q|
|---|--:|---|
|No Edge|X|Q(previous)|

یعنی:

> بدون Clock Edge، مقدار قبلی حفظ می‌شود.

---

# 8. Timing Diagram

فرض کنیم:

```text
D:
____‾‾‾‾____‾‾‾

CLK:
__|‾|__|‾|__|‾|__
  ↑    ↑    ↑
```

در هر Rising Edge، مقدار `D` نمونه‌برداری می‌شود.

پس:

```text
D = 0 → Q = 0
D = 1 → Q = 1
```

اما تغییر `D` بین Edgeها الزاماً باعث تغییر `Q` نمی‌شود.

---

# 9. D Flip-Flop در VHDL

یک نمونه ساده:

```vhdl
library ieee;
use ieee.std_logic_1164.all;

entity d_flip_flop is
    port (
        clk : in  std_logic;
        d   : in  std_logic;
        q   : out std_logic
    );
end entity;

architecture rtl of d_flip_flop is
begin

    process(clk)
    begin
        if rising_edge(clk) then
            q <= d;
        end if;
    end process;

end architecture;
```

قسمت کلیدی:

```vhdl
if rising_edge(clk) then
    q <= d;
end if;
```

این تقریباً یکی از مهم‌ترین الگوهای VHDL برای طراحی Sequential Logic است.

---

# 10. چرا `q <= d` بلافاصله اتفاق نمی‌افتد؟

این نکته برای فهم VHDL بسیار مهم است.

در:

```vhdl
q <= d;
```

`q` یک **signal** است.

Assignment به Signal در همان لحظه به شکل متغیر معمولی Python یا C رفتار نمی‌کند؛ مقدار جدید در زمان‌بندی شبیه‌سازی و پس از اجرای process اعمال می‌شود.

در طراحی زیر:

```vhdl
process(clk)
begin
    if rising_edge(clk) then
        q1 <= d;
        q2 <= q1;
    end if;
end process;
```

در یک Clock Edge:

```text
q1 ← مقدار قبلی d
q2 ← مقدار قبلی q1
```

بنابراین:

```text
D → FF1 → FF2
```

می‌تواند یک Pipeline دو مرحله‌ای بسازد.

---

# 11. Reset

یک Flip-Flop معمولاً باید بتواند به یک وضعیت مشخص برگردد.

مثلاً:

```text
Reset
  ↓
Q = 0
```

این برای راه‌اندازی سیستم بسیار مهم است.

مثلاً اگر Counter داشته باشیم:

```text
Reset
  ↓
0000
```

سپس:

```text
0001
0010
0011
...
```

---

# 12. D Flip-Flop با Synchronous Reset

در این حالت Reset فقط در Clock Edge بررسی می‌شود:

```vhdl
process(clk)
begin
    if rising_edge(clk) then

        if reset = '1' then
            q <= '0';
        else
            q <= d;
        end if;

    end if;
end process;
```

رفتار:

```text
Clock Edge
    ↓
Reset?
 ┌──┴───┐
Yes    No
 ↓      ↓
Q=0    Q=D
```

---

# 13. D Flip-Flop با Asynchronous Reset

در این مدل Reset مستقل از Clock است:

```vhdl
process(clk, reset)
begin

    if reset = '1' then
        q <= '0';

    elsif rising_edge(clk) then
        q <= d;
    end if;

end process;
```

اگر:

```text
reset = 1
```

شود، `q` بدون منتظر ماندن برای Clock به صفر می‌رود.

---

# 14. Reset Synchronous یا Asynchronous؟

|ویژگی|Synchronous Reset|Asynchronous Reset|
|---|---|---|
|وابسته به Clock|بله|خیر|
|Reset در Edge|بله|لازم نیست|
|طراحی ساده|بله|بله|
|کاربرد|بسیار رایج|بسته به معماری|
|رفتار Timing|ساده‌تر در Clock Domain|نیازمند توجه بیشتر|

در آموزش اولیه، بهتر است دانشجو **هر دو را بشناسد** اما در پروژه‌های RTL همیشه طبق نیاز FPGA و استاندارد طراحی پروژه عمل کند.

---

# 15. Enable

بسیاری از Flip-Flopها یا Registerها به یک `Enable` نیاز دارند.

مثلاً:

```text
Enable = 1
    ↓
Q ← D
```

ولی:

```text
Enable = 0
    ↓
Q ← Q
```

یعنی مقدار قبلی حفظ شود.

در VHDL:

```vhdl
process(clk)
begin
    if rising_edge(clk) then
        if enable = '1' then
            q <= d;
        end if;
    end if;
end process;
```

این مفهوم بعداً برای:

```text
Counters
Registers
Timers
FSMs
```

بسیار مهم خواهد بود.

---

# 16. D Flip-Flop با Reset و Enable

می‌توان هر دو را ترکیب کرد:

```vhdl
process(clk)
begin
    if rising_edge(clk) then

        if reset = '1' then
            q <= '0';

        elsif enable = '1' then
            q <= d;

        end if;

    end if;
end process;
```

ترتیب اولویت اینجا:

```text
Reset
  ↓
Enable
  ↓
Data
```

است.

---

# 17. T Flip-Flop

نوع دیگری از Flip-Flop، **T Flip-Flop** است.

T یعنی Toggle.

اگر:

```text
T = 0
```

باشد:

```text
Q(next) = Q
```

اگر:

```text
T = 1
```

باشد:

```text
Q(next) = NOT Q
```

Truth Table:

|T|Q(next)|
|--:|--:|
|0|Q|
|1|NOT Q|

مثلاً:

```text
Q = 0
T = 1
```

بعد از Clock:

```text
Q = 1
```

و بعد:

```text
Q = 0
```

و دوباره:

```text
Q = 1
```

به همین دلیل T Flip-Flop برای فهم Counterها بسیار مفید است.

---

# 18. JK Flip-Flop

JK Flip-Flop نسخه عمومی‌تر و تاریخی‌تر خانواده Flip-Flopها است.

Truth Table:

|J|K|Q(next)|
|--:|--:|---|
|0|0|Q|
|0|1|0|
|1|0|1|
|1|1|NOT Q|

پس:

```text
J=0,K=0 → Hold
J=0,K=1 → Reset
J=1,K=0 → Set
J=1,K=1 → Toggle
```

در طراحی FPGA مدرن معمولاً دانشجو بیشتر با **D Flip-Flop** سروکار دارد، چون ابزار سنتز می‌تواند منطق لازم را به منابع FPGA نگاشت کند.

بنابراین JK را بیشتر برای **درک Digital Logic و تاریخچه طراحی Flip-Flop** آموزش بده، نه به‌عنوان الگوی اصلی VHDL.

---

# 19. SR Flip-Flop

SR یا Set-Reset نیز یکی از ساختارهای پایه‌ای حافظه است.

ورودی‌ها:

```text
S = Set
R = Reset
```

به شکل مفهومی:

|S|R|رفتار|
|--:|--:|---|
|0|0|Hold|
|0|1|Reset|
|1|0|Set|
|1|1|وابسته به پیاده‌سازی / حالت ممنوع در ساختارهای کلاسیک|

این Flip-Flop برای فهم اینکه Memory چگونه از Logic Gates ساخته می‌شود مفید است.

---

|نوع|ایده اصلی|کاربرد آموزشی|
|---|---|---|
|SR|Set / Reset|پایه حافظه|

```text

D

Register

Counter

```

باید مسیر اصلی باشد.

# 21. Flip-Flop و Register

یک Flip-Flop:

```text
1 bit
```

ذخیره می‌کند.

مثلاً:

```text
FF → 1 bit
```

اما اگر 8 بیت بخواهیم:

```text
FF FF FF FF FF FF FF FF
└──────────┬────────────┘
           ↓
       8-bit Register
```

پس:

> **Register مجموعه‌ای از Flip-Flopهاست که معمولاً با Clock مشترک کار می‌کنند.**

مثلاً:

```text
D[7:0]
  ↓
8 D Flip-Flops
  ↓
Q[7:0]
```

---

# 22. Flip-Flop و Counter

Counter نیز از Flip-Flopها و منطق ترکیبی ساخته می‌شود.

مثلاً:

```text
Clock
  ↓
┌─────┐
│ FF  │
└─────┘
  ↓
┌─────┐
│ FF  │
└─────┘
  ↓
┌─────┐
│ FF  │
└─────┘
```

با اضافه شدن Logic مناسب:

```text
Flip-Flops
    +
Combinational Logic
    ↓
Counter
```

بنابراین Counter یک مثال عالی از ترکیب دو فصل قبلی است.

---

# 23. Flip-Flop و Pipeline

یک کاربرد بسیار مهم دیگر، Pipeline است.

مثلاً:

```text
Input
  ↓
Combinational Logic
  ↓
Register
  ↓
Combinational Logic
  ↓
Register
  ↓
Output
```

به شکل سخت‌افزاری:

```text
       Stage 1       Stage 2
          ↓            ↓
Input → Logic → FF → Logic → FF → Output
                 ↑           ↑
                CLK         CLK
```

این ساختار در طراحی CPU، پردازنده‌ها و سیستم‌های FPGA بسیار مهم است.

# 24. Timing Parameters

برای درک حرفه‌ای‌تر Flip-Flop، چند پارامتر Timing باید معرفی شوند.

### Setup Time

داده باید مدت مشخصی **قبل از Clock Edge** پایدار باشد.

```text
D ───────────────
             ↑
         Setup Window
             ↑
CLK ─────────↑
```

---

### Hold Time

داده باید مدت کوتاهی **بعد از Clock Edge** نیز پایدار بماند.

```text
CLK ─────────↑────────
             │
          Hold Window
```

---

### Clock-to-Q Delay

بعد از Clock Edge، خروجی `Q` فوراً در همان لحظه فیزیکی تغییر نمی‌کند.

یک تأخیر کوچک وجود دارد:

```text
Clock Edge
    ↓
   delay
    ↓
Q changes
```

این مفاهیم در Timing Analysis FPGA اهمیت زیادی دارند.

# 25. Metastability

این موضوع را می‌توان در سطح مقدماتی فقط معرفی کرد.

اگر ورودی یک Flip-Flop نزدیک به Clock Edge تغییر کند و شرایط Setup/Hold رعایت نشود، خروجی ممکن است برای مدت کوتاهی در یک وضعیت نامطمئن قرار بگیرد.

این پدیده:

> **Metastability**

نام دارد.

این موضوع مخصوصاً هنگام انتقال سیگنال بین دو Clock Domain مهم است.

بعداً در مباحث پیشرفته‌تر:

```text
Clock Domain Crossing
Synchronizer
Two-Flip-Flop Synchronizer
```

بررسی می‌شود.

# 27. Testbench فلیپ‌فلاپ

Testbench باید Clock تولید کند.

مثلاً:

```text
CLK
    ┌───┐   ┌───┐   ┌───┐
────┘   └───┘   └───┘   └───

D
───────┐       ┌──────────
       └───────┘

Q
───────┐       ┌──────────
       └───────┘
        ↑
   Clock Edge
```

برای D Flip-Flop باید آزمایش کنیم:

1. `D = 0`
    
2. Clock Edge
    
3. بررسی `Q = 0`
    
4. `D = 1`
    
5. Clock Edge
    
6. بررسی `Q = 1`
    
7. تغییر `D` بدون Clock
    
8. بررسی اینکه `Q` تغییر نکرده است.
    
9. فعال کردن Reset
    
10. بررسی `Q = 0`

# 29. چیزی که دانشجو باید در پایان بداند

در پایان این بخش، دانشجو باید بتواند این زنجیره را توضیح دهد:

```text
Clock
  ↓
Edge
  ↓
Flip-Flop
  ↓
1-bit Storage
  ↓
Multiple Flip-Flops
  ↓
Register
  ↓
State
  ↓
Counter / FSM
```

و از نظر VHDL باید این الگو برایش کاملاً طبیعی شده باشد:

```vhdl
process(clk)
begin
    if rising_edge(clk) then
        if reset = '1' then
            q <= '0';
        elsif enable = '1' then
            q <= d;
        end if;
    end if;
end process;
```

یعنی دانشجو دیگر `process` و `rising_edge` را صرفاً به‌عنوان **Syntax** نمی‌بیند؛ می‌فهمد که این کد دارد یک **عنصر حافظه‌ی Clocked** را توصیف می‌کند.

### جایگاه Flip-Flop در کل مسیر

```text
Digital Logic
      │
      ├── Combinational
      │      ├── Adder
      │      ├── MUX
      │      ├── Decoder
      │      └── ALU
      │
      └── Sequential
             │
             ├── Flip-Flop
             │      ↓
             │   Register
             │      ↓
             │   Counter
             │      ↓
             │    State
             │      ↓
             │     FSM
             │
             └── Clock / Timing
```

این دقیقاً همان نقطه‌ای است که دانشجو از **«مدار منطقی»** وارد دنیای **«سیستم دیجیتال دارای حافظه و وضعیت»** می‌شود.
