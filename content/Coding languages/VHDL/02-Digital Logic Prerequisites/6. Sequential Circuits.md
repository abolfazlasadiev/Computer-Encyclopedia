# مدارهای ترتیبی (Sequential Circuits) — نسخه کامل و جامع

## مقدمه: از بی‌حافظگی تا حافظه

تا اینجا با **مدارهای ترکیبی (Combinational Circuits)** آشنا شدیم. یاد گرفتیم که در این مدارها، خروجی فقط به **ورودی فعلی** بستگی دارد. اگر ورودی تغییر کند، خروجی بلافاصله (با تأخیر انتشار) تغییر می‌کند. این مدارها **بی‌حافظه (Memoryless)** هستند.

اما در دنیای واقعی، بسیاری از سیستم‌ها نیاز به **حافظه** دارند:

- یک **چراغ راهنمایی** باید به خاطر داشته باشد که الان در کدام مرحله (قرمز، سبز، زرد) قرار دارد
- یک **شمارنده (Counter)** باید مقدار فعلی خود را به خاطر بسپارد تا بتواند به عدد بعدی برود
- یک **پردازنده** باید نتیجه محاسبات قبلی را در ثبات‌های خود ذخیره کند
- یک **ماشین‌حالت (FSM)** باید وضعیت فعلی خود را بداند تا تصمیم بگیرد به کدام وضعیت برود

اینجاست که **مدارهای ترتیبی (Sequential Circuits)** وارد می‌شوند. مدارهای ترتیبی **حافظه (Memory)** دارند و خروجی آنها به **ورودی فعلی + وضعیت قبلی (State)** بستگی دارد.

---

## ۱. مدار ترتیبی چیست؟ تعریف جامع

**مدار ترتیبی (Sequential Circuit)** مداری است که در آن **خروجی‌ها به مقدار فعلی ورودی‌ها و همچنین وضعیت قبلی مدار (State) بستگی دارند**.

### تعریف ریاضی

یک مدار ترتیبی را می‌توان به صورت زیر مدل کرد:

```
Next State  = F(Current State, Inputs)
Output      = G(Current State, Inputs)
```

که در آن:
- **Current State** = وضعیت فعلی (ذخیره شده در عناصر حافظه)
- **Next State** = وضعیت بعدی (پس از اعمال Clock)
- **Inputs** = ورودی‌های فعلی
- **Output** = خروجی‌های مدار

### ویژگی‌های کلیدی

1. **دارای حافظه (Memory):** وضعیت قبلی را ذخیره می‌کند
2. **وابسته به زمان:** ترتیب وقوع رویدادها مهم است
3. **معمولاً با Clock:** برای هماهنگ‌سازی از سیگنال ساعت استفاده می‌کند
4. **قابل توصیف با جدول حالت (State Table):** به جای جدول درستی

### قیاس با دنیای واقعی

یک مدار ترتیبی مانند **یک ماشین‌حساب** است:
- ورودی: دکمه‌هایی که فشار می‌دهید
- خروجی: عددی که روی صفحه نمایش داده می‌شود
- **حافظه:** مقدار فعلی صفحه نمایش را به خاطر می‌سپارد
- اگر دکمه «+» را بزنید، ماشین‌حساب به خاطر می‌سپارد که در حالت جمع قرار دارد

در مقابل، یک **چراغ‌قوه** که با فشار دکمه روشن و با رها کردن خاموش می‌شود، یک مدار ترکیبی است (بدون حافظه).

## ۲. تفاوت اساسی: ترکیبی در مقابل ترتیبی

| ویژگی | مدار ترکیبی | مدار ترتیبی |
|-------|------------|-------------|
| **حافظه** | ندارد | دارد |
| **خروجی** | تابع ورودی فعلی | تابع ورودی فعلی + وضعیت قبلی |
| **Clock** | ندارد | معمولاً دارد |
| **تغییر خروجی** | فوری (با تأخیر) | در لبه Clock |
| **طراحی** | جدول درستی + جبر بولی | جدول حالت + نمودار حالت |
| **مثال** | AND Gate, Adder, MUX | Flip-Flop, Register, Counter, FSM |
| **پیچیدگی** | ساده‌تر | پیچیده‌تر |

### تصویر مفهومی

**مدار ترکیبی:**
```
ورودی ────→ [گیت‌های منطقی] ────→ خروجی
                  (بدون حافظه)
```

**مدار ترتیبی:**
```
ورودی ────→ [گیت‌های منطقی] ────→ خروجی
                  ↑        ↓
                  └── [حافظه/State] ──┘
                       ↑
                      Clock
```

## ۳. عناصر حافظه در مدارهای ترتیبی

### ۳.۱. Latch (قفل)

**Latch** ساده‌ترین عنصر حافظه است. با سیگنال **Enable** کنترل می‌شود و به محض فعال شدن Enable، ورودی را به خروجی منتقل می‌کند.

**ویژگی‌ها:**
- **حساس به سطح (Level-Sensitive):** در تمام مدت Enable=1، ورودی را دنبال می‌کند
- **ساده‌تر از Flip-Flop:** با ترانزیستورهای کمتری ساخته می‌شود
- **مشکل:** اگر Enable طولانی باشد، ممکن است داده ناخواسته تغییر کند

**کاربرد:** در مدارهای خاص که نیاز به قفل کردن داده دارند.

### ۳.۲. Flip-Flop (فلیپ‌فلاپ)

**Flip-Flop** پیشرفته‌ترین و پرکاربردترین عنصر حافظه است. برخلاف Latch، **حساس به لبه (Edge-Sensitive)** است و فقط در لحظه تغییر Clock (لبه) ورودی را نمونه‌برداری می‌کند.

**ویژگی‌ها:**
- **حساس به لبه (Edge-Triggered):** فقط در لحظه لبه Clock نمونه‌برداری می‌کند
- **ایمن‌تر:** کمتر در معرض نویز و تغییرات ناخواسته است
- **استاندارد طراحی سنکرون:** اساس تمام مدارهای دیجیتال مدرن

---

## ۴. Clock و لبه‌های آن

### ۴.۱. سیگنال Clock چیست؟

**Clock** یک سیگنال دیجیتال است که به طور دوره‌ای بین ۰ و ۱ تغییر می‌کند.

```
     ┌───┐   ┌───┐   ┌───┐
─────┘   └───┘   └───┘   └───
     ↑       ↑       ↑
   Rising  Rising  Rising
   Edge    Edge    Edge
```

### ۴.۲. دو نوع لبه مهم

**Rising Edge (لبه صعودی):** تغییر از ۰ به ۱
```
     ┌───┐
─────┘   └───
     ↑
  Rising Edge
```

**Falling Edge (لبه نزولی):** تغییر از ۱ به ۰
```
     ┌───┐
─────┘   └───
          ↓
       Falling Edge
```

### ۴.۳. چرا لبه مهم است؟

در طراحی سنکرون (Synchronous Design)، **همه** عناصر حافظه در یک لبه مشخص از Clock نمونه‌برداری می‌کنند. این باعث می‌شود:
- سیستم **هماهنگ (Synchronous)** باشد
- رفتار مدار **قابل پیش‌بینی** باشد
- طراحی **ساده‌تر** شود

## ۵. D Flip-Flop — قلب مدارهای ترتیبی

### ۵.۱. ساختار و عملکرد

**D Flip-Flop (Data Flip-Flop)** مهم‌ترین و پرکاربردترین نوع Flip-Flop است.

```
D ────┐
      │    ┌─────────┐
      ├───→│ D Flip- │──→ Q
      │    │  Flop   │
CLK ──┴───→│         │
           └─────────┘
```

**قانون عملکرد:**
> در لبه Rising Clock، مقدار D به Q منتقل می‌شود.

| قبل از Edge | بعد از Edge |
|:-----------:|:-----------:|
| D = 0       | Q = 0       |
| D = 1       | Q = 1       |

**نکته بسیار مهم:** تغییر D در **بین** لبه‌های Clock، تأثیری روی Q ندارد. Q فقط در لبه Clock به‌روز می‌شود.

### ۵.۲. D Flip-Flop با Reset

**Reset** برای قرار دادن Flip-Flop در یک وضعیت مشخص (معمولاً ۰) استفاده می‌شود.

**دو نوع Reset:**

**۱. Synchronous Reset (همزمان):**
```vhdl
process(clk)
begin
    if rising_edge(clk) then
        if reset = '1' then
            q <= '0';
        else
            q <= d;
        end if;
    end if;
end process;
```
Reset فقط در لبه Clock اثر می‌کند.

**۲. Asynchronous Reset (ناهمزمان):**
```vhdl
process(clk, reset)
begin
    if reset = '1' then
        q <= '0';
    elsif rising_edge(clk) then
        q <= d;
    end if;
end process;
```
Reset بلافاصله و بدون نیاز به Clock اثر می‌کند.

### ۵.۳. D Flip-Flop با Enable

**Enable** مشخص می‌کند که آیا Flip-Flop باید در لبه Clock به‌روز شود یا خیر.

```vhdl
process(clk)
begin
    if rising_edge(clk) then
        if enable = '1' then
            q <= d;
        end if;
    end if;
end process;
```

وقتی Enable=0، Flip-Flop مقدار قبلی خود را حفظ می‌کند.

### ۵.۴. D Flip-Flop کامل (Reset + Enable)

```vhdl
process(clk)
begin
    if rising_edge(clk) then
        if reset = '1' then
            q <= '0';
        elsif enable = '1' then
            q <= d;
        end if;
    end if;
end process;
```

## ۶. Register — مجموعه‌ای از Flip-Flop‌ها

### ۶.۱. Register چیست؟

یک **Register** مجموعه‌ای از Flip-Flop‌هاست که یک کلمه چندبیتی را ذخیره می‌کند.

```
n-bit Register = n × D Flip-Flop
```

**مثال: 8-bit Register**
```
D7 ──→ [D-FF] ──→ Q7
D6 ──→ [D-FF] ──→ Q6
D5 ──→ [D-FF] ──→ Q5
D4 ──→ [D-FF] ──→ Q4
D3 ──→ [D-FF] ──→ Q3
D2 ──→ [D-FF] ──→ Q2
D1 ──→ [D-FF] ──→ Q1
D0 ──→ [D-FF] ──→ Q0
         ↑
        CLK (مشترک)
```

### ۶.۲. Register در VHDL

```vhdl
library ieee;
use ieee.std_logic_1164.all;

entity register_8bit is
    port (
        clk   : in  std_logic;
        reset : in  std_logic;
        en    : in  std_logic;
        d     : in  std_logic_vector(7 downto 0);
        q     : out std_logic_vector(7 downto 0)
    );
end entity;

architecture rtl of register_8bit is
begin
    process(clk)
    begin
        if rising_edge(clk) then
            if reset = '1' then
                q <= (others => '0');
            elsif en = '1' then
                q <= d;
            end if;
        end if;
    end process;
end architecture;
```

### ۶.۳. کاربردهای Register

- **ثبات‌های CPU:** ذخیره داده‌ها و آدرس‌ها
- **بافر (Buffer):** هماهنگ‌سازی داده بین دو بخش
- **خط تأخیر (Delay Line):** ایجاد تأخیر زمانی
- **Pipeline Register:** ذخیره داده بین مراحل خط لوله

---

## ۷. Shift Register — جابه‌جایی داده

### ۷.۱. Shift Register چیست؟

یک **Shift Register** نوعی Register است که داده را در هر لبه Clock به چپ یا راست جابه‌جا می‌کند.

### ۷.۲. Shift Register ۴ بیتی (Shift Right)

```
SI ──→ [FF] ──→ [FF] ──→ [FF] ──→ [FF] ──→ SO
            ↑        ↑        ↑        ↑
           CLK      CLK      CLK      CLK
```

**مثال:**
```
مقدار اولیه: ۱۰۰۰
Shift:       ۰۱۰۰
Shift:       ۰۰۱۰
Shift:       ۰۰۰۱
Shift:       ۰۰۰۰ (با ورودی صفر)
```

### ۷.۳. انواع Shift Register

| نوع | ورودی | خروجی | کاربرد |
|-----|-------|-------|--------|
| **SISO** | سریال | سریال | تأخیر، تولید تأخیر |
| **SIPO** | سریال | موازی | تبدیل سریال → موازی (UART RX) |
| **PISO** | موازی | سریال | تبدیل موازی → سریال (UART TX) |
| **PIPO** | موازی | موازی | ذخیره‌سازی داده |
| **Universal** | همه | همه | ترکیبی از همه حالت‌ها |

### ۷.۴. Shift Register در VHDL

```vhdl
library ieee;
use ieee.std_logic_1164.all;

entity shift_register_4bit is
    port (
        clk : in  std_logic;
        si  : in  std_logic;  -- ورودی سریال
        q   : out std_logic_vector(3 downto 0)
    );
end entity;

architecture rtl of shift_register_4bit is
    signal reg : std_logic_vector(3 downto 0);
begin
    process(clk)
    begin
        if rising_edge(clk) then
            reg <= reg(2 downto 0) & si;  -- Shift Left
        end if;
    end process;
    q <= reg;
end architecture;
```

### ۷.۵. کاربردهای Shift Register

- **UART/SPI/I²C:** تبدیل داده سریال به موازی و برعکس
- **ضرب و تقسیم بر توان ۲:** Shift Left = ضرب در ۲، Shift Right = تقسیم بر ۲
- **تولید تأخیر:** با عبور داده از چند مرحله
- **Ring Counter:** تولید دنباله‌های تکراری

## ۸. Counter — شمارنده

### ۸.۱. Counter چیست؟

یک **Counter** مدار ترتیبی است که از یک حالت به حالت بعدی در هر لبه Clock حرکت می‌کند.

```
      ┌─────────────┐
CLK ─→│   Counter   │──→ Q[3:0]
      └─────────────┘
```

### ۸.۲. Up Counter (شمارنده صعودی)

**دنباله:** ۰۰۰۰ → ۰۰۰۱ → ۰۰۱۰ → ۰۰۱۱ → ... → ۱۱۱۱ → ۰۰۰۰

**کد VHDL:**
```vhdl
library ieee;
use ieee.std_logic_1164.all;
use ieee.numeric_std.all;

entity up_counter is
    port (
        clk   : in  std_logic;
        reset : in  std_logic;
        q     : out unsigned(3 downto 0)
    );
end entity;

architecture rtl of up_counter is
    signal count : unsigned(3 downto 0);
begin
    process(clk)
    begin
        if rising_edge(clk) then
            if reset = '1' then
                count <= (others => '0');
            else
                count <= count + 1;
            end if;
        end if;
    end process;
    q <= count;
end architecture;
```

### ۸.۳. Down Counter (شمارنده نزولی)

**دنباله:** ۱۱۱۱ → ۱۱۱۰ → ۱۱۰۱ → ... → ۰۰۰۰ → ۱۱۱۱

```vhdl
process(clk)
begin
    if rising_edge(clk) then
        if reset = '1' then
            count <= (others => '1');
        else
            count <= count - 1;
        end if;
    end if;
end process;
```

### ۸.۴. Up/Down Counter (شمارنده دوطرفه)

با ورودی کنترل جهت:

```vhdl
process(clk)
begin
    if rising_edge(clk) then
        if reset = '1' then
            count <= (others => '0');
        elsif up_down = '1' then
            count <= count + 1;  -- Up
        else
            count <= count - 1;  -- Down
        end if;
    end if;
end process;
```

### ۸.۵. Modulo-N Counter (شمارنده مدولار)

شمارنده‌ای که تا N-1 بشمارد و سپس به ۰ برگردد.

```vhdl
process(clk)
begin
    if rising_edge(clk) then
        if reset = '1' then
            count <= (others => '0');
        elsif count = N - 1 then
            count <= (others => '0');
        else
            count <= count + 1;
        end if;
    end if;
end process;
```

### ۸.۶. کاربردهای Counter

- **شمارش رویدادها:** تعداد دفعات وقوع یک رویداد
- **تولید تأخیر:** با شمارش تا یک مقدار مشخص
- **تقسیم فرکانس:** کاهش سرعت Clock
- **آدرس‌دهی حافظه:** تولید آدرس‌های متوالی
- **تایمر و ساعت دیجیتال:** شمارش ثانیه‌ها، دقیقه‌ها و ساعت‌ها

## ۹. تقسیم‌کننده فرکانس (Frequency Divider)

یک Counter می‌تواند به عنوان **تقسیم‌کننده فرکانس** استفاده شود.

### ۹.۱. اصل عملکرد

```
Clock_IN (50 MHz)
       ↓
   Counter
       ↓
Clock_OUT (کمتر)
```

### ۹.۲. مثال: تقسیم بر ۱۰۰۰

```vhdl
entity frequency_divider is
    port (
        clk_in  : in  std_logic;
        reset   : in  std_logic;
        clk_out : out std_logic
    );
end entity;

architecture rtl of frequency_divider is
    signal count : integer range 0 to 999;
begin
    process(clk_in)
    begin
        if rising_edge(clk_in) then
            if reset = '1' then
                count <= 0;
                clk_out <= '0';
            elsif count = 999 then
                count <= 0;
                clk_out <= '1';
            else
                count <= count + 1;
                clk_out <= '0';
            end if;
        end if;
    end process;
end architecture;
```

### ۹.۳. کاربردهای تقسیم‌کننده فرکانس

- **تنظیم سرعت LED:** چشم انسان نمی‌تواند تغییرات سریع ببیند
- **تولید Baud Rate:** برای ارتباطات سریال (UART)
- **ساعت دیجیتال:** از ۵۰ MHz به ۱ Hz
- **PWM:** تولید سیگنال با Duty Cycle قابل تنظیم

## ۱۰. State — وضعیت در مدارهای ترتیبی

### ۱۰.۱. State چیست؟

**State (وضعیت)** اطلاعاتی است که وضعیت فعلی سیستم را توصیف می‌کند. State در عناصر حافظه (Flip-Flop‌ها) ذخیره می‌شود.

### ۱۰.۲. مثال: چراغ راهنمایی

```
States: RED, GREEN, YELLOW
Transition: RED → GREEN → YELLOW → RED → ...
```

هر State نشان‌دهنده وضعیت فعلی چراغ‌هاست.

### ۱۰.۳. State Register

**State Register** مجموعه‌ای از Flip-Flop‌هاست که State فعلی را ذخیره می‌کند.

```
Next State ←───┐
                │
    [State Register] ← Clock/Reset
                │
Current State ──┘
```

### ۱۰.۴. State و FSM

State مفهوم اصلی در **Finite State Machine (FSM)** است. FSM موضوع فصل بعدی است، اما در اینجا باید دانشجو با مفهوم State آشنا شود.

---

## ۱۱. Timing در مدارهای ترتیبی

### ۱۱.۱. مفاهیم پایه Timing

**۱. Propagation Delay (t_pd):**
زمانی که طول می‌کشد تا تغییر ورودی در خروجی دیده شود.

**۲. Setup Time (t_setup):**
زمانی که داده باید **قبل از** لبه Clock پایدار باشد.

```
        Setup Time
             ↓
D ───────────████████────
                     ↑
                   Clock
```

**۳. Hold Time (t_hold):**
زمانی که داده باید **بعد از** لبه Clock پایدار بماند.

```
D ────████████────────────
          ↑
       Clock
          ↓
      Hold Time
```

**۴. Clock-to-Q Delay (t_cq):**
زمانی که طول می‌کشد تا تغییر از Clock تا خروجی Q دیده شود.

### ۱۱.۲. شرط عملکرد صحیح

برای اینکه یک Flip-Flop درست کار کند:

```
t_setup + t_hold ≤ T (پریود Clock)
```

و:

```
t_cq + t_pd_combinational ≤ T
```

این مفاهیم در طراحی FPGAهای با سرعت بالا بسیار مهم هستند.

## ۱۲. مدارهای ترتیبی در VHDL

### ۱۲.۱. الگوی استاندارد Clocked Process

```vhdl
process(clk)
begin
    if rising_edge(clk) then
        -- کد سنکرون
    end if;
end process;
```

### ۱۲.۲. با Reset همزمان

```vhdl
process(clk)
begin
    if rising_edge(clk) then
        if reset = '1' then
            -- مقداردهی اولیه
        else
            -- عملکرد عادی
        end if;
    end if;
end process;
```

### ۱۲.۳. با Reset ناهمزمان

```vhdl
process(clk, reset)
begin
    if reset = '1' then
        -- مقداردهی اولیه
    elsif rising_edge(clk) then
        -- عملکرد عادی
    end if;
end process;
```

### ۱۲.۴. با Enable

```vhdl
process(clk)
begin
    if rising_edge(clk) then
        if enable = '1' then
            -- به‌روزرسانی
        end if;
    end if;
end process;
```

### ۱۲.۵. قوانین مهم

۱. **همیشه از `rising_edge(clk)`** برای شناسایی لبه Clock استفاده کنید
۲. **همه سیگنال‌های استفاده‌شده** باید در لیست حساسیت باشند (برای Reset ناهمزمان)
۳. **از Multiple Drivers** خودداری کنید (هر سیگنال فقط در یک process نوشته شود)
۴. **از `<=`** برای انتساب به سیگنال‌ها استفاده کنید

## ۱۳. Nonblocking vs Blocking در VHDL

### ۱۳.۱. Nonblocking Assignment (`<=`)

وقتی از `<=` در یک process استفاده می‌کنیم، **همه** انتساب‌ها در پایان process انجام می‌شوند.

**مثال:**
```vhdl
process(clk)
begin
    if rising_edge(clk) then
        q1 <= d;
        q2 <= q1;
    end if;
end process;
```

**رفتار:** در لبه Clock:
- `q1` مقدار `d` را می‌گیرد
- `q2` مقدار **قدیمی** `q1` را می‌گیرد (نه مقدار جدید)

این رفتار برای شبیه‌سازی صحیح Registerها ضروری است.

### ۱۳.۲. چرا مهم است؟

اگر `q2` مقدار جدید `q1` را می‌گرفت، در واقع یک Pipeline نبود و رفتار سخت‌افزار را درست توصیف نمی‌کرد.

## ۱۴. Testbench برای مدارهای ترتیبی

### ۱۴.۱. تولید Clock

```vhdl
process
begin
    clk <= '0';
    wait for 5 ns;
    clk <= '1';
    wait for 5 ns;
end process;
```

یا:
```vhdl
clk <= not clk after 5 ns;
```

### ۱۴.۲. تولید Reset

```vhdl
process
begin
    reset <= '1';
    wait for 20 ns;
    reset <= '0';
    wait;
end process;
```

### ۱۴.۳. Testbench کامل برای Counter

```vhdl
library ieee;
use ieee.std_logic_1164.all;
use ieee.numeric_std.all;

entity tb_counter is
end entity;

architecture sim of tb_counter is
    signal clk   : std_logic := '0';
    signal reset : std_logic := '0';
    signal q     : unsigned(3 downto 0);
begin
    -- Instantiate Counter
    uut: entity work.up_counter
        port map (clk => clk, reset => reset, q => q);
    
    -- Clock Generation
    clk <= not clk after 5 ns;
    
    -- Test Sequence
    process
    begin
        -- Reset
        reset <= '1';
        wait for 20 ns;
        reset <= '0';
        
        -- Wait for 16 clock cycles
        wait for 160 ns;
        
        -- Check value
        assert q = "0000" report "Counter should roll over" severity error;
        
        report "Test completed";
        wait;
    end process;
end architecture;
```

## ۱۵. اشتباهات رایج در مدارهای ترتیبی

### اشتباه ۱: فراموش کردن Clock در لیست حساسیت

**نادرست:**
```vhdl
process(d)  -- clk در لیست نیست!
begin
    if rising_edge(clk) then
        q <= d;
    end if;
end process;
```

**درست:**
```vhdl
process(clk)  -- clk در لیست است
begin
    if rising_edge(clk) then
        q <= d;
    end if;
end process;
```

### اشتباه ۲: استفاده از `if rising_edge` در مدار ترکیبی

**نادرست:**
```vhdl
process(a, b)  -- این یک مدار ترکیبی است
begin
    if rising_edge(a) then  -- اشتباه!
        y <= b;
    end if;
end process;
```

### اشتباه ۳: ایجاد Latch ناخواسته

**نادرست:**
```vhdl
process(clk)
begin
    if rising_edge(clk) then
        if reset = '1' then
            q <= '0';
        -- بدون else: وقتی reset=0، q مقدار قبلی را نگه می‌دارد
        end if;
    end if;
end process;
```

### اشتباه ۴: استفاده از `after` در سنتز

```vhdl
q <= d after 10 ns;  -- در سنتز پشتیبانی نمی‌شود
```

## ۱۸. جمع‌بندی نهایی

### آنچه باید به خاطر بسپارید

۱. **مدار ترتیبی** = مدار با حافظه (خروجی به ورودی فعلی + وضعیت قبلی بستگی دارد)
۲. **Flip-Flop** = عنصر حافظه یک بیتی (حساس به لبه Clock)
۳. **D Flip-Flop** = مهم‌ترین نوع، `Q(next) = D` در لبه Clock
۴. **Register** = مجموعه‌ای از Flip-Flop‌ها برای ذخیره چند بیت
۵. **Shift Register** = Register که داده را جابه‌جا می‌کند
۶. **Counter** = Register که در هر Clock افزایش/کاهش می‌یابد
۷. **State** = وضعیت فعلی سیستم (ذخیره شده در Registerها)
۸. **Synchronous Design** = همه عناصر با یک Clock مشترک کار می‌کنند
۹. **در VHDL، `rising_edge(clk)`** = شناسایی لبه صعودی Clock
۱۰. **Reset** = قرار دادن مدار در وضعیت اولیه

### زنجیره طراحی

```
مسئله → جدول حالت → نمودار حالت → State Register → Next-State Logic → Output Logic → VHDL → شبیه‌سازی → تأیید
```

### تفاوت اصلی با مدارهای ترکیبی

| مدار ترکیبی | مدار ترتیبی |
|------------|------------|
| `y <= a and b;` | `process(clk) begin if rising_edge(clk) then q <= d; end if; end process;` |
| بدون Clock | با Clock |
| بدون حافظه | با حافظه |
| ورودی فعلی → خروجی | ورودی فعلی + State → خروجی |

### پیام نهایی

مدارهای ترتیبی **قلب تپنده** سیستم‌های دیجیتال هستند. هر سیستم دیجیتال پیچیده‌ای که حافظه، شمارش، زمان‌بندی یا کنترل نیاز دارد، از مدارهای ترتیبی استفاده می‌کند.

با تسلط بر مدارهای ترتیبی، شما وارد مرحله جدیدی از طراحی دیجیتال شده‌اید. اکنون می‌توانید سیستم‌هایی طراحی کنید که:
- **وضعیت خود را به خاطر می‌سپارند**
- **رویدادها را شمارش می‌کنند**
- **زمان را اندازه می‌گیرند**
- **داده را ذخیره و جابه‌جا می‌کنند**

گام بعدی، ترکیب تمام این مفاهیم در **ماشین‌های حالت (Finite State Machines)** است که به شما اجازه می‌دهد سیستم‌های کنترلی پیچیده‌ای مثل چراغ راهنمایی، دستگاه‌های فروش خودکار و در نهایت **پردازنده** طراحی کنید.
