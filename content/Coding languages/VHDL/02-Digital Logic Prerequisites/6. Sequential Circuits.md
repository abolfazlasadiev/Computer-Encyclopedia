# مدارهای ترتیبی - Sequential Circuits

بعد از **Binary → Logic Gates → Truth Tables → Combinational Circuits**، حالا باید وارد یکی از مهم‌ترین بخش‌های Digital Logic شویم:

> **Sequential Circuits**

اگر در مدارهای ترکیبی خروجی فقط به **ورودی فعلی** وابسته بود، در مدار ترتیبی خروجی به **ورودی فعلی + وضعیت قبلی مدار** وابسته است.

یعنی اینجا برای اولین بار مفهوم **Memory / State** وارد طراحی دیجیتال می‌شود.

---

# 1. مدارهای ترتیبی - Sequential Circuit چیست؟

یک مدار ترتیبی می‌تواند وضعیت قبلی خود را حفظ کند.

مدل ساده:

```text
Inputs
   │
   ▼
┌──────────────┐
│ Combinational│
│    Logic     │
└──────┬───────┘
       │
       ▼
   ┌───────┐
   │ State │
   │Memory │
   └───┬───┘
       │
       └──────────┐
                  ▼
             Next State
```

بنابراین:

```text
Current Inputs
      +
Previous State
      ↓
Next State / Output
```

مثلاً یک Counter را در نظر بگیر:

```text
0000
  ↓
0001
  ↓
0010
  ↓
0011
  ↓
0100
```

برای اینکه مدار بداند بعد از `0011` باید به `0100` برود، باید **وضعیت فعلی خود را حفظ کند**.

این همان چیزی است که مدارهای ترتیبی فراهم می‌کنند.

---

# 2. تفاوت Combinational و Sequential

این تفاوت باید کاملاً در ذهن دانشجو تثبیت شود.

### Combinational

```text
Input ───→ Logic ───→ Output
```

مثلاً:

```text
A + B → Sum
```

اگر ورودی تغییر کند، خروجی بر اساس ورودی جدید تغییر می‌کند.

---

### Sequential

```text
             ┌─────────┐
             │ Memory  │
             └────┬────┘
                  │
                  ▼
Input ───→ Logic ───→ Output
             │
             └──────→ Next State
```

پس:

```text
Output = F(Current Input, Previous State)
```

---

# 3. چرا Memory لازم داریم؟

فرض کن می‌خواهیم یک چراغ را روشن نگه داریم.

اگر فقط یک مدار ترکیبی داشته باشیم:

```text
Button → Logic → LED
```

با رها کردن Button، LED نیز خاموش می‌شود.

اما اگر بخواهیم سیستم **وضعیت قبلی** را حفظ کند:

```text
Button
   ↓
Logic
   ↓
Memory
   ↓
LED
```

حالا مدار می‌تواند بداند:

```text
LED was ON
```

یا:

```text
LED was OFF
```

این مفهوم پایه‌ی:

```text
Register
Counter
Timer
FSM
CPU
Memory
```

است.

---

# 4. Clock چیست؟

بسیاری از مدارهای ترتیبی با یک **Clock** هماهنگ می‌شوند.

کلاک Clock یک سیگنال دوره‌ای است:

```text
      ┌───┐   ┌───┐   ┌───┐
──────┘   └───┘   └───┘   └──
```

دو سطح اصلی دارد:

```text
HIGH → 1
LOW  → 0
```

و مرتب بین این دو وضعیت تغییر می‌کند.

---

# 5. Clock Edge

در طراحی دیجیتال معمولاً به جای اینکه مدار در تمام مدت Clock واکنش نشان دهد، روی یک **Edge** نمونه‌برداری می‌کند.

دو Edge مهم:

### Rising Edge

```text
0 → 1
```

### Falling Edge

```text
1 → 0
```

در VHDL معمولاً مدارهای synchronous را با:

```vhdl
rising_edge(clk)
```

توصیف می‌کنیم.

مثلاً:

```vhdl
process(clk)
begin
    if rising_edge(clk) then
        q <= d;
    end if;
end process;
```

یعنی:

> در هر Rising Edge کلاک، مقدار `d` در `q` ذخیره شود.

---

# 6. Flip-Flop چیست؟

فلیپ فلاپ**Flip-Flop** یکی از پایه‌ای‌ترین عناصر حافظه دیجیتال است.

یک Flip-Flop می‌تواند یک Bit را ذخیره کند.

یعنی:

```text
0
```

یا:

```text
1
```

یک مدل ساده:

```text
D ─────┐
       │
      D Flip-Flop ─── Q
       │
CLK ───┘
```

در Rising Edge:

```text
Q ← D
```

---

# 7. D Flip-Flop

دی فلیپ فلاپ D Flip-Flop مهم‌ترین Flip-Flop برای شروع VHDL است.

رفتار:

|Rising Edge|D|Q بعد از Edge|
|---|--:|--:|
|↑|0|0|
|↑|1|1|

یعنی:

```text
Q(next) = D
```

اما فقط در لحظه فعال Clock.

این تفاوت بسیار مهم است.

در مدار ترکیبی:

```text
D تغییر کند
   ↓
Q می‌تواند تغییر کند
```

اما در D Flip-Flop:

```text
D تغییر کند
   ↓
Q لزوماً تغییر نمی‌کند
   ↓
Clock Edge
   ↓
Q ← D
```

---

# 8. D Flip-Flop در VHDL

یک نمونه ساده:

```vhdl
library ieee;
use ieee.std_logic_1164.all;

entity d_flip_flop is
    port (
        clk : in  std_logic;
        d   : in  std_logic;
        q   : out std_logic
    );
end entity;

architecture rtl of d_flip_flop is
begin

    process(clk)
    begin
        if rising_edge(clk) then
            q <= d;
        end if;
    end process;

end architecture;
```

اینجا:

```text
clk → Clock
d   → Data Input
q   → Stored Value
```

و:

```vhdl
if rising_edge(clk) then
    q <= d;
end if;
```

رفتار Flip-Flop را توصیف می‌کند.

---

# 9. Reset

مدارهای ترتیبی معمولاً به یک روش برای قرار دادن سیستم در وضعیت مشخص نیاز دارند.

مثلاً Counter را نمی‌خواهیم از یک مقدار تصادفی شروع کنیم.

به همین دلیل از **Reset** استفاده می‌کنیم.

مثلاً:

```text
Reset
  ↓
0000
  ↓
0001
  ↓
0010
```

Reset می‌تواند:

- Synchronous
    
- Asynchronous
    

باشد.

---

# 10. Synchronous Reset

در Reset هم همراه Clock عمل می‌کند.

مثلاً:

```vhdl
process(clk)
begin
    if rising_edge(clk) then
        if reset = '1' then
            q <= '0';
        else
            q <= d;
        end if;
    end if;
end process;
```

در اینجا حتی اگر `reset` تغییر کند، `q` در همان لحظه تغییر نمی‌کند؛ تغییر `q` در Rising Edge انجام می‌شود.

---

# 11. Asynchronous Reset

در این مدل Reset مستقل از Clock عمل می‌کند.

مثلاً:

```vhdl
process(clk, reset)
begin
    if reset = '1' then
        q <= '0';
    elsif rising_edge(clk) then
        q <= d;
    end if;
end process;
```

اگر:

```text
reset = 1
```

شود، Flip-Flop بدون انتظار برای Clock به مقدار Reset می‌رود.

---

# 12. Register چیست؟

اگر یک Flip-Flop یک Bit ذخیره کند:

```text
1 Flip-Flop → 1 Bit
```

پس برای ذخیره ۸ بیت:

```text
8 Flip-Flops → 8-bit Register
```

مدل:

```text
D7 ──→ FF ──→ Q7
D6 ──→ FF ──→ Q6
D5 ──→ FF ──→ Q5
...
D0 ──→ FF ──→ Q0
```

همه با یک Clock مشترک.

در VHDL:

```vhdl
signal data : std_logic_vector(7 downto 0);
```

و مثلاً:

```vhdl
process(clk)
begin
    if rising_edge(clk) then
        data <= input_data;
    end if;
end process;
```

این مفهوم بعدها در:

```text
CPU Registers
Datapath
Pipeline
Memory Interfaces
```

بسیار مهم است.

---

# 13. Shift Register

یک Shift Register مجموعه‌ای از Flip-Flopهاست که داده را در هر Clock جابه‌جا می‌کند.

مثلاً:

```text
Q3 ← Q2 ← Q1 ← Q0
```

اگر:

```text
0001
```

داشته باشیم و هر Clock یک بار Shift کنیم:

```text
0001
0010
0100
1000
```

یا در جهت دیگر:

```text
0001
0000
0000
0000
```

بسته به نوع طراحی.

Shift Register در:

```text
Serial Communication
UART
SPI
Data Conversion
Delay Lines
```

کاربرد دارد.

یکی از اولین مدارهای ترتیبی مهم **Counter** است.

مثلاً یک Counter چهار بیتی:

```text

0001
 ↓
0010
 ↓
0011
 ↓

 ↓

 ...

        │   Counter     │

        └───────┬───────┘
                │
                ▼

```

# 18. Frequency Divider

کلاک Clock FPGA ممکن است بسیار سریع باشد، اما برای پروژه‌ای مثل LED چشم انسان تغییرات بسیار سریع را نمی‌بیند.

می‌توان با Counter یک Clock Enable یا تقسیم‌کننده فرکانس ساخت.

مثلاً:

```text
Fast Clock
    ↓
Counter
    ↓
Slower Timing Signal
```

این مفهوم بعدها در:

```text
Digital Clock
Stopwatch
UART
PWM
Timer
```

بسیار مهم می‌شود.

# 19. State

یکی از مهم‌ترین مفاهیم Sequential Logic، **State** است.

State یعنی:

> اطلاعاتی که وضعیت فعلی سیستم را توصیف می‌کند.

مثلاً یک Traffic Light:

```text
RED
GREEN
YELLOW
```

این سه مقدار State هستند.

سیستم ممکن است چنین رفتاری داشته باشد:

```text
RED
 ↓
GREEN
 ↓
YELLOW
 ↓
RED
```

این دقیقاً پایه‌ی **Finite State Machine** است.

بنابراین:

```text
Flip-Flop
   ↓
Register
   ↓
State
   ↓
FSM
```

---

# 20. Sequential Circuit و FSM

یک FSM معمولاً از سه بخش تشکیل می‌شود:

```text
Current State
     ↓
Next-State Logic
     ↓
Next State
     ↓
State Register
     ↓
Current State
```

مدل کامل‌تر:

```text
              ┌─────────────────┐
Inputs ──────→│ Next-State Logic│
              └────────┬────────┘
                       │
                       ▼
                 ┌───────────┐
Clock ──────────→│   State   │
                 │  Register │
                 └─────┬─────┘
                       │
                       ▼
                 Current State
                       │
                       ▼
                 Output Logic
                       │
                       ▼
                    Output
```

این موضوع در بخش بعدی یعنی **Finite State Machines** به‌طور کامل بررسی خواهد شد.

# 21. Timing

اینجا برای اولین بار باید دانشجو با مفهوم **Timing** جدی‌تر آشنا شود.

فرض کن:

```text
Clock
      ┌───┐       ┌───┐
──────┘   └───────┘   └───
          ↑           ↑
        Edge        Edge
```

Flip-Flop در Edge داده را نمونه‌برداری می‌کند.

اما سخت‌افزار واقعی زمان می‌برد تا سیگنال‌ها تغییر کنند.

به همین دلیل مفاهیمی مانند:

```text
Propagation Delay
Setup Time
Hold Time
Clock-to-Q Delay
```

مهم می‌شوند.

---

# 22. Setup Time

داده باید مدت کوتاهی **قبل از Clock Edge** پایدار باشد.

```text
        Setup
          ↓
D ────────████████────
                  ↑
                Clock
```

اگر داده درست قبل از Edge تغییر کند، ممکن است Flip-Flop نتواند مقدار را به‌درستی ثبت کند.

---

# 23. Hold Time

داده باید مدت کوتاهی **بعد از Clock Edge** نیز پایدار بماند.

یعنی:

```text
Setup Time
     +
Clock Edge
     +
Hold Time
```

باید شرایط مناسب برای نمونه‌برداری فراهم شود.

در طراحی FPGAهای واقعی، Timing یکی از موضوعات بسیار مهم است.

---

# 24. Nonblocking Assignment در VHDL

در VHDL assignmentها با `<=` انجام می‌شوند و در مدل‌سازی سخت‌افزار، مفهوم **signal update** و delta cycle اهمیت دارد.

مثلاً:

```vhdl
process(clk)
begin
    if rising_edge(clk) then
        q1 <= d;
        q2 <= q1;
    end if;
end process;
```

در یک Clock Edge:

```text
q1 ← d
q2 ← previous q1
```

نه اینکه `q2` فوراً مقدار جدید `q1` را بگیرد.

این رفتار برای مدل‌سازی Registerها و Pipeline بسیار مهم است.

# 25. Clocked vs Unclocked Sequential Logic

همه مدارهای ترتیبی الزاماً یکسان نیستند.

### Synchronous Sequential Logic

بر اساس Clock کار می‌کند:

```text
Clock
  ↓
State Update
```

نمونه:

```text
Register
Counter
Synchronous FSM
```

### Asynchronous Sequential Logic

ممکن است بدون Clock مرکزی تغییر کند.

این نوع طراحی پیچیده‌تر است و در مسیر مقدماتی VHDL بهتر است فعلاً فقط مفهوم آن معرفی شود.

برای شروع FPGA Design، تمرکز اصلی باید روی:

> **Synchronous Digital Design**

باشد.

# 26. VHDL برای Sequential Logic

الگوی اصلی را دانشجو باید به‌خوبی بشناسد:

```vhdl
process(clk)
begin
    if rising_edge(clk) then
        -- state update
    end if;
end process;
```

با Reset:

```vhdl
process(clk)
begin
    if rising_edge(clk) then
        if reset = '1' then
            -- reset state
        else
            -- normal operation
        end if;
    end if;
end process;
```

این الگو در بخش بزرگی از طراحی RTL استفاده می‌شود.

# 27. یک Counter ساده در VHDL

برای مثال یک Counter چهار بیتی:

```vhdl
library ieee;
use ieee.std_logic_1164.all;
use ieee.numeric_std.all;

entity counter is
    port (
        clk   : in  std_logic;
        reset : in  std_logic;
        q     : out unsigned(3 downto 0)
    );
end entity;

architecture rtl of counter is
    signal count : unsigned(3 downto 0);
begin

    process(clk)
    begin
        if rising_edge(clk) then
            if reset = '1' then
                count <= (others => '0');
            else
                count <= count + 1;
            end if;
        end if;
    end process;

    q <= count;

end architecture;
```

اینجا دانشجو چند مفهوم را یکجا می‌بیند:

```text
Clock
Reset
Register
State
Counter
numeric_std
Unsigned
Sequential Process
```

# 31. مسیر مفهومی این بخش

دانشجو باید این زنجیره را در پایان Sequential Circuits بفهمد:

```text
Logic Gates
     ↓
Combinational Logic
     ↓
       ┌──────────┐
Clock →│ Flip-Flop│
       └────┬─────┘
            ↓
         Register
            ↓
          Counter
            ↓
           State
            ↓
           FSM
            ↓
      Digital System
```

و از دید VHDL:

```text
Combinational
      ↓
Concurrent Assignment
      ↓
Combinational Process
      ↓
Clock
      ↓
rising_edge(clk)
      ↓
Flip-Flop
      ↓
Register
      ↓
Counter
      ↓
FSM
```

**نکته مهم آموزشی:** در این بخش هنوز FSM را کامل آموزش نده. فقط مفهوم **State** را معرفی کن. FSM باید فصل مستقل بعدی باشد، چون آنجا دانشجو می‌تواند تمام چیزهایی را که تا اینجا یاد گرفته—Combinational Logic + Registers + Clock + State—در یک سیستم کنترلی واقعی مثل **Traffic Light** یا **Vending Machine** ترکیب کند.
