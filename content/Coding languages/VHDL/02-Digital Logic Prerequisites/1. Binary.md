# باینری (Binary) — مبنای دودویی (نسخه کامل و جامع)

## مقدمه: چرا باینری؟

تصور کنید می‌خواهید با یک لامپ ساده پیام ارسال کنید. تنها کاری که می‌توانید انجام دهید این است که لامپ را **روشن** یا **خاموش** کنید. با همین دو حالت ساده، اگر به اندازه کافی صبر کنید، می‌توانید هر پیامی را ارسال کنید! این دقیقاً همان کاری است که سیستم‌های دیجیتال انجام می‌دهند، اما با سرعت نور و میلیاردها بار در ثانیه.

سیستم‌های دیجیتال بر اساس **دو وضعیت** کار می‌کنند: 
- **ولتاژ پایین (Low)** ≈ 0 ولت
- **ولتاژ بالا (High)** ≈ ولتاژ تغذیه (مثلاً 3.3V یا 5V)

این دو وضعیت را با **۰** و **۱** نمایش می‌دهیم. به همین دلیل، مبنای **دودویی (Binary)** پایه و اساس تمام سیستم‌های دیجیتال است.

---

## ۱. سیستم‌های عددی: مروری سریع

### سیستم ده‌دهی (Decimal - Base 10)
ما انسان‌ها به خاطر داشتن ۱۰ انگشت، از سیستم ده‌دهی استفاده می‌کنیم:
- ارقام: ۰, ۱, ۲, ۳, ۴, ۵, ۶, ۷, ۸, ۹
- ارزش مکانی: ۱۰⁰, ۱۰¹, ۱۰², ۱۰³, ...

مثال: عدد ۳۵۷ در مبنای ۱۰ یعنی:
```
۳۵۷ = 3×10² + 5×10¹ + 7×10⁰
     = 300 + 50 + 7
```

### سیستم دودویی (Binary - Base 2)
سیستم‌های دیجیتال از دو وضعیت استفاده می‌کنند:
- ارقام: ۰, ۱
- ارزش مکانی: ۲⁰, ۲¹, ۲², ۲³, ...

مثال: عدد ۱۰۱۱ در مبنای ۲ یعنی:
```
۱۰۱۱₂ = 1×2³ + 0×2² + 1×2¹ + 1×2⁰
      = 8 + 0 + 2 + 1
      = ۱۱₁₀
```

## ۲. بیت (Bit): کوچک‌ترین واحد اطلاعات

**بیت (Bit)** مخفف **Binary Digit** است و کوچک‌ترین واحد اطلاعات در دنیای دیجیتال محسوب می‌شود.

### یک بیت چقدر اطلاعات دارد؟
یک بیت فقط می‌تواند یکی از دو مقدار را داشته باشد:
- ۰ (خاموش، Low، False، No)
- ۱ (روشن، High، True، Yes)

### قیاس با دنیای واقعی
یک بیت مانند یک کلید چراغ است: یا روشن است یا خاموش. با یک کلید نمی‌توانید وضعیت‌های مختلفی مثل «نیمه‌روشن» یا «کمی روشن» داشته باشید. این سادگی باعث می‌شود مدارهای دیجیتال بسیار قابل اعتماد و مقاوم در برابر نویز باشند.

---

## ۳. توانایی نمایش اعداد با n بیت

هر بیت که به مجموعه اضافه می‌شود، تعداد حالات ممکن را **دو برابر** می‌کند:

| تعداد بیت | تعداد حالات | محدوده اعداد (Unsigned) |
|----------|------------|------------------------|
| ۱ بیت    | ۲¹ = ۲     | ۰ تا ۱                 |
| ۲ بیت    | ۲² = ۴     | ۰ تا ۳                 |
| ۳ بیت    | ۲³ = ۸     | ۰ تا ۷                 |
| ۴ بیت    | ۲⁴ = ۱۶    | ۰ تا ۱۵                |
| ۸ بیت    | ۲⁸ = ۲۵۶   | ۰ تا ۲۵۵               |
| ۱۶ بیت   | ۲¹⁶ = ۶۵۵۳۶ | ۰ تا ۶۵۵۳۵            |
| ۳۲ بیت   | ۲³² ≈ ۴.۲ میلیارد | ۰ تا ۴,۲۹۴,۹۶۷,۲۹۵ |

### فرمول کلی
```
با n بیت می‌توان ۲ⁿ مقدار مختلف را نمایش داد
حداکثر مقدار (Unsigned) = ۲ⁿ - ۱
```

### مثال: تصویر یک صفحه نمایش
یک صفحه نمایش Full HD (۱۹۲۰×۱۰۸۰ پیکسل) با ۲۴ بیت رنگ (۸ بیت برای هر رنگ قرمز، سبز و آبی):
- هر پیکسل: ۲²⁴ ≈ ۱۶.۷ میلیون رنگ مختلف
- کل پیکسل‌ها: ۱۹۲۰ × ۱۰۸۰ ≈ ۲ میلیون پیکسل
- کل بیت‌ها: ۲ میلیون × ۲۴ ≈ ۴۸ میلیون بیت

## ۴. اصطلاحات پایه: Nibble، Byte و Word

در دنیای دیجیتال، به مجموعه‌های خاصی از بیت‌ها نام‌های مشخصی داده‌ایم:

```
Nibble (نیبل) = ۴ بیت
مثال: ۱۰۱۰

Byte (بایت) = ۸ بیت = ۲ نیبل
مثال: ۱۰۱۱۰۱۰۱

Word (کلمه) = معمولاً ۱۶ بیت = ۲ بایت
Double Word = ۳۲ بیت = ۴ بایت
Quad Word = ۶۴ بیت = ۸ بایت
```

### کاربرد عملی
- **Nibble**: در نمایش Hexadecimal (هر رقم Hex = یک Nibble)
- **Byte**: واحد پایه حافظه و ذخیره‌سازی (هر کاراکتر ASCII یک بایت)
- **Word**: واحد پایه در پردازنده‌های ۱۶ بیتی (مثل ۸۰۸۶)
- **Double Word**: واحد پایه در پردازنده‌های ۳۲ بیتی (مثل ۸۰۳۸۶ و Pentium)
- **Quad Word**: واحد پایه در پردازنده‌های ۶۴ بیتی (مثل Core i7 و Ryzen)

## ۵. نمایش اعداد در باینری

### تبدیل Decimal → Binary

روش اصلی: **تقسیم متوالی بر ۲**

مثال: تبدیل ۲۵ به باینری

```
۲۵ ÷ ۲ = ۱۲   باقیمانده: ۱  ← LSB
۱۲ ÷ ۲ = ۶    باقیمانده: ۰
۶ ÷ ۲ = ۳     باقیمانده: ۰
۳ ÷ ۲ = ۱     باقیمانده: ۱
۱ ÷ ۲ = ۰     باقیمانده: ۱  ← MSB
```

خواندن از پایین به بالا: **۱۱۰۰۱₂**

**روش سریع‌تر: جمع توان‌های ۲**

بزرگ‌ترین توان ۲ کوچک‌تر یا مساوی ۲۵: ۱۶
```
۲۵ - ۱۶ = ۹
بزرگ‌ترین توان ۲ کوچک‌تر یا مساوی ۹: ۸
۹ - ۸ = ۱
بزرگ‌ترین توان ۲ کوچک‌تر یا مساوی ۱: ۱
۱ - ۱ = ۰
```
پس: ۲۵ = ۱۶ + ۸ + ۱ = ۲⁴ + ۲³ + ۲⁰

یعنی: ۱۱۰۰۱₂ (چون ۲² و ۲¹ صفر هستند)

### تبدیل Binary → Decimal

مثال: ۱۰۱۱۰۱₂ را به ده‌دهی تبدیل کنید:

```
۱×۲⁵ = ۳۲
۰×۲⁴ = ۰
۱×۲³ = ۸
۱×۲² = ۴
۰×۲¹ = ۰
۱×۲⁰ = ۱
─────────────
جمع = ۴۵
```

پس: **۱۰۱۱۰۱₂ = ۴۵₁₀**

## ۶. باینری در سخت‌افزار: از ولتاژ تا منطق

### سطوح ولتاژ

در یک مدار دیجیتال واقعی، ولتاژها به صورت زیر تفسیر می‌شوند:

```
برای منطق Positive (مثبت):
ولتاژ ۰ تا ۰.۸ ولت → LOW → ۰
ولتاژ ۲ تا ۵ ولت → HIGH → ۱

منطق Negative (منفی):
ولتاژ LOW → ۱
ولتاژ HIGH → ۰
```

### حاشیه امنیت (Noise Margin)

چرا محدوده‌ها اینقدر باز هستند؟ برای ایجاد **حاشیه امنیت در برابر نویز**:

```
         │ نویز │
  ۰.۸V ──┼──────┼── ۲V
  LOW    │      │ HIGH
         │      │
```

اگر ولتاژ به دلیل نویز کمی تغییر کند، همچنان در محدوده صحیح باقی می‌ماند.

### مثال: سیگنال دیجیتال روی سیم

```
زمان → 0  1  2  3  4  5  6  7  8
        ┌─┐     ┌─┐     ┌─┐
ولتاژ  │ │     │ │     │ │
High ──┘ └─────┘ └─────┘ └─────
        ┌─┐     ┌─┐     ┌─┐
Low  ──┘ └─────┘ └─────┘ └─────
       0  1  0  1  0  1  0  1
```

این سیگنال در واقع دنباله باینری `۰۱۰۱۰۱۰۱` را نشان می‌دهد.

## ۷. هگزادسیمال (Hexadecimal): میانبری برای باینری

باینری برای انسان‌ها خواندن سخت است. یک عدد ۱۶ بیتی مثل `۱۰۱۱۰۱۰۱۱۰۱۰۱۰۱۰` طولانی و خسته‌کننده است. اینجاست که **هگزادسیمال (مبنای ۱۶)** وارد می‌شود.

### چرا ۱۶؟
هر رقم هگزادسیمال دقیقاً معادل **۴ بیت** (یک Nibble) است.

### جدول تبدیل ۴ بیتی

| باینری | هگزادسیمال | ده‌دهی |
|--------|-----------|--------|
| ۰۰۰۰   | ۰         | ۰      |
| ۰۰۰۱   | ۱         | ۱      |
| ۰۰۱۰   | ۲         | ۲      |
| ۰۰۱۱   | ۳         | ۳      |
| ۰۱۰۰   | ۴         | ۴      |
| ۰۱۰۱   | ۵         | ۵      |
| ۰۱۱۰   | ۶         | ۶      |
| ۰۱۱۱   | ۷         | ۷      |
| ۱۰۰۰   | ۸         | ۸      |
| ۱۰۰۱   | ۹         | ۹      |
| ۱۰۱۰   | A         | ۱۰     |
| ۱۰۱۱   | B         | ۱۱     |
| ۱۱۰۰   | C         | ۱۲     |
| ۱۱۰۱   | D         | ۱۳     |
| ۱۱۱۰   | E         | ۱۴     |
| ۱۱۱۱   | F         | ۱۵     |

### تبدیل باینری به هگزادسیمال

مثال: `۱۰۱۱۰۱۰۱۱۰۱۰۱۰۱۰₂` را به هگزادسیمال تبدیل کنید:

مرحله ۱: از راست به چپ به گروه‌های ۴ بیتی تقسیم کنید:
```
۱۰۱۱ ۰۱۰۱ ۱۰۱۰ ۱۰۱۰
```

مرحله ۲: هر گروه را به هگزادسیمال تبدیل کنید:
```
۱۰۱۱ = B
۰۱۰۱ = ۵
۱۰۱۰ = A
۱۰۱۰ = A
```

نتیجه: **B5AA₁₆**

### تبدیل هگزادسیمال به باینری

مثال: `F3A1₁₆` را به باینری تبدیل کنید:

هر رقم را به ۴ بیت تبدیل کنید:
```
F = ۱۱۱۱
۳ = ۰۰۱۱
A = ۱۰۱۰
۱ = ۰۰۰۱
```

نتیجه: `۱۱۱۱۰۰۱۱۱۰۱۰۰۰۰۱₂`

## ۸. اعداد علامت‌دار (Signed Numbers)

تا اینجا اعداد را بدون علامت (Unsigned) دیدیم. اما در دنیای واقعی، اعداد منفی هم وجود دارند!

### روش‌های نمایش اعداد منفی

#### ۱. علامت و مقدار (Sign-Magnitude)
- بیت اول = علامت (۰ برای مثبت، ۱ برای منفی)
- بقیه بیت‌ها = مقدار مطلق

مثال (۴ بیتی):
```
۰۱۰۱ = +۵
۱۱۰۱ = -۵
```

**مشکل:** دو صفر داریم (۰۰۰۰ و ۱۰۰۰ هر دو صفر هستند!)

#### ۲. متمم یک (One's Complement)
- معکوس کردن همه بیت‌ها

مثال (۴ بیتی):
```
۰۱۰۱ = +۵
۱۰۱۰ = -۵
```

**مشکل:** باز هم دو صفر داریم!

#### ۳. متمم دو (Two's Complement) ✓ (روش استاندارد)
- متمم یک بگیرید، سپس ۱ اضافه کنید

### دو متمم (Two's Complement) با جزئیات

برای تبدیل یک عدد مثبت به منفی در دو متمم:

**مثال: تبدیل +۵ به -۵ (در ۴ بیت)**

مرحله ۱: +۵ = ۰۱۰۱
مرحله ۲: متمم یک: ۱۰۱۰
مرحله ۳: اضافه کردن ۱: ۱۰۱۰ + ۱ = ۱۰۱۱

پس: **-۵ = ۱۰۱۱**

**بررسی:** ۱۰۱۱ + ۰۱۰۱ = ۱۰۰۰۰ (که با ۴ بیت می‌شود ۰۰۰۰)

### جدول کامل اعداد دو متمم (۴ بیتی)

| باینری | مقدار دو متمم |
|--------|--------------|
| ۰۱۱۱   | +۷           |
| ۰۱۱۰   | +۶           |
| ۰۱۰۱   | +۵           |
| ۰۱۰۰   | +۴           |
| ۰۰۱۱   | +۳           |
| ۰۰۱۰   | +۲           |
| ۰۰۰۱   | +۱           |
| ۰۰۰۰   | ۰            |
| ۱۱۱۱   | -۱           |
| ۱۱۱۰   | -۲           |
| ۱۱۰۱   | -۳           |
| ۱۱۰۰   | -۴           |
| ۱۰۱۱   | -۵           |
| ۱۰۱۰   | -۶           |
| ۱۰۰۱   | -۷           |
| ۱۰۰۰   | -۸           |

### نکات مهم دو متمم

۱. **محدوده:** با n بیت، محدوده از `-2ⁿ⁻¹` تا `+2ⁿ⁻¹-1`
۲. **یک صفر بیشتر:** فقط یک صفر وجود دارد (۰۰۰۰)
۳. **ساده‌ترین عملیات:** جمع و تفریق به سادگی انجام می‌شود
۴. **گسترش علامت (Sign Extension):** برای بزرگ کردن تعداد بیت‌ها، بیت علامت (MSB) را تکرار کنید

### گسترش علامت (Sign Extension)

وقتی یک عدد ۴ بیتی را به ۸ بیت تبدیل می‌کنیم:

```
+۵ (۴ بیت) = ۰۱۰۱ → ۰۰۰۰۰۱۰۱ (۸ بیت)
-۵ (۴ بیت) = ۱۰۱۱ → ۱۱۱۱۱۰۱۱ (۸ بیت)
```

بیت علامت (MSB) را تکرار می‌کنیم تا اندازه بزرگتر شود.

### مثال‌های عملی

#### جمع دو عدد در دو متمم
```
  +۵ = ۰۱۰۱
+ -۳ = ۱۱۰۱
───────────
  +۲ = ۰۰۱۰ (با نادیده گرفتن بیت نقلی)
```

#### تفریق با دو متمم
A - B = A + (متمم دو B)

```
۵ - ۳ = ۵ + (-۳) = ۰۱۰۱ + ۱۱۰۱ = ۰۰۱۰ = ۲
```

## ۹. باینری در VHDL

### std_logic: یک بیت

```vhdl
signal bit1 : std_logic;
```
- یک سیگنال تک‌بیتی
- می‌تواند مقادیر: '0', '1', 'X', 'U', 'Z', 'W', 'L', 'H', '-'
- '0' و '1' مهم‌ترین مقادیر برای منطق دیجیتال هستند

### std_logic_vector: آرایه‌ای از بیت‌ها

```vhdl
signal data : std_logic_vector(7 downto 0);
```
- یک آرایه ۸ بیتی
- اندیس‌ها از ۷ تا ۰ (MSB به LSB)
- قابل استفاده به عنوان عدد، آدرس، داده، دستور، یا هر چیز دیگری

### انتساب مقدار

```vhdl
-- باینری مستقیم
data <= "10110101";

-- هگزادسیمال
data <= x"B5";  -- همان ۱۰۱۱۰۱۰۱

-- OCTAL (مبنای ۸) - کمتر استفاده می‌شود
data <= o"265";  -- معادل باینری ۰۱۰ ۱۱۰ ۱۰۱
```

### تفاوت std_logic و std_logic_vector

```
std_logic        → یک بیت (یک سیم)
std_logic_vector → چند بیت (یک باس)
```

مثال:
```vhdl
signal enable : std_logic;              -- یک بیت
signal address : std_logic_vector(7 downto 0);  -- ۸ بیت
signal data_bus : std_logic_vector(31 downto 0); -- ۳۲ بیت
```

### نکته: std_logic_vector عدد نیست!

وقتی می‌نویسیم:
```vhdl
signal data : std_logic_vector(7 downto 0);
```

فقط می‌گوییم این یک مجموعه ۸ بیتی است. این مجموعه می‌تواند باشد:
- یک عدد ۰ تا ۲۵۵ (Unsigned)
- یک عدد -۱۲۸ تا +۱۲۷ (Signed)
- یک دستور ماشین
- یک کاراکتر ASCII
- ۸ کلید مجزا
- یک نمونه رنگ
- بخشی از یک آدرس

برای اینکه VHDL بداند این یک عدد است، باید از کتابخانه‌های خاص استفاده کنیم:

```vhdl
library ieee;
use ieee.numeric_std.all;

signal a : unsigned(7 downto 0);  -- عدد بدون علامت ۸ بیتی
signal b : signed(7 downto 0);    -- عدد علامت‌دار ۸ بیتی
```

## ۱۰. Bit Ordering: MSB و LSB

**MSB (Most Significant Bit)** = باارزش‌ترین بیت
**LSB (Least Significant Bit)** = کم‌ارزش‌ترین بیت

در `std_logic_vector(7 downto 0)`:
```
MSB = bit 7
LSB = bit 0

مثال: ۱۰۱۱۰۱۰۱
       ↑      ↑
       MSB    LSB
```

### چرا دو نوع اندیس‌گذاری وجود دارد؟

**downto** (اندیس نزولی):
```vhdl
data(7 downto 0)  -- MSB = 7, LSB = 0
```
- استاندارد در VHDL برای اعداد
- آسان‌تر برای کار با محاسبات ریاضی

**to** (اندیس صعودی):
```vhdl
data(0 to 7)  -- LSB = 0, MSB = 7
```
- گاهی برای باس‌ها یا پروتکل‌های خاص استفاده می‌شود
- کمتر رایج است

### مثال عملی

```vhdl
signal data : std_logic_vector(7 downto 0) := "10110101";

-- دسترسی به بیت‌ها
bit7 := data(7);  -- '1' (MSB)
bit0 := data(0);  -- '1' (LSB)
bit3 := data(3);  -- '0'
```

## ۱۱. مثال‌های عملی از کاربرد باینری در سخت‌افزار

### مثال ۱: ۴ کلید به عنوان ورودی باینری

```
کلیدها: SW3 SW2 SW1 SW0
وضعیت: 1   0   1   0
         ↓   ↓   ↓   ↓
عدد باینری: ۱۰۱۰ = ۱۰₁₀
```

در VHDL:
```vhdl
switches <= "1010";  -- ۴ بیت
```

### مثال ۲: ۷-سگمنت دیکدر

یک دیکدر ۴ بیتی که عدد باینری را به ۷-سگمنت تبدیل می‌کند:

```
ورودی (۴ بیت) → خروجی (۷ سگمنت)
۰ (۰۰۰۰) → نمایش "۰"
۱ (۰۰۰۱) → نمایش "۱"
...
۹ (۱۰۰۱) → نمایش "۹"
```

### مثال ۳: آدرس‌دهی حافظه

```
یک حافظه با ۱۰۲۴ خانه → نیاز به ۱۰ بیت آدرس
چون ۲¹⁰ = ۱۰۲۴

آدرس ۰ = ۰۰۰۰۰۰۰۰۰۰
آدرس ۵۱۲ = ۱۰۰۰۰۰۰۰۰۰
آدرس ۱۰۲۳ = ۱۱۱۱۱۱۱۱۱۱
```

### مثال ۴: پروتکل UART (ارسال سریال)

یک بایت داده `'A'` (ASCII 65 = 01000001):
```
Start Bit (0) → Data (01000001) → Stop Bit (1)
```
این دنباله بیت‌ها به صورت سریال روی یک سیم فرستاده می‌شود.

## ۱۲. اشتباهات رایج دانشجویان

### اشتباه ۱: فکر کردن اینکه std_logic_vector همیشه عدد است
```vhdl
signal data : std_logic_vector(7 downto 0);
-- این لزوماً یک عدد نیست! می‌تواند آدرس، دستور، رنگ، ASCII و غیره باشد
```

### اشتباه ۲: فراموش کردن اینکه بیت‌ها اندیس دارند
```vhdl
signal data : std_logic_vector(7 downto 0);
-- data(0) = LSB، data(7) = MSB
```

### اشتباه ۳: قاطی کردن اندازه‌ها
```
یک بایت = ۸ بیت
۴ بایت = ۳۲ بیت
۸ بایت = ۶۴ بیت
```

### اشتباه ۴: فراموش کردن نوع اعداد (Signed vs Unsigned)
```
"11111111" به عنوان unsigned = ۲۵۵
"11111111" به عنوان signed = -۱
```

### اشتباه ۵: استفاده از اعداد ده‌دهی مستقیم در VHDL
```vhdl
-- اشتباه:
data <= 255;  -- این کار نمی‌کند!

-- درست:
data <= "11111111";  -- باینری
data <= x"FF";       -- هگز
data <= to_unsigned(255, 8);  -- با کتابخانه
```

## ۱۳. تمرین‌های عملی

### سطح مبتدی

**۱.** عدد ۷ را به باینری ۴ بیتی تبدیل کنید.  
**پاسخ:** ۰۱۱۱

**۲.** عدد ۱۰ را به باینری ۴ بیتی تبدیل کنید.  
**پاسخ:** ۱۰۱۰

**۳.** عدد ۲۳ را به باینری ۵ بیتی تبدیل کنید.  
**پاسخ:** ۱۰۱۱۱

**۴.** `۱۰۱۰₂` را به ده‌دهی تبدیل کنید.  
**پاسخ:** ۱۰

**۵.** `۱۱۰۱۰۱₂` را به ده‌دهی تبدیل کنید.  
**پاسخ:** ۵۳

**۶.** `۱۰۱۰۱۱۱۰₂` را به هگزادسیمال تبدیل کنید.  
**پاسخ:** ۰xAE

**۷.** `F3₁₆` را به باینری تبدیل کنید.  
**پاسخ:** ۱۱۱۱۰۰۱۱

### سطح متوسط

**۸.** چند مقدار مختلف را می‌توان با ۷ بیت نمایش داد؟  
**پاسخ:** ۲⁷ = ۱۲۸

**۹.** حداکثر مقدار Unsigned با ۱۰ بیت چقدر است؟  
**پاسخ:** ۲¹⁰ - ۱ = ۱۰۲۳

**۱۰.** محدوده اعداد Signed دو متمم با ۶ بیت چیست؟  
**پاسخ:** -۳۲ تا +۳۱

**۱۱.** چگونه عدد -۷ را در دو متمم ۴ بیتی نمایش می‌دهیم؟  
**پاسخ:** +۷ = ۰۱۱۱ → متمم یک = ۱۰۰۰ → +۱ = ۱۰۰۱

**۱۲.** `۱۰۱۱۰۱۱۰₂` را به هگزادسیمال تبدیل کنید.  
**پاسخ:** ۰xB6

**۱۳.** `A5₁₆` را به باینری تبدیل کنید.  
**پاسخ:** ۱۰۱۰۰۱۰۱

**۱۴.** فرق بین MSB و LSB را توضیح دهید.  
**پاسخ:** MSB = باارزش‌ترین بیت، LSB = کم‌ارزش‌ترین بیت

**۱۵.** چرا `std_logic_vector` لزوماً یک عدد نیست؟  
**پاسخ:** می‌تواند آدرس، دستور، داده خام، و غیره باشد

### سطح پیشرفته

**۱۶.** یک بیت چند حالت می‌تواند داشته باشد؟  
**پاسخ:** ۲ حالت (۰ و ۱)

**۱۷.** در VHDL، چگونه یک سیگنال ۸ بیتی با مقدار ۰x3F تعریف می‌کنیم؟  
**پاسخ:** `signal data : std_logic_vector(7 downto 0) := x"3F";`

**۱۸.** تفاوت `unsigned` و `signed` در VHDL چیست؟  
**پاسخ:** unsigned = بدون علامت (۰ تا ۲ⁿ-۱)، signed = علامت‌دار با دو متمم

**۱۹.** چرا در سخت‌افزار از باینری استفاده می‌کنیم؟  
**پاسخ:** چون مدارهای دیجیتال با دو وضعیت ولتاژ (LOW/HIGH) کار می‌کنند

**۲۰.** عدد باینری زیر را به ده‌دهی و هگزادسیمال تبدیل کنید:  
`۱۰۱۱۰۱۰۱۱۰۱۰۱۰۱۰₂`  
**پاسخ:** ده‌دهی = ۴۶۶۹۰، هگز = 0xB6AA

## ۱۴. جمع‌بندی: باینری در مسیر آموزشی

### آنچه باید به خاطر بسپارید

۱. **باینری = مبنای ۲** با ارقام ۰ و ۱
۲. **بیت (Bit) = کوچک‌ترین واحد اطلاعات**
۳. **با n بیت می‌توان ۲ⁿ مقدار مختلف نمایش داد**
۴. **بایت = ۸ بیت**
۵. **هگزادسیمال = میانبری برای باینری** (هر رقم = ۴ بیت)
۶. **دو متمم = روش استاندارد برای اعداد منفی**
۷. **در VHDL، std_logic_vector فقط یک مجموعه بیت است، نه لزوماً یک عدد**
۸. **برای کار با اعداد، از unsigned و signed استفاده کنید**

### ارتباط با مباحث بعدی

باینری پایه و اساس همه مباحث بعدی است:
- **دروازه‌های منطقی** بر اساس ۰ و ۱ کار می‌کنند
- **مدارهای ترکیبی** از این ۰ و ۱ها برای محاسبات استفاده می‌کنند
- **فلیپ‌فلاپ‌ها** این ۰ و ۱ها را ذخیره می‌کنند
- **ثبات‌ها** گروه‌هایی از این ۰ و ۱ها را نگه می‌دارند
- **پردازنده‌ها** همه چیز را با ۰ و ۱ انجام می‌دهند

با درک عمیق باینری، شما پایه‌ای محکم برای ورود به دنیای طراحی دیجیتال و VHDL خواهید داشت.
