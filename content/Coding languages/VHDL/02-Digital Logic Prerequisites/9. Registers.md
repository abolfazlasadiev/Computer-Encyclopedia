# Registers — ثبات‌ها

بعد از **Flip-Flops**، طبیعی‌ترین قدم **Registers** است.

اگر یک Flip-Flop بتواند **یک بیت** را ذخیره کند، یک Register مجموعه‌ای از چند Flip-Flop است که برای ذخیره‌ی یک کلمه‌ی چندبیتی با هم کار می‌کنند.

مسیر اصلی:

```text
1 Flip-Flop
     ↓
1 Bit
     ↓
Multiple Flip-Flops
     ↓
Register
     ↓
Shift Register
     ↓
CPU Registers / Datapath
```

---

# 1. Register چیست؟

یک Register مجموعه‌ای از Storage Elementهاست که معمولاً با یک Clock مشترک کار می‌کنند.

مثلاً یک Register چهار بیتی:

```text
        ┌──────────────┐
D0 ────→│ D Flip-Flop  │────→ Q0
        └──────────────┘
              ↑
             CLK

D1 ────→│ D Flip-Flop  │────→ Q1
              ↑
             CLK

D2 ────→│ D Flip-Flop  │────→ Q2
              ↑
             CLK

D3 ────→│ D Flip-Flop  │────→ Q3
              ↑
             CLK
```

در واقع:

```text
4-bit Register = 4 × D Flip-Flop
```

و:

```text
8-bit Register = 8 × D Flip-Flop
```

---

# 2. چرا Register لازم داریم؟

Flip-Flop فقط یک بیت ذخیره می‌کند:

```text
FF → 1 bit
```

اما سیستم دیجیتال معمولاً با داده‌های چندبیتی کار می‌کند:

```text
00001101
10110110
01010101
```

پس باید چند Flip-Flop را کنار هم قرار دهیم.

مثلاً:

```text
D[7:0]
   ↓
┌─────────────────┐
│   8-bit Register│
└─────────────────┘
   ↓
Q[7:0]
```

حالا می‌توانیم یک مقدار ۸ بیتی را در یک Clock Edge ذخیره کنیم.

---

# 3. Register چگونه کار می‌کند؟

فرض کنیم:

```text
D = 10110101
```

و Clock Edge اتفاق بیفتد:

```text
        Rising Edge
             ↓
D = 10110101
             ↓
        ┌─────────┐
        │ Register│
        └─────────┘
             ↓
Q = 10110101
```

بعد اگر ورودی تغییر کند:

```text
D = 00001111
```

خروجی لزوماً بلافاصله تغییر نمی‌کند.

تا Clock Edge بعدی:

```text
Q = 10110101
```

باقی می‌ماند.

در Edge بعد:

```text
Q = 00001111
```

پس:

> Register داده را در یک لحظه مشخص از Clock دریافت و تا زمان Update بعدی حفظ می‌کند.

---

# 4. Register در مقابل Combinational Circuit

این تفاوت بسیار مهم است.

### Combinational

```text
A ───→ Logic ───→ Y
```

اگر `A` تغییر کند، `Y` می‌تواند تغییر کند.

---

### Register

```text
D ───→ Register ───→ Q
             ↑
            CLK
```

تغییر `D` به‌تنهایی باعث تغییر `Q` نمی‌شود.

Clock مشخص می‌کند چه زمانی داده ثبت شود.

---

# 5. Basic Register

ساده‌ترین Register:

```text
Input Data
    ↓
D Flip-Flops
    ↓
Stored Data
```

مثلاً 8-bit:

```text
D[7:0]
   │
   ▼
┌─────────────┐
│  8-bit      │
│  Register   │
└──────┬──────┘
       │
       ▼
Q[7:0]
```

همه Flip-Flopها Clock مشترک دارند.

---

# 6. Register با Reset

معمولاً Register باید بتواند به مقدار مشخصی Reset شود.

مثلاً:

```text
Reset
  ↓
Q = 00000000
```

در VHDL:

```vhdl
process(clk)
begin
    if rising_edge(clk) then
        if reset = '1' then
            q <= (others => '0');
        else
            q <= d;
        end if;
    end if;
end process;
```

این برای یک Register با عرض دلخواه بسیار مفید است.

---

# 7. `(others => '0')` چیست؟

در VHDL اگر:

```vhdl
q : out std_logic_vector(7 downto 0);
```

داشته باشیم:

```vhdl
q <= (others => '0');
```

یعنی تمام بیت‌ها صفر شوند:

```text
00000000
```

اگر:

```vhdl
q : out std_logic_vector(15 downto 0);
```

باشد، همان عبارت تبدیل می‌شود به:

```text
0000000000000000
```

این یکی از الگوهای بسیار مفید VHDL برای Vectorها است.

---

# 8. Register با Enable

همیشه نمی‌خواهیم Register در هر Clock مقدار جدید بگیرد.

مثلاً:

```text
Enable = 1
    ↓
Load Data

Enable = 0
    ↓
Keep Previous Value
```

مدل:

```text
D ───────────────┐
                 ↓
             ┌───────┐
Enable ─────→│Register│──→ Q
CLK ─────────→│       │
             └───────┘
```

در VHDL:

```vhdl
process(clk)
begin
    if rising_edge(clk) then
        if reset = '1' then
            q <= (others => '0');

        elsif enable = '1' then
            q <= d;

        end if;
    end if;
end process;
```

اگر `enable = 0` باشد، هیچ assignment جدیدی انجام نمی‌شود و Register مقدار قبلی خود را نگه می‌دارد.

---

# 9. Parallel Load

یکی از کاربردهای مهم Register، **Parallel Load** است.

فرض کنیم:

```text
D = 11010110
```

با یک Clock Edge:

```text
11010110
   ↓
Register
   ↓
11010110
```

تمام بیت‌ها هم‌زمان وارد Register می‌شوند.

به این می‌گوییم:

> **Parallel Load**

---

# 10. Shift Register

نوع مهم دیگری از Register، **Shift Register** است.

در اینجا داده به‌جای اینکه فقط ذخیره شود، در هر Clock به سمت چپ یا راست حرکت می‌کند.

مثلاً:

```text
Q3 Q2 Q1 Q0
```

اگر Shift Left کنیم:

```text
Q2 Q1 Q0 0
```

و اگر Shift Right:

```text
0 Q3 Q2 Q1
```

البته نحوه ورود بیت جدید به طراحی بستگی دارد.

---

# 11. مثال Shift Register

فرض کنیم:

```text
Initial:
0001
```

Shift Left:

```text
0010
```

Clock بعد:

```text
0100
```

Clock بعد:

```text
1000
```

پس:

```text
0001
  ↓
0010
  ↓
0100
  ↓
1000
```

---

# 12. Serial و Parallel

در Registerها دو مفهوم مهم داریم:

### Serial

بیت‌ها یکی‌یکی منتقل می‌شوند:

```text
1 → 0 → 1 → 1 → 0
```

### Parallel

چند بیت هم‌زمان منتقل می‌شوند:

```text
10110110
```

از ترکیب این دو مفهوم، چهار ساختار معروف به وجود می‌آید.

---

# 13. چهار نوع اصلی Shift Register

## SISO

**Serial-In Serial-Out**

```text
Serial In
   ↓
[FF] → [FF] → [FF] → [FF]
                       ↓
                   Serial Out
```

داده بیت‌به‌بیت وارد و بیت‌به‌بیت خارج می‌شود.

---

## SIPO

**Serial-In Parallel-Out**

```text
Serial In
    ↓
[FF] → [FF] → [FF] → [FF]
       ↓      ↓      ↓
      Q3     Q2     Q1     Q0
```

داده به صورت Serial وارد می‌شود، اما در نهایت می‌توان کل مقدار را به صورت Parallel خواند.

این ساختار برای تبدیل:

```text
Serial → Parallel
```

بسیار مهم است.

---

## PISO

**Parallel-In Serial-Out**

```text
D3 D2 D1 D0
 \  |  |  /
  [Register]
      ↓
 Serial Out
```

داده ابتدا به صورت Parallel بارگذاری می‌شود و سپس بیت‌ها یکی‌یکی خارج می‌شوند.

یعنی:

```text
Parallel → Serial
```

---

## PIPO

**Parallel-In Parallel-Out**

```text
D[3:0]
  ↓
Register
  ↓
Q[3:0]
```

داده هم‌زمان وارد و هم‌زمان خارج می‌شود.

این همان ساختار کلاسیک یک Register معمولی است.

---

# 14. جدول مقایسه

|نوع|Input|Output|کاربرد|
|---|---|---|---|
|SISO|Serial|Serial|Delay / Serial Data|
|SIPO|Serial|Parallel|Serial → Parallel|
|PISO|Parallel|Serial|Parallel → Serial|
|PIPO|Parallel|Parallel|Data Storage|

این جدول را می‌توان در دانشنامه به‌عنوان یک Reference سریع قرار داد.

---

# 15. Universal Shift Register

یک **Universal Shift Register** می‌تواند چند عملیات انجام دهد:

```text
Hold
Shift Left
Shift Right
Parallel Load
```

مثلاً با دو بیت Select:

```text
S1 S0
```

می‌توان عملیات را انتخاب کرد:

|S1|S0|Operation|
|--:|--:|---|
|0|0|Hold|
|0|1|Shift Right|
|1|0|Shift Left|
|1|1|Parallel Load|

این پروژه بسیار خوب است چون چند مفهوم را با هم ترکیب می‌کند:

```text
MUX
+
Flip-Flop
+
Register
+
Shift Logic
```

---

# 16. Register File

وقتی چند Register کنار هم قرار بگیرند، می‌توانیم ساختاری مثل **Register File** بسازیم.

مثلاً:

```text
R0
R1
R2
R3
R4
R5
R6
R7
```

هر Register مثلاً 32 بیت است.

در یک CPU می‌توانیم:

```text
Register File
      ↓
Read Data
      ↓
ALU
      ↓
Write Back
```

داشته باشیم.

این مفهوم بعداً برای ساخت **CPU** بسیار مهم خواهد شد.

---

# 17. Register در CPU

در یک CPU Registerها برای نگهداری موقت داده استفاده می‌شوند.

مثلاً:

```text
┌───────────────┐
│ Register R0   │
├───────────────┤
│ Register R1   │
├───────────────┤
│ Register R2   │
├───────────────┤
│ Register R3   │
└───────────────┘
       ↓
      ALU
```

مثلاً:

```text
R1 = 10
R2 = 20
```

و ALU:

```text
R1 + R2
```

را محاسبه می‌کند.

نتیجه ممکن است دوباره در یک Register ذخیره شود:

```text
R3 = 30
```

پس مسیر:

```text
Register
   ↓
ALU
   ↓
Register
```

یکی از پایه‌های **Datapath** است.

---

# 18. Register و Pipeline

Registerها در Pipeline نیز بسیار مهم هستند.

مثلاً:

```text
Input
  ↓
Combinational Logic
  ↓
Register
  ↓
Combinational Logic
  ↓
Register
  ↓
Output
```

هر Register مرز یک Pipeline Stage را ایجاد می‌کند.

مثلاً در یک سیستم:

```text
Stage 1
   ↓
Register
   ↓
Stage 2
   ↓
Register
   ↓
Stage 3
```

این موضوع در پردازنده‌های مدرن اهمیت زیادی دارد.

# 19. Register در VHDL

یک Register عمومی:

```vhdl
library ieee;
use ieee.std_logic_1164.all;

entity register_8bit is
    port (
        clk   : in  std_logic;
        reset : in  std_logic;
        en    : in  std_logic;
        d     : in  std_logic_vector(7 downto 0);
        q     : out std_logic_vector(7 downto 0)
    );
end entity;

architecture rtl of register_8bit is
begin

    process(clk)
    begin
        if rising_edge(clk) then

            if reset = '1' then
                q <= (others => '0');

            elsif en = '1' then
                q <= d;

            end if;

        end if;
    end process;

end architecture;
```

رفتار:

```text
Reset = 1
    ↓
Q = 00000000
```

و:

```text
Reset = 0
Enable = 1
    ↓
Clock Edge
    ↓
Q = D
```

و:

```text
Enable = 0
    ↓
Q remains unchanged
```

# 20. Shift Register در VHDL

مثلاً یک Shift Register چهار بیتی:

```vhdl
library ieee;
use ieee.std_logic_1164.all;

entity shift_register is
    port (
        clk : in  std_logic;
        si  : in  std_logic;
        q   : out std_logic_vector(3 downto 0)
    );
end entity;

architecture rtl of shift_register is
    signal reg : std_logic_vector(3 downto 0);
begin

    process(clk)
    begin
        if rising_edge(clk) then
            reg <= reg(2 downto 0) & si;
        end if;
    end process;

    q <= reg;

end architecture;
```

قسمت:

```vhdl
reg <= reg(2 downto 0) & si;
```

یعنی بیت‌ها Shift شوند و `si` وارد Register شود.


# 24. زنجیره آموزشی این قسمت

این بخش باید یک رابطه کاملاً روشن با فصل قبل و فصل بعد داشته باشد:

```text
D Flip-Flop
     ↓
Multiple Flip-Flops
     ↓
Register
     ↓
Shift Register
     ↓
Register File
```

و از طرف دیگر:

```text
Register
   ↓
Counter
   ↓
Timer
   ↓
Digital Clock
```

و:

```text
Register
   ↓
State Storage
   ↓
Next-State Logic
   ↓
FSM
```

و در سطح بالاتر:

```text
Registers
     +
ALU
     +
Control Logic
     ↓
Datapath
     ↓
CPU
```

## چیزی که دانشجو باید در پایان این بخش بفهمد

نباید فقط بداند:

> «Register یعنی `std_logic_vector`.»

بلکه باید بفهمد:

```text
std_logic_vector
       ↓
ممکن است یک مجموعه بیت باشد
       ↓
اگر با Clock ذخیره شود
       ↓
می‌تواند یک Register سخت‌افزاری باشد
```

و این کد:

```vhdl
process(clk)
begin
    if rising_edge(clk) then
        q <= d;
    end if;
end process;
```

از نظر سخت‌افزاری یعنی:

```text
        ┌──────────────┐
D ─────→│              │────→ Q
        │   Register   │
CLK ───→│              │
        └──────────────┘
```

پس دانشجو از اینجا باید به یک درک مهم برسد:

> **در VHDL ما صرفاً برنامه نمی‌نویسیم؛ ساختار و رفتار سخت‌افزار را توصیف می‌کنیم.**

و Register یکی از بهترین مثال‌ها برای فهمیدن این تفاوت است.
