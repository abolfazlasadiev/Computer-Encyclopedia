# Registers — ثبات‌ها (نسخه کامل و جامع با تحلیل عمیق)

## مقدمه: از بیت تا کلمه — سفر به قلب حافظه دیجیتال

در دنیای دیجیتال، همه چیز با **بیت** شروع می‌شود. یک بیت کوچک‌ترین واحد اطلاعات است که می‌تواند ۰ یا ۱ باشد. اما واقعیت این است که سیستم‌های دیجیتال به ندرت با یک بیت منفرد کار می‌کنند. آنها با **کلمه‌ها (Words)** سروکار دارند — گروه‌هایی از بیت‌ها که اعداد، کاراکترها، آدرس‌ها یا دستورات را نشان می‌دهند.

سوال اساسی این است: **چگونه می‌توانیم یک کلمه چندبیتی را در سخت‌افزار ذخیره کنیم؟**

پاسخ در **ثبات‌ها (Registers)** نهفته است. اگر یک **فلیپ‌فلاپ (Flip-Flop)** بتواند یک بیت را ذخیره کند، یک ثبات مجموعه‌ای از فلیپ‌فلاپ‌هاست که با هم کار می‌کنند تا یک کلمه چندبیتی را ذخیره کنند.

---

## ۱. ثبات چیست؟ تعریف جامع و عمیق

یک **ثبات (Register)** در ساده‌ترین تعریف، **گروهی از سلول‌های حافظه** است که همه با یک سیگنال ساعت (Clock) مشترک کنترل می‌شوند. هر سلول حافظه معمولاً یک فلیپ‌فلاپ از نوع D است.

### تعریف رسمی

از دیدگاه طراحی دیجیتال:

> **ثبات** یک مدار ترتیبی است که از n فلیپ‌فلاپ تشکیل شده و می‌تواند n بیت اطلاعات را به صورت موازی ذخیره کند. همه فلیپ‌فلاپ‌ها توسط یک سیگنال Clock مشترک کنترل می‌شوند و معمولاً سیگنال‌های Reset و Enable نیز دارند.

### تصویر ذهنی ساده

ثبات را مانند یک **جعبه ابزار چندبخشی** تصور کنید که هر بخش آن یک بیت اطلاعات را نگه می‌دارد. وقتی سیگنال ساعت فعال می‌شود، تمام بخش‌های این جعبه به‌طور همزمان اطلاعات جدید را از ورودی می‌گیرند و تا زمانی که سیگنال ساعت بعدی بیاید، آن را حفظ می‌کنند.

```
ثبات ۴ بیتی = ۴ عدد فلیپ‌فلاپ D
ثبات ۸ بیتی = ۸ عدد فلیپ‌فلاپ D
ثبات ۳۲ بیتی = ۳۲ عدد فلیپ‌فلاپ D
ثبات ۶۴ بیتی = ۶۴ عدد فلیپ‌فلاپ D
```

### قیاس با دنیای واقعی

یک ثبات مانند **یک تخته‌ی وایت‌برد با n بخش** است:
- هر بخش می‌تواند یک رقم (۰ یا ۱) را نشان دهد
- با یک سیگنال (پاک‌کن) همه بخش‌ها صفر می‌شوند (Reset)
- با یک سیگنال (دستور نوشتن) همه بخش‌ها همزمان به‌روز می‌شوند (Clock)
- اطلاعات تا زمانی که کسی آنها را تغییر دهد، باقی می‌مانند (حافظه)

## ۲. معماری داخلی یک ثبات — تحلیل عمیق

بیایید یک ثبات ۴ بیتی را با جزئیات کامل بررسی کنیم:

### نمای بیرونی

```
ورودی‌ها (D3 D2 D1 D0) ────┐
                              │
                         ┌────┴────┐
                         │  ثبات   │
                         │ ۴ بیتی  │
                         └────┬────┘
                              │
خروجی‌ها (Q3 Q2 Q1 Q0) ─────┘
              ↑
             CLK
              ↑
           RESET
              ↑
           ENABLE
```

### نمای داخلی

```
D3 ────→ ┌─────────────────┐ ────→ Q3
         │  D Flip-Flop    │
         │  با Reset/Enable │
D2 ────→ ├─────────────────┤ ────→ Q2
         │  D Flip-Flop    │
         │  با Reset/Enable │
D1 ────→ ├─────────────────┤ ────→ Q1
         │  D Flip-Flop    │
         │  با Reset/Enable │
D0 ────→ ├─────────────────┤ ────→ Q0
         │  D Flip-Flop    │
         │  با Reset/Enable │
         └─────────────────┘
                    ↑
              CLK (مشترک)
              RESET (مشترک)
              ENABLE (مشترک)
```

### نکته بسیار مهم: بارگذاری موازی (Parallel Load)

همه فلیپ‌فلاپ‌ها **همزمان** و در **لبه (Edge)** یکسان از سیگنال ساعت فعال می‌شوند. این یعنی تمام بیت‌های داده در یک لحظه خاص ذخیره می‌شوند.

**مقایسه با بارگذاری سریال:**
- **بارگذاری موازی:** همه بیت‌ها همزمان ذخیره می‌شوند (یک لبه Clock)
- **بارگذاری سریال:** بیت‌ها یکی‌یکی و در چند لبه Clock ذخیره می‌شوند

## ۳. رفتار ثبات در مقابل مدارهای ترکیبی — تحلیل عمیق

این یکی از مهم‌ترین مفاهیمی است که هر دانشجوی مهندسی دیجیتال باید کاملاً درک کند:

### مدار ترکیبی (Combinational Circuit)

```
A ────→ [دروازه‌های منطقی] ────→ Y
```

- **بدون حافظه:** خروجی فقط به ورودی فعلی بستگی دارد
- **واکنش فوری:** اگر ورودی A تغییر کند، خروجی Y بلافاصله (با تأخیر انتشار Gate) تغییر می‌کند
- **مثال:** AND Gate, Adder, MUX

### ثبات (Register)

```
D ────→ [ثبات] ────→ Q
              ↑
             CLK
```

- **دارای حافظه:** خروجی به ورودی‌های قبلی بستگی دارد
- **واکنش کنترل‌شده:** اگر ورودی D تغییر کند، خروجی Q تغییر نمی‌کند مگر اینکه لبه ساعت (Clock Edge) بیاید
- **مثال:** Register, Counter, FSM

### مثال عینی و گام‌به‌گام

فرض کنید یک ثبات ۴ بیتی داریم که مقدار `۱۰۱۰` را ذخیره کرده است:

```
لحظه ۰: سیستم راه‌اندازی می‌شود، ثبات خالی است
         D = ۱۰۱۰, Q = ۰۰۰۰ (نامشخص)

لحظه ۱: لبه Rising Clock اتفاق می‌افتد
         Q = ۱۰۱۰ (داده ذخیره شد)

لحظه ۲: ورودی تغییر می‌کند
         D = ۰۱۱۰, Q = ۱۰۱۰ (هنوز تغییر نکرده!)

لحظه ۳: لبه Rising Clock بعدی اتفاق می‌افتد
         Q = ۰۱۱۰ (حالا تغییر کرد)

لحظه ۴: Reset فعال می‌شود
         Q = ۰۰۰۰ (ثبات پاک شد)
```

### چرا این رفتار مهم است؟

این رفتار به ما اجازه می‌دهد تا **زمان‌بندی (Timing)** را در سیستم‌های دیجیتال کنترل کنیم:

1. **هماهنگ‌سازی:** همه بخش‌های سیستم با یک ضرب‌آهنگ (Clock) کار می‌کنند
2. **پایداری داده:** داده‌ها بین لبه‌های Clock پایدار می‌مانند
3. **پیش‌بینی‌پذیری:** رفتار سیستم قابل پیش‌بینی است
4. **طراحی ساده‌تر:** نیازی به نگرانی درباره تغییرات ناگهانی نیست

**بدون ثبات‌ها، سیگنال‌ها به‌طور نامنظم و غیرقابل پیش‌بینی تغییر می‌کردند و طراحی سیستم‌های پیچیده تقریباً غیرممکن بود.**

## ۴. کاربردهای اصلی ثبات‌ها — تحلیل جامع

### ۱. ذخیره‌سازی موقت داده (Data Storage)

در پردازنده‌ها، ثبات‌ها برای نگهداری موقت داده‌هایی که قرار است پردازش شوند استفاده می‌شوند.

**مثال:**
```
MOV R1, #5    ; مقدار ۵ را در ثبات R1 ذخیره کن
ADD R2, R1, #3 ; R2 = R1 + 3 = 8
```

ثبات R1 مقدار ۵ را نگه می‌دارد تا زمانی که دستور ADD از آن استفاده کند.

### ۲. بافر (Buffer)

برای هماهنگ‌سازی داده‌ها بین دو بخش که با سرعت‌های متفاوت کار می‌کنند.

**مثال:**
```
CPU (سریع) ──→ [Buffer Register] ──→ حافظه (کندتر)
```

ثبات بافر داده را نگه می‌دارد تا بخش کندتر بتواند آن را بخواند.

### ۳. خط تأخیر (Delay Line)

با عبور دادن داده از چند ثبات پشت سر هم، می‌توان تأخیر زمانی ایجاد کرد.

**مثال:**
```
ورودی → [ثبات] → [ثبات] → [ثبات] → خروجی
```

هر ثبات یک لبه Clock تأخیر ایجاد می‌کند. با ۳ ثبات، خروجی ۳ لبه Clock دیرتر از ورودی ظاهر می‌شود.

### ۴. تبدیل سریال به موازی و برعکس

با استفاده از ثبات‌های شیفت (Shift Register) می‌توان داده را از حالت سریال به موازی تبدیل کرد یا برعکس.

**مثال (SIPO - Serial-In Parallel-Out):**
```
داده سریال: ۱ ۰ ۱ ۱ (بیت‌به‌بیت وارد می‌شود)
پس از ۴ لبه Clock:
خروجی موازی: ۱۰۱۱ (همزمان خوانده می‌شود)
```

### ۵. حافظه در مدارهای ترتیبی

ثبات‌ها عناصر حافظه اصلی در ماشین‌های حالت (State Machines) هستند.

**مثال (FSM - Finite State Machine):**
```
State Register (ثبات وضعیت)
       ↓
Next-State Logic
       ↓
State Register (به‌روز می‌شود)
```

ثبات وضعیت، وضعیت فعلی ماشین حالت را ذخیره می‌کند.

### ۶. خطوط لوله (Pipeline)

در پردازنده‌های مدرن، ثبات‌ها مرزهای مراحل خط لوله را مشخص می‌کنند.

**مثال:**
```
مرحله ۱ ← [ثبات] ← مرحله ۲ ← [ثبات] ← مرحله ۳
```

هر ثبات داده را بین مراحل منتقل می‌کند.

## ۵. ثبات با قابلیت Reset — تحلیل عمیق

### چرا به Reset نیاز داریم؟

۱. **شروع از وضعیت مشخص:** سیستم باید از یک حالت مشخص شروع کند
۲. **بازیابی از خطا:** در صورت بروز مشکل، سیستم را به حالت اولیه برگرداند
۳. **طراحی قابل پیش‌بینی:** رفتار اولیه سیستم مشخص است
۴. **تست و دیباگ:** امکان تست سیستم از یک نقطه شروع مشخص

### دو نوع Reset

**۱. Reset همزمان (Synchronous Reset):**

```
if rising_edge(clk) then
    if reset = '1' then
        q <= (others => '0');
    else
        q <= d;
    end if;
end if;
```

- Reset فقط در لبه ساعت اثر می‌کند
- طراحی ساده‌تر از نظر Timing
- مصرف توان کمتر (در برخی فناوری‌ها)

**۲. Reset ناهمزمان (Asynchronous Reset):**

```
if reset = '1' then
    q <= (others => '0');
elsif rising_edge(clk) then
    q <= d;
end if;
```

- Reset بلافاصله و بدون توجه به ساعت اثر می‌کند
- پاسخ سریع‌تر به Reset
- ممکن است مشکلات Timing ایجاد کند

### مقایسه عمیق

| ویژگی | Synchronous Reset | Asynchronous Reset |
|-------|-------------------|-------------------|
| **وابستگی به Clock** | بله | خیر |
| **زمان پاسخ** | تا لبه بعدی Clock | فوری |
| **پیچیدگی طراحی** | کمتر | بیشتر |
| **مشکلات Timing** | کمتر | بیشتر |
| **مصرف توان** | کمتر | بیشتر (در برخی موارد) |
| **کاربرد در FPGA** | بسیار رایج | بسته به نیاز |

### مثال: ثبات ۸ بیتی با Reset همزمان

```vhdl
library ieee;
use ieee.std_logic_1164.all;

entity register_8bit is
    port (
        clk   : in  std_logic;
        reset : in  std_logic;
        d     : in  std_logic_vector(7 downto 0);
        q     : out std_logic_vector(7 downto 0)
    );
end entity;

architecture rtl of register_8bit is
begin
    process(clk)
    begin
        if rising_edge(clk) then
            if reset = '1' then
                q <= (others => '0');  -- همه بیت‌ها صفر می‌شوند
            else
                q <= d;
            end if;
        end if;
    end process;
end architecture;
```

## ۶. ثبات با قابلیت Enable — تحلیل عمیق

### چرا به Enable نیاز داریم؟

۱. **کنترل به‌روزرسانی:** فقط وقتی که نیاز است، ثبات به‌روز شود
۲. **صرفه‌جویی در توان:** بخش‌های غیرضروری را غیرفعال کنید
۳. **هماهنگ‌سازی:** داده را در زمان مناسب ذخیره کنید
۴. **طراحی انعطاف‌پذیر:** امکان انتخاب زمان به‌روزرسانی

### مدل رفتاری

```
اگر Enable = 1:
    در لبه ساعت بعدی، مقدار D را بگیر

اگر Enable = 0:
    مقدار قبلی را حفظ کن (تغییر نکن)
```

### پیاده‌سازی در VHDL

```vhdl
process(clk)
begin
    if rising_edge(clk) then
        if reset = '1' then
            q <= (others => '0');
        elsif enable = '1' then
            q <= d;
        end if;
    end if;
end process;
```

### کاربرد عملی

**مثال: شمارنده مشتریان فروشگاه**

تصور کنید یک فروشگاه دارید و می‌خواهید تعداد مشتریان را بشمارید. شما فقط زمانی که مشتری جدیدی وارد می‌شود (Enable فعال می‌شود) باید مقدار را به‌روز کنید. در بقیه زمان‌ها، مقدار فعلی باید حفظ شود.

```
ثبات شمارش = تعداد مشتریان فعلی
Enable = 1 وقتی مشتری جدید وارد می‌شود
در غیر این صورت Enable = 0
```

## ۷. مقایسه انواع ثبات‌ها — جدول جامع

| نوع ثبات | ورودی | خروجی | کنترل | کاربرد اصلی |
|---------|-------|-------|-------|-------------|
| **ثبات ساده** | موازی | موازی | Clock | ذخیره‌سازی عمومی |
| **ثبات با Enable** | موازی | موازی | Clock + Enable | به‌روزرسانی کنترل‌شده |
| **ثبات با Reset** | موازی | موازی | Clock + Reset | مقداردهی اولیه |
| **ثبات با Reset + Enable** | موازی | موازی | Clock + Reset + Enable | ترکیبی از هر دو |
| **ثبات شیفت‌دهنده** | سریال/موازی | سریال/موازی | Clock + کنترل شیفت | تبدیل داده |
| **ثبات جهانی** | سریال/موازی | سریال/موازی | Clock + Select | همه کاربردها |

## ۸. ثبات‌های شیفت (Shift Registers) — تحلیل عمیق

### تعریف و مفهوم

ثبات شیفت یک نوع خاص از ثبات است که در هر لبه ساعت، بیت‌های خود را به چپ یا راست انتقال می‌دهد. این حرکت بیت‌ها مانند یک **نوار نقاله** است که بیت‌ها را در هر گام یک خانه جابه‌جا می‌کند.

### ساختار داخلی ثبات شیفت ۴ بیتی (Shift Right)

```
SI ────→ [D-FF] ────→ [D-FF] ────→ [D-FF] ────→ [D-FF] ────→ SO
               ↑            ↑            ↑            ↑
              CLK          CLK          CLK          CLK
```

در هر لبه Clock:
- بیت جدید از SI وارد می‌شود
- هر بیت یک خانه به راست حرکت می‌کند
- آخرین بیت از SO خارج می‌شود

### مثال گام‌به‌گام: Shift Right با ورودی صفر

```
مقدار اولیه: ۱۰۰۰
SI = ۰ (ورودی صفر)

لبه ۱: ۰۱۰۰  (بیت ۱ از سمت راست خارج شد، ۰ از چپ وارد شد)
لبه ۲: ۰۰۱۰
لبه ۳: ۰۰۰۱
لبه ۴: ۰۰۰۰  (همه بیت‌ها صفر شدند)
```

### کاربردهای ثبات شیفت

۱. **تبدیل سریال به موازی (SIPO)**
   - دریافت داده بیت‌به‌بیت از یک خط (مثل UART)
   - خواندن همزمان همه بیت‌ها
   - کاربرد: ارتباطات سریال

۲. **تبدیل موازی به سریال (PISO)**
   - بارگذاری همزمان داده
   - خروجی بیت‌به‌بیت
   - کاربرد: ارسال داده به صورت سریال

۳. **ضرب و تقسیم بر توان‌های ۲**
   - شیفت به چپ = ضرب در ۲
   - شیفت به راست = تقسیم بر ۲
   - کاربرد: محاسبات سریع

۴. **تولید تأخیر زمانی (Delay Line)**
   - با عبور داده از n مرحله، n لبه Clock تأخیر ایجاد می‌شود
   - کاربرد: هماهنگ‌سازی سیگنال‌ها

۵. **تولید دنباله‌های بیتی تکراری (Ring Counter)**
   - با بازخورد از خروجی به ورودی
   - کاربرد: تولید پالس‌های کنترلی

## ۹. چهار نوع اصلی ثبات شیفت — تحلیل کامل

### ۱. SISO (Serial-In Serial-Out)

**ساختار:**
```
ورودی سریال → [FF] → [FF] → [FF] → [FF] → خروجی سریال
```

**ویژگی‌ها:**
- داده بیت‌به‌بیت وارد می‌شود
- داده بیت‌به‌بیت خارج می‌شود
- ساده‌ترین نوع ثبات شیفت

**کاربردها:**
- ایجاد تأخیر در مسیر داده
- تولید خط تأخیر (Delay Line)
- فیلترهای دیجیتال ساده

**VHDL:**
```vhdl
entity siso_4bit is
    port (clk : in std_logic; si : in std_logic; so : out std_logic);
end entity;

architecture rtl of siso_4bit is
    signal reg : std_logic_vector(3 downto 0);
begin
    process(clk)
    begin
        if rising_edge(clk) then
            reg <= reg(2 downto 0) & si;
        end if;
    end process;
    so <= reg(3);
end architecture;
```

---

### ۲. SIPO (Serial-In Parallel-Out)

**ساختار:**
```
ورودی سریال → [FF] → [FF] → [FF] → [FF]
                      ↓      ↓      ↓      ↓
                    Q3     Q2     Q1     Q0  (خروجی موازی)
```

**ویژگی‌ها:**
- داده بیت‌به‌بیت وارد می‌شود
- همه بیت‌ها همزمان قابل خواندن هستند
- **تبدیل سریال → موازی**

**کاربردها:**
- تبدیل داده سریال به موازی (مثلاً در UART Receiver)
- جمع‌آوری داده از سنسورهای سریال
- دریافت داده از پروتکل‌های ارتباطی (SPI, I²C)

**VHDL:**
```vhdl
entity sipo_4bit is
    port (clk : in std_logic; si : in std_logic; q : out std_logic_vector(3 downto 0));
end entity;

architecture rtl of sipo_4bit is
    signal reg : std_logic_vector(3 downto 0);
begin
    process(clk)
    begin
        if rising_edge(clk) then
            reg <= reg(2 downto 0) & si;
        end if;
    end process;
    q <= reg;
end architecture;
```

### ۳. PISO (Parallel-In Serial-Out)

**ساختار:**
```
D3 D2 D1 D0 (ورودی موازی)
 \  |  |  /
  [ثبات شیفت]
       ↓
    خروجی سریال
```

**ویژگی‌ها:**
- داده همزمان بارگذاری می‌شود
- بیت‌ها یکی‌یکی خارج می‌شوند
- **تبدیل موازی → سریال**

**کاربردها:**
- تبدیل داده موازی به سریال (مثلاً در UART Transmitter)
- ارسال داده به صورت سریال
- پروتکل‌های ارتباطی

**VHDL:**
```vhdl
entity piso_4bit is
    port (clk : in std_logic; load : in std_logic; d : in std_logic_vector(3 downto 0); so : out std_logic);
end entity;

architecture rtl of piso_4bit is
    signal reg : std_logic_vector(3 downto 0);
begin
    process(clk)
    begin
        if rising_edge(clk) then
            if load = '1' then
                reg <= d;  -- بارگذاری موازی
            else
                reg <= reg(2 downto 0) & '0';  -- شیفت
            end if;
        end if;
    end process;
    so <= reg(3);
end architecture;
```

## ۱۰. ثبات شیفت جهانی (Universal Shift Register) — تحلیل کامل

### تعریف و مفهوم

یک **Universal Shift Register** یک ثبات شیفت است که می‌تواند چندین عملیات مختلف را انجام دهد:
- **Hold:** نگهداری مقدار فعلی
- **Shift Left:** شیفت به چپ
- **Shift Right:** شیفت به راست
- **Parallel Load:** بارگذاری موازی

این قابلیت‌ها با استفاده از **مالتی‌پلکسرها (MUX)** در ورودی هر فلیپ‌فلاپ پیاده‌سازی می‌شوند.

### انتخاب عملیات با سیگنال Select

با استفاده از دو بیت Select، می‌توانیم یکی از چهار عملیات را انتخاب کنیم:

| S1 | S0 | عملیات | توضیح |
|:--:|:--:|:-------|-------|
| ۰  | ۰  | Hold | مقدار فعلی حفظ می‌شود |
| ۰  | ۱  | Shift Right | بیت‌ها یک خانه به راست می‌روند |
| ۱  | ۰  | Shift Left | بیت‌ها یک خانه به چپ می‌روند |
| ۱  | ۱  | Parallel Load | داده موازی بارگذاری می‌شود |

### ساختار داخلی (برای هر بیت)

```
برای بیت i ام ثبات:

ورودی‌های MUX:
0: مقدار فعلی خودش (Hold)
1: مقدار بیت قبلی (Shift Right)
2: مقدار بیت بعدی (Shift Left)
3: ورودی موازی (Parallel Load)

S1 S0 ──→ MUX ──→ D-FF ──→ Q[i]
```

### کد VHDL کامل

```vhdl
library ieee;
use ieee.std_logic_1164.all;

entity universal_shift_register is
    generic (
        WIDTH : integer := 4
    );
    port (
        clk     : in  std_logic;
        reset   : in  std_logic;
        s1, s0  : in  std_logic;          -- Select bits
        si      : in  std_logic;          -- Serial Input (for shift)
        d       : in  std_logic_vector(WIDTH-1 downto 0);  -- Parallel Input
        q       : out std_logic_vector(WIDTH-1 downto 0)   -- Output
    );
end entity;

architecture rtl of universal_shift_register is
    signal reg : std_logic_vector(WIDTH-1 downto 0);
begin
    process(clk)
    begin
        if rising_edge(clk) then
            if reset = '1' then
                reg <= (others => '0');
            else
                case s1 & s0 is
                    when "00" =>  -- Hold
                        reg <= reg;
                    when "01" =>  -- Shift Right
                        reg <= si & reg(WIDTH-1 downto 1);
                    when "10" =>  -- Shift Left
                        reg <= reg(WIDTH-2 downto 0) & si;
                    when "11" =>  -- Parallel Load
                        reg <= d;
                    when others =>
                        reg <= reg;
                end case;
            end if;
        end if;
    end process;
    q <= reg;
end architecture;
```

## ۱۱. فایل ثبات (Register File) — تحلیل عمیق

### تعریف و مفهوم

وقتی چند ثبات را کنار هم قرار دهیم و بتوانیم به هر کدام با یک آدرس دسترسی داشته باشیم، یک **فایل ثبات (Register File)** ایجاد می‌شود. این ساختار در قلب تمام پردازنده‌ها قرار دارد و **مغز حافظه‌دار** CPU محسوب می‌شود.

### ساختار فایل ثبات

```
        ┌─────────┐
R0 ────→│ ثبات ۰  │
R1 ────→│ ثبات ۱  │
R2 ────→│ ثبات ۲  │
...     │ ...     │
R7 ────→│ ثبات ۷  │
        └─────────┘
             ↓
        ┌─────────────┐
        │  Decoder    │ (برای انتخاب ثبات)
        └─────────────┘
             ↓
        خروجی انتخاب‌شده
```

### ویژگی‌های فایل ثبات

۱. **چندین ثبات**: معمولاً ۸، ۱۶ یا ۳۲ ثبات
2. **عرض ثبات**: هر ثبات معمولاً ۸، ۱۶، ۳۲ یا ۶۴ بیت است
3. **انتخاب‌پذیری**: با استفاده از آدرس می‌توان یک ثبات خاص را انتخاب کرد
4. **دسترسی همزمان**: معمولاً دو پورت خواندن و یک پورت نوشتن دارد (برای اجرای دستورات RISC)

### معماری دو پورت خواندن - یک پورت نوشتن

```
                    ┌─────────────────┐
Write Address ─────→│                 │
Write Data ─────────│                 │
Write Enable ──────→│   Register      │
                    │   File          │
Read Address A ────→│                 │──→ Read Data A
Read Address B ────→│                 │──→ Read Data B
                    └─────────────────┘
```

**چرا دو پورت خواندن؟**
در پردازنده‌های RISC، یک دستور معمولی مانند `ADD R3, R1, R2` نیاز به خواندن دو ثبات (R1 و R2) همزمان دارد.

### فایل ثبات در VHDL

```vhdl
library ieee;
use ieee.std_logic_1164.all;
use ieee.numeric_std.all;

entity register_file is
    generic (
        NUM_REGS : integer := 8;     -- تعداد ثبات‌ها
        DATA_WIDTH : integer := 8    -- عرض هر ثبات
    );
    port (
        clk      : in  std_logic;
        reset    : in  std_logic;
        write_en : in  std_logic;
        addr_a   : in  std_logic_vector(2 downto 0);  -- آدرس پورت A
        addr_b   : in  std_logic_vector(2 downto 0);  -- آدرس پورت B
        addr_w   : in  std_logic_vector(2 downto 0);  -- آدرس پورت نوشتن
        data_w   : in  std_logic_vector(DATA_WIDTH-1 downto 0);  -- داده ورودی
        data_a   : out std_logic_vector(DATA_WIDTH-1 downto 0);  -- خروجی پورت A
        data_b   : out std_logic_vector(DATA_WIDTH-1 downto 0)   -- خروجی پورت B
    );
end entity;

architecture rtl of register_file is
    type reg_array is array (0 to NUM_REGS-1) of std_logic_vector(DATA_WIDTH-1 downto 0);
    signal registers : reg_array;
begin
    -- فرآیند نوشتن (سخت‌افزاری)
    process(clk)
    begin
        if rising_edge(clk) then
            if reset = '1' then
                for i in 0 to NUM_REGS-1 loop
                    registers(i) <= (others => '0');
                end loop;
            elsif write_en = '1' then
                registers(to_integer(unsigned(addr_w))) <= data_w;
            end if;
        end if;
    end process;
    
    -- فرآیند خواندن (ترکیبی - بدون Clock)
    data_a <= registers(to_integer(unsigned(addr_a)));
    data_b <= registers(to_integer(unsigned(addr_b)));
end architecture;
```

## ۱۲. ثبات‌ها در پردازنده (CPU) — تحلیل عمیق

### انواع ثبات‌ها در CPU

| نوع ثبات | علامت اختصاری | کاربرد |
|----------|--------------|--------|
| **ثبات‌های همه‌منظوره** | GPR | ذخیره موقت داده‌ها و آدرس‌ها |
| **ثبات برنامه‌شمار** | PC | آدرس دستور بعدی |
| **ثبات دستور** | IR | دستور در حال اجرا |
| **ثبات نشانگر پشته** | SP | آدرس بالای پشته |
| **ثبات وضعیت** | SR/PSW | پرچم‌های وضعیت (Carry, Zero, etc.) |

### مسیر داده (Datapath) ساده

```
        ┌─────────────────┐
        │  فایل ثبات      │
        │  (Register File) │
        └────────┬────────┘
                 │
                 ▼
        ┌─────────────────┐
        │      ALU        │
        └────────┬────────┘
                 │
                 ▼
        ┌─────────────────┐
        │  ثبات نتیجه    │
        └─────────────────┘
```

### مثال: جمع دو عدد با ثبات‌ها

```assembly
; کد اسمبلی ساده
MOV R1, #10    ; بارگذاری ۱۰ در ثبات R1
MOV R2, #20    ; بارگذاری ۲۰ در ثبات R2
ADD R3, R1, R2 ; R3 = R1 + R2 = ۳۰
```

**مراحل اجرا در سخت‌افزار:**

1. **دستور MOV R1, #10**
   - داده ۱۰ به ثبات R1 نوشته می‌شود

2. **دستور MOV R2, #20**
   - داده ۲۰ به ثبات R2 نوشته می‌شود

3. **دستور ADD R3, R1, R2**
   - داده از ثبات R1 خوانده می‌شود (Port A)
   - داده از ثبات R2 خوانده می‌شود (Port B)
   - هر دو داده به ALU فرستاده می‌شوند
   - ALU عملیات ADD را انجام می‌دهد (۱۰ + ۲۰ = ۳۰)
   - نتیجه در ثبات R3 نوشته می‌شود

## ۱۳. ثبات‌ها در خطوط لوله (Pipeline) — تحلیل عمیق

### مفهوم Pipeline

در پردازنده‌های مدرن، از **خط لوله (Pipeline)** برای افزایش سرعت استفاده می‌شود. یک دستور به چند مرحله تقسیم می‌شود و هر مرحله در یک لبه Clock اجرا می‌شود.

### مثال: خط لوله ۳ مرحله‌ای

```
مرحله ۱ (Fetch) → [ثبات] → مرحله ۲ (Decode) → [ثبات] → مرحله ۳ (Execute)
```

هر ثبات، **مرز مرحله (Stage Boundary)** را مشخص می‌کند و داده را از مرحله قبل به مرحله بعد منتقل می‌کند.

### مزایا

۱. **افزایش توان عملیاتی (Throughput):** در هر لبه Clock، یک دستور جدید کامل می‌شود
2. **اجرای همزمان:** چند دستور همزمان در مراحل مختلف در حال اجرا هستند
3. **استفاده بهتر از منابع:** بخش‌های مختلف پردازنده همزمان فعال هستند

### مثال: دستورات در Pipeline

```
Clock 1: IF1 (دستور ۱)
Clock 2: IF2 | ID1 (دستور ۲ و دستور ۱)
Clock 3: IF3 | ID2 | EX1 (دستور ۳، ۲ و ۱)
Clock 4: IF4 | ID3 | EX2 | WB1 (دستور ۴، ۳، ۲ و ۱)
```

## ۱۴. ثبات‌ها در مقابل حافظه — تحلیل مقایسه‌ای

درک تفاوت ثبات و حافظه (RAM) برای هر مهندس کامپیوتر ضروری است:

| ویژگی | ثبات (Register) | حافظه (RAM) |
|-------|-----------------|-------------|
| **سرعت** | بسیار بالا (چند پیکوثانیه) | پایین‌تر (چند نانوثانیه) |
| **ظرفیت** | کم (چند بایت) | زیاد (چند گیگابایت) |
| **قیمت** | بسیار گران (به ازای هر بیت) | ارزان‌تر (به ازای هر بیت) |
| **موقعیت** | داخل CPU (روی دای) | خارج از CPU (یا روی دای به عنوان کش) |
| **دسترسی** | مستقیم (بدون آدرس‌دهی) | نیاز به آدرس‌دهی |
| **مصرف انرژی** | کم (به ازای هر بیت) | بیشتر (به ازای هر بیت) |
| **ساختار** | فلیپ‌فلاپ | خازن‌ها (DRAM) یا فلیپ‌فلاپ (SRAM) |
| **تعداد** | معمولاً ۸ تا ۶۴ عدد | میلیون‌ها تا میلیاردها |
| **حجم داده** | داده‌های در حال پردازش | داده‌های ذخیره‌شده |

### سلسله‌مراتب حافظه در کامپیوتر

```
CPU
  │
  ├── ثبات‌ها (Registers) ← سریع‌ترین، گران‌ترین، کوچک‌ترین
  │
  ├── کش L1 (Cache)
  │
  ├── کش L2 (Cache)
  │
  ├── کش L3 (Cache)
  │
  └── RAM ← کندترین، ارزان‌ترین، بزرگ‌ترین
```

## ۱۵. ثبات‌های پیشرفته — تحلیل تخصصی

### ثبات چرخشی (Rotating Register)

در این نوع، بیت‌ها به جای اینکه با صفر پر شوند، به صورت چرخشی جابجا می‌شوند. این یعنی بیت خارج‌شده از یک سمت، به سمت دیگر وارد می‌شود.

```
شیفت چپ چرخشی ۴ بیتی:
۱۰۰۱
  ↓ (چرخش)
۰۰۱۱
  ↓
۰۱۱۰
  ↓
۱۱۰۰
  ↓
۱۰۰۱ (بازگشت به مقدار اولیه)
```

**کاربردها:**
- تولید دنباله‌های بیتی
- رمزنگاری ساده
- تولید اعداد شبه‌تصادفی

**VHDL:**
```vhdl
-- شیفت چپ چرخشی ۴ بیتی
reg <= reg(2 downto 0) & reg(3);

-- شیفت راست چرخشی ۴ بیتی
reg <= reg(0) & reg(3 downto 1);
```

### ثبات حلقه‌ای (Ring Register)

یک ثبات حلقه‌ای، یک ثبات شیفت با بازخورد است که در آن خروجی آخرین بیت به ورودی اولین بیت متصل می‌شود.

```
[FF] → [FF] → [FF] → [FF]
  ↑                    ↓
  └────────────────────┘
```

**مثال: Ring Counter 4-bit**
```
۱۰۰۰
۰۱۰۰
۰۰۱۰
۰۰۰۱
۱۰۰۰ (بازگشت)
```

**کاربردها:**
- تولید دنباله‌های بیتی تکراری
- شمارنده‌های حلقه‌ای
- تولید پالس‌های کنترلی

### Linear Feedback Shift Register (LFSR)

یک LFSR یک ثبات شیفت با بازخورد XOR از برخی بیت‌هاست. این ساختار برای تولید دنباله‌های شبه‌تصادفی بسیار مفید است.

```
[FF] → [FF] → [FF] → [FF]
  ↑                    ↓
  └────── XOR ─────────┘
```

**کاربردها:**
- تولید اعداد شبه‌تصادفی
- رمزنگاری
- تولید کدهای تصحیح خطا

## ۱۷. پروژه‌های پیشنهادی — ساختار گام‌به‌گام

### سطح ۱: ثبات‌های پایه (Fundamental Registers)

| شماره | پروژه | توضیح | مفاهیم کلیدی |
|-------|-------|-------|--------------|
| ۱ | **ثبات ۴ بیتی ساده** | پیاده‌سازی با ۴ D-FF | D-FF, Clock, Parallel Load |
| ۲ | **ثبات ۸ بیتی با Reset** | با Reset همزمان و ناهمزمان | Synchronous/Asynchronous Reset |
| ۳ | **ثبات ۸ بیتی با Enable** | با قابلیت فعال/غیرفعال‌سازی | Enable Signal, Power Saving |
| ۴ | **ثبات ۱۶ بیتی کامل** | ترکیب Reset + Enable | Full Control Logic |

### سطح ۲: ثبات‌های شیفت (Shift Registers)

| شماره | پروژه | توضیح | مفاهیم کلیدی |

## ۱۸. جمع‌بندی نهایی — تحلیل عمیق و نتیجه‌گیری

ثبات‌ها یکی از اساسی‌ترین بلوک‌های ساختمانی در طراحی دیجیتال هستند. درک عمیق آنها برای هر مهندس الکترونیک یا کامپیوتر ضروری است. بیایید همه چیز را مرور کنیم:

### آنچه باید به خاطر بسپارید

**۱. تعریف اصلی:**
> **ثبات = مجموعه‌ای از فلیپ‌فلاپ‌ها با ساعت مشترک**

**۲. تفاوت اساسی با مدارهای ترکیبی:**
- مدارهای ترکیبی: خروجی فقط به ورودی فعلی بستگی دارد (بدون حافظه)
- ثبات‌ها: خروجی به ورودی فعلی + مقدار ذخیره‌شده بستگی دارد (با حافظه)

**۳. کاربردهای اصلی:**
- ذخیره‌سازی موقت داده در CPU
- بافر برای هماهنگ‌سازی سرعت‌ها
- خطوط تأخیر (Delay Lines)
- تبدیل سریال ↔ موازی
- عنصر حافظه در ماشین‌های حالت (FSM)
- مرزهای مراحل در خطوط لوله (Pipeline)

**۴. کنترل‌های مهم:**
- **Clock:** زمان دقیق به‌روزرسانی
- **Reset:** مقداردهی اولیه (همزمان یا ناهمزمان)
- **Enable:** کنترل به‌روزرسانی

**۵. انواع اصلی:**
- **ساده (PIPO):** ذخیره‌سازی عمومی
- **شیفت (Shift):** جابه‌جایی بیت‌ها
- **جهانی (Universal):** ترکیبی از همه قابلیت‌ها
- **فایل ثبات (Register File):** مجموعه‌ای از ثبات‌ها

**۶. در VHDL:**
```vhdl
process(clk)
begin
    if rising_edge(clk) then
        if reset = '1' then
            q <= (others => '0');
        elsif enable = '1' then
            q <= d;
        end if;
    end if;
end process;
```

### پیام نهایی و ارتباط با مباحث بعدی

ثبات‌ها نقطه عطفی در یادگیری طراحی دیجیتال هستند. آنها اولین گام از **«مدارهای منطقی»** به سوی **«سیستم‌های دیجیتال»** هستند.

```
Flip-Flop (۱ بیت)
     ↓
Register (n بیت)
     ↓
Shift Register
     ↓
Register File
     ↓
Counter
     ↓
Timer
     ↓
FSM (ماشین حالت)
     ↓
Control Unit
     ↓
CPU
```

ثبات‌ها پایه و اساس مباحث پیشرفته‌تر هستند:

```
ثبات → شمارنده → تایمر → ساعت دیجیتال
ثبات → ماشین حالت → کنترلر → CPU
ثبات → حافظه کش → سیستم حافظه
ثبات → خط لوله → پردازنده فوق‌پیمانه
ثبات → فایل ثبات → معماری RISC
```

با تسلط بر ثبات‌ها، شما گام بزرگی در جهت درک سیستم‌های دیجیتال پیچیده برداشته‌اید. در مباحث بعدی، خواهید دید که چگونه این بلوک‌های ساده در کنار هم سیستم‌های قدرتمندی مانند پردازنده‌ها را می‌سازند.

> **مهم‌ترین اصل:**
> در VHDL ما برنامه نمی‌نویسیم؛ ما ساختار و رفتار سخت‌افزار را توصیف می‌کنیم. ثبات‌ها بهترین مثال برای درک این تفاوت اساسی هستند.
