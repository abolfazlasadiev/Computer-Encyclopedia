# جبر بولی (Boolean Algebra) — نسخه کامل و جامع

## مقدمه: چرا جبر بولی؟

تصور کنید می‌خواهید یک مدار دیجیتال طراحی کنید که چراغ یک اتاق را بر اساس چند شرط کنترل کند. مثلاً چراغ باید روشن شود اگر:
- سنسور حرکت تشخیص حرکت دهد **و**
- ساعت بین ۲۰ تا ۶ صبح باشد **و**
- حالت امنیتی سیستم غیرفعال باشد

چگونه این شرایط را به زبان سخت‌افزار توصیف می‌کنیم؟ چگونه می‌توانیم مطمئن شویم مدارمان درست کار می‌کند؟ چگونه می‌توانیم مدار را ساده‌تر و کم‌هزینه‌تر کنیم؟

پاسخ همه این سوالات **جبر بولی (Boolean Algebra)** است. جبر بولی زبان ریاضی سیستم‌های دیجیتال است. همانطور که جبر معمولی برای حل معادلات ریاضی استفاده می‌شود، جبر بولی برای طراحی و تحلیل مدارهای منطقی به کار می‌رود.

---

## ۱. جبر بولی چیست؟ تعریف جامع

**جبر بولی (Boolean Algebra)** یک ساختار جبری است که با مقادیر **درست/غلط** (True/False) یا **۰/۱** سروکار دارد. این جبر توسط **جرج بول (George Boole)** در قرن نوزدهم معرفی شد و بعدها در طراحی مدارهای دیجیتال به کار گرفته شد.

### ویژگی‌های اصلی جبر بولی

۱. **مقادیر گسسته (Discrete):** فقط دو مقدار دارد (۰ و ۱)
۲. **عملگرهای اصلی:** AND (·)، OR (+)، NOT (¬)
۳. **قوانین خاص:** قوانینی که رفتار این عملگرها را تعیین می‌کنند
۴. **کاربرد در سخت‌افزار:** هر عبارت بولی را می‌توان به یک مدار دیجیتال تبدیل کرد

### تفاوت جبر بولی با جبر معمولی

| ویژگی | جبر معمولی | جبر بولی |
|-------|-----------|----------|
| مقادیر | اعداد حقیقی (بی‌نهایت) | فقط ۰ و ۱ |
| عملگر `+` | جمع معمولی | OR (یا) |
| عملگر `·` | ضرب معمولی | AND (و) |
| عملگر `-` | تفریق | وجود ندارد |
| عملگر `/` | تقسیم | وجود ندارد |
| قانون توزیع | `A(B+C) = AB+AC` | دو قانون توزیع دارد |
| معکوس | `A + (-A) = 0` | `A + ¬A = 1` |

## ۲. متغیرها و مقادیر بولی

### متغیر بولی (Boolean Variable)

یک متغیر بولی فقط می‌تواند یکی از دو مقدار زیر را داشته باشد:
- `0` (False، Low، خاموش)
- `1` (True، High، روشن)

**مثال‌ها:**
```
A = 1 (سنسور حرکت فعال است)
B = 0 (ساعت شب نیست)
C = 1 (سیستم امنیتی غیرفعال است)
```

### ثابت‌های بولی

دو ثابت اصلی داریم:
- `0` = False
- `1` = True

### تابع بولی (Boolean Function)

یک تابع بولی یک یا چند متغیر بولی را می‌گیرد و یک مقدار بولی برمی‌گرداند.

**مثال:**
```
Y = A AND B
```
اگر `A=1` و `B=1`، آنگاه `Y=1`. در غیر این صورت `Y=0`.

---

## ۳. عملگرهای اصلی جبر بولی

### ۳.۱. عملگر AND (·)

**عملگر AND** خروجی `1` می‌دهد اگر و فقط اگر **همه ورودی‌ها `1` باشند**.

| A | B | Y = A · B |
|---|---|-----------|
| ۰ | ۰ | ۰ |
| ۰ | ۱ | ۰ |
| ۱ | ۰ | ۰ |
| ۱ | ۱ | ۱ |

**معادله:** `Y = A · B` یا `Y = AB`

**مفهوم:** «همه شرایط باید برقرار باشند»

**در VHDL:** `y <= a and b;`

---

### ۳.۲. عملگر OR (+)

**عملگر OR** خروجی `1` می‌دهد اگر **حداقل یکی از ورودی‌ها `1` باشد**.

| A | B | Y = A + B |
|---|---|-----------|
| ۰ | ۰ | ۰ |
| ۰ | ۱ | ۱ |
| ۱ | ۰ | ۱ |
| ۱ | ۱ | ۱ |

**معادله:** `Y = A + B`

**مفهوم:** «حداقل یکی از شرایط کافی است»

**در VHDL:** `y <= a or b;`

---

### ۳.۳. عملگر NOT (¬)

**عملگر NOT** مقدار ورودی را **معکوس** می‌کند.

| A | Y = ¬A |
|---|--------|
| ۰ | ۱ |
| ۱ | ۰ |

**معادله:** `Y = ¬A` یا `Y = A̅` یا `Y = A'`

**مفهوم:** «برعکس شرط»

**در VHDL:** `y <= not a;`

---

## ۴. عملگرهای مشتق‌شده

### ۴.۱. NAND = ¬(AND)

`Y = ¬(A · B)`

| A | B | Y |
|---|---|---|
| ۰ | ۰ | ۱ |
| ۰ | ۱ | ۱ |
| ۱ | ۰ | ۱ |
| ۱ | ۱ | ۰ |

**در VHDL:** `y <= not (a and b);`

---

### ۴.۲. NOR = ¬(OR)

`Y = ¬(A + B)`

| A | B | Y |
|---|---|---|
| ۰ | ۰ | ۱ |
| ۰ | ۱ | ۰ |
| ۱ | ۰ | ۰ |
| ۱ | ۱ | ۰ |

**در VHDL:** `y <= not (a or b);`

---

### ۴.۳. XOR = OR انحصاری

`Y = A ⊕ B = (A · ¬B) + (¬A · B)`

| A | B | Y |
|---|---|---|
| ۰ | ۰ | ۰ |
| ۰ | ۱ | ۱ |
| ۱ | ۰ | ۱ |
| ۱ | ۱ | ۰ |

**در VHDL:** `y <= a xor b;`

---

### ۴.۴. XNOR = ¬(XOR)

`Y = ¬(A ⊕ B) = (A · B) + (¬A · ¬B)`

| A | B | Y |
|---|---|---|
| ۰ | ۰ | ۱ |
| ۰ | ۱ | ۰ |
| ۱ | ۰ | ۰ |
| ۱ | ۱ | ۱ |

**در VHDL:** `y <= a xnor b;`

---

## ۵. قوانین پایه جبر بولی

### ۵.۱. قوانین تک‌متغیره

| قانون | فرمول AND | فرمول OR | توضیح |
|-------|-----------|----------|--------|
| **Identity** (هم‌نهشتی) | `A · 1 = A` | `A + 0 = A` | مقدار با خودش برابر است |
| **Null** (صفر/یک) | `A · 0 = 0` | `A + 1 = 1` | صفر همه‌چیز را صفر می‌کند، یک همه‌چیز را یک |
| **Idempotent** (تکرار) | `A · A = A` | `A + A = A` | تکرار مقدار را تغییر نمی‌دهد |
| **Complement** (مکمل) | `A · ¬A = 0` | `A + ¬A = 1` | یک مقدار و مکملش |
| **Double Negation** (دومکمل) | `¬(¬A) = A` | `¬(¬A) = A` | دو بار نقیض، خود مقدار |

### ۵.۲. قوانین دو یا چند متغیره

| قانون | فرمول | توضیح |
|-------|-------|--------|
| **Commutative** (جابه‌جایی) | `A·B = B·A` و `A+B = B+A` | ترتیب مهم نیست |
| **Associative** (شرکت‌پذیری) | `(A·B)·C = A·(B·C)` و `(A+B)+C = A+(B+C)` | نحوه گروه‌بندی مهم نیست |
| **Distributive** (توزیع‌پذیری) | `A·(B+C) = A·B + A·C` و `A + B·C = (A+B)·(A+C)` | توزیع AND روی OR و برعکس |
| **Absorption** (جذب) | `A + A·B = A` و `A·(A+B) = A` | جذب عبارت اضافی |
| **De Morgan** (دمورگان) | `¬(A·B) = ¬A + ¬B` و `¬(A+B) = ¬A · ¬B` | تبدیل AND به OR با نقیض |

## ۶. قانون توزیع‌پذیری (Distributive Law) — بررسی عمیق

قانون توزیع‌پذیری در جبر بولی **دو شکل** دارد، برخلاف جبر معمولی که فقط یک شکل دارد.

### شکل اول (مشابه جبر معمولی)

```
A · (B + C) = (A · B) + (A · C)
```

**مثال عددی:**
```
A=1, B=0, C=1
سمت چپ: 1 · (0+1) = 1 · 1 = 1
سمت راست: (1·0) + (1·1) = 0 + 1 = 1 ✓
```

### شکل دوم (منحصر به جبر بولی)

```
A + (B · C) = (A + B) · (A + C)
```

**مثال عددی:**
```
A=1, B=0, C=1
سمت چپ: 1 + (0·1) = 1 + 0 = 1
سمت راست: (1+0) · (1+1) = 1 · 1 = 1 ✓
```

**چرا این مهم است؟** این قانون به ما اجازه می‌دهد عبارات بولی را به دو شکل SOP (Sum of Products) و POS (Product of Sums) تبدیل کنیم.

---

## ۷. قانون جذب (Absorption Law) — بررسی عمیق

قانون جذب یکی از کاربردی‌ترین قوانین برای ساده‌سازی مدارهاست.

### شکل اول

```
A + A·B = A
```

**اثبات:**
```
A + A·B = A·1 + A·B        (قانون Identity)
        = A·(1 + B)        (قانون Distributive)
        = A·1              (قانون Null: 1+B=1)
        = A                (قانون Identity)
```

### شکل دوم

```
A · (A + B) = A
```

**اثبات:**
```
A·(A+B) = A·A + A·B    (قانون Distributive)
        = A + A·B      (قانون Idempotent: A·A = A)
        = A            (قانون Absorption شکل اول)
```

### مثال عملی

عبارت زیر را ساده کنید:
```
Y = A + A·B + A·C
```

**حل:**
```
Y = A + A·(B + C)    (فاکتور‌گیری)
  = A                (قانون Absorption)
```

یعنی مدار به یک سیم ساده تبدیل می‌شود!

---

## ۸. قوانین دمورگان (De Morgan's Laws) — بررسی عمیق

قوانین دمورگان از مهم‌ترین قوانین جبر بولی هستند. این قوانین رابطه بین AND و OR را با نقیض نشان می‌دهند.

### قانون اول

```
¬(A · B) = ¬A + ¬B
```

**به زبان ساده:** نقیض AND برابر با OR نقیض‌هاست.

**مثال:** «نه (A و B هر دو ۱ هستند)» یعنی «یا A ۰ است یا B ۰ است»

### قانون دوم

```
¬(A + B) = ¬A · ¬B
```

**به زبان ساده:** نقیض OR برابر با AND نقیض‌هاست.

**مثال:** «نه (A یا B ۱ است)» یعنی «هم A ۰ است و هم B ۰ است»

### کاربرد عملی

**تبدیل NAND به NOR و برعکس:**

یک گیت NAND را می‌توان به صورت OR با ورودی‌های نقیض‌شده پیاده‌سازی کرد:

```
NAND(A,B) = ¬(A·B) = ¬A + ¬B
```

و یک گیت NOR را می‌توان به صورت AND با ورودی‌های نقیض‌شده پیاده‌سازی کرد:

```
NOR(A,B) = ¬(A+B) = ¬A · ¬B
```

## ۹. اشکال استاندارد عبارات بولی

### ۹.۱. Sum of Products (SOP)

**SOP** عبارتی است که در آن چند **Product Term** (AND) با هم OR شده‌اند.

```
Y = A·B + A·¬C + B·C
```

**ساختار سخت‌افزاری:**
```
A ──┐
    AND ──┐
B ──┘     │
          │
A ──┐     │
    AND ──┼── OR ──→ Y
¬C ─┘     │
          │
B ──┐     │
    AND ──┘
C ──┘
```

**مزیت:** پیاده‌سازی با گیت‌های AND و OR ساده است.

**معایب:** ممکن است به گیت‌های بیشتری نیاز داشته باشد.

---

### ۹.۲. Product of Sums (POS)

**POS** عبارتی است که در آن چند **Sum Term** (OR) با هم AND شده‌اند.

```
Y = (A+B) · (A+¬C) · (B+C)
```

**ساختار سخت‌افزاری:**
```
A ──┐
    OR ──┐
B ──┘     │
          │
A ──┐     │
    OR ──┼── AND ──→ Y
¬C ─┘     │
          │
B ──┐     │
    OR ──┘
C ──┘
```

**مزیت:** گاهی به گیت‌های کمتری نیاز دارد.

**معایب:** پیاده‌سازی با گیت‌های NOR و OR ساده‌تر است.

---

### ۹.۳. مقایسه SOP و POS

| ویژگی | SOP | POS |
|-------|-----|-----|
| ساختار | AND → OR | OR → AND |
| فرم | `Σ(Product Terms)` | `Π(Sum Terms)` |
| گیت‌های اصلی | AND, OR | OR, AND |
| کاربرد | طراحی با NAND | طراحی با NOR |
| مثال | `AB + A¬C + BC` | `(A+B)(A+¬C)(B+C)` |

---

## ۱۰. Minterm و Maxterm

### ۱۰.۱. Minterm

برای هر ترکیب ورودی که خروجی `1` است، یک **Minterm** تعریف می‌شود.

یک Minterm محصولی (AND) از همه متغیرهاست که:
- اگر متغیر = ۱ → خود متغیر
- اگر متغیر = ۰ → نقیض متغیر

**مثال (۳ متغیر A, B, C):**

| A | B | C | Minterm |
|---|---|---|---------|
| ۰ | ۰ | ۰ | `¬A·¬B·¬C` (m₀) |
| ۰ | ۰ | ۱ | `¬A·¬B·C` (m₁) |
| ۰ | ۱ | ۰ | `¬A·B·¬C` (m₂) |
| ۰ | ۱ | ۱ | `¬A·B·C` (m₃) |
| ۱ | ۰ | ۰ | `A·¬B·¬C` (m₄) |
| ۱ | ۰ | ۱ | `A·¬B·C` (m₅) |
| ۱ | ۱ | ۰ | `A·B·¬C` (m₆) |
| ۱ | ۱ | ۱ | `A·B·C` (m₇) |

**نکته:** یک Minterm فقط برای **یک** ترکیب خاص ورودی، مقدار `1` می‌دهد و برای بقیه ترکیب‌ها `0` است.

---

### ۱۰.۲. Maxterm

برای هر ترکیب ورودی که خروجی `0` است، یک **Maxterm** تعریف می‌شود.

یک Maxterm مجموعی (OR) از همه متغیرهاست که:
- اگر متغیر = ۰ → خود متغیر
- اگر متغیر = ۱ → نقیض متغیر

**مثال (۳ متغیر A, B, C):**

| A | B | C | Maxterm |
|---|---|---|---------|
| ۰ | ۰ | ۰ | `A+B+C` (M₀) |
| ۰ | ۰ | ۱ | `A+B+¬C` (M₁) |
| ۰ | ۱ | ۰ | `A+¬B+C` (M₂) |
| ۰ | ۱ | ۱ | `A+¬B+¬C` (M₃) |
| ۱ | ۰ | ۰ | `¬A+B+C` (M₄) |
| ۱ | ۰ | ۱ | `¬A+B+¬C` (M₅) |
| ۱ | ۱ | ۰ | `¬A+¬B+C` (M₆) |
| ۱ | ۱ | ۱ | `¬A+¬B+¬C` (M₇) |

**نکته:** یک Maxterm فقط برای **یک** ترکیب خاص ورودی، مقدار `0` می‌دهد و برای بقیه ترکیب‌ها `1` است.

---

### ۱۰.۳. ارتباط Minterm و Maxterm

هر Minterm و Maxterm با اندیس یکسان، مکمل یکدیگرند:

```
mᵢ = ¬Mᵢ
Mᵢ = ¬mᵢ
```

**مثال:** m₃ = ¬A·B·C و M₃ = A+¬B+¬C

بررسی: `¬m₃ = ¬(¬A·B·C) = A + ¬B + ¬C = M₃` ✓

## ۱۱. نمایش استاندارد (Canonical Forms)

### ۱۱.۱. Canonical SOP (Sum of Minterms)

یک عبارت SOP که از جمع (OR) همه Mintermهایی که خروجی `1` هستند تشکیل شده باشد.

**مثال:** برای جدول درستی زیر:

| A | B | C | Y |
|---|---|---|:---:|
| ۰ | ۰ | ۰ | ۰ |
| ۰ | ۰ | ۱ | ۱ |
| ۰ | ۱ | ۰ | ۰ |
| ۰ | ۱ | ۱ | ۱ |
| ۱ | ۰ | ۰ | ۱ |
| ۱ | ۰ | ۱ | ۰ |
| ۱ | ۱ | ۰ | ۰ |
| ۱ | ۱ | ۱ | ۱ |

خروجی برای m₁, m₃, m₄, m₇ برابر `1` است.

پس:
```
Y = m₁ + m₃ + m₄ + m₇
  = ¬A·¬B·C + ¬A·B·C + A·¬B·¬C + A·B·C
```

**نشان‌گذاری فشرده:**
```
Y = Σ(1, 3, 4, 7)
```

---

### ۱۱.۲. Canonical POS (Product of Maxterms)

یک عبارت POS که از ضرب (AND) همه Maxtermهایی که خروجی `0` هستند تشکیل شده باشد.

برای مثال بالا، خروجی برای M₀, M₂, M₅, M₆ برابر `0` است.

پس:
```
Y = M₀ · M₂ · M₅ · M₆
  = (A+B+C) · (A+¬B+C) · (¬A+B+¬C) · (¬A+¬B+C)
```

**نشان‌گذاری فشرده:**
```
Y = Π(0, 2, 5, 6)
```

## ۱۲. ساده‌سازی با جبر بولی — مثال‌های عملی

### مثال ۱: ساده‌سازی با Absorption

```
Y = A·B + A·¬B
```

**حل:**
```
Y = A·(B + ¬B)    (Distributive)
  = A·1           (Complement)
  = A             (Identity)
```

**نتیجه:** `Y = A`

---

### مثال ۲: ساده‌سازی با قوانین متعدد

```
Y = A·B + A·C + B·C
```

**حل:**
```
Y = A·B + A·C + B·C
  = A·(B+C) + B·C    (Distributive)
  = A·B + A·C + B·C  (همان عبارت اولیه)
```

این عبارت را نمی‌توان با جبر بولی ساده‌تر کرد. اما با K-Map می‌توان:

```
Y = A·B + C·(A+B)
```

---

### مثال ۳: کاربرد قوانین دمورگان

عبارت زیر را ساده کنید:
```
Y = ¬(A·B) + ¬(A·C)
```

**حل:**
```
Y = ¬(A·B) + ¬(A·C)
  = (¬A + ¬B) + (¬A + ¬C)    (De Morgan)
  = ¬A + ¬A + ¬B + ¬C         (Associative)
  = ¬A + ¬B + ¬C              (Idempotent)
```

**نتیجه:** `Y = ¬(A·B·C)` (با De Morgan)

---

### مثال ۴: ساده‌سازی یک عبارت پیچیده

```
Y = A·B·C + A·¬B·C + A·B·¬C
```

**حل:**
```
Y = A·C·(B + ¬B) + A·B·¬C    (فاکتور‌گیری از دو جمله اول)
  = A·C·1 + A·B·¬C           (Complement)
  = A·C + A·B·¬C             (Identity)
  = A·(C + B·¬C)             (Distributive)
  = A·(C + B)                (Absorption: C + B·¬C = C + B)
```

**نتیجه:** `Y = A·(B + C)`

---

### مثال ۵: اثبات یک رابطه

ثابت کنید:
```
A + ¬A·B = A + B
```

**حل:**
```
A + ¬A·B = (A + ¬A)·(A + B)    (Distributive شکل دوم)
         = 1·(A + B)            (Complement)
         = A + B                (Identity)
```

## ۱۳. نقشه کارنو (Karnaugh Map) — مقدمه

جبر بولی برای ساده‌سازی عبارات با ۲ یا ۳ متغیر خوب است، اما برای ۴ متغیر یا بیشتر، **نقشه کارنو (K-Map)** روش بصری و سیستماتیک‌تری ارائه می‌دهد.

### ۱۳.۱. K-Map ۲ متغیره

| | B=0 | B=1 |
|---|---|---|
| **A=0** | m₀ | m₁ |
| **A=1** | m₂ | m₃ |

**گروه‌بندی:** می‌توان گروه‌های ۱، ۲ و ۴ تایی تشکیل داد.

---

### ۱۳.۲. K-Map ۳ متغیره

| | BC=00 | BC=01 | BC=11 | BC=10 |
|---|---|---|---|---|
| **A=0** | m₀ | m₁ | m₃ | m₂ |
| **A=1** | m₄ | m₅ | m₇ | m₆ |

**نکته:** ترتیب ستون‌ها به صورت ۰۰, ۰۱, ۱۱, ۱۰ است (کد گری).

---

### ۱۳.۳. K-Map ۴ متغیره

| | CD=00 | CD=01 | CD=11 | CD=10 |
|---|---|---|---|---|
| **AB=00** | m₀ | m₁ | m₃ | m₂ |
| **AB=01** | m₄ | m₅ | m₇ | m₆ |
| **AB=11** | m₁₂ | m₁₃ | m₁₅ | m₁₄ |
| **AB=10** | m₈ | m₉ | m₁₁ | m₁₀ |

---

### مثال K-Map

جدول درستی زیر را با K-Map ساده کنید:

| A | B | C | Y |
|---|---|---|---|
| ۰ | ۰ | ۰ | ۱ |
| ۰ | ۰ | ۱ | ۰ |
| ۰ | ۱ | ۰ | ۱ |
| ۰ | ۱ | ۱ | ۱ |
| ۱ | ۰ | ۰ | ۰ |
| ۱ | ۰ | ۱ | ۰ |
| ۱ | ۱ | ۰ | ۱ |
| ۱ | ۱ | ۱ | ۱ |

**K-Map:**

| | BC=00 | BC=01 | BC=11 | BC=10 |
|---|---|---|---|---|
| **A=0** | 1 | 0 | 1 | 1 |
| **A=1** | 0 | 0 | 1 | 1 |

**گروه‌بندی:**
- گروه ۱: m₀ (A=0, B=0, C=0) → `¬A·¬B·¬C`
- گروه ۲: m₂, m₃ (A=0, B=1) → `¬A·B`
- گروه ۳: m₆, m₇ (A=1, B=1) → `A·B`

**نتیجه:** `Y = ¬A·¬B·¬C + ¬A·B + A·B`

## ۱۴. جبر بولی در VHDL

### ۱۴.۱. عملگرهای منطقی در VHDL

| عملگر | توضیح | مثال |
|-------|-------|------|
| `and` | AND | `y <= a and b;` |
| `or` | OR | `y <= a or b;` |
| `not` | NOT | `y <= not a;` |
| `nand` | NAND | `y <= a nand b;` |
| `nor` | NOR | `y <= a nor b;` |
| `xor` | XOR | `y <= a xor b;` |
| `xnor` | XNOR | `y <= a xnor b;` |

### ۱۴.۲. اولویت عملگرها (Precedence)

در VHDL، اولویت عملگرها به این صورت است (از بالا به پایین):
1. `not`
2. `and`, `or`, `nand`, `nor`, `xor`, `xnor` (همه یکسان)

**توصیه:** از پرانتز استفاده کنید تا ابهام برطرف شود.

```vhdl
-- خوب
y <= (a and b) or (c and d);

-- بد (مبهم)
y <= a and b or c and d;
```

### ۱۴.۳. عملگرهای منطقی روی Vectorها

عملگرهای منطقی روی `std_logic_vector` به صورت **بیتی (Bitwise)** عمل می‌کنند:

```vhdl
signal a : std_logic_vector(3 downto 0) := "1010";
signal b : std_logic_vector(3 downto 0) := "1100";
signal y : std_logic_vector(3 downto 0);

y <= a and b;  -- نتیجه: "1000"
```

### ۱۴.۴. مثال کامل

**عبارت بولی:** `Y = A·B + ¬C`

**VHDL:**
```vhdl
library ieee;
use ieee.std_logic_1164.all;

entity boolean_example is
    port (
        a, b, c : in  std_logic;
        y       : out std_logic
    );
end entity;

architecture rtl of boolean_example is
begin
    y <= (a and b) or (not c);
end architecture;
```

## ۱۵. اشتباهات رایج دانشجویان

### اشتباه ۱: اشتباه گرفتن `+` بولی با جمع معمولی

```
❌ 1 + 1 = 2  (در جبر معمولی)
✅ 1 + 1 = 1  (در جبر بولی، چون OR است)
```

### اشتباه ۲: استفاده نادرست از قوانین دمورگان

```
❌ ¬(A·B) = ¬A·¬B  (غلط)
✅ ¬(A·B) = ¬A + ¬B  (درست)
```

### اشتباه ۳: فراموش کردن شکل دوم قانون توزیع‌پذیری

```
❌ فقط A·(B+C) = AB+AC را بلد بودن
✅ A + B·C = (A+B)·(A+C) را هم دانستن
```

### اشتباه ۴: قاطی کردن SOP و POS

```
❌ فکر کردن SOP = Product of Sums
✅ SOP = Sum of Products (AND → OR)
✅ POS = Product of Sums (OR → AND)
```

### اشتباه ۵: فراموش کردن جذب (Absorption)

```
❌ A + A·B = A·(1+B) و در اینجا گیر کردن
✅ A + A·B = A  (نتیجه نهایی)
```

## ۱۶. تمرین‌های جامع

### تمرین ۱: ساده‌سازی با جبر بولی

عبارات زیر را ساده کنید:

**الف)**
```
Y = A·B + A·¬B
```
**پاسخ:** `Y = A`

---

**ب)**
```
Y = A·B + A·C + A·B·C
```
**پاسخ:**
```
Y = A·B + A·C + A·B·C
  = A·(B + C + B·C)
  = A·(B + C)      (زیرا B + B·C = B)
  = A·B + A·C
```

---

**ج)**
```
Y = (A+B)·(A+¬B)
```
**پاسخ:**
```
Y = (A+B)·(A+¬B)
  = A·A + A·¬B + B·A + B·¬B
  = A + A·¬B + A·B + 0
  = A·(1 + ¬B + B)
  = A·1
  = A
```

---

**د)**
```
Y = ¬(A·B) + ¬(A·C) + ¬(B·C)
```
**پاسخ:**
```
Y = ¬(A·B) + ¬(A·C) + ¬(B·C)
  = (¬A + ¬B) + (¬A + ¬C) + (¬B + ¬C)
  = ¬A + ¬A + ¬B + ¬B + ¬C + ¬C
  = ¬A + ¬B + ¬C
```

---

### تمرین ۲: تبدیل Truth Table به Expression

جدول درستی زیر را به SOP و POS تبدیل کنید:

| A | B | C | Y |
|---|---|---|---|
| ۰ | ۰ | ۰ | ۰ |
| ۰ | ۰ | ۱ | ۱ |
| ۰ | ۱ | ۰ | ۰ |
| ۰ | ۱ | ۱ | ۰ |
| ۱ | ۰ | ۰ | ۱ |
| ۱ | ۰ | ۱ | ۰ |
| ۱ | ۱ | ۰ | ۱ |
| ۱ | ۱ | ۱ | ۱ |

**حل:**

خروجی `1` برای: m₁, m₄, m₆, m₇

**SOP:**
```
Y = m₁ + m₄ + m₆ + m₇
  = ¬A·¬B·C + A·¬B·¬C + A·B·¬C + A·B·C
```

**ساده‌سازی:**
```
Y = ¬A·¬B·C + A·¬B·¬C + A·B·¬C + A·B·C
  = ¬A·¬B·C + A·¬C·(¬B + B) + A·B·C
  = ¬A·¬B·C + A·¬C + A·B·C
  = C·(¬A·¬B + A·B) + A·¬C
  = C·(A·B + ¬A·¬B) + A·¬C
  = C·XNOR(A,B) + A·¬C
```

**POS:**
خروجی `0` برای: M₀, M₂, M₃, M₅

```
Y = M₀ · M₂ · M₃ · M₅
  = (A+B+C) · (A+¬B+C) · (A+¬B+¬C) · (¬A+B+¬C)
```

---

### تمرین ۳: طراحی با جبر بولی

یک مدار طراحی کنید که خروجی آن `1` باشد اگر و فقط اگر تعداد ۱های ورودی (A, B, C) فرد باشد.

**حل:**

این مدار یک **Parity Generator** است.

**جدول درستی:**

| A | B | C | تعداد ۱ها | Y |
|---|---|---|---|---|
| ۰ | ۰ | ۰ | ۰ | ۰ |
| ۰ | ۰ | ۱ | ۱ | ۱ |
| ۰ | ۱ | ۰ | ۱ | ۱ |
| ۰ | ۱ | ۱ | ۲ | ۰ |
| ۱ | ۰ | ۰ | ۱ | ۱ |
| ۱ | ۰ | ۱ | ۲ | ۰ |
| ۱ | ۱ | ۰ | ۲ | ۰ |
| ۱ | ۱ | ۱ | ۳ | ۱ |

**SOP:**
```
Y = m₁ + m₂ + m₄ + m₇
  = ¬A·¬B·C + ¬A·B·¬C + A·¬B·¬C + A·B·C
```

**ساده‌سازی با جبر بولی:**
```
Y = A ⊕ B ⊕ C  (XOR سه‌تایی)
```

**VHDL:**
```vhdl
y <= a xor b xor c;
```

---

### تمرین ۴: اثبات با جبر بولی

ثابت کنید:
```
A·B + A·¬B = A
```

**حل:**
```
A·B + A·¬B = A·(B + ¬B)    (Distributive)
            = A·1           (Complement)
            = A             (Identity)
```

## ۱۹. جمع‌بندی نهایی

### آنچه باید به خاطر بسپارید

۱. **جبر بولی** = زبان ریاضی سیستم‌های دیجیتال
۲. **سه عملگر اصلی:** AND (·), OR (+), NOT (¬)
۳. **قوانین کلیدی:** Identity, Null, Idempotent, Complement, Double Negation
۴. **قوانین مهم:** Commutative, Associative, Distributive (دو شکل), Absorption
۵. **قوانین دمورگان:** `¬(A·B) = ¬A + ¬B` و `¬(A+B) = ¬A·¬B`
۶. **SOP** = Sum of Products (AND → OR)
۷. **POS** = Product of Sums (OR → AND)
۸. **Minterm** = محصول همه متغیرها (برای خروجی ۱)
۹. **Maxterm** = مجموع همه متغیرها (برای خروجی ۰)
۱۰. **Karnaugh Map** = روش بصری ساده‌سازی برای ۳ تا ۶ متغیر

### جبر بولی در VHDL

```
عبارت بولی          ←→  کد VHDL
A · B               ←→  a and b
A + B               ←→  a or b
¬A                  ←→  not a
¬(A·B)              ←→  not (a and b)
A ⊕ B               ←→  a xor b
¬(A⊕B)              ←→  a xnor b
A·B + A·¬B          ←→  (a and b) or (a and not b)
```

### پیام نهایی

جبر بولی فقط یک درس ریاضی نیست؛ **پایه و اساس تمام طراحی‌های دیجیتال است**. هر مدار پیچیده‌ای که در آینده طراحی خواهید کرد، در نهایت به یک عبارت بولی ساده تبدیل می‌شود. درک عمیق جبر بولی به شما کمک می‌کند:
- مدارهای کارآمدتر طراحی کنید
- مدارهای موجود را تحلیل کنید
- کد VHDL بهینه‌تری بنویسید
- مشکلات منطقی را سریعتر پیدا و حل کنید

با تسلط بر جبر بولی، شما گام بزرگی در مسیر تبدیل شدن به یک طراح دیجیتال حرفه‌ای برداشته‌اید.
