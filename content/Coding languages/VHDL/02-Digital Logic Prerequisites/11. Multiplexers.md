# Multiplexers — مالتی‌پلکسرها (نسخه کامل و جامع با تحلیل عمیق)

## مقدمه: انتخاب، قلب سیستم‌های دیجیتال

در دنیای سیستم‌های دیجیتال، یکی از رایج‌ترین کارها **انتخاب** است:

- پردازنده باید انتخاب کند که از کدام ثبات داده بخواند
- ALU باید انتخاب کند که کدام عملیات را انجام دهد
- سیستم ارتباطی باید انتخاب کند که از کدام کانال داده دریافت کند
- حافظه باید انتخاب کند که کدام آدرس را بخواند

سوال اساسی: **چگونه می‌توانیم بین چندین منبع داده یکی را انتخاب کنیم؟**

پاسخ در **مالتی‌پلکسر (Multiplexer)** نهفته است. MUX یکی از پرکاربردترین و اساسی‌ترین مدارهای ترکیبی است که در هر سیستم دیجیتالی، از کوچک‌ترین مدار گرفته تا پیچیده‌ترین پردازنده، یافت می‌شود.

---

## ۱. مالتی‌پلکسر چیست؟ تعریف جامع و عمیق

**مالتی‌پلکسر (Multiplexer)** که به اختصار **MUX** نامیده می‌شود، یک مدار ترکیبی است که **چندین ورودی داده** را دریافت کرده و بر اساس **سیگنال‌های انتخاب (Select)**، **یکی از آنها** را به **خروجی** منتقل می‌کند.

### تعریف رسمی

> **MUX** مداری با n ورودی داده، m ورودی انتخاب (که ۲ᵐ = n)، و یک خروجی است که مقدار یکی از ورودی‌ها را بر اساس ترکیب بیت‌های انتخاب، به خروجی می‌فرستد.

### نام‌های دیگر

- **Data Selector** (انتخاب‌گر داده)
- **Data Multiplexer**
- **Selector**

### قیاس با دنیای واقعی

یک MUX مانند **یک سوئیچ چندوظیفه** است:
- چندین ورودی (منابع مختلف) به سوئیچ وصل هستند
- با چرخاندن یک دیال (Select)، یکی از منابع به خروجی متصل می‌شود
- در هر لحظه فقط یک منبع به خروجی وصل است

## ۲. ایده اصلی: 2:1 MUX — ساده‌ترین نوع

### ساختار

```
        ┌─────────────┐
A ─────→│             │
B ─────→│    2:1 MUX  │────→ Y
S ─────→│             │
        └─────────────┘
```

### قانون عملکرد

```
اگر S = 0 → Y = A
اگر S = 1 → Y = B
```

### جدول درستی

| S | Y |
|:---:|:---:|
| 0 | A |
| 1 | B |

یا به شکل کامل‌تر:

| S | A | B | Y |
|:---:|:---:|:---:|:---:|
| 0 | 0 | X | 0 |
| 0 | 1 | X | 1 |
| 1 | X | 0 | 0 |
| 1 | X | 1 | 1 |

( X = اهمیت ندارد )

### معادله بولین

```
Y = (A · ¬S) + (B · S)
```

### تحلیل معادله

- وقتی S=0: `¬S = 1`، بنابراین `A · 1 = A` و `B · 0 = 0` → `Y = A`
- وقتی S=1: `¬S = 0`، بنابراین `A · 0 = 0` و `B · 1 = B` → `Y = B`

---

## ۳. MUX از دیدگاه گیت‌های منطقی

یک 2:1 MUX را می‌توان با گیت‌های ساده ساخت:

```
             ┌─────┐
S ──────────→│ NOT │───→ ¬S
             └─────┘
                │
A ──────────────┼──→ AND ──┐
                │          │
                └──────────┤
                           OR ───→ Y
B ─────────────────→ AND ──┘
                     ↑
                     S
```

**نکته مهم:** MUX یک قطعه جادویی نیست؛ از گیت‌های منطقی ساخته شده است. این درک برای دانشجو بسیار مهم است.

### تعداد گیت‌های مورد نیاز

برای یک 2:1 MUX:
- ۱ گیت NOT
- ۲ گیت AND
- ۱ گیت OR
- **مجموع: ۴ گیت**

---

## ۴. 4:1 MUX — گسترش به چهار ورودی

### ساختار

```
D0 ─────┐
D1 ─────┤
D2 ─────┤──→ 4:1 MUX ───→ Y
D3 ─────┤
S1 ─────┤
S0 ─────┘
```

### جدول درستی

| S1 | S0 | Y |
|:---:|:---:|:---:|
| 0 | 0 | D0 |
| 0 | 1 | D1 |
| 1 | 0 | D2 |
| 1 | 1 | D3 |

### معادله بولین

```
Y = D0·¬S1·¬S0 + D1·¬S1·S0 + D2·S1·¬S0 + D3·S1·S0
```

### تعداد گیت‌های مورد نیاز (تخمینی)

برای یک 4:1 MUX:
- ۴ AND gate (هر کدام با ۳ ورودی)
- ۱ OR gate (با ۴ ورودی)
- گیت‌های NOT برای معکوس‌سازی Selectها

---

## ۵. قانون عمومی MUX

### فرمول اصلی

```
تعداد ورودی‌های داده = ۲^(تعداد خطوط انتخاب)
```

### جدول انواع MUX

| نوع MUX | ورودی‌های داده | خطوط انتخاب | فرمول |
|---------|---------------|-------------|-------|
| 2:1 | 2 | 1 | 2¹ = 2 |
| 4:1 | 4 | 2 | 2² = 4 |
| 8:1 | 8 | 3 | 2³ = 8 |
| 16:1 | 16 | 4 | 2⁴ = 16 |
| 32:1 | 32 | 5 | 2⁵ = 32 |
| 2ⁿ:1 | 2ⁿ | n | 2ⁿ = 2ⁿ |

### رابطه ریاضی

```
n = تعداد خطوط انتخاب
تعداد ورودی‌ها = 2ⁿ
```

## ۶. MUXهای با ورودی Vector (Bus MUX)

### مفهوم

MUX فقط برای سیگنال‌های تک‌بیتی نیست. می‌تواند **باس‌های (Bus)** چندبیتی را نیز انتخاب کند.

### مثال: 2:1 MUX 8-bit

```
         ┌─────────────────┐
A[7:0] ─→│                 │
B[7:0] ─→│    2:1 MUX     │──→ Y[7:0]
S ──────→│    8-bit       │
         └─────────────────┘
```

### تحلیل

یک 8-bit MUX در واقع **۸ عدد MUX 1-bit موازی** است:

```
A0 ──┐
     ├── MUX ──→ Y0
B0 ──┘   ↑
         S
A1 ──┐
     ├── MUX ──→ Y1
B1 ──┘   ↑
         S
... (تکرار برای هر بیت)
```

### VHDL

```vhdl
entity mux2_8bit is
    port (
        a : in  std_logic_vector(7 downto 0);
        b : in  std_logic_vector(7 downto 0);
        s : in  std_logic;
        y : out std_logic_vector(7 downto 0)
    );
end entity;

architecture rtl of mux2_8bit is
begin
    y <= a when s = '0' else b;
end architecture;
```

### کاربردها

- انتخاب بین دو ثبات در CPU
- انتخاب بین دو مسیر داده در ALU
- انتخاب بین دو کانال ارتباطی

## ۷. ساخت MUXهای بزرگتر از MUXهای کوچکتر (Hierarchical Design)

### 4:1 MUX از سه 2:1 MUX

```
D0 ──┐
     ├── MUX ──┐
D1 ──┘  S0     │
               ├── MUX ──→ Y
D2 ──┐  S1     │
     ├── MUX ──┘
D3 ──┘  S0
```

### تحلیل

- ۳ عدد 2:1 MUX
- S0 به MUXهای سطح اول می‌رود
- S1 به MUX سطح دوم می‌رود

### 8:1 MUX از 2:1 MUXها

```
D0 ─┐
    ├─MUX─┐
D1 ─┘     │
          ├─MUX─┐
D2 ─┐     │     │
    ├─MUX─┘     │
D3 ─┘           │
                ├─MUX─┐
D4 ─┐           │     │
    ├─MUX─┐     │     │
D5 ─┘     │     │     │
          ├─MUX─┘     │
D6 ─┐     │           │
    ├─MUX─┘           │
D7 ─┘                 │
                      │
                      ├─MUX → Y
                      │
                 S2 ──┘
```

**مزیت:** استفاده از بلوک‌های کوچک‌تر و قابل استفاده مجدد

## ۸. MUX Tree — ساختار درختی

### مفهوم

برای تعداد زیادی ورودی، MUXها را می‌توان به صورت **درخت** مرتب کرد تا تأخیر کمتر شود.

```
سطح ۱ (ورودی)    سطح ۲          سطح ۳ (خروجی)

D0 ─┐
    ├─MUX─┐
D1 ─┘     │
          ├─MUX─┐
D2 ─┐     │     │
    ├─MUX─┘     │
D3 ─┘           │
                ├─MUX → Y
D4 ─┐           │
    ├─MUX─┐     │
D5 ─┘     │     │
          ├─MUX─┘
D6 ─┐     │
    ├─MUX─┘
D7 ─┘
```

### مزایا

- **تأخیر کمتر:** log₂(N) سطح به جای N سطح
- **ساختار منظم:** قابل گسترش به تعداد دلخواه ورودی
- **قابل فهم:** ساده‌تر از طراحی تخت

## ۹. MUX در VHDL — روش‌های مختلف

### روش ۱: `when ... else` (Concurrent Conditional Assignment)

**مناسب برای:** 2:1 MUX و MUXهای ساده

```vhdl
y <= a when s = '0' else b;
```

**برای MUX 4:1:**
```vhdl
y <= d0 when s = "00" else
     d1 when s = "01" else
     d2 when s = "10" else
     d3;
```

---

### روش ۲: `with ... select` (Selected Assignment)

**مناسب برای:** MUXهای با چندین ورودی

```vhdl
with s select
    y <= d0 when "00",
         d1 when "01",
         d2 when "10",
         d3 when "11";
```

---

### روش ۳: `case` در Process

**مناسب برای:** MUXهای پیچیده‌تر

```vhdl
process(all)
begin
    case s is
        when "00" => y <= d0;
        when "01" => y <= d1;
        when "10" => y <= d2;
        when "11" => y <= d3;
        when others => y <= '0';
    end case;
end process;
```

---

### روش ۴: `if` در Process

**مناسب برای:** MUXهای با شرایط خاص

```vhdl
process(all)
begin
    if s = "00" then
        y <= d0;
    elsif s = "01" then
        y <= d1;
    elsif s = "10" then
        y <= d2;
    else
        y <= d3;
    end if;
end process;
```

---

### روش ۵: Gate-Level (ساختار گیت‌ها)

**مناسب برای:** درک مفهومی و آموزشی

```vhdl
architecture gate_level of mux2 is
    signal not_s, and1, and2 : std_logic;
begin
    not_s <= not s;
    and1 <= a and not_s;
    and2 <= b and s;
    y <= and1 or and2;
end architecture;
```

| روش | خوانایی | مختصر بودن | مناسب برای |

## ۱۱. MUX در ALU — کاربرد کلیدی

### ساختار ALU با MUX

```
A ────┐
B ────┤
      │    ┌──────────────┐
      ├───→│  Arithmetic  │──→ ADD
      │    │  Unit        │──→ SUB
      │    └──────────────┘
      │
      │    ┌──────────────┐
      ├───→│  Logic       │──→ AND
      │    │  Unit        │──→ OR
      │    └──────────────┘
      │
      │    ┌──────────────┐
      └───→│  Comparator  │──→ CMP
           └──────────────┘
                    │
                    ↓
              ┌─────────────┐
              │    MUX      │──→ Result
              │  (4:1)      │
              └─────────────┘
                    ↑
               Operation Select
```

### VHDL برای ALU با MUX

```vhdl
library ieee;
use ieee.std_logic_1164.all;
use ieee.numeric_std.all;

entity alu_with_mux is
    port (
        a, b   : in  unsigned(7 downto 0);
        op     : in  std_logic_vector(1 downto 0);
        result : out unsigned(7 downto 0)
    );
end entity;

architecture rtl of alu_with_mux is
    signal add_res, sub_res, and_res, or_res : unsigned(7 downto 0);
begin
    -- محاسبه نتایج مختلف
    add_res <= a + b;
    sub_res <= a - b;
    and_res <= a and b;
    or_res  <= a or b;
    
    -- انتخاب نتیجه با MUX
    with op select
        result <= add_res when "00",
                  sub_res when "01",
                  and_res when "10",
                  or_res  when "11";
end architecture;
```

## ۱۲. MUX در CPU و Datapath

### نقش MUX در CPU

در یک پردازنده، MUXها در بخش‌های مختلفی استفاده می‌شوند:

**۱. انتخاب منبع داده برای ALU:**
```
ثبات A ──┐
ثبات B ──┤
داده فوری ─┼── MUX ──→ ALU
           │
         Select
```

**۲. انتخاب آدرس حافظه:**
```
PC ──────┐
ثبات آدرس ─┼── MUX ──→ Address Bus
          │
        Select
```

**۳. انتخاب داده برای نوشتن در ثبات:**
```
نتیجه ALU ──┐
داده حافظه ──┼── MUX ──→ Write Data
             │
           Select
```

### Datapath ساده با MUX

```
                    ┌─────────────────┐
                    │  Register File  │
                    └────────┬────────┘
                             │
                ┌────────────┼────────────┐
                │            ▼            │
                │     ┌─────────────┐     │
                │     │    MUX      │     │
                │     │  (منبع ALU) │     │
                │     └──────┬──────┘     │
                │            ▼            │
                │     ┌─────────────┐     │
                │     │    ALU      │     │
                │     └──────┬──────┘     │
                │            ▼            │
                │     ┌─────────────┐     │
                │     │    MUX      │     │
                │     │ (نتیجه)    │     │
                │     └──────┬──────┘     │
                │            ▼            │
                │     ┌─────────────┐     │
                └────→│  Register   │     │
                      │  (نتیجه)    │     │
                      └─────────────┘     │
```

## ۱۳. MUX در مقابل DEMUX — تفاوت اساسی

### Multiplexer (MUX)

**چند ورودی → یک خروجی**
```
D0 ──┐
D1 ──┤
D2 ──┼──→ MUX ──→ Y
D3 ──┘
      ↑
    Select
```

**کاربرد:** انتخاب یکی از چندین منبع

---

### Demultiplexer (DEMUX)

**یک ورودی → چند خروجی**
```
             ┌──→ Y0
             │
D ──→ DEMUX ─┼──→ Y1
             │
             ├──→ Y2
             │
             └──→ Y3
              ↑
            Select
```

**کاربرد:** هدایت یک منبع به یکی از چندین مقصد

### جدول مقایسه

| ویژگی | MUX | DEMUX |
|-------|-----|-------|
| **جهت** | چند به یک | یک به چند |
| **ورودی‌ها** | چندین | یک |
| **خروجی‌ها** | یک | چندین |
| **کاربرد** | انتخاب منبع | هدایت به مقصد |

---

## ۱۴. MUX در مقابل Decoder — تفاوت مفهومی

### Decoder

**ورودی کد → فعال‌سازی یک خروجی**

```
2-bit Input → Decoder → 4 Outputs (یکی فعال)
```

**کاربرد:** فعال‌سازی یک خط خاص (مثل انتخاب حافظه)

### MUX

**چند ورودی داده → انتخاب یک ورودی**

```
4 Inputs → MUX → 1 Output (بر اساس Select)
```

**کاربرد:** انتخاب داده از بین چند منبع

### رابطه MUX و Decoder

یک MUX را می‌توان با یک Decoder و گیت‌های AND ساخت:

```
Decoder (برای Select)
      ↓
خروجی‌های Decoder (هر کدام یک Select را فعال می‌کنند)
      ↓
هر خروجی Decoder یک ورودی داده را به AND gate متصل می‌کند
      ↓
OR gate (ترکیب همه ANDها)
      ↓
خروجی MUX
```

## ۱۵. MUX و Tri-State — روش‌های اشتراک Bus

### Tri-State روش

```
Device 1 ──┐
Device 2 ──┤
Device 3 ──┘
    Tri-State Buffer
```

**مزیت:** اشتراک یک Bus توسط چندین دستگاه
**معایب:** مدیریت Enable/Disable، مسائل Electrical

### MUX روش

```
Device 1 ──┐
Device 2 ──┤
Device 3 ──┘
       MUX
```

**مزیت:** ساده‌تر، بدون مسائل Electrical
**معایب:** ممکن است نیاز به Logic بیشتری داشته باشد

### در FPGA

در FPGAهای مدرن، برای منطق داخلی از **MUX** و Routing داخلی استفاده می‌شود. Tri-State عمدتاً در I/Oها و برای اتصال به Busهای خارجی استفاده می‌شود.

## ۱۶. اشتباهات رایج در VHDL

### اشتباه ۱: Incomplete Assignment (ایجاد Latch ناخواسته)

**نادرست:**
```vhdl
process(all)
begin
    if s = '1' then
        y <= b;
    end if;
end process;
```

**مشکل:** وقتی s=0، y مقدار جدیدی نمی‌گیرد → Latch

**درست:**
```vhdl
process(all)
begin
    if s = '1' then
        y <= b;
    else
        y <= a;
    end if;
end process;
```

### اشتباه ۲: استفاده از `when ... else` بدون حالت پیش‌فرض

**نادرست:**
```vhdl
y <= d0 when s = "00" else
     d1 when s = "01" else
     d2 when s = "10";
-- s = "11" -> undefined
```

**درست:**
```vhdl
y <= d0 when s = "00" else
     d1 when s = "01" else
     d2 when s = "10" else
     d3;  -- حالت پیش‌فرض
```

### اشتباه ۳: فراموش کردن لیست حساسیت در Process

**نادرست:**
```vhdl
process  -- لیست حساسیت خالی
begin
    y <= a when s = '0' else b;
end process;
```

**درست:**
```vhdl
process(all)  -- یا process(a, b, s)
begin
    y <= a when s = '0' else b;
end process;
```

### اشتباه ۴: استفاده از Clock برای MUX

**نادرست:**
```vhdl
process(clk)  -- MUX نباید Clock داشته باشد
begin
    if rising_edge(clk) then
        y <= a when s = '0' else b;
    end if;
end process;
```

**درست:**
```vhdl
process(all)  -- بدون Clock
begin
    y <= a when s = '0' else b;
end process;
```

## ۱۹. تمرین‌های مفهومی و طراحی

### تمرین ۱: طراحی MUX با گیت‌ها

یک 2:1 MUX را با استفاده از گیت‌های NAND طراحی کنید.

**پاسخ:**
```
Y = ¬( ¬(A·¬S) · ¬(B·S) )
```

### تمرین ۲: تحلیل MUX

یک 4:1 MUX با ورودی‌های D0=1, D1=0, D2=1, D3=0 و Select S1S0="10" چه خروجی دارد؟

**پاسخ:** Y = D2 = 1

### تمرین ۳: گسترش MUX

چگونه می‌توان با 4:1 MUX یک 8:1 MUX ساخت؟

**پاسخ:** با دو 4:1 MUX (برای انتخاب بین گروه‌های ۴ تایی) و یک 2:1 MUX (برای انتخاب بین دو گروه)

### تمرین ۴: MUX در VHDL

عبارت VHDL زیر را به یک MUX تبدیل کنید:
```vhdl
y <= a when sel = "00" else
     b when sel = "01" else
     c when sel = "10" else
     d;
```

**پاسخ:** این یک 4:1 MUX با ورودی‌های a, b, c, d و Select sel است.

### تمرین ۵: طراحی سیستم

یک سیستم طراحی کنید که از یک MUX برای انتخاب بین دو منبع داده (A و B) و ارسال آن به یک ALU استفاده کند. ALU می‌تواند ADD یا SUB انجام دهد.

## ۲۱. جمع‌بندی نهایی و تحلیل عمیق

### آنچه باید به خاطر بسپارید

**۱. تعریف اصلی:**
> **MUX = انتخابی از بین چند ورودی بر اساس Select**

**۲. فرمول اصلی:**
```
تعداد ورودی‌ها = ۲^(تعداد Select)
```

**۳. معادله 2:1 MUX:**
```
Y = (A · ¬S) + (B · S)
```

**۴. انواع اصلی:**
- **2:1 MUX:** ساده‌ترین
- **4:1 MUX:** با ۲ بیت Select
- **8:1 MUX:** با ۳ بیت Select
- **Bus MUX:** با ورودی‌های Vector

**۵. کاربردهای اصلی:**
- انتخاب منبع داده در ALU
- انتخاب نتیجه در ALU
- مسیریابی داده در Datapath
- انتخاب در Register File
- انتخاب در CPU

**۶. در VHDL:**
```vhdl
-- ساده‌ترین روش
y <= a when s = '0' else b;

-- روش با case
process(all)
begin
    case s is
        when "00" => y <= d0;
        when "01" => y <= d1;
        when "10" => y <= d2;
        when "11" => y <= d3;
        when others => y <= '0';
    end case;
end process;
```

### پیام نهایی

MUX یکی از **پرکاربردترین** و **اساسی‌ترین** مدارهای ترکیبی است. از یک مدار ساده تا پیچیده‌ترین پردازنده، MUXها در همه جا حضور دارند. درک عمیق MUX به شما کمک می‌کند:

- **طراحی Datapath** را بهتر درک کنید
- **کد VHDL** بهینه‌تری بنویسید
- **مدارهای ترکیبی** را بهتر تحلیل کنید
- **سیستم‌های دیجیتال** بزرگ‌تر را طراحی کنید

گام بعدی، **Decoderها (رمزگشاها)** هستند که با MUX مکمل بوده و مفهوم «انتخاب» را از زاویه دیگری نشان می‌دهند.
